# SketchBRep ロゴセット

元画像の立方体・メガネ・青い押し出し面・矢印・Sketch/BRepの色分けを参照して再構築したロゴです。原画像そのものの自動トレースではありません。面の境界、曲線、余白を整理し、微細なテクスチャはベクターグラデーションに置き換えています。

- 01-editable: 各面・線をID付き要素として分離。文字は Century Gothic Bold。編集時は同フォントを使用してください。フォントファイルは同梱していません。
- 02-outlined: 文字を含めてアウトライン化したフルロゴと、補助線付きの詳細シンボル。フォント不要。
- 03-app-icon: 補助線を省き、輪郭とメガネを太くした正方形アイコン。SVG、1024pxと256pxのPNG。
- 04-png: フルロゴの透過PNG、1024・256・3072px。3072px版が高解像度の本番用です。
- 05-windows: 16/24/32/48/64/128/256pxを含む32bit ICO。各サイズをSVGから個別レンダリング。
- 06-readme: 横長SVG（文字アウトライン）と2480×880pxの透過PNG。
- 07-preview: 白背景の一覧画像。プレビューだけは不透明です。

背景は描画していません。白い天面はロゴの一部です。濃色の輪郭・文字を持つため、白または明るい背景での使用を想定しています。PNGはストレートな透過背景です。SVGのストロークは編集可能なままです。「完全パス化版」は文字アウトライン化・フォント非依存を意味します。

元画像の書体は特定できなかったため、Century Gothic Boldで字形を組み直し、横幅・字間・位置を調整しています。原画との完全一致は保証しません。

SVGのXML構造、画像埋め込み・外部参照なし、文字アウトラインの有無、PNGのアルファと余白、ICOの7サイズを検証済み。詳細はvalidation.json。全ファイルへのリンクはindex.html。


## アプリ用コンパクト版（2026-10-28）

小さなタスクバー表示では、横に伸びる矢印と広い余白によって立方体が小さく見えていました。アプリ専用には既存の立方体・メガネ・青い押し出し面を保ち、矢印を省いたコンパクト版を使用します。元のロゴセットは保持しています。

- `03-app-icon/sketchbrep-app-icon-compact.svg` と256/1024px PNG：小さなアイコン用の構図。透明背景です。
- `05-windows/sketchbrep-compact.ico`：16/20/24/32/40/48/64/96/128/256px。各サイズをSVGから個別に描画。EXEのリソースとQtの起動中アイコンに同じICOを使用します。
- `compact-validation.json`：ICOのサイズ別の描画範囲。各サイズで透明な角を保ち、図柄がキャンバスを十分に使うことを検証しています。
- About画面は、コンパクトな立方体とテーマに対応する文字表示を使用します。元の明るい背景向けワードマークを暗い背景に直接貼る方式は使いません。

開発時に再生成する場合のみ、CairoSVGとPillowを用意し、リポジトリのルートで `python tools/branding/generate_compact_icon.py` を実行します。これらは通常のビルド・アプリ実行には不要です。
