# キーと操作の一覧

## カメラ

| 操作 | キー・マウス |
|---|---|
| ズーム | ホイール |
| 回転（オービット） | ホイールを押してドラッグ |
| 移動（パン） | Shift＋ホイールドラッグ |
| フォーカス | ダブルクリック |
| 標準ビュー | F2 アイソメ / F3 平面 / F4 正面 / F5 右 / F6 背面 / F7 左 |
| 透視・平行投影 | F8 |
| 全体表示 | Shift+Z |
| 平面・立面モード | Alt+1〜5（平面・正面・右・背面・左）、Alt+→ / Alt+← で次の立面、Alt+0 で 3D |
| X 線表示 | Alt+X |

## ツール

| ツール | キー | ツール | キー |
|---|---|---|---|
| 選択 | Space | 線 | L |
| 矩形 | R | 回転矩形 | Shift+R |
| 円 | C | 円弧 | A |
| 多角形 | Shift+C | 曲線 | N |
| プッシュ/プル | P | フォローミー | Shift+F |
| 移動 | M | 回転 | Q |
| 尺度 | S | オフセット | F |
| 回転体 | V | フィレット | Shift+E |
| メジャー | T | 分度器 | Shift+P |
| 寸法 | D | テキスト | Shift+T |
| 断面 | Shift+S | ペイント | B（Alt+クリックで色を拾う） |
| 消しゴム | E | 壁 | W |
| スラブ | Shift+W | 開口 | O |
| 部材 | I | | |

## 作図中

| 操作 | キー |
|---|---|
| 寸法を打つ | 数字を打って Enter（`3000`、`4.5m`、`3000,4500`） |
| 推論の方向をロック | Shift を押したまま |
| 軸にロック／立てて描く | → 赤軸 / ← 緑軸 / ↑ 青軸（水平な面）、↓ で解除 |
| コピー（移動・回転中） | Ctrl |
| 配列・等分割（確定直後） | `x3` で 3 個並べる、`/3` で間を 3 等分 |
| 中止・1 手戻る | Esc |

## 編集

| 操作 | キー |
|---|---|
| 元に戻す / やり直し | Ctrl+Z / Ctrl+Y |
| コピー / 切り取り / 貼り付け | Ctrl+C / Ctrl+X / Ctrl+V（同じ位置に貼り付け: Ctrl+Shift+V） |
| グループ化 / 解除 | Ctrl+G / Ctrl+Shift+G |
| コンポーネントを作成 | Ctrl+K |
| 非表示 / すべて表示 | Ctrl+H / Ctrl+Shift+H |
| ロック | Ctrl+L |
| 選択解除 | Ctrl+T |
