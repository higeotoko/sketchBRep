# 困ったとき・不具合の報告

## 作業を守る仕組み

| 仕組み | 内容 |
|---|---|
| 自動保存 | 未保存の変更があると、既定 5 分ごとに復旧用の別ファイルに保存します（元のファイルは書き換えません） |
| 復旧 | 正しく終了しなかった次の起動で「前回、正しく終了しなかった作業があります」と出ます |
| バックアップ | 上書き保存の前の版を `ファイル名.sbr.bak1`〜`.bak3` として同じフォルダに残します |

設定は「ファイル > 自動保存とバックアップの設定...」です。

## 落ちたときの記録

SketchBRep が突然終了したときは、直前の操作（使ったツール、編集、開いた・保存したファイル名、警告）と、どこで止まったかを、記録ファイルに書きます。次の起動で場所をお知らせします。

- 記録ファイルの場所: 「ヘルプ > 不具合を報告...」の「記録のフォルダを開く」
- 記録は自動では**どこにも送りません**。送るかどうかは、あなたが決めます。
- モデルの形やファイルの中身は記録しません（ファイル名は記録します）。

## 不具合を報告するとき

「ヘルプ > 不具合を報告...」を開くと、バージョンと直前の操作をコピーできます。販売ページの連絡先へ、次を送ってください。

1. 何をしたら、どうなったか（できれば手順）
2. 「報告用の情報をコピー」で写した内容
3. 落ちたときは、記録のフォルダの `crash-...txt`
4. 可能なら、そのときの `.sbr` ファイル

## よくあること

| 症状 | 対処 |
|---|---|
| 画面が真っ黒・何も出ない | グラフィックスのドライバーを更新してください（OpenGL 3.3 以上が必要です） |
| 操作が重い | 「表示 > 表示品質」を下げる。重い計算（ブーリアン・フィレット・シェルなど）は、0.4 秒を超えると「中止」付きの画面が出ます。中止するとモデルは元のままです |
| 面ができない | 線が閉じているか、同じ平面にあるかを確認。画面下の案内に理由が出ます |
| 「Windows によって PC が保護されました」 | 「詳細情報」→「実行」。早期アクセス版はまだ署名していません |
