# ファイルのやり取り（インポート・エクスポート）

「ファイル > インポート...」「ファイル > エクスポート...」から使います。

| 形式 | インポート | エクスポート | メモ |
|---|---|---|---|
| SketchBRep（.sbr） | 開く | 保存 | 自分の形式。すべての情報が残ります |
| STEP（.step / .stp） | ○ | ○ | ほかの 3D CAD との受け渡しに |
| IGES（.igs / .iges） | ○ | ○ | |
| BREP（.brep / .brp） | ○ | ○ | OCCT の形式 |
| Rhino（.3dm） | ○ | ○ | |
| COLLADA（.dae） | ○ | ○ | SketchUp との受け渡しに |
| SketchUp（.skp） | ○ | ○ | SketchUp の SDK を置いた PC だけ一覧に出ます（下を見てください） |
| STL（.stl） | | ○ | 3D プリント用 |
| glTF（.glb / .gltf） | | ○ | レンダリング用（Blender・Twinmotion・Unreal Engine など）。材質の色・透明度・金属感・粗さ付き |
| IFC（.ifc） | | ○ | ほかの BIM ソフト用（IFC4）。階・壁・開口・窓と扉・床・屋根・柱と梁・室・通り芯 |
| DXF（.dxf） | ○ | 図面のみ | 2D の線・円弧を読み込みます。Jw_cad の Shift_JIS の DXF も読めます |
| DWG（.dwg） | ○ | 図面のみ | ODA File Converter（無料）が必要です |
| JWW（.jww） | ○ | 図面のみ | Jw_cad の図面の線・円・円弧・寸法線・ブロックを読み込みます |
| 画像 | 下絵（.png / .jpg / .bmp / .gif） | 画面の画像（.png） | 下絵はトレース用に配置できます |

## SketchUp（.skp）を読み書きするとき

SketchUp のファイルは、Trimble の SketchUp SDK を使って読み書きします。SDK は SketchBRep に入っていません。SDK を置いた PC で、そのフォルダを環境変数 `SBR_SKETCHUP_SDK` に入れる（またはその PC でビルドした版を使う）と、一覧に「SketchUp (*.skp)」が出ます。

- 書き出し：物ごとにグループ（物の名前）。平らな面は 1 枚の面（穴もそのまま）、曲面は滑らかに見える三角形。色は材質。SketchUp 2021 以降で開けます。
- 読み込み：グループ・コンポーネントごとに物 1 つ。閉じた物は立体。色は材質から。隠した物とテクスチャは読みません（色で表示）。

## IFC を書き出すとき

「ファイル > エクスポート」で「IFC」を選ぶと、建物の部品を、ほかの BIM ソフトで開ける形（IFC4）で書き出します。

| モデルの物 | IFC での扱い |
|---|---|
| レベル | 階（レベルが無い時は、高さ 0 の階「GL」を 1 つ） |
| 壁ツールの壁 | 壁。仕様つきの壁は、仕様の名前と「外壁かどうか」、長さ・厚さ・高さ・体積 |
| 壁の開口 | 壁の穴。建具を付けた開口は、窓か扉（腰高が 0 の建具は扉、それより上は窓） |
| スラブ・屋根 | 床・屋根（屋根は種類と面積） |
| 柱・梁などの部材 | 柱・梁・その他の部材 |
| 室 | 空間（壁芯と内法の面積。高さは上のレベルまで。上にレベルが無ければ 2400） |
| 通り芯 | グリッド |
| その他の立体 | 種類の無い部品 |

- 線・面・注記・寸法は書き出しません。
- 閉じていない室は書き出しません。
- 曲がった面は、三角形に分けて書き出します。
- 書き出した後に、入れた数と、仮に決めたこと・入れなかった物を表示します。
- 同じモデルをもう一度書き出しても、部品の ID は変わりません（相手のソフトで、同じ部品として扱えます）。
- 窓・扉は、大きさと開き方の種類だけを書きます（枠や障子の形は、まだありません）。
- IFC の読み込みは、まだできません。

## 2D 図面（DXF・DWG・JWW）を読み込むとき

- 読み込む前に、何が入っているかと、読み込めないもの（文字・点・塗りなど）の数が出ます。
- 「レイヤごとにまとめる」を選ぶと、Jw のレイヤ（グループ/レイヤ）ごとにグループになります。
- 読み込んだ後は平面で全体を表示します。線が閉じていれば、プッシュ/プルで立ち上げられます。
- JWW が読めないときは、Jw_cad で「DXF 形式で保存」してから読み込んでください。

## 図面一式（図番つき）

ファイル →「図面一式を書き出す（図番つき、1 つの PDF）」で、次の図面を 1 つの PDF にまとめて書き出します。

1. 図面リスト（A-01）：図番・図面名・縮尺・用紙の一覧
2. 階ごとの平面図（床から 1100 で切断。下の階は隠す）
3. 南・東・北・西の立面図
4. 建具表・室の表・面積の表・仕上げ表（入れた物がある時だけ）

どの図面も、表題欄に図番（A-02、A-03…）と図面名が入ります。縮尺は 1:100、用紙は図面ごとに入る大きさ（A4〜A1）です。工事名・作成者は、図面の書き出しで最後に入れた値を使います。AI からは `export_drawing_set`（DXF・JWW を 1 枚ずつのファイルで）。
