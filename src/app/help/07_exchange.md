# ファイルのやり取り（インポート・エクスポート）

「ファイル > インポート...」「ファイル > エクスポート...」から使います。

| 形式 | インポート | エクスポート | メモ |
|---|---|---|---|
| SketchBRep（.sbr） | 開く | 保存 | 自分の形式。すべての情報が残ります |
| STEP（.step / .stp） | ○ | ○ | ほかの 3D CAD との受け渡しに |
| IGES（.igs / .iges） | ○ | ○ | |
| BREP（.brep / .brp） | ○ | ○ | OCCT の形式 |
| Rhino（.3dm） | ○ | ○ | |
| COLLADA（.dae） | ○ | ○ | SketchUp との受け渡しに |
| STL（.stl） | | ○ | 3D プリント用 |
| DXF（.dxf） | ○ | 図面のみ | 2D の線・円弧を読み込みます。Jw_cad の Shift_JIS の DXF も読めます |
| DWG（.dwg） | ○ | 図面のみ | ODA File Converter（無料）が必要です |
| JWW（.jww） | ○ | 図面のみ | Jw_cad の図面の線・円・円弧・寸法線・ブロックを読み込みます |
| 画像 | 下絵（.png / .jpg / .bmp / .gif） | 画面の画像（.png） | 下絵はトレース用に配置できます |

## 2D 図面（DXF・DWG・JWW）を読み込むとき

- 読み込む前に、何が入っているかと、読み込めないもの（文字・点・塗りなど）の数が出ます。
- 「レイヤごとにまとめる」を選ぶと、Jw のレイヤ（グループ/レイヤ）ごとにグループになります。
- 読み込んだ後は平面で全体を表示します。線が閉じていれば、プッシュ/プルで立ち上げられます。
- JWW が読めないときは、Jw_cad で「DXF 形式で保存」してから読み込んでください。
