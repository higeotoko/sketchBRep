# はじめに

SketchBRep は、押し出しや移動などの直感的な操作で、正確な形（B-rep）を作る 3D モデラーです。

## 5 分でひと通り

| やること | 操作 |
|---|---|
| 箱を作る | 矩形（R）で 2 点をクリック → プッシュ/プル（P）で面をクリックして引き上げる |
| 寸法を決める | 描いている途中で数字を打って Enter（例: `3000`、`4.5m`、矩形は `3000,4500`） |
| 動かす・回す | 移動（M）・回転（Q）。Ctrl でコピー、確定後に `x3` と打つと 3 個並ぶ |
| 視点 | ホイールでズーム、ホイールを押してドラッグで回転、Shift＋ホイールドラッグで移動 |
| 元に戻す | Ctrl+Z（やり直しは Ctrl+Y） |
| 保存 | Ctrl+S（拡張子 `.sbr`）。自動保存とバックアップもあります |

## 画面の見方

- **ツールパレット**（左）: よく使うツール。「表示 > ツール名を表示」で名前も出ます。
- **画面下の案内**: 次に何をクリックするか、できない時はその理由が出ます。
- **右下の入力欄**: 数値を打つ場所。単位（mm）は欄の外に出ているので、数字だけ打てば OK です。ツールが出した値は、最初のキーで丸ごと置き換わります。
- **Esc**: いつでも 1 手戻ります。
