# 形を作る・直す

## 基本

| 操作 | やり方 |
|---|---|
| プッシュ/プル（P） | 面をクリックして引く・押す。曲面（円柱の側面など）も押し引きできます |
| 移動（M）・回転（Q） | 物・面・辺・点を動かします。Ctrl でコピー |
| オフセット（F） | 面の縁を内側・外側にずらします |
| フォローミー（Shift+F） | 断面をパスに沿わせます |
| 尺度（S） | グリップをドラッグして伸び縮み。数値でも指定できます |
| ソリッド | 「ソリッド」メニューで和・差・積 |

## 曲面・辺の操作（Rhino 風）

順番はどちらでも OK です（先に選んでからコマンド、またはコマンドの後にクリック）。確定前に青いプレビューが出ます。

| 操作 | メニュー | 流れ |
|---|---|---|
| 2 レールスイープ | 曲面 | レール1 → レール2 → 断面 → Enter |
| 縁から面 | 曲面 | 線を 2〜4 本クリック → Enter |
| パッチ | 曲面 | 閉じた輪郭の線をクリック → Enter |
| フィレット（Shift+E） | ソリッド | 辺をクリック → 半径を打って Enter |
| 面取り | ソリッド | 辺をクリック → 寸法を打って Enter |
| シェル | ソリッド | 開ける面をクリック → 厚みを打って Enter |

- フィレット・面取りは、平らな面の角や、線どうし（AutoCAD のフィレットのように）にも使えます。半径 0 で角をぴったり合わせます。
- 値が大きすぎて作れない時は、使える値の目安が出ます。

## グループとコンポーネント

- Ctrl+G でグループ、Ctrl+K でコンポーネント。ダブルクリックで中に入って編集、Esc で出ます。
- コンポーネントは、1 つを直すと同じものが全部変わります。右クリック「この配置 > この配置だけ独立」で切り離せます。
