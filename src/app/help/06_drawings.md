# 図面を書き出す

「ファイル > 図面を書き出す（平面・断面・立面）...」で、平面図・断面図・立面図を作ります。

1. 種類・切る位置・縮尺・用紙・書き出すもの・表題欄を選びます。右のプレビューがすぐ変わります。
2. 「書き出す（PDF・DXF・JWW・DWG）...」を押して、形式を選んで保存します。プリンターに直接送るときは「印刷...」です（用紙は図面に合わせて設定され、縮尺どおりに印刷します）。

| 項目 | 選べるもの |
|---|---|
| 種類 | 平面図 / 断面図 / 立面図 |
| 平面図の切る位置 | レベル＋そこからの高さ（初期 1200 mm） |
| 断面図の位置 | 今の断面、通り芯、モデルの中央。見る側を 2 つから |
| 立面図の向き | 南（正面）/ 東 / 北 / 西 |
| 縮尺 | 1:20〜1:500 |
| 用紙 | 自動（収まる一番小さい用紙）/ A4〜A1 横 |
| 書き出すもの | 切断面の塗り、隠れ線、通り芯、レベル、寸法・文字、図面枠と表題欄 |

## 形式

| 形式 | 内容 |
|---|---|
| PDF | 印刷用。実寸の縮尺で印刷できます（印刷時は「実際のサイズ」を選んでください） |
| DXF | AutoCAD・Jw_cad などで開けます（R12、日本語は Shift_JIS） |
| JWW | Jw_cad の形式。線色・線種・レイヤが分かれています |
| DWG | 「ファイル > DWG 変換ソフトの設定...」で ODA File Converter（無料）を設定すると書き出せます |

- 北は +Y（モデルの奥）です。平面図に方位マークが付きます。
- 隠れ線の計算は、大きなモデルでは時間がかかります。計算は裏で行うので、その間も設定を変えられます。

## リアル表示と太陽

- 「表示 > リアル表示（材質・太陽・影）」（F9）で、材質の金属感・粗さ、太陽の光と影のある表示に切り替わります。選択や編集はいつもどおりです。
- 「表示 > 太陽の位置（日時・場所）...」で、日付・時刻・場所・真北の向きを決めます。時刻のスライダーを動かすと影がその場で動きます。OK でモデルに保存されます。
