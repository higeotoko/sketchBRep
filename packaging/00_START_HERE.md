# SketchBRep をはじめる（早期アクセス版）

ダウンロードありがとうございます。SketchBRep は、押し出しや移動などの直感的な操作で、正確な形（B-rep）を作る 3D モデラーです。建築向けの通り芯・レベル・柱梁、図面の書き出しが付いています。

## 起動

1. zip を好きな場所（例：`ドキュメント\SketchBRep`）に展開します。zip のまま起動しないでください。
2. `SketchBRep.exe` をダブルクリックします。
3. 「Windows によって PC が保護されました」と出た場合は、「詳細情報」→「実行」を押します（早期アクセス版は、まだ署名をしていません）。

## 5 分でひと通り

| やること | 操作 |
|---|---|
| 箱を作る | 矩形ツール（R）で 2 点をクリック → プッシュ/プル（P）で面をクリックして引き上げる。数値を打って Enter で寸法指定 |
| 動かす・回す | 移動（M）・回転（Q）。Ctrl でコピー、確定後に `x3` と打つと 3 個並ぶ |
| 視点 | ホイールでズーム、ホイールを押してドラッグで回転、Shift＋ホイールドラッグで移動 |
| 通り芯・レベル | 「ツール > 通り芯を作成」「ツール > レベル（GL・FL）を編集」 |
| 図面 | 「ファイル > 図面を書き出す」で平面図・断面図・立面図を PDF・DXF・JWW・DWG に |
| 保存 | Ctrl+S（拡張子 `.sbr`）。自動保存とバックアップもあります |

キーの一覧は「ヘルプ > 操作方法」にあります。機能ごとの説明は `manual` フォルダにあります。

## 動作環境

- Windows 10 / 11（64 ビット）
- OpenGL 3.3 以上が使えるグラフィックス（多くの PC で使えます）
