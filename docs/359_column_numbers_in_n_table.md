# 359. N値の柱を耐力壁配置図の番号で呼ぶ

国交省マニュアル（確認申請・審査マニュアル 経過措置対応版）のチェックリストには、柱頭柱脚金物算定の項目として「10-2 対象となる柱の位置と計算表の対応」がある。作成例では、柱頭柱脚金物算定平面図の柱の番号と、算定表の「柱」の番号が対応している。

docs/358 の算定表は、柱を架構の内部の名前（column/0/0/1）で書いていた。これでは図と表を突き合わせられない。耐力壁配置図（docs/333）は、もう柱に番号（□n、通し柱は ◎n）を振っている。

## 直したこと

- N値計算（columnNValues）の各柱に `number` を付けた。
  - 番号の振り方は耐力壁配置図と同じ（docs/333）。その階の柱を、上の列から下へ、各列は左から右へ数える。
  - 通し柱は両方の階に数えるので、1階と2階の図の両方に同じ柱が番号つきで出る。
- 柱頭柱脚金物算定表の「柱」の欄を「柱番号」にした。通し柱は「（通し柱）」を付ける（例：「20（通し柱）」）。
- 申請の段階7の行で、未評価の柱を「1階 柱 20：理由」のように番号で書く。

どのモデルでも、算定表の番号でその階の耐力壁配置図の柱を探せる。

## 例題で見たこと

例題Eで、1階・2階とも次のとおり、耐力壁配置図の画像の番号と同じだった。

- 左上 (0, 7280)：1
- 左下 (0, 0)：20
- 右下 (9100, 0)：25

## 確認

- `TimberWorkflow.ColumnNValuesFollowTheManualsFormula` に足した：
  - 2階の耐力壁配置図（bracingFloor 2）を作る。
  - N値の各柱の番号が、その柱の位置に図が書いた番号の文字と同じであることを確かめる（壁の付く2本）。
  - 算定表の柱番号の欄が空でないことも確かめる。
- コアのテスト 902 本（スキップ 8）が通る。
