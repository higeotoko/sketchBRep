# 292. 使用建築材料表（シックハウス対策の内装材）

様式1-2 の表1「使用建築材料表」にあたる表を、室の仕上げ（docs/115）と、材料ごとに入れたホルムアルデヒドの区分から作る。docs/285「ここから先」の 3 の一部。

## 法令

建築基準法施行令 第20条の7を e-Gov で 2026-11-26 に確認した。 [建築基準法施行令](https://laws.e-gov.go.jp/law/325CO0000000338)

- 居室の内装（壁・床・天井と、開口部の建具の室内側）の仕上げに、第一種ホルムアルデヒド発散建築材料は使わない（第1項第1号）。
- 第二種・第三種を使う時は、その面積に換気回数と住宅等の居室かどうかで決まる数値を掛けた面積（両方使う時は合計）が、居室の床面積を超えない（第1項第2号）。
- 大臣認定を受けたものは、ひとつ下の区分、または規制の対象外とみなす（第2項〜第4項）。

## 入力

仕上げの材料名（室の仕上げと同じ書き方）ごとに、区分 first（第一種）・second（第二種）・third（第三種）・exempt（規制対象外：F☆☆☆☆、または対象の材料でない）と、表示（F☆☆☆☆など）・資料を入れる。全体を入れ替える形で、取り消しは1回。モデルの設定 `interiorMaterials` に保存する。

- AI：`set_interior_materials {items: [{name, class, mark, source}]}`。商品名から区分を推測しない。

## 表

居室ごと（「居室でない」と入れた室を除く）に、床・壁・天井の仕上げ、区分、表示、令20条の7でどうなるか、資料を出す。

- 第一種：「使用できない（第1項第1号）」。
- 第二種・第三種：「使用面積の制限（第1項第2号）。面積は未照合」。
- 規制対象外：「制限なし」。
- 区分が未入力の材料：「区分を入れて照合」。未入力の行数を注に書く。
- 図面一式では、仕上げを入れた室がある時に「使用建築材料表」の表の図面を入れる。
- AI：`interior_material_table`（読み取りのみ）。
- 受付チェックシートの照合で、様式1-2「使用建築材料表」が「図面あり」になる。

## 残り

- 第二種・第三種を使う時の面積の照合（仕上げの面積、換気回数、住宅等の居室かどうか）。
- 建具の室内側の材料。
- 天井裏等の措置（令20条の9）。
