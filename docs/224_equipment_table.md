# 224. 設備の機器を入れて「機器表」にする（2026-11-21）

docs/210・215 の「まだ」の「設備（換気・冷暖房・給湯・照明）の機器」。熊本県「省エネ仕様基準適合説明図」の記載例（2025 年）は、平面・断面図と同じ紙に「機器表（一次エネルギー消費量基準）」を載せている（部位・凡例・仕様又は使用材料等・性能値・基準値(参考)。例：暖冷房設備 ルームエアコン 型番、エネルギー消費効率区分（い）／換気設備 壁付式第三種換気設備／給湯設備 電気ヒートポンプ給湯機 JIS効率 3.8／照明設備 LED ダウンライト）。それに合わせた。

## 入れ方

- AI：`set_equipment` の `items`（一覧ごと入れ替え。`[]` で全部消す）、`list_equipment` で読む。1 回の Undo で戻る。保存される（設定の `equipment`）。
- 1 つの機器：

| 欄 | 中身 |
|---|---|
| kind | `heating_cooling` 暖冷房設備・`ventilation` 換気設備・`hot_water` 給湯設備・`lighting` 照明設備・`solar` 太陽光発電設備・`other` その他 |
| name | 名前（要る）。例「ルームエアコン」 |
| model | 型番 |
| value | 性能値。カタログに書いてある通りの 1 行（「エネルギー消費効率区分（い）」「JIS効率 3.8」など）。数として計算には使わない |
| count | 台数（1〜999、既定 1） |
| source | 資料 |

- どれも 1 行、100 字まで。種類が違う・名前が無い・台数が 0 の時は断る（何も変わらない）。
- AI には「人が言った物だけ。メーカー・型番・値を推測しない」と書いた。
- 画面（ダイアログ）からの入力は、まだ無い。

## 出る所

- **機器表**（`equipmentTable`）：部位・仕様又は使用材料等（名前　型番）・性能値（無ければ「未入力」）・数・資料。種類の順（暖冷房・換気・給湯・照明・太陽光・その他）。
  - 断熱範囲図の紙があれば、その紙に断熱仕様表（docs/223）と並べて載せる。
  - 断熱範囲図の紙が無い時は、図面一式に「機器表」の紙を 1 枚足す。
  - 記載例の「凡例」（平面図の機器の記号）と「基準値(参考)」の列は入れていない。機器をモデルの中に置いていない、基準値との照合をしていないため。注に「基準値との照合・一次エネルギー消費量の計算はしていません」。
- **申請図の工程 9（省エネ・設備）の「設備」の行**：
  - 何も無い時：未入力（入れ方の案内）。
  - 暖冷房・換気・給湯・照明のどれかが無い時：未入力。入れた機器と、入っていない種類を書く。
  - 4 つそろった時：入力済み（照合・計算はしていない、と書く）。

## 確認

**計算テスト済み**
- `Schedules.EquipmentForTheEnergyDocuments`：
  - 何も無い時は工程 9 の「設備」が未入力。
  - エアコン（2 台）と換気を入れると Undo 1 回分。`list_equipment` に 2 つ、種類の名前と台数。「設備」は未入力で「給湯設備・照明設備」が足りないと出る。
  - 種類違い・名前なし・改行・台数 0 は断られ、一覧は変わらない。
  - 4 種類そろうと入力済み。保存して読み戻しても 4 つ、値も同じ。
  - 断熱が無い時は「機器表」の紙ができ、断熱を入れると断熱範囲図（1FL）の紙に機器表が載って、機器表だけの紙は無くなる。
  - Undo で元の何も無い状態に戻る。
- 工程・計画概要・断熱まわりのテスト 14 件もそのまま成功。Windows ローカル：コア全件 787 件成功・8 件スキップ。図面・表・工程パネル・省エネまわりの GUI 15 件が成功。

**Windows 実機確認（人の操作）**：まだ。docs/105 の 14-34。
