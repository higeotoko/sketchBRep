# 壁と開口から区間候補を取り出す（2026-11-05）

追記：この後、柱位置での分割、両端柱・上下材の参照と幾何診断を [docs/65](65_wall_bay_member_references.md) で追加した。以下は開口除外区間の初期実装時点の記録。

docs/60・61で課題とした「耐力壁指定と実部材の関連付け」の最初の段階。
壁の元形状と開口から、開口の横幅を除いた幾何的な区間を取り出す。
基準は配布記録コミット `a05b30f`、直前のアプリ実装は `1870d1d`。

## 画面

「建築 > 木造 > 壁の区間候補（開口を除く）...」またはツールメニューから開く。
作業を続けられる別ウィンドウで、表示中の全ての壁、または平面の作業面の高さで絞り込める。
壁名・既存の階属性・方向・区間長・形状の高さを一覧にする。
行を選ぶと対象の壁を選択し、その区間をモデル上で橙色に強調する。

強調表示は作図プレビューと別に持つため、作図ツールを切り替えても取り違えない。
壁や開口の変更・移動・削除・Undo等で文書が変わったら、古い候補と強調表示を消す。
「モデルから再抽出」で現在の候補を取得する。閉じると区間の強調表示を消す。
形状・属性・壁量入力を変更せず、履歴も増やさない。

## 取り出す区間

- 壁ツール由来の既知の矩形押出しと、既知の矩形押出しによる開口Subtractに限定する。
  架構生成・平面での開口配置と同じ壁基準線を使う。
- 窓・扉の横幅を投影して壁から除く。垂れ壁・腰壁は、この段階の区間には含めない。
  横方向に重なる複数開口は、その範囲をまとめて除く。上下に離れた開口でも同じ扱い。
- 回転・移動した親グループ、中央/左右の基準線に対応し、世界座標で返す。
- 作業面の高さの絞込みは壁下端以上・上端未満。非表示の壁は省略する。
  ロック中でも読取り対象にはできるが、形状や属性を編集する処理はない。
- 円形の穴や任意形状へ編集した壁、方向を判別できない開口は、その壁全体を未対応として報告する。
  穴を無視して壁全長を候補にする処理はしない。

候補は柱間で分割していない。左右柱・上下横架材の有無、柱の欠損、筋かい・面材、接合条件、
有効な壁倍率は未確認であり、耐力壁として成立することを示さない。
形状の高さを筋かいの算定高さへ流用しない。斜め壁は形状候補として示すが、既存のX/Y壁量には未対応。

## AI・CLI

```json
{"command":"list_wall_bays","args":{"elevation":0}}
```

`ids:[wallId,...]` で対象壁を限定できる。空配列は対象なし。存在しないIDや不正な高さはエラー。
候補ごとにhost、host_name、level、世界座標のstart/end、length_mm、t0/t1、geometry_height_mm、
direction、source_signatureを返す。`status:candidate_only`、`verified:false` で、壁倍率を付けない。
返却全体にsequence・revision、未対応の壁の理由、省略した非表示壁の数を含める。
GUI・CLI・MCPは同じ読取り関数を使う。

候補IDはこのスナップショット内だけで有効。壁形状や開口を変えた後に流用しない。
source_signatureは元の壁・配置・開口の変化を識別する補助情報で、今回永続的な計算入力へのリンクは作らない。
