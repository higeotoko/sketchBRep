# 354. 部屋に入らない部屋名

平面図の部屋名は、部屋の印の点を中心に「名前／(面積)／(天井高)」の3行で書いていた（docs/298）。部屋に収まるかどうかは見ていなかった。

例題Eの「ホール・階段」（幅 910、階段が中を占める）では、部屋名が階段と壁の線にかかっていた。実際の家にはトイレ・収納・廊下・ホールのような小さい部屋がいくつもあるので、例題だけの話ではない。

## 直したこと

平面図の部屋名の置き方（設備を避けて下げる docs/334 の後）：

1. 今の位置で、部屋の内法の外形の中に収まり、図の線（壁・階段・扉の開き・設備の記号など）にかからなければ、そのまま。
2. そうでなければ、部屋の中で近い所を探す（紙で 1.5 mm 刻み、16 周まで）。収まって線にかからない最初の所へ、3行ごと動かす。
3. 部屋の中にそういう所が無ければ、3行を1行にまとめてシートの上に置き、部屋の印へ引出線を引く。例：「ホール・階段 (3.31 m²)」。
   - 置き方は、ほかの記号と同じ仕組み（docs/208・333・353）。近くの空いた所を探す。
   - 書いてあることは何も落とさない（名前・面積・天井高・床の高さ）。
   - 通り芯の線は避けない（通り芯の方が文字の所で止まる、docs/353）。最初は通り芯も避けていたので、2階の床では空きが見つからなかった。そのため図の上の外まで飛んで、長い引出線になっていた。

部屋名の文字は図の中で動くだけで、部屋の面積などの数値は変わらない。

## 例題で見たこと

例題Eの図面一式を描き直した。シートの点検では、次の4枚の重なりが 0 になった（docs/353 の後は 2・2 件残っていた）。

- 1FL 平面図
- 2FL 平面図
- 断熱範囲図（1FL）
- 断熱範囲図（2FL）

「ホール・階段 (3.31 m²)」は、階段のすぐ右に短い引出線付きで出た。図面一式の見本（GoldenSheets）は変わらなかった。見本の部屋名は、どれも元の位置で収まっている。

## 残り

- 外に出した部屋名の置き場所が、隣の部屋の床の上になることがある（例題では子供室の上）。引出線で指してはいるが、建物の外に出す方が読みやすい場面もある。

## 確認

- `Schedules.RoomTagsTooBigForTheirRoomGoOutWithALeader`：
  - 910 角の WC を足す。居間の名前は図の中にあり、WC の名前は図の中に無い。
  - WC は「WC (…m²)」の1行として、WC の印を指す記号になり、シートに1回だけ書かれる。
  - 直す前は、WC の名前が部屋の中（壁の上）に書かれるので失敗する。
- コアのテスト 897 本（スキップ 8）、図面・シート・平面・部屋の GUI テストが通る。
