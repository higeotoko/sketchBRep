# 210. 省エネ：適用ルート・地域、断熱、建具の性能の入力と仕様の表（2026-11-21）

調査資料（第2.8版）§3 の順番の「4 省エネ仕様基準」と、docs/201 の「まだ」。これまで第9工程（省エネ・設備）は、モデルに入れる所が無くて、ほとんどが「未入力」だった。ここでは、申請図書の省エネの説明図・仕様表に要る値を入れる所を作った。

仕様基準の値（地域ごとの断熱材の熱抵抗・開口部の熱貫流率など）は告示の値なので、原文を確かめるまでは照合しない。入れた値の一覧を出すところまでにした。

## 入れ方（AI のコマンド。どれも1回の Undo で戻る）

| コマンド | 入れる物 | 置き場所 |
|---|---|---|
| `set_energy_route` | 適用ルート（spec 仕様基準／performance 性能基準／other）、地域の区分（1〜8）、確認資料 | 敷地境界の輪郭の属性 `energy_route`・`energy_region`・`energy_source`（敷地境界が要る） |
| `set_insulation` | 壁・床・屋根の断熱：材料、厚さ（mm）、熱伝導率 λ（W/(m·K)）または熱抵抗 R（m²·K/W）、入れ方（充填／外張り／内張り）、資料（カタログ・仕様書） | 各物の属性 `insulation`。材料を空にすると消える |
| `set_opening_performance` | 開口の熱貫流率 U（W/(m²·K)）、ガラス、資料 | 壁の属性 `opening_performance`（開口の ID ごと。開口を動かしても付いていく） |

資料の無い値は断る（どこから持ってきた値か分からなくなるため）。部屋や柱などに断熱を入れようとすると断る。

## 第9工程の行（`permitEnergyChecks`）

| 行 | 中身 |
|---|---|
| 適用ルート・地域 | 入っていれば「仕様基準　6 地域」などと確認資料、「基準の値との比較はしていない」。無ければ「未入力」 |
| 壁の仕様：○○ | 仕様（層）ごとの壁の数と層、入れた断熱（「グラスウール 16K 100 mm（充填）　λ 0.038（R 2.63）」のように。R は厚さ÷λ、R を入れた時はその値）。断熱の入っていない壁があれば、その数と「未入力」 |
| 仕様の無い壁 | 厚さだけで断熱も無い壁（厚さだけでも断熱を入れれば「厚さだけの壁」の行に入る） |
| 床・屋根の断熱 | 床・屋根のうち断熱を入れた数。無い物を選べる |
| 建具の性能 | 開口のうち熱貫流率を入れた数 |
| 設備 | 未入力（機器はまだモデルに無い） |
| まだ確かめていない事 | 仕様基準の値との比較、外皮・一次エネルギーの計算、省エネ基準への適合 |

## 省エネ仕様の表（`scheduleTable(document, 11)`）

部位（外皮：壁・床・屋根、開口部）ごとに、名前（壁は仕様の名前、床・屋根は種類名）、数、断熱・性能、資料を並べる。同じ名前・同じ断熱の物は1行にまとめる。開口部は符号・熱貫流率・ガラスでまとめる。注に、基準との比較をしていない事を書く。

- 表の窓：「省エネ仕様」のタブ（12番目）と CSV。中身が無い時は、入れ方を注に出す。
- 表だけの紙：`export_schedule` の `table: "energy"`。図面に並べる：`export_drawing` の `tables` に `energy`。
- 図面一式：入れた値がある時だけ、表の紙として入る。
