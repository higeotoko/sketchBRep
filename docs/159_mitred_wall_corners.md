# 壁の立体の留め（Fable に渡す物の 1、2026-11-16）

[docs/106](106_handoff_and_roadmap.md) の「Fable に渡す物」の 1。[docs/107](107_slanted_wall_corners.md)・[docs/140](140_layer_line_mitres.md) の「まだ」（壁の立体を留めにすること）。作業は Fable 5.2。
オーナーの指示：2026-11-16（「あとは Fable でよろしく」）。

## 直す前

- 角では、片方の壁が角の先まで通り、もう片方がその面に突き付く。壁の面に、厚さの分だけ内へ入った所に継ぎ目の縦の線が出る。
- 直角でない角では、突き付けの端が四角いままなので、片側に三角のすき間、片側に重なりが残る（体積も合わない）。

## 直した後

「ツール」→「壁の角（留め）」→「**壁の角を留めにする**（選んだ壁、無ければ全部）」（AI：`mitre_wall_corners {walls, on}`）。

| 項目 | 内容 |
|---|---|
| 留めになる角 | 印を付けた壁が **2 枚だけ**で合う角。両方の壁に印がある時だけ |
| 形 | 2 枚とも、角の**内側の点と外側の点を結ぶ線**（対角線）で終わる。厚さの違う壁・直角でない角でも同じ決まり |
| 留めにならない所 | T 字（間仕切りが壁の途中に当たる所）、3 枚以上が集まる角、曲がりが浅い角（約 14.5° より浅い）、片方だけ印のある角。そこは今までどおり |
| 壁のまま | 長さ・仕様・開口・室・つながり・通り芯・屋根に合わせる、は今までどおり。プロパティの長さも変わらない |
| 動かした時 | 壁を動かす・長さや仕様（厚さ）を変える・屋根を変える・隣の壁を消す → 留めを作り直す（同じ取り消し 1 回の中で） |
| 外す | 「壁の角の留めを外す」（`on: false`）で四角い端に戻る |
| 取り消し | 1 回 |

### 体積

- 直角の角：2 枚の合計は前と同じ（角の四角を対角線で分けただけ）。
- 直角でない角：すき間・重なりが無くなり、合計が「壁の線の周長 × 厚さ × 高さ」にぴったり合う。

## 実装で決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 壁の名目の形 | **変えない**（壁の長方形は描いたまま。突き付けの決まりのまま） | つながり・室・長さ・開口・層の線は、全部この長方形を読んでいる。ここを変えると全部を作り直すことになる |
| 立体の作り | 壁のレシピのいちばん内側に、角の「足す分」（`corner-fill`：留めの線までの壁の帯）と「切る分」（`corner-trim`：留めの線より先）を入れる。屋根に合わせる時（docs/100）と同じ作り | 突き付く側には角の三角を足し、通る側は切る。開口・屋根の切り取りは、その外側で今までどおり効く |
| いつ留めにするか | 命令で印を付けた壁だけ（壁ツールで描いた時は今までどおり突き付け） | 留めは壁ごとにブーリアンが 2 回増える。大きいモデルの重さと、今までのファイル・テストの形を変えないため。初めから留めにするかは、オーナーに聞いてから |
| 作り直しの判定 | 壁ごとに「作った留めの形」（留めの点・高さ）を覚え、変わった壁だけ作り直す | 関係ない編集のたびに全部の壁を作り直さない |
| 角の決め方 | 今までの「角」（片方の端が相手の端の所で面にある）をそのまま使う | 層の線の留め（docs/140）と同じ角になる |

## いっしょに直した不具合

**斜めの壁を外へ動かすと、その壁が縮まず、両方の角から突き出ていた**（docs/107 から）。
原因：「相手の壁の端を通り過ぎたら、つながりを外す」検査が、角（L 字）にも効いていた。角では相手の端も一緒に動くので、この検査をしないようにした（T 字は今までどおり）。
docs/107 のテストは室の面積だけを見ていたので通っていた。壁の体積（長さ）も見るようにした。

## まだやっていないこと

- ~~壁ツールで描く時に、初めから留めにする設定~~ → 済（docs/177、壁ツールの初めの設定）。壁のプロパティに留めの印を出すこと。
- ~~T 字~~（仕様のある壁どうしは済、docs/177）・3 枚の角の納まり。
- 平面図で、同じ仕様の壁の留めの線（対角線）を消すこと。T 字での層の線のつながり（Fable に渡す物の 7）。
- 壁をコピーした直後は、コピー先の留めの形は元のまま（次にその壁か隣を変えた時に作り直す）。
- 留めの大きいモデルでの重さ（測っていない）。
