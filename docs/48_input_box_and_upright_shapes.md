# 数値入力と、円・多角形・円弧を立てて描く（2026-11-02 JST）

## 数値入力欄

| 変更点 | こうした | 理由 |
|---|---|---|
| 単位 | 「mm」「°」は入力欄の外（右隣）に出す。欄の中は数字だけ | 打ち直す時に単位を消す手間をなくすため |
| 「.0」 | 「1000.0」は「1000」と表示する | 同じく、消す手間を減らすため |
| 打ち始め | ツールが出した値は、最初のキーで丸ごと置き換わる | 前の値を消してから打つ手間をなくすため |
| 打ち始めの場所 | 画面上で打っても、入力欄をクリックしてから打っても、同じように置き換わる | |
| 入力欄のクリック | クリックすると値が全選択になる | |

- 単位を付けて打つこともできる（例: `1.2m`）。打たなければ mm として扱う。
- 自分で打ち始めた後は、ツールの表示で上書きされない。

## 円・多角形・円弧を立てて描く

矩形と同じ方法で、立てて描けるようにした。

| 方法 | 操作 |
|---|---|
| 矢印キーで固定 | 描く前か描いている途中に、矢印キーを押す。→ で赤軸に垂直な面、← で緑軸に垂直な面、↑ で水平な面。もう一度押すか ↓ で解除 |
| モデルの点に合わせる | 中心（円弧は始点）をクリックした後、カーソルをモデルの点（端点・線の上など）に合わせる。その点が地面より上や下にあれば、自動で立つ。候補が2つある時は、画面の正面を向いている面を選ぶ |
| 面の上に描く | 今まで通り。面の上で始めると、その面に沿う |

- 固定中は、画面下に「緑軸に垂直な面に固定中」のように出る。
- 円弧は、終点を決めるまでに面が決まる。膨らみはその面の中で決める。
