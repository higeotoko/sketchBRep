## 1. 壁ツールで描く壁は、初めから角が留め

| 項目 | 内容 |
|---|---|
| 壁ツール | 描いた壁に、初めから留めの印が付く。2 枚の壁が合う角は対角線で終わる（docs/159 と同じ形）。描くのと同じ取り消し 1 回 |
| 前に描いた壁 | 印のある壁（留めにした壁・今の壁ツールで描いた壁）と合う角は、そこも留めになる。印の無い壁（前の版のファイル）との角は今まで通り突き付け |
| やめる時 | 「壁の設定」の「角：2 枚の壁が合う角を留め（対角線）にする」を外す。後からは今まで通り「ツール」→「壁の角（留め）」 |
| AI | `create_wall` の `mitre: true`。**初めは false**（突き付けのまま） |

## 2. T 字で、間仕切りのボードが外壁のボードへ回り込む

両方とも仕様（層）のある壁で、両方に留めの印がある T 字（間仕切りの端が外壁の内側の面にある所）。

| 壁 | 変わる所 |
|---|---|
| 間仕切り | 芯（柱）が、外壁の内側の層（石膏ボードなど）を抜けて、外壁の芯の面まで伸びる |
| 外壁 | 間仕切りの芯の幅だけ、内側の層が切り取られる（芯はそのまま） |

- ボードは、外壁の面から間仕切りの面へ L 字に回る。外壁の芯と間仕切りの芯が突き当たる。
- 2 枚の体積の合計は変わらない（外壁から減った分が間仕切りに足される）。
- 平面図：間仕切りの芯の線は外壁の芯の面まで。外壁の、面と芯の間の層の線は、間仕切りの芯の所で切れる。ハッチ（docs/173）も同じ形に付く。
- 間仕切りを動かす・仕様を変える・外す → 同じ取り消し 1 回の中で作り直す（留めと同じ仕組み）。
- 間仕切りが外壁より低い時は、間仕切りの高さの所だけ。

### 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| いつ回り込むか | 両方の壁に留めの印がある T 字 | 壁ツールで描く壁は初めから印が付くので、これからの物は回り込む。前の版のファイルと、印の無い壁の形・数量は変えない |
| 外壁から切る幅 | 間仕切りの**芯の幅**だけ | 間仕切りのボードは外壁のボードに当たって止まり、ボードが角を回る（「回り込み」）。間仕切りの厚さ全部を切ると、外壁のボードが途切れて見える |
| 間仕切りが伸びる所 | 外壁の芯の面まで | 柱どうしが当たる納まり |
| 壁の名目の形 | 変えない（docs/159 と同じ） | つながり・室・長さ・開口は、描いた長方形を読んでいる。室の面積は変わらない |
| 作り | docs/159 の角の「足す分」「切る分」に入れた（間仕切りは足す分だけ、外壁は切る分だけ） | 留めと同じ所で作り直されるので、動かした時もついてくる |

## まだやっていないこと

- 続けて別に描いた壁の端どうし（線の端が合うだけで、片方の端が相手の面に無い所）は、今まで通り角と見なさない（重なる）。1 本の折れ線・閉じた外周で描いた角と、相手の面まで描いた T 字が対象。
- 仕様の無い壁どうしの T 字、3 枚以上が集まる所、十字（間仕切りどうし）は今まで通り。
- 壁のプロパティに留めの印を出すこと。
