# 333. 壁量の図を国交省マニュアルの耐力壁図の線で描く

docs/332 の残りの続き。国交省マニュアルの耐力壁図（冊子 28 ページ）の凡例は、次のとおり。

- 一般壁：細い1本線
- 開口部：二重線
- 耐力壁：太線
- 柱：番号入りの四角（□n）
- 通し柱：その四角を丸で囲む（◎n）
- 筋かい：docs/331 の三角

うちの壁量の図（耐力壁配置図）は、ふつうの平面図と同じくモデルを切って描いていた。だから壁の切り口の塗りや斜線、床組・根太などの部材が重なり、耐力壁の太線が埋もれていた（docs/332 の画像）。そこで、マニュアルと同じ「線の図」にした。

## 描き方

- モデルを切った形・見えがかりは描かない。描くのは次のものだけ。
  - 通り芯と寸法（今までどおり）
  - 下に書いた壁と柱
  - 筋かいの三角、壁記号、四分割の側端部分（今までどおり）
- 壁（`Modeler::wallLines`）：
  - 切断の高さに立つ壁を、壁の厚みの真ん中を通る1本線にする。
  - 窓・戸・開口のところで区切って、そこを二重線（紙の上で中心から 0.5 mm ずつ）にする。
  - 開口は、高さに関係なく全部入れる。高窓でも、壁量では開口部だから。
- 耐力壁：壁量の計算に入れた壁を太線で重ねる（docs/208 のまま）。
- 柱（kind が column・through_column で、切断の高さを通るもの）：
  - 紙の上で幅 2.4 mm ほどの四角を描いて、中に番号を入れる。番号の桁が増えると四角を横に広げる。
  - 番号は、上の列から下へ、各列の中は左から右へ 1, 2, 3…と振る。マニュアルの例と同じ順。
  - 通し柱は、四角を丸で囲む。
- 凡例：「一般壁」「開口部」「耐力壁」「柱」「通し柱」を、図と同じ線・記号で出す。図に出たものだけ。
- 図の上の注記：「太線…」の説明は凡例に移した。注記には、壁記号の意味と破線の意味だけを残した。

## 残り

- 柱番号を表（N値計算・柱頭柱脚の金物の表など）とつなぐこと。今は図の中だけの番号で、モデルを変えると振り直しになる。
- 準耐力壁等。

## 確認

- `Schedules.BracingPlanDrawsWallsAsLinesAndOpeningsDoubled`：見本の建物で次を確かめる。
  - 開口は 5 つ（南の窓 2、北の窓と開口、東の戸）。
  - 壁量の図の細線の数は、壁の区切りの数＋開口の数になる（二重線は2本）。
  - 塗りは出ない。
- `Quantities.BracingPlansNumberTheColumns`：
  - 架構の柱の数だけ四角が出る。
  - 通し柱の数だけ丸が出る。
  - 「1」は左上にある（上にも、同じ列の左にも柱が無い）。
- `WallQuantityForms.BracingPlanShowsTheWallsAndTheSideParts`：注記の確認を壁記号に変えた。
- コアのテスト 866 本、壁・図面・シート・架構・表の画面の GUI テストが通る。
