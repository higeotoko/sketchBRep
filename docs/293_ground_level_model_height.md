# 293. 地盤面をモデルの高さとつなぐ

docs/288 の残り「地盤面と、モデルのGL・高さの制限で使う地盤面との照合」の一部。測点の高さは基準点からの値なので、基準点がモデルのどの高さ（Z）にあるかを入れられるようにした。

## 入力

- 「建物の接地外周・高さ」の画面に「基準点のモデル高さ Z（mm）」を加えた。空欄でもよい。
- AI：`set_site_ground` の `datum_z`。
- 敷地の接地外周の情報として保存する（`datumZ`）。取り消しは接地外周の保存と同じ1回。

## 使い方

- 地盤面算出表の注に、地盤面のモデルの高さ（Z ＝ 基準点のZ ＋ 地盤面）を書く。レベル「GL」がある時は、そのZと差を書く。基準点のZが未入力なら、照合していないと書く。
- `ground_level_table` は `level_z_mm`、`gl_z_mm`、`gl_minus_level_mm` を返す。
- 道路斜線の「路面と地盤から算定」で、「確認した敷地地盤面（モデルZ）」の初期値に地盤面算出表の値を入れる（地盤面が「算出」の時だけ。書き換えられる）。
- 隣地斜線・北側斜線・高度地区の画面と、高さ制限の合成でも、地盤面の初期値を、これまでのレベル「GL」から地盤面算出表の値に変えた（「算出」で基準点のZがある時だけ。ない時は従来どおりGL）。
- `set_site_ground` と `get_site_ground_status` の `legal_status` は、これまでの固定の「未評価」ではなく、地盤面算出表の状態（算出・区分が必要・要確認）を返す。

例：基準点 Z −500、地盤面 ＋75 → 地盤面 Z −425。GL が Z 0 なら差は ＋425 mm。

## 残り

- GLのレベルを地盤面に合わせるかどうかは設計者が決める（レベルを動かすと部材も動くため、自動では変えない）。
- 高低差3 m超の区分。
