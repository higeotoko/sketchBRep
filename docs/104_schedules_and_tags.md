# 建具表・室の表・面積の表・札（G-11・N-10・N-11、2026-11-14）

[docs/97](97_bim_gaps_and_priority.md) の順位 6。関係する約束は B-07（部品から表を出す）・B-05（図面と表がずれない）。
受け入れ条件 BIM-AC-09（表の数と平面の記号の数が合う）の土台。
オーナーの指示：2026-11-14（「6 に進んで」）。

## できること

| 項目 | 内容 |
|---|---|
| 表の窓 | 建築ツールバーの「室」の右の矢印 →「表（建具表・室の表・面積の表）」。モデルから読んだ**今の値**が出る |
| 建具表 | 符号ごとに、種類・建具・幅・高さ・数・腰高。その下に開口ごとの一覧（行をクリックすると、その壁を選ぶ） |
| 室の表 | 室名・階・壁芯・内法・内法の周長・状態、合計 |
| 面積の表 | 階ごとに、壁で囲まれた面積（壁芯）・室の数・室のない閉じた所・室の合計・床スラブの面積。合計の行 |
| CSV | どの表も「この表を CSV に保存」。UTF-8（先頭に BOM）・日本語の見出し・長さは mm・面積は ㎡ |
| 開口の符号（札） | 平面モードで、切っている開口の横に符号（W1・D1・O1）が出る。図面の平面図（DXF・JWW・PDF）にも出る |
| 室の札 | 室の目印に、室名と**今の壁芯の面積**が出る（「居間  24.00 m²」）。壁を動かすと数字が変わる。図面にも同じ文字が出る |
| AI | `opening_schedule`・`room_schedule`・`area_table`（`include_csv` で CSV も返す） |

## 符号の決まり

- 見るのは、壁（壁ツールの壁）の縦の面を抜いた開口。
- 種類：建具なし = **O**（開口）。建具ありで、腰高が 0（床に付く）なら **D**（扉）、それ以外は **W**（窓）。IFC の書き出し（[docs/101](101_ifc_export.md)）と同じ分け方。
- **種類・建具・幅・高さが同じ開口は、同じ符号**。腰高が違っても同じ符号で、表の「腰高」に並べて出す。
- 番号の順：窓 → 扉 → 開口。その中は、幅 → 高さ → 建具の名前の順。同じモデルなら、いつも同じ符号になる。
- 符号は**持たない**（毎回モデルから読み直す）。表・平面の札・図面は、同じ 1 つの関数から出すので、数がずれない。

### 例（8000 × 6000、間仕切り 1 枚）

| 符号 | 種類 | 建具 | 幅 | 高さ | 数 | 腰高 |
|---|---|---|---|---|---|---|
| W1 | 窓 | 引違い | 1600 | 1200 | 2 | 900 |
| W2 | 窓 | 窓 | 1600 | 1200 | 1 | 900 |
| D1 | 扉 | 片開き 左吊元・内開き | 900 | 2100 | 1 | 0 |
| O1 | 開口 | | 800 | 2000 | 1 | 900 |

1100 の高さの平面には W1 が 2 つ、W2・D1・O1 が 1 つずつ出る。500 の高さの平面には D1 だけ（ほかは腰高が 900）。

## 面積の決まり

| 列 | 中身 |
|---|---|
| 壁で囲まれた面積（壁芯） | その階の床から 1100 の高さで切れる壁が囲む、閉じた所の全部。**室を置いていない所も入る** |
| 室の合計 | 閉じていて、ほかの室と重なっていない室だけ。内法が出ない室があれば、内法の合計は「未評価」 |
| 室のない閉じた所 | 閉じた所の数 − 室の数。置き忘れに気づくための数 |
| 床スラブ | 上面がその階のレベルに付いているスラブの平面の面積（体積 ÷ 厚さ。階段の開口は引かれる） |
| 法の床面積・建築面積 | **いつも「未評価」**。算入・不算入の決まり（吹抜け・階段・庇・ポーチなど）を見ていないので、数字を出さない |

- 同じ高さにレベルが 2 つある時（GL と 1FL）は、「〜FL」という名前の方を階として 1 行にする。
- 形を直接変えた壁は壁として読まない。その枚数を表の下に出す。
- レベルの高さにない室は、「（レベルなし）」の行にまとめる。

## 室の札

- 出すのは壁芯の面積（表の「壁芯」と同じ数字）。内法は、プロパティと表で見る。
- 壁が開いて閉じなくなった室は「室名（閉じていない）」。ほかの室と同じ場所にある室は、室名だけ。
- 画面では、モデルが変わるたびに読み直す（室が 1 つも無ければ、何もしない）。

## 実装で決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 表の持ち方 | 持たない。`doc::openingSchedule`・`roomSchedule`・`areaTable` が文書だけから読む | 古くならない。図面（文書の写しで動く）からも同じ関数を呼べる |
| 符号 | 並べ方を決めて毎回付ける | 表と平面と図面で、必ず同じになる。手で付けた符号を守る仕組みは、品番を持つ時（順位 7）に一緒に作る |
| 札の文字 | 表と同じ関数（`roomTagText`）から | 画面・図面・AI で同じ文字 |
| CSV の保存 | バイト列のまま書く | Qt の文字列に通すと先頭の BOM が落ち、Excel で日本語が化ける（画面テストで見つけて直した） |
| 室の一覧の窓 | 今までの「室の一覧と面積」は残した | 画面テストと使い方を変えない。表の窓の「室の表」は、周長の列と CSV が増えたもの |

## まだやっていないこと

- **符号を手で決める・固定する**こと、建具の**品番・材質・ガラス・金物**。姿図（建具の立面の絵）。
- 符号の頭文字を変えること（AW・WD など）。階ごとに番号を分けること。
- 表を**図面のシートに置く**こと（今は窓と CSV）。
- 開口の札の位置を動かすこと。札は開口を抜いた側の面から 300 の所に出る（混んだ所では重なることがある）。
- **法の床面積・建築面積・延べ面積**。吹抜け・階段の穴を室から引くこと。
- 室の用途・仕上げ・天井高（N-02）、仕上げ表。
- 柱・梁・屋根・階段の表（木材は「木材の拾い出し」がある）。
- 3D の表示（平面モード以外）での開口の札。室の札の字の大きさ・内法への切り替え。
