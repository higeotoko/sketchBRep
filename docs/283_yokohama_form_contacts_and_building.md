# 確認申請書の連絡先と建築物別概要

「計画概要の項目」を計画、建築主、代理者、設計者、工事監理者、工事施工者、建築物のタブに分けた。「確認申請のWord様式」の「転記元の項目を編集」からも開ける。保存、取り消し、MCPからの読み書きは既存の計画概要と同じ操作を使う。

- 建築主のフリガナ、郵便番号、住所を両様式の対応欄に転記する。建築主の電話番号は、欄がある第二号様式に入る。
- 代理者、代表設計者、代表工事監理者の氏名、建築士資格と登録番号、事務所名と登録番号、連絡先を個別に入力できる。代表工事施工者の氏名・営業所・連絡先も転記する。従来の担当者メモは参照できる。氏名や資格への割り振りは個別欄で入力する。確認申請書の第一面には代表設計者氏名、第二面の備考には物件名を入れる。
- 単一棟の新築・用途地域の区分なしを選ぶと、申請に係る棟数を1棟とし、入力した他棟数、地上・地下の階数、確認済みの最高高さを第二号・第三号様式に転記する。第二号様式の第四面には番号、主要用途、工事種別、単一の構造、階数、最高高さと軒高を転記する。階数・高さには申請条件を確認した値を使う。値の形式や最高高さと軒高の関係に不整合があるときは転記一覧に表示する。
- 他の建築関係者、複数棟や階別の明細、主要構造部の耐火区分、建蔽率・容積率は、案件の根拠と照合する欄として残る。様式の項目と記入例は公式原本を参照した。 [横浜市の法定様式](https://www.city.yokohama.lg.jp/business/bunyabetsu/kenchiku/tetsuduki/kakunin/dl/dl-hotei.html)
