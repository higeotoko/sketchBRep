# 242. AI がアプリを人と同じに操作する（ファイル・窓、2026-11-22）

## オーナーの方針（2026-11-22）

- 「MCP は最大限太くして、AI 上から動かせることが大事。これは上位思想」。PC を壊すような物は置いておく。
- 「オーナー確認項目をできる限り絞り自動化したい」。
- ChatGPT の接続は、ChatGPT のサーバー（クラウド）から、オーナーが用意する HTTPS トンネル（秘密の URL）を通ってこの PC に入ってくる道。これには、好きな場所へのファイル操作と画面操作は出さない（オーナー了承「おすすめの分け方で」）。

## 決まり

| 道 | モデルの操作・図面の絵（docs/241） | ファイル（save・open・export_* を好きな場所へ） | 窓の操作（ui_*） |
|---|---|---|---|
| この PC の MCP（Claude など、sbr_mcp → 名前付きパイプ） | できる | できる（既定） | できる（既定） |
| ChatGPT の接続（クラウド → トンネル → アプリ） | できる | できない | できない（batch の中に入れても） |

- AI メニュー「この PC の AI にファイル操作と画面操作を許す」（既定 ON）を OFF にすると、この PC の AI もファイルと窓の操作ができなくなる。
- 今までの「AI に別名保存を許可（上書きはしない）」は、この項目が OFF の時の別名保存の許可として残る。

## 足したコマンド（窓の操作）

| コマンド | すること |
|---|---|
| `ui_windows` | 出ている窓の一覧（題・名前・答え待ちの窓か）と、ステータスバーの文 |
| `ui_list` | 窓の中のボタン・入力欄・選択肢・チェック・表（セルの中身）・ラベル・パネルを、人が読むままに。それぞれ `ref`（名前、無ければ #番号）。`menus: true` でメニュー項目（メニューの道筋・名前・使えるか・チェック）も |
| `ui_capture` | 窓を、閉じずにそのまま絵に |
| `ui_set` | 入力欄・数・チェック・選択肢・タブ・表のセル（中の選択肢・数・チェックも）に値を入れる |
| `ui_click` | ボタンを押す（ref かボタンの字。OK・キャンセルも） |
| `ui_trigger` | メニュー項目を選ぶ（名前・字・「ファイル/図面一式を書き出す」のような道筋） |
| `ui_key` | キーを押す（Escape・Return・Delete・Ctrl+Z など） |

- ボタンとメニューは、答えを返した直後に押される。窓が開いて答え待ちになっても、次のコマンドはその窓の中で動く（窓の閉じるのを待たない）。
- AI がボタン・メニューから開いたファイルの窓は、アプリ自身の窓（Windows の窓ではない）になり、AI が名前を入れて進められる。人が開く時は今までどおり Windows の窓。

## 確認

**GUI テスト済み**
- `GuiPhase1::aiWorksTheWindowsAndFiles`：`ui_list`（menus）に「設備の機器」の項目。`ui_trigger equipmentAction` → `ui_windows` で答え待ちの窓「設備の機器」→ `ui_list` で機器の表（4 行）→ `ui_set` で 1 行目の名前「ルームエアコン」と台数 2 → `ui_capture` → `ui_click OK`。取り消し 1 回分の変更で、機器 1 つ（ルームエアコン・2 台）。`save_copy`・`save` が好きな場所に書ける。ChatGPT の道（`executeRemote`）：list_objects はできる、ui_windows・save・batch の中の ui_windows はできない。項目を OFF にすると、この PC の AI も ui_windows・save ができない。
- `GuiPhase1::aiBridgeOverLocalSocket`：パイプから save_copy が書ける。メニューの項目を OFF にすると save は断られる。
- `McpServer.AppCommandSpecsAreValidSchemas`：アプリのコマンド 18 個。
- Windows ローカル：コア全件成功（800 件・8 件スキップ）。AI まわりの GUI 18 件成功。落ちた 2 件は既知のローカルだけの物（クリップボードの `chatGptConnectionDialogControlsBridge`、175% の画素の `paintedFaceFollowsItsMaterial`）。

**Windows 実機確認**：入れ替えた後、AI が `ui_*` で docs/105 の項目を流す（docs/244〜 の台本）。
