## 階段の曲がり角ごと

| 項目 | 内容 |
|---|---|
| どこで | 階段を選んで、プロパティ |
| 曲がり角が 1 つ | 今まで通り「曲がり角」が 1 つ |
| 2 つ以上（折り返しなど） | 「曲がり角 1」「曲がり角 2」…が並ぶ（上りの順）。角ごとに、踊り場か 2〜6 段回りを選ぶ |
| 変えると | 選んだ角だけが変わり、ほかの角はそのまま。取り消し 1 回 |

AI からは前から角ごとに指定できた（`turns` の並び）。それを画面でもできるようにした。

## 平面で別の壁へ開口をコピー

| 項目 | 内容 |
|---|---|
| やり方 | 平面モードで、移動ツールで開口（穴、または建具の記号の所）をつかむ → Ctrl でコピーにする → **ほかの壁の上で**クリック |
| あく所 | クリックした所を真ん中に、同じ腰高で。幅・高さ・建具・手で決めた符号と品番も同じ |
| 向き | 元の開口と同じ向きの面からあける（内開き・外開きが元と同じ側） |
| 断る所 | その壁からはみ出す・ほかの開口に重なる（理由を出して、何も変えない） |
| ステータス | 別の壁の上に来ると「開口 n を ○○ へコピー」と出る |

### 直したこと（作る途中で）

開口をつかむと、動きが「壁沿い」に固定される。そのままでは、カーソルが別の壁まで届かなかった。平面でコピーにしている時は、固定とは別に、カーソルの本当の位置で別の壁を探すようにした。

## まだやっていないこと

- 3D・立面で、別の壁の面の上に置いてコピーすること（今は平面だけ）。
- 別の壁へコピーした直後に「*3」で増やすこと。
