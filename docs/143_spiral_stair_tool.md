# らせん階段を階段ツールで描く（docs/139 の続き、2026-11-16）

[docs/139](139_spiral_stair.md)（らせん階段）の「まだ」（階段ツールでらせんを描くこと）。作業は Opus 5.5。

## できること

| 項目 | 内容 |
|---|---|
| 設定 | 階段ツールの設定（建築ツールバーの階段の▼）に「階段の形」：**歩く線**（今まで）か **らせん（中心 → 上がり始め）**。「らせんの回る角度」（90〜720°、初めは 270°、負で時計回り） |
| 描き方 | らせんの時：**中心**をクリック → **歩く線の上がり始め**をクリック（中心からの距離が歩く線の半径。長さを打ってもよい）→ Enter |
| プレビュー | 2 点目を動かす間、段の形が出る |
| そのほか | 幅・段数・蹴上の上限・上がる高さ・形（塊／踏板）・上の床に開口をあける、は今まで通り |

3 点以上クリックした時は、はじめの 2 点を使う。
