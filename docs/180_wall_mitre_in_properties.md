# 壁のプロパティに「角を留めにする」（2026-11-18）

## できること

壁を 1 枚選ぶと、プロパティの「種類」の下に **角：□ 角を留めにする** が出る。

| 操作 | 結果 |
|---|---|
| 見る | その壁に留めの印があるか（壁ツールで描いた壁は初めから入っている、docs/177） |
| 外す | その壁の角は突き付けに戻る。仕様のある壁どうしの T 字の回り込み（docs/177）もやめる。相手の壁の角も合わせて直す |
| 入れる | 相手の壁にも印がある角は留め、T 字は回り込み |
| 取り消し | 1 回 |

鍵をかけた壁では押せない。何枚もまとめて変える時は、今まで通り「ツール」→「壁の角（留め）」。
