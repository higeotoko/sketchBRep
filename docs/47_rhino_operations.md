# ライノ的な曲面・辺の操作（2026-11-02 JST）

Rhino でよく使う標準的な操作を5種類追加した。

- Sweep2
- EdgeSrf（縁から面）
- Patch
- フィレット・面取り
- Shell

どれも SketchBRep のいつもの操作感に合わせてある。

## 共通のルール

1. **順番はどちらでもよい。** 先に物を選んでからコマンドを選んでもいいし、コマンドを選んでからクリックしてもいい。
2. **画面下に「次は何をクリックするか」が出る。** まだ作れない時は、その理由も出る。
3. **選んだものは役割ごとの色で表示する。**
   - Sweep2 のレール1は赤、レール2は緑、断面は青。
   - フィレット・面取りの辺は紫。
   - シェルで開ける面はオレンジ。
4. **確定前に青いプレビューを出す。** 実際に作る時と同じ計算を使う。
5. **数値は右下の入力欄に打って Enter を押す。**
   - 何も打たずに Enter を押すと、表示中の値で作る。
   - 作った直後なら、打ち直すと同じ操作の寸法が変わる（Undo 1回にまとまる）。
6. **Esc で1手戻る。** 最後に選んだものが外れる。
7. **右クリックメニューには、選んでいる物に合う操作だけが出る。**
   - 線を選んでいる時: 縁から面・パッチ・2レールスイープ。
   - 立体を選んでいる時: フィレット・面取り・シェル。
8. **失敗した時は理由を出す。** フィレット・面取りの値が大きすぎる時は、その辺で使える値の目安（「約 N mm まで」）も出す。

## 場所

| 操作 | メニュー | その他 |
|---|---|---|
| 2 レールスイープ | 曲面 > 2 レールスイープ | 右クリック（線を3本以上選んでいる時） |
| 縁から面 | 曲面 > 縁から面 | 右クリック（線を2〜4本選んでいる時） |
| パッチ | 曲面 > パッチ | 右クリック（線を選んでいる時） |
| フィレット | ソリッド > フィレット | ツールパレット（Shift+E）、右クリック |
| 面取り | ソリッド > 面取り | 右クリック |
| シェル | ソリッド > シェル | 右クリック |

普段の画面が混まないように、ツールパレットにはよく使うフィレットだけを置いた。

## 操作の流れ

| 操作 | 流れ | ひと工夫 |
|---|---|---|
| **2 レールスイープ** | レール1 → レール2 → 断面（何本でも）→ Enter | 2本のレールの両方に触れている線は、断面として自動で選ばれる。断面には面も使える |
| **縁から面** | 線か立体の辺を2〜4本クリック → Enter | 4本目をクリックすると、すぐに作る。2本の場合は、その間をまっすぐつなぐ面になる |
| **パッチ** | 閉じた輪郭になる線・辺をクリック → Enter | 平らな輪郭なら、普通の平らな面になる |
| **フィレット・面取り** | 立体の辺をクリック → 半径（面取りは寸法）を打って Enter | Shift でクリックすると辺を追加・解除できる。ダブルクリックすると、なめらかにつながった辺をまとめて選ぶ。前回の値を覚えている |
| **シェル** | 開けたい面をクリック → 厚みを打って Enter | Shift で面を追加できる。面を選ばずに立体だけを選ぶと、閉じた空洞になる |

- 線（ポリライン・曲線）は、Rhino と同じく1本まるごと選ばれる。
- 面や立体の辺は、1本ずつ選ばれる。

## 作ったあと

| 項目 | こうした | 理由 |
|---|---|---|
| 元の線 | 残す | Rhino と同じ。作り直したり、別の面に使い回したりできるように |
| 作った物 | 新しい物として選んだ状態にする。グループにはしない | すぐに移動やプッシュプルができるように。グループにしたい時は、いつも通り自分でまとめる |
| フィレット・シェルの数値 | 作り方の記録（レシピ）に残す。プロパティで後から変えられる（例: 「Fillet radius」） | SketchBRep の強みである「後から寸法を変えられる」を活かすため |
| 元の線を動かした時 | 作った面は付いてこない（今回は対象外） | Rhino の「ヒストリ」のような機能。作るのが重いので次の段階にする |
| 保存・Undo | すべて SBR に保存され、Undo 1回で取り消せる | |

## 計算で決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| Sweep2 | 各位置で、断面の「レール1側の端からレール2側の端まで」を2本のレールの間に合わせて回し、幅方向にだけ伸ばす。高さは保つ。そうして並べた断面をなめらかにつなぐ | OCCT に元からある2レール機能は、内部の伸縮計算で失敗することがあったため。各レールの長さに対する割合で位置を合わせる |
| Sweep2 の断面の数 | 断面が1本なら、レールに沿って17か所に並べる。複数なら、それぞれの位置と両端だけを使う | 曲がったレールにも沿わせつつ、描いた断面はそのまま通すため |
| 縁から面（2本） | 2本の向きをそろえてから、まっすぐつなぐ | 向きが逆だと面がねじれる（蝶ネクタイ形）ため |
| 縁から面（3〜4本）・パッチ | 端どうしがつながった閉じた輪郭に、なめらかな面を張る | |
| 辺の覚え方 | 辺の中点とその向きで覚える。形が作り直された後も、その点を通って同じ向きの辺を探す。見つからない時や2本ある時は止める | 違う辺を黙って丸めないため（面の時と同じ方針） |
| 「約 N mm まで」の目安 | 失敗した時だけ、値を半分ずつにして試し、使える最大値を探す | 普段は余計な計算をしないため |

## AI から

- `sweep2`, `edge_surface`, `patch`, `fillet_edges`, `chamfer_edges`, `shell` を追加した（docs/06）。
- フィレット・面取り・シェルの結果には `parameter` が入る。`set_parameter` を使うと、後から寸法を変えられる。
