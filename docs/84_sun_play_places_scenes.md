# 太陽の再生・47 都道府県・シーンのリアル表示（2026-11-06）

docs/82_sun_position と docs/83_sky_reflections の続き。

## 1 日の影を再生する

「表示 > 太陽の位置（日時・場所）...」の時刻の横に「再生」ボタンを付けた。

- 押すと、10 分ずつ時刻が進み、影がその場で動く（0.08 秒ごと）。もう一度押すと止まる（ボタンは「停止」になる）。
- 夜から押すと、日の出の少し前から始める。日の入りで止まる。
- OK で、止めた時刻を保存する。キャンセルなら元のまま。

## 場所：47 都道府県

場所の一覧を、47 都道府県の県庁のおおよその位置（緯度・経度、0.01° くらい）にした。影には十分な精度。時差は +9 時間。一覧に無い場所は、緯度・経度で指定する。

## シーンがリアル表示を覚える

- シーン（保存したビュー）を作る・「今のビューで更新」すると、リアル表示かどうかも覚える。
- シーンを開くと、リアル表示の入・切もそのとおりになる（メニューの印も）。
- `.sbr` の `scenes[].realistic`。今までのシーン（記録なし）は、開いても表示を変えない。
