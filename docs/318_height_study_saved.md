# 318. 高さ制限の調べ方をモデルに保存する

docs/317 の道路斜線は、アプリの「高さ制限の合成」で作る下書きがあるときだけ描いていた。下書きはモデルに残らず、モデルが変わると使えなくなる（Codex の作り）。そのため、開き直すたびに作り直しが要り、MCP からの図面一式にも出なかった。

## 下書きの中身を確かめた

下書きの値は、どれも画面で人が入れた数値と、人が選んだ辺だった。

- 道路境界での斜線の高さ（モデルZ）・勾配・幅員・適用距離・建物の後退
- 隣地斜線の立上り・勾配
- 北側斜線の立上り
- 高度地区
- 地盤面
- 確認済みの隣地の辺

建物の後退距離も、モデルから測った値ではなく、人が入れた数値だった。だから保存しても推測は入らない。

## 保存の仕方

- 人が入れた値を、それを入れた敷地（敷地の輪郭の点・用途地域・高度地区）と一緒に保存する（設定 `heightStudy`）。
- 敷地が保存したときと同じ間だけ使う（`savedHeightStudy`）。敷地が変われば使わない。
- アプリ：「高さ制限の合成」で試算・照合した値は、画面を閉じたときにモデルに保存する。
  - 1回で元に戻せる。
  - 保存で変わるのは設定だけなので、下書き（根拠の断面など）はそのまま使える。
  - 次に開くと、前回の値が入った状態で出る。
- 図面一式：アプリの下書きが無いときは、保存した値で道路斜線を描く。開き直した後も、MCP の `export_drawing_set` からも同じ図になる。
- 斜線を描いた図には、注記を添える：「道路斜線：高さ制限の確認で入力した値（勾配・適用距離・建物の後退）による。法規の適合は未評価」。
  - 建物を動かすと、入力した後退距離が古くなることがある。注記の値で人が見直せるようにした。
- MCP：
  - `set_height_study`：値を入れる。`clear` で消す。
  - `height_study`：保存した値と、今の敷地に合っているか（`current`）を読む。

## 確認

- `Drawing.HeightStudyIsKeptForItsSite`：
  - MCP で入れて読める。後退距離 500 も残る。
  - 保存して開き直しても残る。
  - 開き直した図面一式に、道路斜線の入ったシートが2枚以上ある。
  - 敷地の輪郭を動かすと使わなくなり、元に戻すとまた使える。
  - `clear` で消える。
- GUI の `combinedHeightShowsLowestSurface`：
  - 画面を閉じるとモデルが1手だけ変わる（以前は「変わらない」を確かめていたのを、この仕様に合わせて直した）。
  - 調べ方が保存されている。
