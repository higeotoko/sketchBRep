## 表の列（開口部仕様表、docs/225）

- 「基準値(参考)」：「U≦4.7　η≦0.59」のように、その地域で見る物だけ。地域が無い時は「地域未入力」、どちらも無い地域は「基準なし」。ドアは「見ていない」。
- 「照合(参考)」：「U 満たす・η 未入力」のように、U と η を別々に。
  - U：満たす／不足／未評価（U が無い）。
  - η：満たす／未入力（窓の η が無い）／**他の方法で**（窓の η が基準より大きい。ガラスの η・付属部材・ひさしや軒でも満たせるので「不足」とは書かない）。
- 注に書いた見ていないこと：ガラスの η・付属部材・ひさしや軒、床面積の 2％・4％以下の窓の除外、ドア。合否の判定ではない。
