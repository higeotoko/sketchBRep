# 外壁開口部の延焼ラインと防火設備の確認

工程10「立面・断面」の「延焼ライン・外壁開口部」から確認パネルを開く。敷地メニューからも開ける。「基準線を設定」で測量図等で確認した通常の隣地境界を選び、確認資料を記録する。道路は、登録した道路境界と中心線が平行で、確認した幅員の中央に中心線がある場合に選ぶ。防火地域・準防火地域の指定は計画概要で入力する。

- **3D**では、1階の床レベルに橙の3 m、2階以上の床レベルに紫の5 mの線と半透明の範囲を出す。防火設備の照合候補となる開口は赤で囲む。建具符号の行を選ぶと該当の窓・扉を黄色で囲み、距離の起点と確認事項を表示する。
- **配置図**では両方の延焼ラインと、採用した道路中心線を表示する。**平面図**ではその階の延焼ラインを表示する。図面一式に「外壁開口部の延焼確認」を加え、建具符号、階、品番、距離、基準線、確認事項を載せる。
- 階の区分は `1FL`、`2FL` などの基準レベルと壁の所属階から読む。外壁の指定や外側を確認できない開口、階をまたぐ開口は「要確認」とする。敷地や道路の設定が変わったときは、保存した条件と比較し、延焼ラインと距離を出さずに基準線の再確認を表示する。
- 「登録線の範囲外」は、選んだ基準線からの距離を表す。ほかの必要な基準線、水路等の取扱い、同一敷地内の別棟、告示による角度の除外、公園等の防火上有効な空地や耐火構造の壁、個々の防火設備の仕様と認定番号は確認事項として残る。内部の防火区画は別工程で扱う。

BIM操作の約束では、同じ基準線を3D・図面・表で使う B-05、階別に表示する B-06、画面とMCPで条件を共有する B-09 に対応する。 [BIM操作の枠](90_bim_operation_framework.md)

## 計算と保存

通常の隣地境界は敷地の外周辺を使う。平行な道路の中心線は敷地外側に幅員の半分だけ移動した直線を使う。選んだ基準線から3,000 mmと5,000 mm以内の領域をB-repで合わせ、敷地輪郭で切り取る。開口ごとの距離は外壁面の開口全幅と各基準線の水平最短距離を求め、小さい値を使う。距離の丸めは表示だけに行う。

敷地輪郭に選択した辺、道路を使うか、確認資料、確認時点の輪郭・道路の条件を保存する。取り消しは1回。MCPでは `set_fire_spread_conditions` で確認した境界の端点と資料を登録し、`fire_spread_review` で距離・対象の符号・確認事項を読む。

## 根拠

- 建築基準法第2条第6号の基本距離は1階が3 m以内、2階以上が5 m以内。第61条は防火地域又は準防火地域内にある建築物の外壁開口部の防火設備に関わる。2026-11-25照合。 [e-Gov 建築基準法](https://laws.e-gov.go.jp/document?lawid=325AC0000000201) · [国土交通省の第2条第6号の解説](https://www.mlit.go.jp/gobuild/content/001489025.pdf)
- 横浜市の令和8年4月版の第1章 1-5では、水路等に接する場合の中心線の扱いを定めている。2026-11-25確認。 [横浜市建築基準法取扱基準集 第1章](https://www.city.yokohama.lg.jp/business/bunyabetsu/kenchiku/tetsuduki/kisoku/toriatsukai.files/01_1.pdf)
- 令和2年国土交通省告示第197号の角度条件は基本距離から除外する部分の個別照合に使う。 [国土交通省の技術的助言](https://www.mlit.go.jp/common/001339936.pdf)
