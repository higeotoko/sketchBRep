# 338. 換気経路の表

国交省マニュアルの平面図チェックリスト（docs/334・337）の 3-9「火を使用する室に関する換気経路」の続き。作成例の平面図には、給気口・換気扇に加えて、戸の「ドアのアンダーカット等（通気措置）」の矢印がある。これで、空気が居室から水回りの換気扇まで流れる道を示している（シックハウスの24時間換気、令第20条の8）。

docs/334 で、給気口・換気扇・レンジフード・アンダーカット等を置けるようにした。でも、それらが室と室をどうつないでいるかは見ていなかった。そこで、置いた設備から空気の道を読む。

## 作り

- `ventilationPaths`：
  - 室：閉じた室ごとに、壁芯の輪郭の中で、その室の床から上の階の床までにある設備を数える。
    - 給気口
    - 排気（換気扇・レンジフード）
    - こんろ等
  - アンダーカット等：その空気の向きの手前 400 mm にある室から、先 400 mm にある室への空気の道として数える。
  - 居室（室の採光の種類が「住宅の居室」か「ほかの居室」）について：
    - 排気のある室まで、アンダーカット等の道をたどれるかを、いちばん短い道で探す。
    - たどれた室の並びを「排気までの経路」に出す（例：居間 → 洗面）。
  - 確認事項（要確認になるもの）：
    - こんろ等があるのに、その室に換気扇・レンジフードが無い（令第20条の3）。
    - 居室から排気までつながっていない。
    - 居室に給気口も排気も無い。
- 「換気経路の表」（図面一式では採光・換気の表の後。export_schedule の `ventilation_paths`）：
  - 列は、階・室・居室・給気口・排気・排気までの経路・確認事項。
  - 設備を1つも置いていない建物では出さない。
- 申請の段階3（平面）のチェックに「換気経路」の行を足した。
  - 給気口か排気が1つでもあるときに出る。
  - 要確認の室を4つまで名前を挙げて出す。

## 例題で見たこと

docs/334 と同じ設備を例題E に置いて、図面一式を描かせた。保存はしていない。図面リストの A-19 に「換気経路の表」が出た（採光・換気計算表の次）。中身は次のとおりで、置いた設備のとおりだった。

| 室 | 置いた設備 | 表の結果 |
|---|---|---|
| LDK | 給気口・レンジフード | 経路あり（LDK） |
| 和室 | 給気口だけ | 要確認（排気までつながっていない） |
| 洗面・浴室 | 換気扇 | 経路あり |
| 主寝室・子供室（2階） | 感知器だけ | 要確認 |

export_schedule の ventilation_paths でも DXF に書き出せた（5 行）。

## しないこと

- 風量（有効換気量、換気回数 0.5 回/h）の計算。室の換気の入力（docs/211・213 の機械換気の風量）とはまだつないでいない。
- 火を使用する室の必要換気量（告示第1826号、docs/337 のとおり本文待ち）。
- 換気経路の矢印を平面図に描くこと。アンダーカット等の矢印は描いている。

## 確認

- `Schedules.VentilationPathsFollowTheUndercuts`（見本の建物の西に居間、東に洗面を置いた）：
  - 設備が無いと表は空。
  - 居間に給気口、洗面に換気扇を置いただけでは、居間は「要確認」（つながっていない）。申請の行も「要確認」。
  - 間仕切りに東向きのアンダーカットを置くと、居間の経路が「居間 → 洗面」になり、申請の行が「入力済み」になる。
  - 向きが逆（西向き）のアンダーカットでは、つながらない。
  - 居間にこんろ等を置くと、令第20条の3 の確認事項が出る。
- コアのテスト 870 本、申請・平面・表の GUI テストが通る。
