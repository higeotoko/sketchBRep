# 206. 用途地域の区分を画面から入れる（2026-11-20）

docs/205 の「まだ」の1つ。採光補正係数の式を選ぶ用途地域の区分を、AI のコマンド（`set_site_zone`）だけでなく、画面から入れられるようにした。

## 画面

- 「ファイル → 敷地・配置図 → 用途地域の区分...」。区分を選び（住居系／工業系／商業系・指定なし／未入力にする）、確認資料（都市計画図など）を入れる。1回の Undo で戻る。敷地境界が無い時は「先に敷地境界を指定してください」。
- 申請図の工程の「1 敷地・配置図」に「用途地域の区分」の行を足した。敷地境界が無ければ「敷地境界待ち」、未入力なら「未入力」で、ボタンで上の入力が開く。入っていれば区分と確認資料と、「用途地域そのもの（どの地域か）の確認は申請先で行う」と出る。行は既存の行の後（「申請条件」の前）に置いた。
