# 15. 角・辺を動かして形を変える（面は平らなまま）

箱の上の辺を持ち上げて片流れ屋根にする、上の面を横にずらして平行六面体にする。
SketchUp なら移動ツールで辺・角・面をつかむだけ。ここでも同じ操作ができる。
ただし **面が平らなままでいられる動きだけ** を受け付ける。

## 操作（移動ツール M）

- **Alt+クリック**: カーソルの下の要素をつかんで形を変える
  - 角（端点に吸着しているとき）
  - 辺
  - 面（Push/Pull と違って、どの方向にも動かせる）
- 選択ツールで**辺を選んでから**移動ツール: 選んだ辺（複数可、同じ形のもの）の角をまとめて動かす。面を 2 つ以上選んだときも同じ
- 面を 1 つだけ選んでいるときは、これまでどおり法線方向の伸縮（Push/Pull）
- 動かしている間は、変形後の形を半透明で予告する
  - 動かせない位置では予告が消え、ステータスバーに理由を出す（「面が平らでなくなるので動かせません」など）
  - その位置でクリックしても何も変わらない（取り消し履歴も増えない）
- 方向は推定（赤・緑・青軸、平行など）か矢印キーで固定、距離は数値入力（例: ↑ で青軸に固定して `500`）
  - 矢印キーで固定したときは、地面と平行な面に縛らずに上下へも動かせる
- 動かした量はパラメータ（「Move N distance」）になり、プロパティから後で変えられる

## 何が許され、何が断られるか

| 動き | 結果 |
|---|---|
| 箱の上の辺を上へ | 上の面が傾き、前後の面と両端の面はどれも平らなまま → OK（片流れ） |
| 上の面全体を横へ | 平行六面体 → OK（体積は変わらない） |
| 角を 1 つだけ上へ | その角に接する 3 面が平らでなくなる → **断る** |
| 辺を底面より下まで | 面が裏返る／形が自分と交差する → **断る** |
| 曲面・円弧の辺がある形 | 断る（多角形の面だけで使える） |
| 平らな面（プロファイル）の角を面内で | OK。面の外へ出す動きは断る |

SketchUp は平らでなくなった面を隠れた三角形に分けて「動いたように」見せる。でもそれをやると、正確な B-rep（面＝平面）という前提が崩れる。ここでは断って、代わりの手を示す：

- 辺ごと・面ごと動かす
- 先に線を引いて面を分けておけば、分けた片側だけを動かせる

## データ

- レシピの修飾子 `MoveVerticesOp{points（移動前の角の位置・ローカル座標）, direction, distance}`
  - 再生成では、その位置にある角を探して動かす
  - 角が見つからないとき（前の段の寸法を変えて角の位置が変わったなど）は、別の角を動かさずに失敗として知らせる
- 計算: `geom::moveVertices`
  1. すべての面が平面かつ直線の辺かを確かめる
  2. 動かした角で各面の輪郭（穴も）を作り直す
  3. 次のどれかに当てはまれば断る
     - 輪郭が一つの平面に乗らない（許容 0.001 mm）
     - 向きが反転する（Newell 法線の向きで判定）
     - 角どうしが重なる
  4. 縫い合わせてソリッドに戻す
  5. 体積・妥当性（`BRepCheck`）・自己交差（`BOPAlgo_ArgumentAnalyzer`）を確かめる
- 塗った面の素材は、「同じ角（動いた角は動いた先）でできた面」へ引き継ぐ。傾いた面も素材はそのまま
- 1 回の操作 = 1 回の取り消し。保存・読み込み（再生成）でも同じ形になる
- 断る条件はコア（`Modeler::moveVertices`）にあるので、AI からも同じ

## AI コマンド

- `move_vertices {id, points: [[x,y,z]...] | edge: index | {"near": [x,y,z]}, delta: [x,y,z]}`
  - 角（または辺）をワールド座標で指定する
  - 断られたら何も変わらず、理由が返る
