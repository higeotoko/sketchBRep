# 15. 角・辺を動かして形を変える（面は平らなまま）

箱の上の辺を持ち上げて片流れ屋根にする、上の面を横にずらして平行六面体にする。
SketchUp なら移動ツールで辺・角・面をつかむだけ。ここでも同じ操作ができる。
ただし **面が平らなままでいられる動きだけ** を受け付ける。

## 操作（移動ツール M）

- **Alt+クリック**: カーソルの下の要素をつかんで形を変える
  - 角（端点に吸着しているとき）
  - 辺
  - 面（Push/Pull と違って、どの方向にも動かせる）
- 選択ツールで**辺を選んでから**移動ツール: 選んだ辺（複数可、同じ形のもの）の角をまとめて動かす。面を 2 つ以上選んだときも同じ
- 面を 1 つだけ選んでいるときは、これまでどおり法線方向の伸縮（Push/Pull）
- 動かしている間は、変形後の形を半透明で予告する
  - 動かせない位置では予告が消え、ステータスバーに理由を出す（「面が平らでなくなるので動かせません」など）
  - その位置でクリックしても何も変わらない（取り消し履歴も増えない）
- 方向は推定（赤・緑・青軸、平行など）か矢印キーで固定、距離は数値入力（例: ↑ で青軸に固定して `500`）
  - 矢印キーで固定したときは、地面と平行な面に縛らずに上下へも動かせる
- 動かした量はパラメータ（「Move N distance」）になり、プロパティから後で変えられる

## 何が許され、何が断られるか

| 動き | 結果 |
|---|---|
| 箱の上の辺を上へ | 上の面が傾き、前後の面と両端の面はどれも平らなまま → OK（片流れ） |
| 上の面全体を横へ | 平行六面体 → OK（体積は変わらない） |
| 角を 1 つだけ上へ | 上の面が平らでなくなる → **Autofold**：動かない 3 つの角の側はもとの平面に残り、動いた角の側が三角形になって、対角線に折れ線ができる（側面は角がその面の中を動くだけなので分けない） |
| 角を斜めに動かす | 平らでいられない面だけを折る。平らなままの面は分けない |
| 辺を底面より下まで | 面が裏返る／形が自分と交差する → **断る** |
| 曲面・円弧の辺がある形 | 断る（多角形の面だけで使える） |
| 平らな面（プロファイル）の角を面内で | OK。面の外へ出すと、面が折れて開いた形（Shell）になる |
| 穴のある面・凹んだ面を折る必要がある | 断る（「先に線で分けてください」と表示）。凹んだ多角形を頂点から扇形に三角形分割すると面がはみ出すので、そういう分け方はしない |

**方針の変更（2026-10-23、SketchUp 操作差分表の T5）**：以前は「面が増える」ことを理由に、平らでなくなる動きをすべて断っていた。今回の要望に合わせて、必要なときだけ面を平らな断片に分ける Autofold を入れた（既定でオン）。
- 分けた断片もそれぞれ正確な平面の B-rep のままで、表示用のメッシュだけを分けているわけではない
- 不正な形（裏返り、つぶれ、自己交差、体積なし）を断る検査はそのまま残している
- `moveVertices(..., autofold=false)` や API の `autofold: false` を使えば、以前と同じく断る動作にできる
- 同じグループの中で辺を共有している隣の面（単独の面を線で分けた片割れなど）も、一緒に動く。座標が同じだけで辺を共有していないものは動かない

## データ

- レシピの修飾子 `MoveVerticesOp{points（移動前の角の位置・ローカル座標）, direction, distance, autofold}`（`autofold` は true のときだけ保存する）
  - 再生成では、その位置にある角を探して動かす
  - 角が見つからないとき（前の段の寸法を変えて角の位置が変わったなど）は、別の角を動かさずに失敗として知らせる
- 計算: `geom::moveVertices`
  1. すべての面が平面かつ直線の辺かを確かめる
  2. 動かした角で各面の輪郭（穴も）を作り直す
  3. 次のどれかに当てはまれば断る
     - 輪郭が一つの平面に乗らない（許容 0.001 mm）
     - 向きが反転する（Newell 法線の向きで判定）
     - 角どうしが重なる
  4. 縫い合わせてソリッドに戻す
  5. 体積・妥当性（`BRepCheck`）・自己交差（`BOPAlgo_ArgumentAnalyzer`）を確かめる
- 塗った面の素材は、「同じ角（動いた角は動いた先）でできた面」へ引き継ぐ。傾いた面も素材はそのまま
- 1 回の操作 = 1 回の取り消し。保存・読み込み（再生成）でも同じ形になる
- 断る条件はコア（`Modeler::moveVertices`）にあるので、AI からも同じ

## AI コマンド

- `move_vertices {id, points: [[x,y,z]...] | edge: index | {"near": [x,y,z]}, delta: [x,y,z]}`
  - 角（または辺）をワールド座標で指定する
  - 断られたら何も変わらず、理由が返る

## 線を隠す（面は分かれたまま）

- 消しゴム（E）で **Shift+クリック**: その辺の線を隠す（SketchUp と同じ）。普通のクリックは今までどおり「線を消して面を一枚に戻す」
- 編集 > **選んだ辺の線を隠す**（選択ツールで辺を選んでから）／ **隠した線をすべて表示**（選択中のもの、未選択なら全部）
- 使いどころ: 素材を塗り分けるために面を分けた線、正面に見せたくない見切り線
- データ
  - `Object::hiddenEdges` は辺の中点と向き（`EdgeMark`、ローカル座標）
  - 見つけ直すときは、同じ点・同じ向きの辺に加えて、**その点を含む同じ直線上の辺**も対象にする。だから高さを変えて辺が伸びても隠れたまま
  - 辺がその線上から無くなったときは何もしない（ほかの辺を隠すことはない）
  - 尺度変更では一緒に拡大縮小し、保存もされる。1 回の取り消し単位
- 表示
  - 隠した辺のある物は面の境界線を描かず、残りの辺を線の重ね表示で描く
  - 隠した辺のない物は従来どおり（軽いまま）
- AI: `set_edges_hidden {id, edges: [index | {"near": [x,y,z]}], hidden}`, `show_hidden_edges {ids}`
- スムーズ（陰影を辺の両側でなめらかにつなぐ）は、多角形メッシュを取り込む段（ステップ 6）で入れる
  - この B-rep では曲面は本物の曲面としてもともとなめらかに描かれる
  - 必要になるのは、取り込んだ三角形メッシュの面だけだから

## 線が主役（交差で面ができる・消しゴムは線を消す）

SketchUp の基本：面は線が囲んだところにでき、線を消せば面も消える。

### 交差した線で面ができる

- 線ツールで引いた線が、同じ平面・同じグループのゆるい直線（または自分自身）と**交差して**囲んだところは面になる。端点どうしをくっつけなくてもいい
  - 例：# の形に 4 本引くと、4 本目で真ん中の四角が面になる
- 交点で線を切り分け、面の縁になった部分は面に入る。はみ出した部分（ひげ）は線として残る
- 囲みが閉じたクリックで線は終わる（端点につないだときと同じ）。1 回の取り消しで線と面がまとめて戻る
- 計算は `geom::arrangeLines`
  1. 平面上の線分をすべての交点・接点で切る
  2. 行き止まりのひげを除く
  3. 各頂点で「時計回りに次の辺」をたどり、最小の閉じた領域を求める
  4. 新しい線に接する領域だけを面にする
- 今は直線のみ。円弧・曲線との交差では面を作らない（端点でつなげば従来どおり面になる）

### 消しゴム（E）は線を消す

| クリックしたもの | 結果 |
|---|---|
| ゆるい線・円弧・曲線 | **クリックした区間だけ**消える。区間の区切りは、線の角、ほかの線や面の縁が交差・接する点。残りは線のまま（L 字の角から円弧の端までを消して、角を丸くできる） |
| 平らな面（ソリッドでない）の外周の辺 | **面が消えて、ほかの辺は線として残る**（四角なら 3 辺）。穴の縁も線で残る |
| 平らな面の、面を分けた線 | 線が消えて面が一枚に戻る（従来どおり） |
| ソリッドの、同じ平面を分けた線 | 線が消えて面が一枚に戻る（従来どおり） |
| ソリッドの角の辺 | **その辺で接する 2 面が消え、形は開いたまま**（立方体なら 4 面の開いた形）。カーソルを合わせた時点で消える面を強調し、ステータスで予告する。穴埋め（編集 > 穴を埋める）でまた閉じられる |
| 面（クリック位置が面の上） | 部材ごと削除（従来どおり） |
| Shift+クリック | 線を隠す（面は分かれたまま） |

- 1 回の操作 = 1 回の取り消し。AI からは `erase_line {id, edge: index | {"near": [x,y,z]}}`（near は消す区間も決める）
- 円弧を途中で切ると円弧のまま（正確な円）、それ以外の曲線は点列を通る曲線になる
