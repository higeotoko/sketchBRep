# 建具の枠・扉・ガラスの寸法を開口ごとに（N-01 の第 2 段、2026-11-16）

[docs/146](146_fitting_solids.md)（建具の形）の「まだ」（建具の寸法を種類ごとに変えること）。作業は Opus 5.5。
オーナーの指示：2026-11-16（「続けて」）。

## できること

| 項目 | 内容 |
|---|---|
| 寸法 | 建具に、枠の見付（10〜200）・扉の板の厚さ（10〜100）・ガラスの厚さ（3〜30）を持たせる。どれも省けて、省くと今までの値（枠 30・扉 40・ガラス 6） |
| 画面から | 開口のプロパティ（建具の種類の下）に「枠」「扉」「ガラス」の欄。変えると 3D・立面・断面の建具の形が変わる。取り消し 1 回 |
| 種類を変えた時 | 建具の種類（片開き → 引違いなど）を変えても、入れた寸法はそのまま |
| AI から | `set_opening_fittings` の `fitting` に `frame`・`leaf`・`glass`（`list_openings` にも出る） |
| 建具表・符号 | 寸法は建具表の「同じ建具か」の決め手には入れていない（建具の名前・幅・高さで決まるまま）。符号ごとに揃えるのは `change_opening_type` の `fitting` に寸法ごと渡す |
| 断る時 | 範囲の外、数でない値、知らない欄 |

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| どこに持つか | 開口の建具（`opening_fittings`）の中 | 開口を動かす・コピーすると一緒に付いていく。符号で揃える仕組み（docs/133）がそのまま使える |
| 引違いの扉 | 2 枚を、真ん中から扉の厚さずつ両側の 2 本のレールに（重ならない） | 前は 40 の時だけ合う決まった値だった。厚さを変えても 2 枚がぶつからない |
| 平面の記号 | 変えない（平面図の建具記号は今までどおり） | 記号は描き方の決まり（docs/63）で、製品の寸法ではない |

## まだやっていないこと

- 開いた状態の扉、取っ手。框（かまち）・桟。
- 種類の登録（docs/149）のように、建具の寸法を名前で登録しておくこと（今は符号で揃える）。
