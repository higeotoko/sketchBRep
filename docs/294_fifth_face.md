# 294. 確認申請書 第五面（建築物の階別概要）を階ごとに転記する

docs/285「ここから先」の 1 の残り「第五面の各階の明細」。第二号様式（確認申請書）の第五面は階ごとに1枚なので、階の数だけ第五面を作って埋める。

## 雛形

`tools/permit_forms/prepare_templates.py` で、第五面（改ページから第六面の手前まで）を `SBR_FIFTH` の注釈で囲み、各欄に差し込み位置を加えた。第三号様式と協定等届出書の雛形は変わらない（SHA256 一致）。

## 転記する値

「確認申請のWord様式」で面積を転記する時（単一棟の新築で、階名と申請階数が対応し、各階の床面積が全体と一致する時。docs/284 の第四面と同じ条件）に、下の階から順に1枚ずつ作る。

| 欄 | 値 |
|---|---|
| 1.番号 | 1、2… |
| 2.階 | 1階、2階、地下1階… |
| 3.柱の小径 | 木造架構の管柱（その階の軸組）と通し柱の断面の小さい辺の最小値（mm） |
| 4.横架材間の垂直距離 | 空欄（モデルから確かに読めないため、様式に記入） |
| 5.階の高さ | その階のレベルから次のレベルまで |
| 6.イ 居室の天井の高さ | その階の居室（「居室でない」以外）の天井高の最小値。天井高が未入力の居室があれば空欄 |
| 6.ロ 特定天井 | 空欄（様式で選ぶ） |
| 7.用途別床面積 | 計画概要の主要用途の区分・名称と、その階の床面積（1行目） |

面積を転記しない時は、第五面は従来どおり1枚の空欄のまま。転記の一覧に「第五面・N階」の行を出す。

複製した第五面では、Wordの段落IDを外し、図形のIDを付け直す（重複を避けるため）。

## 残り

- 用途が複数ある建物の用途別床面積（室の用途ごとの集計）。
- 横架材間の垂直距離（令43条）。木造架構の横架材の高さから求めることはできるが、どの横架材の間かは確認が要る。
- 主要構造部の耐火区分、複数棟（docs/285 から持ち越し）。
