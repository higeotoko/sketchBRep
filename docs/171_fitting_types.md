# 建具の型（建具の種類と寸法を名前で登録、2026-11-18）

[docs/157](157_fitting_sizes.md)（建具の寸法）の「まだ」（種類の登録のように、建具の寸法を名前で登録しておくこと）。[docs/106](106_handoff_and_roadmap.md) の「残り（Opus で可）」の「建具の寸法の登録」。作業は Opus 5.5。
オーナーの指示：2026-11-17（「続けて」）。

## できること

| 項目 | 内容 |
|---|---|
| 型 | 建具の**種類**（窓・引違い・片開きなど）と**寸法**（枠の見付・扉の厚さ・ガラスの厚さ）を、名前を付けて登録する。床・屋根の種類（docs/149）と同じ登録に、部位「建具」として入る |
| 使う | 開口のプロパティの「型」で選ぶ。その型の種類と寸法になり、型の名前が付く。**吊元・開き勝手・引き勝手は開口ごとのまま** |
| 登録する | 開口のプロパティの「型として登録」で名前を入れる。その建具の種類と寸法が型になり、その開口に型の名前が付く（取り消し 1 回）。同じ名前の型があれば、それを直す |
| 型を直す | 登録し直すと、その型の建具が全部の壁で一緒に直る（吊元などは残る。取り消し 1 回） |
| 型から外れる | 開口の種類や寸法を手で変えると、型の名前が外れる。「型なし」を選んでも外れる（建具はそのまま） |
| AI から | `define_fitting_type {name, fitting}`、`list_fitting_types`、`remove_fitting_type {name}`。`set_opening_fittings` の `fitting` に `{"type_name": 名前}`（吊元などを足してもよい） |
| 型を消す | 建具はそのまま、型の名前だけ外れる |
| 断る時 | 登録していない名前、「なし」を型にする、床・屋根の種類と同じ名前 |

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 型に入れる物 | 種類と寸法だけ。吊元・開き勝手・引き勝手は入れない | 同じ型の扉でも、左吊りと右吊りがあるのが普通 |
| 符号との関係 | 別の物のまま。符号（docs/133）は建具表の行の名前、型は建具の作りの名前 | 同じ型を違う大きさの開口に使う（W1・W2 が同じサッシ）ことがある |
| 置き場所 | 床・屋根の種類と同じ登録（設定）。床・屋根の種類の窓と表には出さない | ファイルの形を変えずに、保存・取り消しがそのまま効く。今までの窓を壊さない |

## まだやっていないこと

- 建具の型の一覧の窓（今は開口のプロパティと AI から）。
- 型に品番・メーカーを持たせること（今は開口ごとの品番、docs/109）。
- 開いた扉・取っ手・框（docs/157 の「まだ」）。
