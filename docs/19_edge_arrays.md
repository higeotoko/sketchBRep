# 線の移動コピー・等間隔配列・等分割（2026-10-23 の指示書への対応）

指示書：「SketchBRep：線の移動コピー・等間隔配列・等分割の改善指示書」（調査の固定点は 3f8cdfb）。

## 原因（再現で確かめたこと）

| 差分 | 修正前 |
|---|---|
| 選んだ辺のコピー（ARR-01） | 移動ツールは、面・ソリッドの辺を選んでいると「角をつかんで変形」の処理に入り、Ctrl を押していても形を変えるだけだった。ポリラインの 1 辺を選んでいる場合は、オブジェクト全体を移動・コピーしていた。辺だけをコピーする入口がなかった |
| 配列の基準（ARR-02） | 再入力のたびに、直前の結果（間隔×本数）から計算し直していた。例：600 → `*5` → `/3` だと 3000 を 3 等分していた |
| 面の分割（ARR-04） | コピーした線が面の上に載っても、面は分割されなかった（オブジェクトのコピーだったため） |

## 修正

- **ARR-01**：辺だけを選んで移動ツールを使い、Ctrl でコピーにすると、選んだ辺だけを線としてコピーする（`Modeler::copyEdges`）。
  - 面やソリッドは変形しないし、オブジェクト全体もコピーしない
  - 基点を置いたあとに Ctrl を押しても切り替わる（予告もコピーの形に変わる）
  - 直線のつながりは折れ線、円弧は円弧、それ以外の曲線は元の形のまま（近似しない）
  - Ctrl を押さないときの「角をつかんで変形」はこれまでどおり
  - グループやオブジェクトを選んだときは、これまでのオブジェクトのコピー
- **ARR-02（暫定仕様）**：最初にマウスや数値で決めた距離（基準）を別に覚えておき、そのあとの入力は毎回この基準から計算する。
  - `*N` / `N*` / `xN` / `Nx`：基準の間隔でコピーを N 本（元を含めて N+1 本）
  - `/N` / `N/`：基準の距離を N 等分
  - 距離の再入力：基準の距離を置き換える（今の配列の種類と本数はそのまま）
  - 前の配列は置き換わる（積み重ならない）。最初のコピーから最後の入力まで、Undo は 1 回で戻る
  - `/0`、不正な文字、上限超えはエラーを出して、直前の結果をそのまま残す
  - ステータスには「コピー 5 本（元を含め 6 本）」と表示する
  - **SketchUp 実機の「2 回目の入力」の扱いとは、まだ照合していない**
- **ARR-04**：まっすぐなコピーが、同じグループの面を辺から辺へ横切るなら、その面を分割する（独立した線は作らない）。既存の辺とぴったり重なるコピーは作らない（例：`/3` の最後の 1 本が面の右端に重なる場合）。端から端に届かない線は、勝手に延ばさず、線として残す。
- **ARR-05（API）**：`copy_array` に次を追加した。GUI も API も、同じ `Modeler::copyEdges` / `copy` を通る。
  - `edges`：辺の指定
  - `divide: true`：`vector` を全体の距離として N 等分する。回転の角度にも使える
  - `count` は 1〜10000 の範囲外ならエラー
