# 201. 申請図の工程：第9工程（省エネ・設備）と第10工程（立面・断面）（2026-11-20）

docs/200 の続き。どちらも、モデルにある物と、まだモデルに無い物をそのまま出す。省エネの計算や法の高さは足していない。

## 第9工程（省エネ・設備）

今のモデルには、断熱材の層・性能の値・設備の機器が無い。この工程の行は、ほとんどが「未入力」になる。それが今の本当の状態なので、隠さずに出す。

| 行 | 出す物 |
|---|---|
| 適用ルート・地域 | 「未入力」。申請先と、どの基準・計算の方法で出すか（仕様基準・性能基準など）、地域の区分。モデルにはまだ入れる所が無い |
| 壁の仕様：○○ | 仕様ごとの壁の数と、外→内の層（名前と厚さ）。名前に「断熱」を含む層があれば「入力済み」、無ければ「未入力」。今の既定の仕様（サイディング・モルタル・石膏ボードなど）には断熱材の層が無い。ボタンでその仕様の壁を選ぶ |
| 仕様の無い壁 | 厚さだけの壁の数（「未入力」、選択できる） |
| 床・屋根の種類 | 床・屋根のうち、種類（層）を付けた数。性能の値はまだ入れる所が無い |
| 建具の性能 | 開口の数。熱貫流率・日射の値やガラスの仕様はまだ入れる所が無い（品番の欄に書ける） |
| 設備 | 換気・冷暖房・給湯・照明などの機器はまだモデルに無い（「未入力」） |
| まだ確かめていない事 | 外皮の性能・一次エネルギー消費量などの計算と、省エネ基準への適合 |

## 第10工程（立面・断面）

| 行 | 出す物 |
|---|---|
| 地盤（GL） | 「GL」という名前のレベルがあるか。無ければ「未入力」（立面・断面の地盤の線と高さの基準のため） |
| いちばん高い所（参考） | 壁・屋根・床・バルコニー・庇・階段・柱・梁のうち、いちばん高い所の GL（無ければ z = 0）からの高さと、その物の名前。法の建築物の高さ・軒の高さの測り方（令 2 条 1 項 6・7 号）による値ではないと書く |
| 断面の切る位置 | 断面ツールで決めた縦の断面の数。無ければ、図面一式では建物の真ん中を通る2つの断面（A-A 東西・B-B 南北、docs/132）を出すと書く |
| 立面の向き | 真北が入っていれば、その角度と、立面図の名前はモデルの軸に沿った向きだという事。無ければ「要確認」 |
| まだ確かめていない事 | 道路斜線・隣地斜線・北側斜線などの高さの制限、法の高さ・軒の高さ、平面・立面・断面の寸法の突合せ |

AI からは `permit_checks` の `stage: 9`・`stage: 10`。
