# 建具の符号の頭文字を AW・AD・WW・WD に（2026-11-18）

[docs/104](104_schedules_and_tags.md)・[docs/109](109_opening_marks_and_products.md)（符号と品番）の決め事。[docs/106](106_handoff_and_roadmap.md) の「オーナーにしかできない事」の 4（符号の頭文字）。作業は Opus 5.5。
オーナーの指示：2026-11-18（「図面上共通の通りがいい符号の頭文字にして」）。

## 直す前

自動で付ける符号は、窓 W1・W2…、扉 D1・D2…、建具の無い開口 O1… だった。

## 直した後

| 建具 | 頭文字 | 例 |
|---|---|---|
| 外壁（外壁の仕様の壁）の窓 | **AW** | AW1・AW2 |
| 外壁の扉 | **AD** | AD1 |
| 内壁（内壁の仕様の壁）の窓 | **WW** | WW1 |
| 内壁の扉 | **WD** | WD1 |
| 仕様の無い壁の窓・扉 | 外壁とみなして AW・AD | |
| 建具の無い開口 | O（今まで通り） | O1 |

- 番号は頭文字ごとに 1 から。並びは窓（AW・WW）、扉（AD・WD）、開口（O）。
- 手で付けた符号（docs/109）が優先なのは今まで通り。自動の番号は、手で付けた符号と同じ物を飛ばす。
- 建具表・平面図の札・IFC の建具の名前・CSV、全部この符号になる。

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 頭文字 | 図面でよく使う「材料＋種類」の書き方（A：アルミ、W：木製、W：窓、D：ドア） | オーナーの指示。外部建具はアルミ、内部建具は木製が住宅でいちばん多い |
| 外か内か | 開口のある壁の仕様（外壁 〜 か内壁 〜 か） | モデルは建具の材料を持っていない。壁の仕様で分けるのが、いちばん外れにくい |
| 仕様の無い壁 | 外壁とみなす | 窓は外壁にあることが多い。違う時は手で符号を付ける（建具表から） |
| 鋼製（SD・SW）など | 自動では付けない | 材料が分からない。手で付ける |

前の版のファイルを開くと、手で付けていない符号は新しい頭文字になる（W1 → AW1 など）。手で付けた符号はそのまま。

## まだやっていないこと

- 建具の材料（アルミ・木製・鋼製・樹脂）を建具の型（docs/171）に持たせて、頭文字をそこから決めること。
