# 床・屋根の種類の窓（登録・層を画面で、N-08 の第 8 段、2026-11-16）

[docs/149](149_registered_types.md)・[docs/151](151_floor_type_layers.md)・[docs/152](152_roof_type_layers.md) の「まだ」（登録の一覧を画面で直す窓、画面から層を入れる窓）。作業は Opus 5.5。
オーナーの指示：2026-11-16（「よろしく」）。

## できること

| 項目 | 内容 |
|---|---|
| 開く所 | 「設定（壁・部材・スラブ・開口）」→「床・屋根の種類（登録・層）...」。屋根ボタンの右の矢印にも |
| 左 | 登録した種類の一覧（「F1（床）」など）。押すと右に値が出る |
| 右 | 種類名・部位（床／屋根）・厚さ・勾配・軒の出・けらばの出（屋根だけ。空は「決めない」）・層の表（上から、名前と厚さ） |
| 層 | 「層を足す」「選んだ層を消す」。層があると厚さの欄は合計になり、直せなくなる。下に「合計 39 mm」 |
| 登録する | 今の値で登録（同じ名前があれば直す）。その種類名の床・屋根が全部その値に。取り消し 1 回 |
| 登録を外す | 一覧で選んだ種類の登録を外す（床・屋根の種類名と寸法はそのまま） |
| 断られた時 | エラーの文が出て、何も変わらない（断る決まりは docs/149・151 と同じ） |

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 窓の形 | 開いている間、登録・外すがすぐ効く（1 回ずつ取り消せる）。「閉じる」で閉じる | OK／キャンセル型にすると、何度も登録を試す時に毎回開き直しになる |
| 層を全部消して登録 | 層を外す（厚さは登録の値のまま） | 表を空にした＝層なし |

## まだやっていないこと

- 層ごとの塗り（ハッチ）、IFC・数量への層。
- 種類の表の窓から、この窓を開くこと。
