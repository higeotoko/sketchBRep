# 階を上の階へ写す（N-07、2026-11-15）

[docs/97](97_bim_gaps_and_priority.md) の N-07（順位 8 の 1 つ）。作業は Opus 5.5。
オーナーの指示：2026-11-15（「出先なので、とりあえず進めて」）。

## できること

| 項目 | 内容 |
|---|---|
| どこで | 階のボタン →「階を上の階へ写す」→「1FL → 2FL」など（すぐ上の階へ） |
| 写る物 | その階に**始まる**立体（その階の床の 300 下〜上の階の床の 300 下。「3D で 1 つの階だけ」と同じ決まり）と、その階の室（室名・用途・仕上げも） |
| 一緒に写る物 | 壁の開口・建具・手で決めた符号と品番、階段とその手すり |
| レベル | 壁の足元・上端、床の上面など、レベルに付いていた物は、同じだけ上のレベルに付く（無ければ外れる） |
| 断る時 | 写す先にもう壁がある（二重になるので）。理由を出して、何も変えない |
| 床 | 写す先にもう床（スラブ）があれば、床は写さない（ステータスに出す） |
| 取り消し | 1 回 |
| AI | `copy_storey {from, to}`（レベルの id か名前） |

## まだやっていないこと

- 写す物を選ぶ（壁だけ、など）。
- 写した後に、上の階の階段の床の開口を作り直すこと（階段は写るが、上の階の上の床の開口は、あけ直しが要る）。
- 屋根・基礎のように、階をまたぐ物の扱い（屋根は上の階の物として写らない）。

## 気をつけること（作る途中で分かった）

レベルを AI から `set_levels` で置き直す時に、レベルの `id` を付けないと、新しいレベルになり、壁などがレベルから外れる。外れた壁は、写す時にもレベルを持たない。docs/106 の「はまった所」と同じ。
