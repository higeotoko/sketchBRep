# 290. 軸組図を図面一式に入れる

様式2（構造受付チェックシート）表2 の「2面以上の軸組図」にあたる図を、木造架構から作って図面一式に入れた。docs/285「ここから先」の 3 の一部。

## 作り方

- 木造架構の部材（軸組のタグ）があり、通り芯が X・Y それぞれ2本以上ある時に作る。外周の4通り（X方向の最初と最後、Y方向の最初と最後）について、外側から見た図を1枚ずつ作る。図面名は「X1通り軸組図」など。
- その通りの前後150 mm（計300 mm）の範囲の部材だけを描く。断面図に奥行きの範囲 `ViewSpec::sectionDepth` を加えた。既存の断面図は0（すべて）のままで変わらない。
- 描く部材は架構の段階のタグ（基礎・土台、1階床組、1階軸組、2階床組、2階軸組、小屋組）。部材符号と断面寸法を書く。伏図と同じ符号。
- 縮尺は1:50。1:100では符号が重なった。図面一式の縮尺が50より小さい（例：1:20）時はその縮尺で描く。
- 断面図の「切る位置」の照合（平面図の切断記号と図番）の対象外。

## 照合

受付チェックシートの照合（docs/286）で、様式2 表2「2面以上の軸組図」が「図面あり」になる。内部の通りの軸組図は、必要に応じて別に用意する。

## 残り

- 内部の通りの軸組図。耐力壁・筋かいの位置を示す通りの選び方。
- レベル名（1FL・土台天端・基礎天端）が近い高さで重なる。断面図・立面図と共通の表示の課題。
- 構造詳細図、使用構造材料一覧表、基礎・地盤説明書、使用建築材料表は未対応。
