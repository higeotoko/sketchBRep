# 296. 図面表現の見直し（1）通り芯・寸法・高さ

docs/285「ここから先」の 4 の続き。公開されている確認申請図書の作成例と、建築製図通則を見比べて、図面一式の表し方を直す。今回は1回目。

- 福井県「確認申請図書の作成例（2階建て木造戸建て住宅）」。 [PDF](https://www.pref.fukui.lg.jp/doc/kenchikujyuutakuka/r04_datutannso_kaisei_d/fil/250326_tosyo_rei.pdf)
- JIS A 0150:1999 建築製図通則：10.1 基準線は通常実線、必要な所は一点鎖線。太さは細線・太線・極太線の順で、比は1:2:4（JIS Z 8312）。10.2 基準線の端には細線で円をかき、円の中に基準記号を書いてよい。 [規格の本文](https://jis.eomec.com/jisa01501999)

## 考え方

見た目を作成例に合わせるのではなく、図の中で何が主役かで線と記号を決める。

- 通り芯とその丸は補助の情報。作成例の平面図・立面図には丸がなく、寸法の列で位置を示している。丸はJISの例のとおり細線の小さな円とし、図より目立たないようにする。
- 寸法は「区間」と「全体」の2段。区間は図と丸の間、全体は反対側に置く（作成例も4辺に寸法がある）。通り芯の線は伸ばさない（伸ばすと用紙が1段大きくなった）。
- 寸法の数字は3桁区切り（7,280）。作成例と日本の図面の書き方に合わせる。
- 立面図・断面図の高さは、法令の高さを読むための情報。地盤面（地盤面算出表の値、なければGL）から、各階・軒の高さ・最高の高さを測る。作成例の「平均地盤面からの軒の高さ・最高の高さ」と同じ考え方。

## 変えたこと

| 対象 | 変更 |
|---|---|
| 通り芯の丸 | 半径5 mm → 3 mm（直径6 mm）、文字4 mm → 2.5 mm。細線のまま |
| 平面図・立面図・断面図の通り芯の寸法 | 区間の寸法に加え、全体の寸法を反対側（上・右）に置く。数字は3桁区切り |
| 図面一式の立面図・断面図 | 右側に、地盤面から各階（〜FL）・軒の高さ・最高の高さの寸法。地盤面算出表の値がある時は「平均地盤面」のレベルを加える（`ViewSpec::heightDims`） |
| 確認用 | GUIテスト `reviewDrawingSetOfAModel`：`SBR_REVIEW_SBR` の .sbr の図面一式を `SBR_REVIEW_OUT` へPNGで出す（ZIPを作らずに見た目を確かめる） |

軒の高さは壁の上端の最大値、最高の高さは壁・屋根・床・バルコニー・庇の上端の最大値とした。令2条1項6号・7号の算定の細部（屋上突出物の除外など）は扱っていない。

## 次回以降

- 線の選定の表（docs/297）：JIS Z 8312 の太さの系列と、役割（切断・見えがかり・隠れ・基準線・寸法・境界）ごとの線種と太さ、白黒印刷での区別を根拠つきで決める。
- 室名に天井高（CH）・床高（FL）を書く。複数行の室名表示が要る（1行に足すと壁にかかった）。
- レベル記号を「▽1FL」の形に、屋根勾配の記号（4/10）、軒の出の寸法、凡例、1枚に複数の図を並べる配置。
- 配置図の道路・隣地境界の線種、断面図の地盤のハッチングと道路。
