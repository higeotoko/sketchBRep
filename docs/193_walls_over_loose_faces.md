# 193. 面の上に作った壁・床が面に巻き込まれないようにする（2026-11-19）

docs/192 の架空モデルの通し確認で見つけた不具合。SketchUp のモデルを組み直すとき、敷地の輪郭を GL（z=0）に描いてから壁を立てる、という順番は普通にあるので先に直した。

## 起きていたこと

`create_wall` と `create_slab`（GUI の壁・床ツールも同じ経路）は、内部で長方形・多角形の面を作ってから押し出している。この面がスケッチの面と同じ処理を通っていた。スケッチの面は、既にある面の上に描くと穴をあけたり重なりを合体したりする（`addProfile` → `punchHole` / `settleOverlaps`）。

z=0 に敷地の輪郭のようなばらの面があると、次のことが起きていた。

- 1枚目の壁の長方形が敷地の面に穴をあける。2枚目以降の壁は、その面と合体し直した「Region of Face 1」（面の切れ端）から押し出される。
- 切れ端から作った壁は、壁として形を読めない（`unreadable_walls`）。そのため部屋が閉じず、面積も出ない。
- 敷地の面は、壁の足元で切り刻まれる。
- 床は床自身は無事だった。ただし敷地の面に床の形の穴があいた（「Polygon > Hole」）。

壁を先に描いてから輪郭を描いた場合は起きなかった。

## 直したこと（`23f7e66`）

- 壁と床の元の面は、スケッチの処理を通さずにそのまま追加する（`addObject`）。まわりの面には穴をあけず、合体もしない。手で描く長方形・円・多角形は今までどおり穴あけ・合体する。
- 床は、以前は「立体の面の上なら面の向きを裏返す」処理（`createPolygon` の `facesIntoSolid`）も通っていた。床は外形を反時計回りにそろえて必ず上へ押し出すので、この裏返しは使わない。
- テスト `Rooms.WallsAndSlabsOverAFaceLeaveItAlone`：敷地の面を先に描き、その上に壁4枚・床・部屋を作る。部屋が閉じる（面積24 m²、読めない壁0）、壁の履歴が「Rectangle …」のまま、敷地の面の履歴・面積が描いたときと同じ、面は1枚だけ、を確かめる。

BIM 操作の約束（docs/90）との関係：部材は部材として作られ、ほかの物（ばらの面）を勝手に変えない。
