# 階段のささら桁（切り欠き）・蹴込み板・親柱（docs/128 の続き、2026-11-16）

[docs/128](128_stair_side_boards.md)（側板）の「まだ」（切り欠きのささら桁、親柱、蹴込み板）。作業は Opus 5.5。
オーナーの指示：2026-11-16（「CI 諸々終わったら次のタスクに進んで、自動で進んでいっていい」）。

## できること

| 項目 | 内容 |
|---|---|
| 板の形 | 側板（ささら桁）を付けた階段で、「板の形」を選べる：**側板**（段をはさむ、今まで）か **ささら桁**（段を上に乗せる） |
| ささら桁 | 幅の**内側**、踏板の下。上は段の形に切り欠き（各段の踏板の下面）、下は段鼻の線から側板と同じ深さ下がった線。床より下には出ない。回り段の所も段ごとに付く |
| 蹴込み板 | 形が「踏板」の階段に付けられる。各段の**前の縁**（歩く線でいちばん下側の辺）に、下の段（または床）から、その段の踏板の下面まで。厚さ 15（AI から 5〜60） |
| 親柱 | 側板（ささら桁）といっしょに付けられる。各板の**足元**と、回り段・踊り場で**内側の板が止まる所**に、105 角（AI から 60〜240）。床から、そこの板の上より 100 上まで |
| 画面から | 階段のプロパティ：側板があれば「板の形」と「親柱」、形が踏板なら「蹴込み板」 |
| AI から | `create_stair`・`change_stair` の `stringer_style`（side / cut）、`riser_boards`・`riser_thickness`、`newels`・`newel_size`。`stair_info` にも出る |
| 保存 | ファイルに残る。前のファイルの階段は、側板の形・蹴込み板なし・親柱なし |

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 蹴込み板 | 踏板の階段だけ | 段々の塊の階段には、もう蹴込みの面がある |
| 親柱の高さ | 板の上から 100 | 手すりの高さとは別に、板の端を受ける柱として。手すりの付け方は別に決める |

## まだやっていないこと

- 段鼻の出（踏板が蹴込みより前に出る）。
- 親柱の形（面取り・頭の飾り）、手すりを親柱につなぐこと。
- 側板・ささら桁・蹴込み板・親柱を IFC で別の部材として書くこと（今は階段の形の一部）。
