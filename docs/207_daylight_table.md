# 207. 採光・換気計算表（2026-11-20）

docs/203・205 の入力と照合を、申請図書の表の形にした。熊本県の図面例（p.9）では、居室ごとに採光・換気を表で示している。同じ中身を、今ある表の仕組み（docs/113）の6番目の表として出す。

## 表の中身（`scheduleTable(document, 6)`）

居室の区分を入れた室（住宅の居室・その他の居室）ごとに、次の行を並べる。「居室でない」と未入力の室は載せない。

| 列 | 中身 |
|---|---|
| 室名・階・区分・床面積 (m2) | 室の最初の行だけ。床面積は壁芯 |
| 開口 | 室の壁の区間に収まる矩形の開口（候補）の符号。候補が無ければ「（開口候補なし）」 |
| 開口の面積 (m2) | 建具表の幅×高さ |
| 採光補正係数 | 入れた値（無ければ「未入力」） |
| 採光に有効な面積 (m2) | 開口の面積×係数 |
| 換気に有効な面積 (m2) | 入れた値（無ければ「未入力」） |
| 照合 | 室ごとの「計」の行に「採光 ○○・換気 ○○」（docs/203 の言い方） |
| 係数の根拠 | 開口に入れた根拠（モデルから求めた時は式、docs/205） |

室ごとの「計」の行では、採光の合計／必要（床面積の 1/7）と、換気の合計／必要（1/20）を出す。足りない値がある時、換気設備の時は空欄にする。

表の注には、床面積と開口の取り方、条文（法 28 条 1・2 項、令 19 条 3 項 表（三）、令 20 条）と e-Gov で確かめた日・版、見ていない物（天窓・縁側・二室一室・大臣の定める緩和、換気設備の基準）、合否の判定ではない事を書く。

## 出し方

- 表の窓：「採光・換気」のタブ（7つ目）。「この表を CSV に保存...」で CSV にもなる。居室の区分を入れた室が無い時は、その旨を注に出す。
- 表だけの紙：AI の `export_schedule` の `table: "daylight"`（DXF・JWW）。
- 図面に並べる：`export_drawing` の `tables` に `daylight`。
- 図面一式：居室の区分を入れた室がある時だけ、表の紙として入る（図面一式の表は 0〜4 番と、この 6 番）。
