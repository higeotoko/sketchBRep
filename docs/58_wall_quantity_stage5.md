# 壁量の指定と比較（段階5）

ツール → **木造の壁量...**。在来軸組の1〜2階について、指定した耐力壁の存在壁量と、
入力した荷重・面積による必要壁量を比較する。意匠・概略の検討用。
建物全体の安全、法令適合、施工できることの判定ではない。

## 入力と操作

1. 建物の高さm、C0の区域指定、地域の風係数cm/m²、入力の根拠を記入する。
   同梱表ではC0は通常0.2／指定区域0.3、風は通常50／強風の指定区域は行政庁が定めた50超75以下。
   区域は自動判別しない。未確認のままなら未評価。
2. 「階と荷重」で下階から上階の順に階を追加する。
   算定用床面積m²、当該階から上を含めた累積荷重Σwi（kN）、X/Y方向の控除後の風見付面積m²を入力する。
   物置等の小屋裏面積、太陽光設備、積載荷重、多雪区域の積雪等は別途算定する。
   風見付面積はその階から上の鉛直投影から、その階床上1.35m以下の部分を除いたもの。
3. 「耐力壁の指定」で世界XY座標mmの区間を入れるか、「通り芯から区間を追加」で通りの交点を指定する。
   X/Yは抵抗する水平力の方向。通り芯参照は通りの移動・間隔変更に追従し、参照の削除は未評価になる。
   傾いた通り芯や、世界X/Yに平行でない壁は未評価。手動座標はモデルの形状とは独立した設計指定。
4. 壁の仕様を選び、筋かいは横架材上端間の高さmmを入力する。
   仕様欄のツールチップと木造の手引きに施工・断面・接合の条件を表示する。
   条件を確認してから「仕様確認」、その階の壁が揃ってから「壁入力完了」をチェックする。
   見えている筋かいや壁の形から、仕様確認済みと推測しない。
5. 「入力をモデルに保存」で既存のUndo履歴に1回の変更として記録する。
   `.sbr`への保存は通常のファイル保存。閉じるだけでは入力の編集はモデルに反映しない。
   「比較表CSV」は編集中の入力による比較表も保存できる。

画面を開いている間にモデルが編集・Undo等で変わったら、古い比較結果を消し、保存とCSV出力を拒否する。
「モデルから再読込」で最新の入力と通り芯を取得する。その際、編集中の未保存入力は破棄する。
係数表または壁仕様を切り替えたら、各壁の仕様確認をやり直す。

## 同梱表と計算

`assets/construction/timber/wall_tables.json` が原本。
[国交省の掲載ページ](https://www.mlit.go.jp/jutakukentiku/build/jutakukentiku_house_tk_000166.html)と、
[令和6年告示447号](https://www.mlit.go.jp/common/001746169.pdf)、
[補足資料](https://www.mlit.go.jp/jutakukentiku/build/content/001753667.pdf)を照合した。
施行日は2025-04-01、表の確認日は2026-11-04。出典・版・施行日・確認日・正誤表の扱いを表に持つ。

- 必要壁量（地震）：床面積当たり `Lw = Ai × C0 × Σwi / (0.0196 × Afi)`（cm/m²）、
  必要壁量mは `Lw × Afi / 100`。
- `Ai = 1 + (1/√αi − αi) × 2T/(1+3T)`、`T = 0.03 × 建物高さm`。
  `αi` はその階の累積荷重／最下階の累積荷重。上階の累積荷重が下階より大きければ未評価。
- 必要壁量（風）：控除後の方向別見付面積 × 地域の風係数 / 100（m）。
- 地震・風の両方が分かるときだけ、大きい方を必要壁量にする。片方が不明なら必要壁量も未評価。
- 存在壁量：確認済みの壁ごとの水平区間長m × 壁倍率を階・方向別に合計する。
  同じ線上で区間が重なる壁は、逆向き・別の仕様でも双方を未評価にして二重計上を避ける。
  異なる階は別扱い。隣接して端点だけを共有する壁は重複ではない。
- 筋かい30×90、45×90、90角の片掛けは1.5、2、3。45×90のたすき掛けは4。
  横架材上端間の高さが3200mm超なら `min(1,3.5×柱間距離/高さ)` を乗じる。
- 告示別表第二(三)の合板仕様は2.5。単に「9mm合板」という名前ではなく、原典のJAS・くぎ・間隔・
  全周直接打付け・屋外等の条件を含む仕様IDで指定する。
- 存在壁量 ≥ 必要壁量なら「合格（壁量比較のみ）」、不足なら不適合。
  比較の数値誤差として1e-10mを許容する。寸法丸めや表示の小数桁で判定しない。

これは建築基準法の告示に基づく算定式で、住宅性能表示の等級判定とは別。
地域係数Zや耐震等級の倍率を黙って追加しない。
「軽い屋根／重い屋根」の旧必要壁量表は同梱しない。
準耐力壁・垂れ壁・腰壁、組合せ壁、斜め壁、四分割法、N値、柱頭柱脚、断面、基礎は未評価。
未確認の係数は0で埋めない。手動指定と現物・実形状の一致は自動検証しない。

## 版の保存と出力

モデルへの入力保存時に、係数表全体を `DocumentSettings.wallCalculation` のJSONへ写して保存する。
同梱表が更新されても、保存済みプロジェクトはその写しを使う。
利用者は現在の同梱版へ明示的に切り替えるか、出典付きの独自表をJSONで登録できる。
元の同梱表は書き換えない。表を外すと「未評価：必要壁量の表がありません」。

計算結果、画面、CSV、架構チェックのLAT-01、図面注記に、根拠・版・施行日・表の確認日を出す。
確認日から365日を超えると注意を強めるが、計算は止めない。
計算日より後の施行日・確認日の表は、その日付の比較では未評価にする。
図面は形状の図なので、壁量の合否は書き込まず、根拠の日付と「別の壁量表を参照」を記載する。
図面のタグ・表示範囲と壁量入力の対象範囲は別である。

## AI / CLI

`get_construction_guide {system:"timber"}` の `wall_tables` が現在の同梱表と条件。
保存済みの表は `check_wall_quantity` の `table_snapshot` で確認する。

```json
{"command":"set_wall_calculation","args":{"inputs":{"height_m":6,"co_designated":false,"wind_coefficient_cm_m2":50,"input_basis":"別途算定した荷重・面積と区域の確認記録","floors":[{"id":"1","name":"1階","area_m2":50,"weight_kn":98,"wind_x_m2":30,"wind_y_m2":6,"walls_complete":true}],"walls":[{"id":"W1","floor":"1","direction":"X","start":[0,0],"end":[910,0],"height_mm":3000,"spec":"brace_45x90","verified":false}]}}}
{"command":"check_wall_quantity","args":{"include_csv":true}}
```

上は操作説明の仮想入力で、建物の荷重や壁配置の推奨値ではない。
`check_wall_quantity` は読み取り専用で、入力・表・壁内訳・階方向別の比較・未評価理由・revisionを返す。
`inputs` を渡せば未保存の案を比較できる。`set_wall_calculation` はモデルの変更でUndoできる。
`table_snapshot` は省略時に現在の同梱表、nullで表なし、オブジェクトで独自表。
独自表は同じ計算法の形で、source、normative、version、method、basis、effective_from、checked_on、errata、entriesが必要。
`earthquake`／`wind` をnullにすると、その必要壁量を未評価にできる。
通り芯は `grid` と `start_axes`／`end_axes`（各 `[X通りID,Y通りID]`）で参照できる。
`frame` で入力の対象架構を記録でき、架構チェックで異なる対象を指定した場合は未評価にする。

インストーラー2ステップの `if: false` と `packaging/installer/SketchBRep.iss` の保持は継続する。
