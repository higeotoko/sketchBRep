# SketchUp とのやり取り（COLLADA .dae）（2026-11-01 JST）

SketchUp の .skp を直接読み書きするには、Trimble の SDK（登録と規約への同意が必要、Windows・Mac 専用）が要る。そのため、先に **COLLADA（.dae）** でのやり取りを作った。

.dae は SketchUp Pro が読み書きできる形式なので、SketchUp 側で1手間かけて行き来する。

## 使い方

| やりたいこと | 操作 |
|---|---|
| SketchBRep → SketchUp | SketchBRep で「ファイル > エクスポート」→ 形式「COLLADA・SketchUp 用 (*.dae)」<br>SketchUp で「ファイル > インポート」→ .dae を選ぶ<br>インポートのオプションで「同一平面の面を結合」をオンにすると、三角形が元の面に戻る |
| SketchUp → SketchBRep | SketchUp で「ファイル > エクスポート > 3D モデル」→ COLLADA (.dae)<br>SketchBRep で「ファイル > インポート」→ .dae を選ぶ |

- 選んでいる物があれば、それだけを書き出す。何も選んでいなければ、見えている物を全部書き出す。
- AI からは `export_dae` / `import_dae` で同じことができる。

## 何が行き来するか

| 内容 | 書き出し（→ SketchUp） | 読み込み（SketchUp →） |
|---|---|---|
| 形 | 三角形の集まり（角は共有）。円柱などの曲面は、約15°ごとの平らな面に分ける | 三角形・多角形を読み、同じ平面の三角形を元の面に結合する。閉じた形は立体（ソリッド）になる |
| 線 | 単独の線・円弧・曲線は、線分として書き出す | 線は線として読み込む |
| 色 | 物ごとの色と、面ごとに塗った色。透明度も書き出す | マテリアルの色を、物の色と面ごとの色にする |
| 単位・向き | mm、Z が上 | ファイルの単位（SketchUp はインチ）を mm に、Y が上のファイルは Z が上に直す |
| グループ・コンポーネント | 物ごとに1つの塊 | コンポーネントは置いてある場所ごとに、別々の物として読み込む（コンポーネントとしてのつながりは残らない） |
| テクスチャ | 書き出さない（色だけ） | そのマテリアルの色（無ければ灰色）で表示し、数を報告する |

- 読み込みは Undo 1回で取り消せる。
- 読み込んだ物は「読み込んだ形」として入る。プッシュプルなど、ふつうの編集はそのままできる。

## 実装で決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 方式 | 外部のライブラリを使わず、XML を読み書きする部分を自前で作った | 依存を増やさず、Linux のテストと Windows の CI の両方で同じように動かすため |
| 書き出しの面 | 三角形の角を共有させる | SketchUp が三角形を辺でつなぎ、「同一平面の面を結合」で元の面に戻せるように |
| 曲面の細かさ | 面からのずれ 1 mm 以内、角度 約15°（AI からは変えられる） | SketchUp の円の標準（24分割）と同じくらいにするため |
| 読み込みの面の結合 | 三角形を辺で縫い合わせ、同じ平面のものを1枚の面にする。閉じていれば立体にする | SketchUp の面に近い形で編集できるように |
| 色の対応 | 結合した面ごとに、いちばん広く占める色を、その面の色にする | 1枚の面に色が混ざる時の決め方 |
| 名前 | ノードの名前。コンポーネントは定義の名前 | SketchUp で付けた名前が分かるように |

## まだやっていないこと

- .skp を直接読み書きすること（公式 SDK が必要。SDK の入手と規約の確認が済んだら取りかかれる）。
- コンポーネントのつながりやタグ（レイヤ）を残すこと。
- テクスチャ（画像）とその貼り方の向き。
- 大きなモデル（三角形が数万以上）の読み込みは時間がかかる。面を縫い合わせて結合する処理が重いため。
- Windows 実機の SketchUp Pro での確認（これから）。
