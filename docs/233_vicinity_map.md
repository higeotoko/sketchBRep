# 233. 付近見取図（国土地理院の地図タイルから）（2026-11-21）

docs/209・214・231・232 の「まだ」の「付近見取図（地図の背景）」。オーナーの選択（2026-11-21）：**アプリが地理院タイルを取る**（ほかの案：人が用意した画像を敷く・地図なしの略図・後回し）。

## 地図の使い方の決まり（調べた物、2026-11-21）

- 国土地理院「地理院タイル一覧」（`https://maps.gsi.go.jp/development/ichiran.html`）：
  - 標準地図（`std`）・淡色地図（`pale`）のズーム 12〜18 は**基本測量成果**（名称：電子地形図（タイル））。「基本測量成果となっているタイルを利用する際には、測量法に基づく申請が必要な場合があります」。同じページに「ウェブサイトやソフトウェア等でリアルタイムに読み込んで利用する場合は出典の明示のみで申請不要」ともある。どの使い方で申請が要るかの個別の記載は無い。
  - 写真（`seamlessphoto`）のズーム 14〜18 は「基本測量成果以外」（出典の明示のみ）。
  - タイルの URL：`https://cyberjapandata.gsi.go.jp/xyz/{std|pale}/{z}/{x}/{y}.png`、`.../seamlessphoto/{z}/{x}/{y}.jpg`。
- 国土地理院「出典の明示」（`https://www.gsi.go.jp/LAW/2930-meizi.html`）：申請不要でも出典を書く。編集・加工した時は、出典とは別にそのことを書く（例「地理院タイルに○○を追記して掲載」）。国土地理院が作ったように見せない。
- → **図面として使う時に申請が要るかは、人が国土地理院「地図の利用手続」で確かめる**。紙にもそう書く。

## 作り

### 位置（文書の設定 `vicinityMap`、保存・Undo 1 回）
- 緯度・経度（世界測地系の度。日本の範囲：緯度 20〜46・経度 122〜154）、ズーム（14〜18、既定 16）、地図（標準地図・淡色地図・写真）。
- 画面：「敷地 > 付近見取図の位置...」。「付近見取図を作らない」ボタンで消す。ダイアログに「敷地の位置が国土地理院のサーバーに送られる」「標準地図・淡色地図は基本測量成果、申請の要否は地図の利用手続で」と書いた。
- AI：`set_vicinity_map`（`lat`・`lon`・`zoom`・`layer`、`clear`）。返り値にタイルの URL と出典。**住所から位置を調べない**（人が言った位置だけ）と説明に書いた。

### タイル（`doc::vicinityTiles`、コア）
- 敷地を含むタイルを真ん中にした 3 × 3 枚（256 px）。Web メルカトル（地理院タイルの切り方）で、敷地が絵のどこに来るか（px）と、そこでの 1 px の地上の長さを出す。
- コアは通信しない。

### 取る（`app::fetchVicinityPicture`、画面のアプリ）
- 図面一式を書き出す時（「ファイル → 図面一式を書き出す」）に、位置があれば取る。
- まずキャッシュ（ユーザーのキャッシュフォルダ `/gsi-tiles/<地図>/<z>/<x>/<y>.<拡張子>`）を見て、無ければ国土地理院から取ってキャッシュに残す（1 枚 15 秒で打ち切り、User-Agent は「SketchBRep」）。
- 取れなかったタイルは灰色。状態の行に「地図タイル：取得 n・キャッシュ n・取れなかった物 n」。
- 環境変数：`SBR_TILE_CACHE`（キャッシュの場所）、`SBR_TILES_OFFLINE`（通信しない。テスト用）。

### 紙（図面一式の 3 枚目、計画概要の次）
- 「付近見取図」：地図の絵（北が上）、敷地の丸（紙で半径 4 mm）と「敷地」の字、地図の枠、方位（真北。「仮」は付けない）。
- 縮尺：絵が紙で 200 × 140 mm 以内に入るいちばん大きい縮尺を、1:1000・1500・2000・2500・3000・5000・7500・10000・15000・20000・25000 から選ぶ（ズーム 16・北緯 35 度なら 1:15000）。用紙は自動。
- 図の注（左上）：
  - 「出典：国土地理院「地理院タイル」（淡色地図）https://maps.gsi.go.jp/development/ichiran.html」
  - 「地理院タイルに敷地の位置・方位を追記して掲載（国土地理院が作成したものではありません）」
  - 標準地図・淡色地図の時：「この地理院タイルは基本測量成果（名称：電子地形図（タイル））です。図面として使う時の申請の要否は、国土地理院「地図の利用手続」で確かめてください」
  - 中心の緯度・経度・ズーム、取れなかったタイルの数。
- 地図の絵が無い時（AI・コマンドからの図面一式）：枠と「地図は、画面の「図面一式を書き出す」で国土地理院の地図タイルから入ります」。
- 絵は画面と PDF に出る。**DXF・JWW・LayOut には絵を書かない**（枠・印・字だけ）。そのために図面の部品に「絵」（`Item::Kind::Image`、RGBA の画素）を足した。

## 追記：ZIP に Qt の TLS 部品を入れた（2026-11-21）

- `a0d88c9` の ZIP を見ると、`Qt6Network.dll` はあるが **TLS の部品（`tls/qschannelbackend.dll` など）が無かった**。これでは実機で HTTPS の地図タイルが取れず、地図は灰色になる（開発用のビルドは Qt の置き場の部品を使うので、テストでは気づかない）。
- ZIP を作る時（`tools/package_windows_local.py` の `--qt-plugin`、`sbr.py package` がビルドの Qt から渡す）に、`tls/qschannelbackend.dll`（Windows の Schannel を使う。OpenSSL は要らない）を足すようにした。承認済みのランタイムのフォルダは変えていない。Qt の一部なので、ライセンスは今ある Qt の物。BUILD_INFO.json の `qt_plugins` に書く。
- 本物のタイルを取る GUI テスト `vicinityMapFetchedOnline` を足した（`SBR_TILES_ONLINE` を付けた時だけ動く。CI では飛ばす）。ローカルで動かし、北緯 35.681236・東経 139.767125（東京駅あたりの見本）・淡色地図の 9 枚を HTTPS で取れた（取得 9）。2 回目はキャッシュ 9。
