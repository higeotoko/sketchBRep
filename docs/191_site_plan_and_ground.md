# 敷地と配置図（検討用）

真北、敷地境界、道路情報、接地外周を SBR に保存して、平面図や配置図に反映する。モデル内の情報を図面と表に反映する操作に対応する（docs/90 B-05・B-07）。

## 設定と出力

1. **表示 → 敷地の真北**で、平面の2点またはモデルの＋Yから時計回りの角度を指定し、確認資料を入力する。真北は平面図・配置図の北矢印と太陽設定に反映する。
2. 敷地の閉じた水平の折れ線か水平面を選び、**ファイル → 敷地・配置図 → 選択した輪郭を敷地境界に指定**で確認資料を入力する。配置図は指定輪郭の面積と建物の上面投影を表示する。
3. **道路・接道情報**では道路側の境界を1辺選び、種別・根拠・幅員・接道長を記入する。道路側境界から建物上面投影までの最短距離を参考表示する。
4. 接地外周を選んで **建物の接地外周・高さ** を開く。基準点・確認資料と各測点高（mm）を入力する。図で P 番号を選ぶと対応する高さ欄が編集でき、表の選択も図へ反映される。
5. **配置図をプレビュー**から PDF・DXF に出力できる。敷地境界を指定したモデルでは図面一式にも配置図が入る。

## コマンド

- `set_site_boundary` は `outline` と `source` で敷地境界を設定する。`outline: null` で解除する。
- `set_site_road` は境界辺の `start`・`end`（ワールド座標、mm）、`source` と、必要に応じて `kind`・`width_m`・`frontage_m` を保存する。
- `set_site_ground` は `outline`・`datum`・`source`・`samples` を保存する。測点は外周順の `[ワールドX, ワールドY, 基準点からの高さ]`（mm）。閉じる始点の再掲は不要。道路と接地外周はそれぞれ `clear: true` で解除できる。
- `export_drawing` の `kind: "site"` で配置図を出力する。

## 計算の範囲

各辺では両端高の平均を辺の高さとして扱う。参考平均高は「水平長×平均高」の合計を外周の水平長の合計で割った値。配置図では、図上の P 番号と辺別計算表を対応させる。

道路側境界からの参考距離は、図面に表示する建物の投影線から求める。直線と円弧はそのまま使い、それ以外の曲線は図面と同じ許容差で折れ線に近似する。

接地輪郭と保存した測点が一致しないときは要確認となる。建物だけを動かした場合は、接地輪郭と測点の再照合が必要。法令上の地盤面、高低差による区分と、道路・接道の適合性は未評価。
