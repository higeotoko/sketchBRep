# 建具の種類をまとめて変える（N-08 の第 1 段、2026-11-16）

[docs/97](97_bim_gaps_and_priority.md) の N-08（種類の一覧：種類を直すと使っている全部が変わる）の第 1 段。建具から。作業は Opus 5.5。
オーナーの指示：2026-11-15（「続けて」）。

## できること

| 項目 | 内容 |
|---|---|
| 種類とは | 建具表の**符号**（AW-1 など手で付けた物、または W1・D1 など自動で付いた物）が同じ開口を、1 つの種類とする |
| 画面から | 開口の穴の面を選ぶ（プロパティが「開口 n」だけになる）→ 同じ符号の開口がほかにあれば「同じ符号（AW-1）のほか n 個を、これと同じ大きさ・建具・品番にする」ボタン。押すと、どの壁の同じ符号の開口も、選んだ開口の幅・高さ・建具・品番になる |
| AI から | `change_opening_type {mark, width, height, fitting, product}`（与えた物だけ変える）、または `{like: {host, opening}}`（その開口に揃える）。返り値は変えた数 |
| 変わらない物 | 位置（中心）と腰高。手で付けた符号はそのまま。自動の符号は、大きさ・建具が変わると付け直される（同じ種類なので、まとまったまま） |
| 断る時 | 1 つでも壁に入らない・ほかの開口と重なる時は、全部やめる（何も変わらない）。その符号の開口が無い時 |
| 取り消し | 1 回 |

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 種類の持ち方 | 新しい「種類の一覧」を作らず、**符号**を種類にした | 建具表がもう符号でまとめている。種類の入れ物を別に持つと、建具表とずれる所ができる |
| 使い方 | 1 つを直してから「揃える」 | 手で 1 つを直すと、手で付けた符号の種類は建具表で「混ざっている」と出る（docs/109）。そこからボタン 1 つで揃う |

## まだやっていないこと

- 床（スラブ）・屋根の種類（N-08 の残り）。
- 種類を名前で登録して、新しい開口をその種類で作ること。
- 建具表の窓から、種類の行を選んで直すこと（今は開口を選んでボタン、または AI）。
