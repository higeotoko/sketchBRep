| 区分 | 確かめ方 |

| A. 自動テストにする | クラウドで自動テストを書く。Linux と Windows の CI で、毎回確かめる |

## Windows の CI でも画面のテストを回す

- これまで Windows の CI では、計算のテストしか回していなかった。今回から、画面の自動テストも回す。対象は gui ラベルのテスト（約190本）。
- Windows の CI 用マシンには GPU がない。そのため、Mesa というソフトで OpenGL（3D表示）を動かす。版は 26.2.3（llvmpipe）で、テストのプログラムの横に置く。
- 画面テストは、zip を作ってアップロードした後に回す。画面テストが失敗しても、zip は受け取れる。
