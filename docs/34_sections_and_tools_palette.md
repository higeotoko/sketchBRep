# 断面表示とツールパレット

## 断面を配置する

1. 「断面」ツール（Shift+S）で、切る向きの基準になる面をクリックします。
2. 半透明の青い平面を見ながら奥行きを決め、クリックまたは数値入力で確定します。
3. 「表示 → 断面 → 保存済み断面」から各断面を操作できます。

配置中と配置後に平面の位置を示します。表示用の平面はモデルの大きさに合わせ、モデルの選択・スナップの対象にはしません。モデル自体を切断・削除する処理ではありません。

## 保存と切り替え

- 複数の断面を作成し、名前を付けて保持できます。SBRファイルを保存すると、断面の位置・向き・名前・カット状態・平面の表示状態も保存されます。
- 保存済み断面の「この断面でカット」で切り替えます。有効なカットはモデル全体で1つです。
- 「断面平面を表示」は平面の目印だけを表示／非表示にします。目印を消してもカットは維持できます。
- 平面の目印は一括表示／非表示もできます。
- 「位置を移動」は法線方向の移動量をmmで指定します。「カット方向を反転」で残す側を入れ替えます。
- 名前変更、移動、反転、表示変更、削除はUndo/Redoに対応します。
- 従来の「断面で切って表示」は、OFFでカットを停止し、ONで最新の断面を再開します。特定の断面に戻す場合は保存済み断面から選びます。

既存のSBRファイルに平面表示の設定がない場合は、平面を表示する状態で読み込みます。STEP/STLなどの形状書き出しに表示用平面やカットは含めません。

SketchUpを参考にした基本操作です。断面平面を直接選択してドラッグ移動・回転する操作、グループ別の同時カット、断面アニメーション、断面線の2D書き出しは今回の実装には含みません。

## ツールパレット

従来の縦一列のツールバーを、タイトルバー付きのドックパネルに変更しました。

- 全25ツールを3列に並べ、オーバーフローのポップアップに隠しません。縦に収まらない場合はスクロールできます。
- 「表示 → ツールパレットを全表示（名前付き）」で名前付き表示／アイコンのみを切り替えられます。
- パレット上部のタイトルバーをドラッグすると独立したウィンドウになります。タイトルバーのダブルクリックでも切り替えられます。
- メインウィンドウの端にドラッグして戻せます。閉じた場合は表示メニューから再表示できます。
- 名前付き表示の設定、フロート状態、フロート時の位置とサイズは次回起動時に復元します。

MCP通信・認証・モデル編集APIの変更はありません。

## 検証

ローカル（Qt 6.8.2 / OCCT 7.8.1）でCore 349件成功、任意ベンチマーク4件スキップ。断面カット・平面表示の独立切り替え・選択の維持・配置・SBR再読込・パレット全25ツールとフロートを検証したGUIテストは6件成功（初期化・終了を含む）。既存HTTP MCP・stdio MCPのCTest 3件も成功。断面・パレットの描画画像も確認。

名前付きパレットで表示領域の幅が変わるため、GUIの共通テスト環境は作図領域の幅を840pxに固定。従来ツールバーとの比較で、固定ウィンドウ幅では座標丸めによって作図テストのクリック対象が変わることを確認しました。影響した数値作図・フォローミー・接線円弧と新機能の再検証は9件成功。テストの期待値やスナップ処理自体は変更していません。
