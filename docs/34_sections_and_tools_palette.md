# 断面とツールパレット

## 断面パレット：4つのボタン

「表示 → 断面」または断面ツール（Shift+S）から操作します。断面ツールを選ぶと、小さな「断面」パレットが開きます。

| ボタン（左から） | 操作 |
| --- | --- |
| 断面平面を配置 | 基準の面をクリックし、奥行きをクリックまたは数値入力で確定 |
| 断面平面を表示 | 位置を示す半透明の平面・破線枠だけを表示／非表示 |
| 断面カットを表示 | 選んだ断面で切って表示／通常表示。OFFでも選んだ断面は保持 |
| 断面塗りつぶしを表示 | 切り口のふたを表示／非表示。カットと平面の表示はそのまま |

**切った中を、目印やふたに遮られずに見る場合：平面OFF・カットON・塗りつぶしOFF。**

切り口を塗りつぶした断面図を見る場合は、平面OFF・カットON・塗りつぶしONにします。カットをOFFにすれば元のモデル表示に戻ります。

3つの表示スイッチは独立しています。個別に非表示にした断面平面は、全体の平面表示をONにしても非表示のままです。保存済み断面のメニューで個別に表示できます。

## 配置中の挙動

- 配置中は半透明の平面で位置を確認できます。
- 配置を確定したら選択ツールに戻ります。通常のクリックで次の断面を置き続けることを防ぎます。
- 配置中に表示ボタンを切り替えた場合も、未確定のプレビューは消えます。Escでも中止できます。
- 確定後の平面は薄い色と破線枠で示し、モデルの選択・スナップの対象にしません。
- パレットは上部をドラッグして移動・ドックできます。閉じても表示スイッチの状態は変わりません。「表示 → 断面」からも同じ操作ができ、表示メニューの「断面」でパレットを再表示できます。

## 保存済み断面

「表示 → 断面 → 保存済み断面」から、名前変更、法線方向への移動、カット方向の反転、削除、使用する断面の切り替えができます。

- SBR保存時に、断面の位置・向き・名前・個別の表示状態と、3つの表示スイッチを保存します。
- カット表示をOFF→ONにしても、最後に追加した断面ではなく、選んでいた断面に戻ります。
- 表示変更、移動、反転、削除などはUndo/Redoに対応します。
- 同時に有効なカットはモデル全体で1つです。
- 表示上のカットです。元の形状を削除せず、STEP/STLなどの形状書き出しにも表示用平面やカットは含めません。

グループごとの多重カット、断面アニメーション、断面線の2D書き出し、平面の直接ドラッグ移動・回転は今回の範囲に含みません。

## 軽さを保つための処理

3つのスイッチは、表示用平面の表示／非表示と、既存の描画用クリップ・切り口塗りつぶしを切り替えます。モデルをブーリアン演算で切断し直す処理は追加していません。

- 断面だけの設定変更では、全オブジェクトの表示を無効化しません。
- 平面の表示用形状とモデル範囲は再利用します。単にスイッチを切り替えるだけでは再生成・再計算しません。
- 平面を隠している間は、モデルが変わっても平面用の範囲計算を後回しにします。
- タグによるモデルの表示変更では、従来どおり必要な再表示を行います。

## SketchUpとの照合

確認日：2026年10月28日。ユーザー提供の断面パレット画像と、SketchUp公式API文書を照合しました。

- [RenderingOptions（SketchUp公式）](https://ruby.sketchup.com/Sketchup/RenderingOptions.html)：`DisplaySectionPlanes`、`DisplaySectionCuts`、`SectionCutFilled`が別々の表示オプション。
- [SectionPlane（SketchUp公式）](https://ruby.sketchup.com/Sketchup/SectionPlane.html)：`activate` / `active?`による使用する断面の指定。表示スイッチと断面の選択を分ける根拠。
- 公式サイト本文は本環境から403で取得できなかったため、公式が公開している[同じAPI文書のソース](https://github.com/SketchUp/ruby-api-docs/tree/gh-pages/Sketchup)のRenderingOptions.htmlとSectionPlane.htmlを取得して確認しました。

基本の表示スイッチをSketchUpに合わせたものです。すべてのSketchUp操作の互換実装ではありません。配置後の自動選択復帰などは、SketchBRepでの誤操作を防ぐための挙動です。

## 通常のツールパレット

全25ツールを3列に並べ、オーバーフローのポップアップに隠しません。縦に収まらない場合はスクロールできます。

- 「表示 → ツールパレットを全表示（名前付き）」で名前付き表示／アイコンのみを切り替え。
- パレット上部のタイトルバーをドラッグ、またはダブルクリックして独立表示。ウィンドウの端に戻してドック。
- 閉じた場合は表示メニューから再表示。
- 名前付き表示の設定とフロート時の位置・サイズを次回起動時に復元。

MCP通信・認証・モデル編集APIの変更はありません。

## 検証結果（クラウドLinux）

Qt 6.8.2 / OCCT 7.8.1 / Xvfbで、Core350件成功、任意ベンチ4件スキップ。断面の配置、未確定プレビューの非表示、各表示スイッチ、保存済み断面の有効化・Undo/Redoなどを検証するGUIテスト6件（初期化・終了を含む）と、既存MCPのCTest3件が成功しました。

通常ケースの240回の状態変更は約0.85秒。提供された20MBのDXFから対応曲線要素約3.6万を141レイヤーオブジェクトとして部分取り込みしたケースでは約1.5秒でした。いずれもスイッチ切り替えによる平面再生成・範囲再計算は0回です。取り込み・初回描画を除いた切り替えの計測値で、端末ごとの描画性能を保証する数値ではありません。

GUI全体のローカル確認では147成功・7スキップ・従来の環境固有の失敗3件（OCCT 7.8.1でのtopEdgesCopiedDownDivideTheSides、moveToolLiftsRidgeIntoGableと、回復ファイル保存先の制約によるautosaveWritesInTheBackground）。最終確認はLinux/Windows CIでも行います。
