# レベル（GL・FL）と、立面での通り芯（2026-11-01 JST）

立面で GL や 1FL の線を引きたい、という話から作った。ARCHICAD の階と Revit のレベルを参考にしている。

方針は「**増やすのは見える基準線だけ**」。階を切り替えて描くモードは作らない。描き方・選び方・動かし方・スナップは、今までのまま。

## できること

| やりたいこと | 操作 |
|---|---|
| レベルを作る・直す | ツール > レベル（GL・FL）を編集...<br>名前と高さの表で、追加・削除・高さの変更・名前の変更ができる。初めて開いた時は、GL 0、1FL 150、2FL 3150 が入っている（そのまま OK でも、直してからでもいい）。「レベルを追加」は、一番上の1つ上（2FL → 3FL、+3000）を足す |
| ガイド線からレベルを作る | 立面でメジャーを使って横のガイド線を引く → 右クリック →「このガイド線をレベルにする...」→ 名前を入れる<br>レベルができ、ガイド線は消える。Undo 1回で元に戻る |
| 立面で見る | レベルは横の一点鎖線と「▽2FL 3300 mm」で出る。正面に向いた通り芯（正面・背面なら X1、X2…、右・左なら Y1、Y2…）は、縦の一点鎖線と、上の端の名前で出る。どれにも吸着できる |
| 平面でその高さに描く | 平面の「作業面 ▾」に、レベルが並ぶ。2FL を選ぶと、2階の床の高さで描ける |
| 柱・梁をレベルの間に置く | 通り芯を右クリック →「通り芯に柱・梁を配置...」で、柱の下端と上端のレベルを選ぶ（梁は上端のレベルに置く）。<br>レベルがある時は、いちばん下の階（1FL〜2FL）が最初から選ばれている。数値での指定もそのまま使える |
| 階高を変える | レベルの表で 2FL の高さを変えると、2FL に置いた柱の上端と梁が一緒に上下する。1FL に置いた柱の足元はそのまま。Undo 1回で全部戻る |

- 立面のときは、地面に寝ている通り芯の線・名前・寸法は出さない（立面では1か所に重なって読めないため）。平面と 3D では今までどおり出る。
- 手で描いた物はレベルに縛られない。レベルに付いていくのは「通り芯に柱・梁を配置」でレベルを選んで置いた物だけ（docs/42 の追従と同じ「頼んだ物だけ」）。
- レベルを表から消すと、そのレベルに付いていた柱・梁は、その場に残る。
- 通り芯を動かした時も、今までどおり柱・梁が付いてくる。高さはレベルのまま。
- AI からは `get_levels`、`set_levels`、`place_members_on_grid` の `base_level` / `top_level` で同じことができる。`get_object` の `grid_pin.levels` で、どのレベルに付いているかが分かる。

### 柱・梁の断面（2026-11-01）

- 「通り芯に柱・梁を配置...」の画面に、「柱の断面を変更...」「梁の断面を変更...」のボタンを付けた。部材の設定画面（鋼材カタログの検索も使える）が開く。選んだ断面は部材パネルの「柱」「梁」の設定として残るので、次に配置する時もそのまま使える。
  - 前は、部材パネルの「柱」「梁」の設定（初期は 105×105 の角材）がそのまま使われ、配置画面からは変えられなかった。
- 置いた後でも変えられる。柱や梁を選んで（複数でもいい）右クリック →「部材の断面を変更...」。選んだ部材がまとめて同じ断面になる。Undo 1回で戻る。通り芯・レベルへの付き方はそのまま。
- AI からは `change_member` の `section` で、断面を丸ごと替えられる。

## 実装で決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| レベルの持ち方 | ファイルの設定（断面やタグの表示と同じ所）に、名前・高さ・変わらない id の一覧で持つ。保存され、Undo の対象 | 物（オブジェクト）にしないので、平面や 3D の邪魔にならない。名前を変えても、柱・梁の付き方が外れない |
| 立面での表示 | 表示だけで作る。物としては増やさない。立面で固定した時だけ出す | 平面・3D では見えない方が描きやすい。表示の都合で物の数が増えない |
| 立面の通り芯 | 通り芯の線のうち、正面に向いたものを、縦の線にして出す。長さは、地面・レベル・モデルの高さに余白を足した範囲 | 立面図の通り芯と同じ見え方にするため |
| 部材の付き方 | 通り芯への固定（docs/43）に、両端のレベルを足した。レベルの高さが変わった分だけ、その端が上下する | 柱を手で伸ばした分や、手でずらした分を消さないため |
| 同じ物の二重配置 | 同じ交点でも、別の階（別のレベルの間）なら別の物として置ける | 2階の柱を、1階の柱と同じ通りに置けるように |

## まだやっていないこと

- 立面でレベルの線を直接ドラッグして高さを変えること。今は表で直す。
- 壁やスラブをレベルに付けること。
- 地下の階の名前の付け方（B1FL など）の初期値。表で自由に付けられる。
- 斜めの通りの立面での表示。
