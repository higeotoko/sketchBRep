# 315. 第五面 ニ（横架材間の垂直距離）をモデルから記入

docs/294 で確認申請書の第五面を階ごとに書き出したけど、「ニ．横架材間の垂直距離」は「様式に記入」のままだった。docs/310 で柱の横架材間の距離を求められるようになったので、第五面にも入れる。

## 求め方

- その階の床レベルの 1 m 下から、その階の上端までに真ん中がある柱の部分を見る。
  - 1階の柱は土台の上から立つので、床レベルより少し下から数える。
- その中で一番長い距離を入れる（`clearDistanceIn`）。
- 通し柱は、各階の床レベルで分けた部分ごとに見る。
- 値は、階の高さと同じ m 表記。
- その階に柱が無ければ空欄のまま。
- 申請書の書き出しの確認表では「転記（特定天井は様式に記入）」とし、横架材間の距離は記入済みとして扱う。

## 確認

- `Quantities.ClearDistanceOfTheColumnsInAStorey`：
  - 全部の高さで見ると、柱の表の最大の距離と同じになる。
  - 柱が無い高さでは空になる。
- 申請書の GUI テスト（`permitWord…`）が今までどおり通る。そのテストのモデルには柱が無いので、欄は空のまま。
