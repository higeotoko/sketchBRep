# 開口の符号を手で決める・品番を持つ（順位 7 の一部、2026-11-14〜15）

オーナーの指示：2026-11-14（「残りの Fable でこなせるものを優先して片付けて」）。

## できること

| 項目 | 内容 |
|---|---|
| 符号を手で決める | 開口に、自分の符号（例：AW-1）を付けられる。**開口を足す・大きさを変える・消す、をしても変わらない** |
| 品番 | 開口に品番を持てる。建具表と CSV の「品番」の列に出る |
| 表・平面・図面 | 手で決めた符号が、建具表・平面モードの札・図面の平面図に出る（同じ 1 つの計算から） |
| 残りの開口 | 今まで通り、種類・建具・幅・高さから付ける。**手で使われた番号は飛ばす**（W1 を手で使えば、次は W2 から） |
| 違う物が混ざった時 | 同じ符号を手で付けた開口の、種類・建具・大きさ・品番が違う時は、表の「注」に出す。**黙って合わせない**（行には、最初の 1 つの値が出る） |
| 元に戻す | 符号と品番を両方空にすると、計算で付ける符号に戻る |
| 入れ方 | 壁を選んで、プロパティの「開口」の各行の**符号**・**品番**の欄に入れる（何も入れていない時は、自動の符号がうすく出る）。AI からは `set_opening_mark {host, openings, mark, product}`。どちらも取り消し 1 回 |

## 持ち方

- 壁の属性 `opening_marks`（JSON：開口の id → `{mark, product}`）。建具（`opening_fittings`）と同じ持ち方なので、ほかの開口を消しても、付けた開口に付いたまま。
- 表は持たない（今まで通り、毎回モデルから読む）。

## まだやっていないこと

- 順位 7 の残り：開口だけを選ぶ、コピー、平面の記号をつかむ（設計は docs/106 の A）。
- 符号の頭文字を変える設定（AW・WD など）。材質・ガラス・金物の欄。姿図。
- IFC の窓・扉に、符号と品番を書くこと（`IfcExport.cpp` の `Tag` に入れるのが筋）。
