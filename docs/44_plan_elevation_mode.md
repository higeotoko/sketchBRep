# 平面・立面モード（平行投影で固定）（2026-10-30 JST）

Rhino の Top / Front / Right ビューのように、平面図・立面図の向きで画面を固定して描けるようにした。

前からあった機能は次の2つ。

- 「表示 > 平面 (上)」（F3）などの標準ビュー
- 「透視投影」の切り替え（F8）

ただ、これには困ることが2つあった。

- 中ボタンを少しドラッグしただけで画面が回ってしまう。
- 正面から見ていても、何もない所をクリックした点は地面（Z=0）に落ちる。正面図に描いたつもりが、地面の上に描かれてしまう。

## できること

| 操作 | 何が起きるか |
|---|---|
| 表示 > 平面・立面モード > 平面 / 正面 / 右側面 / 背面 / 左側面（Alt+1〜5） | その向きの平行投影で固定する |
| 画面右下の「3D｜平面｜正面｜右｜背面｜左」 | 押した向きで、すぐ固定する。いま固定している向きのボタンが押された状態で表示される。「3D」で固定を解く |
| 表示 > 平面・立面モード > 次の立面へ（Alt+→）／前の立面へ（Alt+←） | 4つの立面を、建物のまわりを回るように順番に切り替える（正面 → 右 → 背面 → 左 → 正面）。3D や平面からは正面になる |
| 固定中の中ボタンドラッグ | 回転せず、画面が移動する。ホイールでの拡大縮小はいつもどおり |
| 固定中に何もない所をクリック | 平面は地面（Z=0）、正面・背面は Y=0、右側面・左側面は X=0 の面の上に点が乗る。長方形・円・円弧・多角形・線も、その面の上に描ける |
| 物の面や角をクリック | いつもどおり、その面や点に吸着する |
| 固定中に別の向きを選ぶ（F3〜F7、または Alt+1〜5） | 固定したまま、その向きに切り替わる |
| 画面右下の「3D」を押す、Alt+0、またはアイソメ（F2） | 固定を解き、固定する前の投影（透視／平行）のアイソメに戻る |
| 透視投影をオンにする、保存したシーンを開く | 固定は解ける |

### 作業面の高さ・奥行き（2026-10-31）

固定中は、画面右下のボタンの横に「作業面: Z=0 ▾」のように、今の作業面を出す。押すと次のメニューが出る。

| メニュー | 何が起きるか |
|---|---|
| 高さを入力...（平面）／奥行きを入力...（立面） | 作業面をその位置へ移す。単位 m も使える。例：平面で 3000 → 2階の床の高さで描ける |
| 地面（Z=0）に戻す／原点（0）に戻す | 元の位置へ戻す |
| 通り芯（立面だけ） | その立面と平行な通りが並ぶ（正面・背面なら Y1、Y2…、右側面・左側面なら X1、X2…）。選ぶと、その通りの位置の立面で描ける。表示は「作業面: Y2 通り（Y=6000 mm）」 |

- 作業面は3つを別々に覚えている（平面の高さ、正面・背面の奥行き、右側面・左側面の奥行き）。正面と背面は同じ面を共有する。平面を 3000 にしても、立面の Y2 はそのまま。
- 3D に戻ると、何もない所の点は今までどおり地面に乗る。
- 作業面を移すと、描きかけの操作は取り消す。
- 物の点・線・面には、いつもどおり吸着する。立面では、奥の線と手前の線が重なって見える所（例：地面の高さの通り芯）をクリックすると、手前の線に吸着する。

- 立面での空と地面の境目を、地面の高さ（Z=0）に合わせた。平行投影の正面・側面では、地面の線が立面図の GL と同じ所に来る。

## 実装で決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 画面の数 | まずは1画面で切り替える | Rhino のような4分割は、3D表示を4つ同時に描き、どの画面でも同じツールが使えるようにする必要があって大がかりになる。先に、1画面でいちばん効く「固定」と「作業面」を入れた |
| 前からある F3〜F7 | 今までどおり固定しない（固定中に押した時だけ、固定したまま向きを変える） | 今の使い方を変えないため |
| 作業面の位置 | 原点を通る面（Y=0、X=0） | Rhino の標準の作業面と同じ。奥にある物の面をクリックすれば、その面に描ける |
| 向きを変えた時 | 描きかけの操作は取り消す | 前の向きで決めた作業面のまま、続きを描かないように |
| 立面の切り替え | 画面下のボタンで1回のクリック。Alt+←/→ で順番に回る | 4つの立面を行き来しやすくするため。矢印キーだけだと、線や長方形の向きの固定（→ ← ↑ ↓）とぶつかるので Alt を付けた |

## まだやっていないこと

- Rhino のような4分割表示（平面・正面・右側面・パース）。
- 作業面の位置は、ファイルには保存しない（開き直すと 0 に戻る）。
- 平面の高さを「階」から選ぶこと。今は数値で入力する（階の一覧はまだ持っていない）。
- 斜めの通りの立面。
- 壁・スラブ・部材ツールは平面で描く前提のまま。立面での描き方は変えていない。

## 検証

- **GUI**（`fixedElevationPansAndDrawsOnItsPlane`）
  - 正面で固定すると、平行投影になる。
  - 中ボタンのドラッグで、向きは変わらずに画面が移動する。実際のマウスのように細かく10回に分けて動かしても、動かした分だけ移動する（2026-10-31 修正。それまでは画面移動が「動き始めた所から」の計算になっていて、細かい動きが積み重ならず、画面が震えるだけで動かなかった。3D での Shift＋中ボタンの画面移動も同じ原因で、一緒に直った）。
  - 何もない所に描いた長方形が、Y=0 の立面に立つ。
  - 「3D に戻る」で、元の投影に戻る。
  - Alt+→ で 正面 → 右 → 背面 → 左 → 正面 と回り、Alt+← で戻る。右側面では作業面が X=0 になる。
  - 画面下の「背面」ボタンで固定でき、ボタンが押された状態になる。「3D」で戻る。
- **GUI**（`workPlaneAtAHeightOrAGridLine`）
  - 正面で通り芯の候補が Y1・Y2 の2つ出る。
  - Y2 を選ぶとボタンに「Y2」と出て、長方形が Y=6000 の立面に立つ。
  - 平面で高さ 3000 にすると、長方形が Z=3000 にできる。
  - 背面に切り替えると、正面と同じ Y=6000 が使われる。
  - 3D に戻すとボタンが消え、地面に戻る。
- 既存の空と地面のテスト（`skyAndGroundFollowTheHorizon`）も合格。
