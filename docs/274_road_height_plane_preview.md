# 274. 道路側の斜線と選択した部材を照合する（2026-11-24）

申請図の工程10「立面・断面」に「道路側の斜線試算」を追加する。高さの差と対象部材をひとつの画面で見て、そこからモデル上の部材を選択できる。B-05とB-09に沿い、画面とMCPは同じB-rep形状と計算を使う。

## 操作

1. 敷地境界を登録し、道路が接するまっすぐな敷地辺を「道路・接道情報」で登録する。
2. 照合したい部材をモデルで選ぶ。工程10の「道路側の斜線試算」を開く。
3. 照合する斜線について、敷地側の道路境界でのモデルZをmmで、勾配を水平1に対する上がりで入力する。高さは建物の後退を反映する前の値を使う。
4. 「試算」を押す。条件が厳しい部材が上に来る。行を選び「3Dで見る」を押すと、部材を選び、青い半透明の斜線面を建物と一緒に表示する。

## 数値の読み方

斜線は登録辺に平行で、敷地へ向かって上がる1枚の平面。選択した各部材で、部材の高さから同じ水平位置での斜線高さを引き、その最大値を求める。正の差なら超過、負の差なら余裕。画面には0.1 mm単位で表示する。B-repを斜線に合わせた座標に移して計測するので、屋根の高い端と道路に近い端が別の点でも、同じ位置どうしの鉛直差を求められる。

高さの起点と勾配は入力した値を使う。道路面との高低差、法令上の幅員・適用距離の決定、建物の後退距離の採否は未評価。適用範囲を調べる出発点は横浜市の案内とする。 [横浜市の高さ制限の案内](https://www.city.yokohama.lg.jp/business/bunyabetsu/kenchiku/annai/20140401121655.files/0139_20250328.pdf)

MCPの `compare_road_height_plane` は `ids`、`edge_height_mm`、`slope` を受け取り、部材名と鉛直差 `excess_mm` を返す。操作と試算はSBRに保存されない。登録した道路辺と選択した部材は、計算する時点の配置を読む。

3Dの青い面は敷地輪郭の内側に表示する。面をクリックしてもモデルの選択を邪魔しない。「表示 → 斜線の試算面を消す」で解除でき、モデルの編集時にも古い面を消す。

## 適用距離を入れた試算

直線で平行な道路を対象に、「採用する道路幅員」と「適用距離」（後退を入れない場合は道路の反対側の境界から測る）を両方入力できる。たとえば幅員6 m、適用距離9 mなら、敷地側の道路境界から奥へ3 mまでを青い面にする。適用端ちょうども含める。画面には両方の境界からの距離を出す。 [道路斜線の測り方（国土交通省）](https://www.mlit.go.jp/jutakukentiku/house/content/001894190.pdf)

範囲をまたぐ部材は範囲内のB-rep部分だけを照合し、部材全体が外にあるときは「適用範囲外」と示す。幅員と距離の両方を空欄にすると、選択部材の全体を対象にする試算に戻る。MCPでは両方を `road_width_mm`・`application_distance_mm` で指定し、範囲外の行は `excess_mm: null` になる。

## 別表第三から勾配と適用距離を入れる

1. 敷地の「高さ制限の条件」に用途地域を登録する。工程10の道路側の斜線試算で「別表第三を参照」を押す。
2. 法第52条第1・2・7・9項に基づく容積率の限度を確認し、百分率で入力する。前面道路の幅員等で限度が変わる敷地では、その条件を反映した値を使う。
3. 表の項、勾配、適用距離を確認して「勾配と適用距離に入力」を押す。試算結果にも参照した項と容積率の限度を表示する。敷地側の高さと幅員は別に入力する。

2026-11-24にe-Govの法第56条および別表第三の本文を照合した。単一の用途地域に収まる敷地について、一の項（住居系）、二の項（商業系）、三の項（工業系）の標準値を参照する。たとえば第一種中高層住居専用地域で容積率の限度が200%なら、勾配1.25、適用距離20 mが表示される。 [建築基準法第56条・別表第三](https://laws.e-gov.go.jp/law/325AC0000000201)

幅員12 m以上で法第56条第3・4項の検討が必要な用途地域では、参照値による試算を止める。個別確認が必要な条件には、備考三の特定行政庁による指定、高層住居誘導地区、複数用途地域、用途地域の指定がない区域がある。法令上の適否は未評価。 [横浜市の建築基準法取扱基準集](https://www.city.yokohama.lg.jp/business/bunyabetsu/kenchiku/tetsuduki/kisoku/toriatsukai.files/00_zenpen.pdf)

B-05とB-09に沿い、MCPの `road_height_table_values` も保存済みの用途地域と `floor_area_limit_percent` から、同じ標準値を返す。`wide_road_rule` は、幅員12 m以上で法第56条第3・4項の検討が必要な用途地域かどうかを示す。

## 建物の後退を入れた試算

直線で平行な道路1本で、建物の後退距離が確認できている場合に「建物の後退距離」に入力する。道路幅員と適用距離も入力する。防火の線や2項道路の道路後退線は別の基準で決まる。建物の後退距離は第56条第2項が定める最小の水平距離。算定から除外する部分は、建築基準法施行令第130条の12と横浜市建築基準法施行細則第13条の2を確認する。算定に含める部位と除外する部位は設計者が確認する。2026-11-24に第56条第1項第1号と第2項の本文、および横浜市の案内を確認した。 [建築基準法](https://laws.e-gov.go.jp/law/325AC0000000201)・[建築基準法施行令](https://laws.e-gov.go.jp/law/325CO0000000338)・[横浜市建築基準法施行細則](https://cgi.city.yokohama.lg.jp/somu/reiki/reiki_honbun/g202RG00000909.html)・[横浜市の高さ制限の案内](https://www.city.yokohama.lg.jp/business/bunyabetsu/kenchiku/annai/20140401121655.files/0139_20250328.pdf)

幅員6 m、適用距離9 m、勾配1.25、後退1 mなら、起点が道路の反対側へ1 m移る。青い斜線は同じ水平位置で1.25 m上がり、敷地側の道路境界から2 mで終わる。部材の照合範囲も同じ起点から求める。適用端が道路内または境界上に来た場合、敷地内に表示する面はない。道路位置や敷地の形は保存済みのものを使う。

MCPでは幅員と適用距離に加えて `building_setback_mm` を指定する。省略時は0。幅員や斜線勾配の特例、複数道路、法令上の適否は未評価。

## 選んだ部材から後退距離を採寸する

1. 算定に含める部材をモデルで選び、工程10の「道路側の斜線試算」で「選択部材から採寸」を押す。
2. 採寸結果で、最短距離と、その距離を決めた部材名を見る。「この値を使う」で後退距離欄に入る。
3. 幅員や適用距離などを入力して「試算」を押す。選択部材の一部が道路側に出ている場合、採寸結果は0 mになる。

登録した直線の道路境界に直角な方向に、選択したB-repの形状から水平の最短距離を測る。境界線は同じ向きに延長して測る。地下部分などを含む部材は、その部材の全形状が採寸に入る。採寸時の選択に入っていない部材や、法令上の除外部分の判定は未評価。モデルの変更後に再試算するときは採寸し直すか、確認した値を入力する。

B-05とB-09に沿い、MCPの `measure_road_building_setback` も同じ形状から採寸する。対象を `ids` で指定すると、最短距離 `distance_mm` と部材の `id`・`name` を返す。SBRの設定やモデルは変わらない。
