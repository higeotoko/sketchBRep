# 326. 凡例に切り口の斜線

docs/303 の凡例は、線のペン（隠れ線・通り芯・敷地境界線など）だけを並べていた。熊本県の作成例の平面図には、大壁・真壁・柱・筋かいなどの記号の凡例がある。

うちの平面図に今出ている記号を例題で確かめた。柱や筋かいの記号は無く、壁の層の切り口に斜線が入っているだけだった（docs/173）。

- 構造用の木材（柱・間柱・根太・土台など、壁の芯）：×
- 合板・野地板：／

斜線は見えがかり線のペンで描くので、ペンからは区別できない。そこで図を作るときに「どの斜線を描いたか」を図に覚えさせ、凡例に見本を出す。

## 作り

- `View::hatchPatterns`：描いた斜線の種類（1：合板等の ／、2：構造材の ×）。
- シート（`Sheet::hatchPatterns`）にも持たせる。1枚に複数の図をまとめたシート（docs/306）では、それぞれの図の分を合わせて出す。
- 凡例：線の行の後に、小さな切り口の箱（断面のペン）を同じ斜線で描いて名前を添える。
  - 構造用の木材の切り口（柱・間柱・土台など）
  - 合板・野地板の切り口
- 斜線を描かない図（画面、縮尺の無い図）では出ない。

## 確認

- `WallLayerLines.CutLayersAreHatchedAtAScale` に追加：
  - 1:20 の平面図で `hatchPatterns` が {1, 2} になる。
  - シートの凡例に2つの名前が出る。
- 例題（基礎あり）の1階平面図の凡例に、通り芯・中心線と2つの斜線の見本が並ぶのを画像で確かめた（`outputs/review-2026-11-27-hatch/legend.png`）。

## 残り

- 柱・通し柱・筋かいの記号を平面図に描くこと（今は描いていないので、凡例にも無い）。
