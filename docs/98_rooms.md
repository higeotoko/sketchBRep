# 室（部屋）：壁で閉じた所と、その面積（G-07、2026-11-14）

[docs/90](90_bim_operation_framework.md) の G-07。[docs/97](97_bim_gaps_and_priority.md) の順位 1。
関係する約束は B-01（部品としてつかめる）・B-04（つながりが保たれる）・B-07（数えられる）・B-09（人と AI が同じ言葉）。
オーナーの指示：2026-11-14（足りない要素を整理し、順位をつけて上から進める）。

## 直す前

- 室という部品が無かった。面積は、テキストの注記に手で書くか、面をクリックして出た数字を写すしかなかった。
- 壁を動かしても、書いた面積は変わらなかった。

## 直した後

建築ツールバーの「室」で、壁で囲まれた所をクリックすると室を置ける。

| 場面 | 動き |
|---|---|
| マウスを置く | 囲まれた形を先に見せ、ステータスバーに「壁芯 ○○ ㎡ ／ 内法 ○○ ㎡」を出す |
| クリック | 室を置く（名前は「室 1」など）。直後に室名を打って Enter で付け替え。取り消し 1 回分 |
| 室を選ぶ | プロパティの先頭に、室・階・壁芯の面積・内法の面積・囲む壁の枚数 |
| 「室」の右の矢印 > 室の一覧と面積 | 全部の室の表と合計。行をクリックすると、その室を選ぶ |
| 壁を動かす・仕切りを足す・消す | 面積は**いつも今の壁から読む**ので、そのまま変わる |

### 2 つの面積

| 名前 | どこからどこまで |
|---|---|
| 壁芯の面積 | 壁を描いた線の内側。木造の壁（仕様つき）は柱心の線 |
| 内法の面積 | 壁の面の内側。壁ごとの厚さ・片寄りを見る |

ここで出す面積は、**法の床面積ではない**（算入・不算入の決まりを何も当てていない）。一覧と AI の返り値に、そう書いてある。

### 勝手に補わない

- 壁で閉じていない所には、室を置けない。すき間をふさぐことはしない。理由と、近くの「どこにも当たっていない壁の端」の位置を出す。
- 置いた後で壁を消して開いた室は「閉じていない」と出し、**面積を出さない**（合計にも入れない）。壁を戻せば、また出る。
- 仕切りが無くなって、2 つの室が同じ場所になった時は、後の室に「ほかの室と同じ場所」と出し、合計に 2 回入れない。
- 1 つの場所に、室は 1 つ。2 つ目は断る。
- 室の中に壁の端が出ている時（袖壁など）は、内法の面積を**未評価**にする（壁の厚さの分を引けないため。壁芯の面積は出す）。
- 壁の面から形を決められない時（室の幅より壁が厚い、など）も、内法は未評価。

### 壁として見るもの

- 壁ツールで描いた壁（開口があってもよい。仕様つきの壁も同じ）。
- 室の床（作業面の高さ）から **1100 上**で切れる壁だけ。腰壁や、別の階の壁は見ない。
- 形を直接変えて「壁ツールの形でなくなった壁」は、壁として数えない。その枚数を、閉じていない理由と一緒に出す。
- 線・箱・柱などは、室を囲まない。

### つながりの決まり

| 壁の並び | 室の見つけ方 |
|---|---|
| 角（突き付け） | 両方の壁の線をのばして、交わる点を角にする |
| T 字（間仕切りが壁の面に当たる） | 間仕切りの線を、相手の壁の線までのばす。相手は、そこで 2 つに分かれる |
| 十字（壁が通り抜けて交わる） | たがいに分け合う |
| 室の中に離れて立つ壁の囲い（コアなど） | 外の室から、その分を引く。囲いの中は、別の室 |
| 行き止まりの壁（袖壁） | 室を分けない |
| 一直線に並んだ、厚さの違う壁 | 内法の形に段を付ける |

「当たっている」と見るのは、壁の端が、相手の壁の厚さの中に届いている時（G-05 のつながりと同じ決まり）。

## AI から

| コマンド | 内容 |
|---|---|
| `create_room {at, base, name}` | 室を置く。閉じていない・もう室がある時は断る |
| `room_at {at, base}` | 置かずに調べる。閉じているか、面積、囲む壁、閉じていない時の壁の端 |
| `list_rooms` | 全部の室。`area_centre`・`area_inner`（㎡。未評価は `null`）、`closed`、`problem`、合計 |

室名は `set_text`、削除は `delete`（ふつうの注記と同じ）。

## 実装で決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 室の持ち方 | **目印（注記のテキスト＋ `kind = room`）だけ**を持つ。形と面積は持たず、聞かれるたびに壁から読む | 壁を変える操作は多い（移動・長さ・仕様・階高・削除・直接編集）。形を持つと、どれか 1 つで直し忘れた時に、古い面積を黙って出す。持たなければ、古くなりようがない |
| 形の見つけ方 | 壁の線で平面のつながりを作り、閉じた輪をたどる（立体の演算を使わない） | 速く、結果が決まっている。計算の途中を試験で 1 つずつ確かめられる |
| 内法 | 輪の各辺を、その壁の面まで内へずらして、となりと交わらせる | 壁ごとに厚さ・片寄りが違ってもよい |
| 分からない時 | 数字を出さない（未評価） | 違う面積を出すより、出さない方が安全（CLAUDE.md） |
| 3D での指し方 | 視線が床と交わる点（手前に壁があっても、その奥の床） | 3D では、室の床の手前に壁が立っていることが多い |
| ファイル | 目印は、ふつうの注記として保存される。古い版のアプリで開くと、ただの注記に見える | 新しい種類の物を足さないので、保存の形が変わらない |

## まだやっていないこと

- **画面に面積の札を出すこと**。今、画面に出るのは室名だけ（面積はプロパティ・一覧・ステータスバー）。室名の横に、今の面積を出す（docs/97 N-11）。
- 室を選んだ時に、形を画面で光らせること。
- 室の表を、図面・CSV に書き出すこと（G-11）。床面積の表（階ごと）、法の床面積（N-10）。
- 室の用途・仕上げ・天井高（N-02）。採光・換気などの計算。
- 曲がった壁。壁ツール以外で作った壁（線・箱・直接変えた壁）で囲んだ室。
- 柱だけで仕切った所、開いた所を「見えない線」で分けること（LDK と廊下など）。
- 吹抜け・階段の穴を、室から引くこと。
- 室の目印を動かして別の場所に入れた時に、知らせること（今は、入った先の室になる）。
