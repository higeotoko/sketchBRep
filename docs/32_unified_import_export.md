# インポート／エクスポートの入口を統合（2026-10-26 JST）

ユーザー依頼：形式別に増えたメニューをまとめ、ファイル選択ダイアログの「ファイルの種類」欄で形式を選びたい。

## 操作

「ファイル」メニューの **インポート...** と **エクスポート...** にまとめた。
画像の下敷き読み込みと、ビューのPNG書き出しもここから使う。
作業ファイルのSBRは、引き続き「開く」「保存」「名前を付けて保存」を使う。

| 操作 | 種類欄で選べる形式 |
|---|---|
| インポート | 対応するすべてのファイル、STEP、DXF、DWG、IGES、BREP、Rhino 3DM、画像・下敷き（PNG/JPEG/BMP/GIF） |
| エクスポート | STEP、STL、IGES、BREP、Rhino 3DM、PNG画像 |

これは入口の整理であり、未対応の形式を新しく追加したものではない。STLの読み込みやDXF／DWGの書き出しは表示しない。

## 動作

- インポートは選択したファイルの拡張子で判別する。「対応するすべてのファイル」からそのまま選べる。大文字の拡張子にも対応する。
- DWGは従来どおり別途ODA File Converterが必要。「DWG 変換ソフトの設定...」はファイルメニューに残す。
- DXFの単位・部分読み込み・大規模図面のレイヤまとめ、3DMの一部読み込み確認は従来の処理へ引き継ぐ。
- エクスポートは選択した種類を使い、拡張子を補完する。別の既知の出力拡張子が入力されていれば、選択した種類の拡張子へ変更する。
- 未知の末尾（例：`model.v1`）は名前の一部として残し、`model.v1.stl` のように拡張子を足す。
- 上書きの確認は、拡張子を合わせた最終ファイル名に対して行う。形式変更で別の既存ファイルへ上書きする場合も確認を省略しない。
- STLは保存先と種類を選んだ後に精度を設定する。BREP／IGESもその後に形状のみの出力であることを案内する。
- キャンセルや上書き拒否では出力ファイル・モデル・Undo履歴を変更しない。
- インポート／エクスポートの直近のフォルダーと、エクスポートの形式をPCごとのQt設定に保持する。モデルには記録しない。

## 検証

既存のGUIテストを新しい操作順に更新。STEP／3DM／IGES／BREPの種類選択から保存・再取り込み、体積と選択範囲、Undoを確認。
不正ファイル・読み込みキャンセル、PNGの形式選択と拡張子変更、上書き拒否時の元ファイル保持、PNGの下敷き取り込みも確認。
STLの種類選択→精度設定・キャンセル、DXF／DWGの共通入口からの取り込みも検証する。

幾何エンジンやCLI/MCPの各コマンドは変更していない。

ローカル結果：共通入口・種類選択・画像・上書き確認のGUI11件、STL GUI5件、DXF／DWG GUI19件合格。DWG自動確認には代替コンバーターを使用している。3DMを無効にしたビルドでは3DMの往復テスト行を追加しない。
