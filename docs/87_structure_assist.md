# 構造の検討に要る数値をモデルの形から読み取る（structure_assist）（2026-11-06）

木造2階建ての住宅をMCPで立ち上げて、構造を確かめる実験をした（docs/86の続き、図面はオーナーの非公開データ）。
そのときにSketchBRepの外のスクリプトで補っていた数値を、読み取り専用のコマンドにした。

壁量の計算（docs/58）は、床面積・見付面積・平面の範囲を手で入力する前提になっている。
このコマンドは、それらをモデルの形から出して、設計者が確かめてから入力できる形で返す。
**結果をそのまま計算に入れることはしない。** 入力するかどうかは設計者が決める。

## 使い方

```json
{"command":"structure_assist","args":{}}
{"command":"structure_assist","args":{"span_depth_limit":15,"limit_basis":"事務所の目安（○○による）"}}
```

| 引数 | 既定 | 内容 |
|---|---|---|
| `storeys` | レベル「1FL」「2FL」… | `[{id, fl}]`。階の床の高さ（世界Z, mm）。レベルの名前が「<n>FL」で終わるものを使う |
| `cell_mm` | 25 | 面積を数えるラスタのセルの大きさ |
| `wind_cut_mm` | 1350 | 見付面積から除く、各階の床面からの高さ |
| `floor_band_mm` | 400 | 床スラブとみなす天端の範囲（各階の床面の何mm下まで） |
| `span_depth_limit` | なし | 梁の「スパン÷梁せい」の上限。**`limit_basis`（どこの値か）と一緒の時だけ**判定する |

## 返すもの

| 項目 | 内容 |
|---|---|
| `wind` | 階ごとの `wind_x_m2`（X方向の力を受ける面＝YZ面への投影）と `wind_y_m2`（XZ面への投影） |
| `floor_slabs` | 階ごとの床スラブ（`kind=slab`）の一覧・面積の和・平面の範囲 |
| `column_alignment` | 上の階の柱の本数、真下に下の階の柱がある本数、柱直下率、陸立ちの柱（何の上に乗っているか） |
| `beams` | 梁ごとの長さ・梁せい・支点の一覧・支点間の最大距離・スパン÷梁せい・両端の持ち出し |
| `suggested_wall_floors` | 上の数値を `set_wall_calculation` の `floors` と同じ形にした案 |

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 見付面積の求め方 | 見えている面・立体を三角形に分けて鉛直面に投影し、セルの中心が覆われたものを数える。通り芯は除く | 屋根の形、張り出し、手すりなどの重なりを、形のまま正しく和にできるため。投影面積は形から決まる量で、推定ではない |
| X/Y の向き | X＝X方向の水平力を受ける面（YZ面への投影） | 壁量計算の入力（docs/58）と同じ約束 |
| 床面積 | `kind=slab` の物の平面の和。バルコニー・吹抜けを含んでいないかは注記で確認を促す | 「床面積に算入する部分」は意匠・法の判断で、形だけでは決められない |
| 柱直下率 | 上の階の柱の平面位置の差1mm以内に、下の階の柱があるか。通し柱は両方の階で数える | よく使われる設計の目安。法令の基準ではないので、合否にはしない |
| 梁の支点 | 梁の下面に接する柱（柱芯の位置）と横架材、梁の端が側面に取り付く部材（どちらも箱の接触、2mm以内） | 小梁を大梁に掛ける納まりを支点として拾うため。接合の仕様・耐力は評価しない |
| 梁の判定 | 上限とその根拠を渡された時だけ `over_limit` / `within_limit` にする。既定は測るだけ | 梁せいの目安は経験則で、出典なしの値で合否を出さない（docs/52の方針） |

## 確かめたこと

- **計算テスト済み**（`tests/test_structure_assist.cpp`、5件）
  - 6×4×6mの箱：見付面積は 4×(6−1.35) ㎡ などが手計算と一致する。モデルは変わらない
  - L字に重なる2枚の床スラブ：重なりを1回だけ数えて28㎡、平面の範囲も正しい
  - 1F柱2本・2F柱2本（うち1本は梁の上）：柱直下率0.5、陸立ちの柱と乗っている床梁を返す
  - 柱2本で受ける6mの梁：スパン6000（柱芯〜柱芯）、比25。上限15と根拠を渡すと `over_limit`。根拠なしの上限は受け付けない
  - レベルがない時は `storeys` を求める注記を返し、指定すれば計算する
- コアのテスト：全617件中、610件成功・7件スキップ（従来どおり）
- **実際のモデルでの確認**（オーナーの検討モデル、CLIで実行）：見付面積が、スクリプトでの手計算とほぼ一致した（1F X 75.2 / Y 39.6 ㎡、2F X 38.8 / Y 18.7 ㎡）。柱直下率59%。スパンの長い梁の一覧から、5.36mを支えなしで飛ばしている小屋梁が見つかった
- GUI 自動確認・Windows 実機確認：まだ（読み取り専用コマンドで、画面の変更はない）

## まだやっていないこと

- 地震の必要壁量を、荷重を入れずに仕様から引くルート（HOWTEC 早見表・表計算ツールの係数）。早見表は試算No.1〜42の表で、データの取り込みと出典の管理が必要なため、別の段階で行う
- 四分割法で、上の階が一部だけ載る側端部分（L字の平面）の扱い
- 斜めの梁・柱（世界X/Yに平行なものだけを対象にしている）
- 床面積に算入しない部分（バルコニー等）の自動判別
