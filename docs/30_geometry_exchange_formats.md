# 軽度の形式追加：BREP / IGES（2026-10-26 JST）

## 判断と今回の対応

ユーザー依頼：インポート／エクスポート形式の追加など、現在の環境でハードルを判断し、軽く実装できるものを進める。
既存のOCCTライブラリを利用し、形状表現を増やさず対応できる **BREP と IGES の入出力**を追加した。
曲面の線分割は前の調査どおり保留。この形式追加には混ぜていない。

| 候補 | 実装のハードルの判断 | 今回 |
|---|---|---|
| OCCT BREPの読み書き | 低。既存のネイティブ保存でも使う形状シリアライズを活用できる | 対応 |
| IGESの読み書き | 低〜中。既存OCCTに変換器があり、単位・妥当性・ファイル操作の連携で対応できる | 対応 |
| OBJ / glTF の書き出し | 中。メッシュ化に加え、頂点・法線・座標系・材質やテクスチャの受け渡しの検証が必要 | 未実装 |
| STL / OBJなどのメッシュ読み込み | 中〜高。大量三角形をそのままB-repの面にすると重くなるため、保持・選択・編集の設計が必要 | 未実装 |
| DXFの書き出し | 中。出力する平面・投影・円弧・スプライン・単位・レイヤ等の設計が必要 | 未実装 |
| SKP / FBX / SAT / SLDPRT等の専用形式 | 高。現在の標準依存だけで安定した入出力を揃える範囲を超える。専用SDKや別の変換手段の調査が必要 | 未実装 |

未実装形式の判断は、必要な作業からの見積もりであり、すべての形式を試作・ベンチマークした結果ではない。
メッシュや素材を取り落としたまま対応済みと扱わず、今回は正確な形状の入出力に範囲を限定した。

## 操作と保持するデータ

ファイルメニューに次を追加：

- **IGES インポート...** / **IGES エクスポート...**（`.igs`, `.iges`）
- **BREP インポート...** / **BREP エクスポート...**（`.brep`, `.brp`）

書き出しは選択オブジェクトがあればその範囲、未選択なら表示中のモデル全体が対象。
グループやコンポーネントの配置を反映し、独立した画像・注記・ガイドを除外する。
正確な曲線・面・立体を対象とし、STLのような三角形への近似は行わない。
元のモデルと編集履歴は変更しない。

**形状のみの入出力。** 名前・色・素材・タグ・元の寸法拘束や作成履歴は復元しない。
作業を続けるための元データはSBR形式で保存する。書き出しの設定画面でもこの制限を案内する。

- BREPはOCCTのテキスト形式。バイナリBREPではない。単位情報を持たないためmmとして扱う。1ファイルを1オブジェクトとして取り込む。
- IGESはB-repモード・mmで書き出す。読み込み時はファイルの単位をmmへ換算する。変換されたルート形状ごとに取り込む。
- IGESではSDKが読み込める可視の幾何形状が対象。注釈・材質・レイヤ等を含めた完全なCADデータ交換を保証する機能ではない。
- IGESの対象ルートの変換が一部失敗した場合や、不正な形状は取り込まず、モデルやUndo履歴を変えない。
- 他CADのIGESには面の集合として保存されたものもある。自動で立体に縫い合わせたり、隙間を補修したりしない。

## CLI / MCP

```json
{"command":"export_brep","args":{"path":"model.brep"}}
{"command":"import_brep","args":{"path":"model.brep"}}
{"command":"export_iges","args":{"path":"model.igs"}}
{"command":"import_iges","args":{"path":"model.igs"}}
```

書き出しの `ids` は省略可能なオブジェクトID配列。
4コマンドともファイルI/Oとして扱い、制限付きアプリブリッジ・preview・原子的batchでは実行しない。
SDKの診断がCLI/MCPのJSON標準出力に混ざらないよう、処理中は診断を標準エラーへ送り、処理後に出力先を復元する。
IGESのグローバルな読み書き処理は直列化している。

## 依存と検証

新しい外部SDKのインストールは不要。現在のOCCTのデータ交換ライブラリを使う。
OCCT7.8以降は `TKDEIGES`、7.6/7.7は `TKIGES` をリンクする。
Windows配布では従来のDLL依存探索で必要なライブラリを同梱する。

- 箱・円筒・曲線、日本語ファイル名、配置・グループ・非表示、画像の除外、元モデルの不変性を確認。
- IGESのインチ指定をmmに換算できることを確認。
- ImportのUndo/Redo、SBR保存・再読込、不正入力とI/O失敗時にモデルを変えないことを確認。
- 成功時と不正入力時のCLI標準出力の分離、外部I/O制限を確認。
- GUIの実際のメニューから保存し、拡張子を補完したファイルを再びメニューから読み込むテストを実行。
- 保存・読み込みで小さな形状を検証したもので、各CADの全IGESデータに対応するという検証ではない。

Windows ZIP の `examples/exchange` に、同梱CLIで作成・再読込を検証した10×20×30 mmの箱（BREP / IGES）とこの説明を同梱する。

ローカル結果：コア341件合格・任意ベンチ4件スキップ。新規GUI6件、STL GUI5件、DXF取り込みGUI17件合格。GUI本体の既存3失敗は変わらない。同梱サンプル生成・再読込のCLIは5応答とも成功したJSONであることを確認。

最終CIはLinux・Windowsとも成功。Windows側のOCCTで旧プリンタ列のtypedefが利用できなかったため、返り値から型を推論する実装に修正済み（`72b1923`）。Windowsコアテスト・配布DLL確認・同梱CLIの新形式往復まで合格。Windows実機の対話操作や他CADでの網羅的な互換性確認は未実施。
