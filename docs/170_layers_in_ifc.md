# 壁・床・屋根の層を IFC の材料の層に（2026-11-18）

[docs/106](106_handoff_and_roadmap.md) の「残り（Opus で可）」の「層を IFC・数量に」のうち IFC。[docs/124](124_wall_layer_lines.md)（壁の層）・[docs/151](151_floor_type_layers.md)・[docs/152](152_roof_type_layers.md)（床・屋根の種類の層）の続き。作業は Opus 5.5。
オーナーの指示：2026-11-17（「続けて」）。

## 直す前

IFC には材料を何も出していなかった。壁の仕様（外壁 サイディングなど）は壁の種類の名前（`Pset_WallCommon` の Reference）だけで、層は入っていなかった。

## できること

| 物 | IFC |
|---|---|
| 仕様のある壁 | `IfcMaterialLayerSetUsage`（`.AXIS2.`、壁の線からの位置）→ `IfcMaterialLayerSet`（名前は壁の仕様の名前）→ 外の面から順に `IfcMaterialLayer`（材料・厚さ・名前） |
| 層を登録した種類の床・屋根 | `IfcMaterialLayerSetUsage`（`.AXIS3.`・`.NEGATIVE.`、上の面から下へ）→ 名前は種類の名前 |
| 材料 | 層の名前ごとに 1 つの `IfcMaterial`。同じ名前（石膏ボード・柱など）は壁の仕様をまたいで使い回す |
| つなぎ | 部材ごとに `IfcRelAssociatesMaterial` |
| 出さない物 | 層の無い物。層の厚さの合計が今の厚さと合わなくなった物（厚さを手で変えた物など。図面の層の線と同じ決まり） |
| AI の `export_ifc` | 返り値に `layer_sets`（層を付けた部材の数） |

### 壁の層の向き

壁の線（描いた線）を基準に、外の面の層から内へ並べる。外が壁の線の左（描いた向きに見て）なら、外の面の位置（線から左へ）から右へ（`.NEGATIVE.`）、外が右なら右の面から左へ（`.POSITIVE.`）。

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 層の組の付け方 | 部材ごとの「使い方」（`IfcMaterialLayerSetUsage`）で付ける | IFC4 で、置いた部材に層を付ける時の決まった形 |
| 壁の基準線 | 描いた線 | 木造の壁は柱の芯で描く（docs/79）。ほかのソフトでも、壁の芯からの位置で読める |
| 形との関係 | 形（Brep）はそのまま。層は材料の情報として付けるだけ | 層ごとに形を分けると、開口・屋根合わせ・留めの作り直しが全部重くなる |

## まだやっていないこと

- 数量（層ごとの面積・体積）を数量の表・IFC の数量に出すこと。
- 壁の基準線 `Axis` と壁に沿う配置軸は、配布版 `4dbf133` で追加した。 [例題A・Bでの確認](269_ifc_material_layers_external_review.md#基準線と厚さ方向の修正後)
- 開口・建具の材料。
