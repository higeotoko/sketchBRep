# 階段の側板（ささら桁）（docs/103 の続き、2026-11-15）

[docs/103](103_stairs.md)・[docs/116](116_stair_handrails.md) の「まだ」（ささら桁（側板））。作業は Opus 5.5。
オーナーの指示：2026-11-15（「続けて」）。

## できること

| 項目 | 内容 |
|---|---|
| どこで | 階段を選んで、プロパティの「側板（ささら桁）」：なし・左・右・両側（上りの向きに見て）。「側板の厚さ」（15〜100、初めは 36） |
| AI | `create_stair`・`change_stair` の `stringer`（none / left / right / both）と `stringer_thickness`。`stair_info` にも出る |
| 置き方 | 階段の幅の**すぐ外**に立つ板 |
| 上の線 | 段の先（段鼻）を結ぶ線より **50 上** |
| 深さ | 縦に測って「蹴上 + 踏板の厚さ + 100」（最低 240）。段板をくわえる深さ |
| 下の端 | 床より下には出ない（いちばん下は床で止まる） |
| 回り段・踊り場 | 外側の板は角を回ってついてくる（角は板の厚さぶん伸ばしてすき間を埋める）。内側の板は角で止まって、上の段から始まる（親柱の所） |
| 1 枚の板 | 片側ごとに 1 つの立体にまとめる（図面に段ごとの継ぎ目が出ない） |
| 保存 | ファイルに残る。前のファイルの階段は「なし」 |

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 形 | 段板をはさむ**側板**（側桁）。段の形に切り欠いたささら桁ではない | docs/103 で「ささら桁（側板）」と書いていた物。住宅の箱階段・側桁階段に多い |
| 位置 | 幅の外 | 幅（有効幅の照合に使う値）を変えないため |
| 上 50・深さ | 決まった値（変えられない） | まず形として見えることを優先。変えたい時は足す |

## まだやっていないこと

- 段の形に切り欠いたささら桁（段板が上に乗る形）。
- 上の 50・深さを変えること。親柱、蹴込み板、段鼻の出。
- 側板を IFC で別の部材（IfcMember の STRINGER）として書くこと（今は階段の形の一部）。
- 回り段の内側の、親柱の形。
