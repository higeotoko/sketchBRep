# DXF の線から面を作る（2026-10-26 JST）

## 操作

1. 選択ツールで、面にしたい1つの輪郭の線・円弧を選ぶ。複数の辺は Ctrl+クリックで追加する。
2. 右クリック → **選択した線から面を生成**。
3. 面が選択された状態になる。そのままプッシュ／プルで押し出せる。

元の線図は保持する。面の追加はUndo1回で戻せる。
レイヤごとにまとめたDXFでも、その中の輪郭の辺だけを選んで作成できる。
レイヤ全体がちょうど1つの輪郭であれば、オブジェクト全体を選択してもよい。
複数の輪郭や不要な線を一度に選んだ場合は、1つの輪郭だけ選び直す。
グループ内の線は、そのグループの編集に入ってから選択する。

## 小さなDXFでの確認

配布ZIPの `examples/dxf` に、手書きの確認用ファイルを同梱する。ユーザー提供の実図面は同梱しない。

| ファイル | 内容 | 確認する操作 |
|---|---|---|
| small_open_rectangle.dxf | 2000×1000 mmの矩形の3辺 | 個別取り込み後、最後の辺を線ツールで描くと自動で面になる |
| small_closed_lines.dxf | 矩形を4本のLINEで構成 | 4辺を選択して右クリックから面生成 |
| small_closed_polyline.dxf | 閉じたLWPOLYLINE | 線図を選択して右クリックから面生成 |
| small_arc_outline.dxf | 半径1000 mmの半円弧と直径 | 円弧と直線を選択して面生成。正確な円弧を保つ |
| small_layer_with_extra_line.dxf | 矩形と離れた線が同じレイヤ | レイヤごとにまとめ、矩形の4辺だけ選択して面生成 |

## 面にならなかった理由

- DXF取り込みは従来から線図のみで、閉じたポリラインでも取り込み直後には面を作らない。
- 取り込んだLINEはOCCTのEdgeであり、自動輪郭探索が想定するWireではなかった。最後の1辺を作図しても探索から漏れていた。Edgeの両端も探索するよう修正した。
- レイヤごとにまとめた図面は、複数の独立した線を含むCompound。これを1本の輪郭として扱うと誤った線を使うため、自動探索では単一の線図として扱わない。輪郭を選んで手動生成する。
- 隙間、同一平面でない輪郭、自己交差、重複、枝分かれでも面を作れない。エラーで理由を案内し、モデルやUndo履歴は変更しない。
- 許容誤差は既存の1e-3 mmを維持。大きな隙間を自動補間したり、3Dの輪郭を平面に押しつぶしたりしない。
- この操作は1つの閉じた輪郭が対象。複数輪郭からの穴判定や、未分割の任意の曲線交差から全領域を抽出する操作ではない。

## 実装・履歴・性能

- `Modeler::faceFromSelection` に集約。GUIは現在の辺／オブジェクト選択を渡す。
- 選択のトポロジーと配置を照合し、古い選択や別のオブジェクトの辺を受け付けない。
- マウス選択のTopLoc datumが別でも、同じTShapeと同じ配置であることを照合する。
- 端点の接続判定は空間セルで行う。面生成は4096辺まで。大きな図面のレイヤ全体ではなく必要な輪郭を選ぶよう案内する。
- 素のImportedShapeは必要な辺だけを面の入力に保存する。元の取り込みオブジェクトは全体を保持する。大きなレイヤ全体を選択辺ごとに複製して保存しない。
- 作成履歴のある曲線はLoopProfile + CurveIntervalOpで保持。円弧のbulge等は面側でも編集可能。元の曲線のパラメータは変えない。
- 保存再読込、Undo/Redo、押し出し、平行移動後の部分選択も回帰テストで確認する。

## 検証結果

- 全ターゲットのビルド成功。コア329件合格、任意ベンチマーク4件スキップ。
- 取り込みGUIは17件すべて合格。小DXFの右クリック生成5ケース、最後の辺を線ツールで描く自動生成ケースも含む。
- GUI本体は135件合格、既存の3件失敗、7件スキップ。既存失敗はこの環境で従来から再現している `topEdgesCopiedDownDivideTheSides`、`moveToolLiftsRidgeIntoGable`、`autosaveWritesInTheBackground`。新しい失敗なし。
- 提供された実DXFの141オブジェクトから、1つの閉じた輪郭の4辺を選択して生成も確認。約7.5 msで面を追加し、元の141オブジェクトを保持（計142）。保存・再読込も成功。実図面のすべての輪郭を検証したものではない。
