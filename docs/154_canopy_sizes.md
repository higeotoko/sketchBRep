# 庇の大きさをプロパティで変える（docs/147 の続き、2026-11-16）

[docs/147](147_canopies.md)・[docs/148](148_canopies_follow.md) の「まだ」（庇の大きさをプロパティで変えること）。作業は Opus 5.5。
オーナーの指示：2026-11-16（「進めて」）。

## できること

| 項目 | 内容 |
|---|---|
| 画面から | 庇を選ぶと、プロパティに「庇」：出・厚さ・両側の長さ・開口の上から。値を変えると、その開口の上に作り直す |
| AI から | `change_canopy {id, depth, thickness, extra, above}`（与えた物だけ変える）。新しい id を返す |
| 名前 | そのまま（物の id は新しくなる。画面では作り直した庇を選び直す） |
| 取り消し | 1 回で元の庇に戻る |
| 断る時 | 大きさの外（docs/147 と同じ）、開口が無くなった庇。断った時は元のまま |

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 作り方 | 消して、同じ開口の上に作り直す（id は新しく） | 開口・壁についてくる作り（docs/148）と同じ道。庇はほかの物から指されていない |

## まだやっていないこと

- IFC で庇を屋根・板の種類として書くこと（今は「その他の立体」）。
