## 課題：柔らかいモデル

オーナーの SketchUp のモデルは、形を自由に動かして作った「柔らかい」モデル。どこが壁で、どこが芯かという情報が入っていない。そのまま読み込むと形（メッシュの立体）になるだけで、壁・開口・床・部屋として扱えない。

## 進め方（案）

1. **調べる（SketchUp の MCP）**：オーナーのモデルの**コピー**を SketchUp で開き、Ruby で読む。グループ・タグ・材質・面のつながりを調べて、何が壁・床・屋根・開口と読めるかを見る。読めた所・迷った所を、コピーの上に色やタグで印を付けてオーナーに見せる。元のモデルは触らない。
2. **読み取りの決まりを作る**：
   - 平行な縦の面が 100〜300 mm 離れて向き合う所 → 壁（厚み・芯の線）
   - 水平な板 → 床、斜めの面 → 屋根
   - 壁の中の穴 → 開口（大きさ・腰高）
   - グループ名・タグ・材質も手がかりにする
3. **整える**：壁の芯を通り芯（910・455 のモジュール）に、厚みを仕様（外壁・内壁）に、高さをレベルに、開口をよくある大きさに寄せる。**ずれの一覧**（「芯から 23 mm」など）を出す。
4. **見せて決める**：柔らかいモデルの上に、硬いモデルの下書きを重ねる。ずれが大きい所・判断が分かれる所だけ、オーナーが決める。黙って直さない。
5. **作る（SketchBRep に組み込む）**：壁ツールの壁・開口と建具・床・部屋として作る。元の SketchUp の物とつなぐ（`skp_source_id`、docs/186 と同じ考え）。また SketchUp で直しても、差分を戻せるようにする。何度でも同じ結果が出て、テストできる形にする（SDK で SKP を読む所、`src/core/src/Skp.cpp` の先）。
