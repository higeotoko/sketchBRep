# AI の別名保存（2026-11-15）

オーナーの指示：2026-11-15（「MCP 利用した時に保存コマンドは AI から使えないようにオフになっていたけど、次の時にはオンにしておいて良い。危ないようだったら別名保存だけでも OK」）。作業は Opus 5.5。

## 決めたこと

**上書き保存は AI に開けず、別名保存（新しいファイルへの写し）だけを開けた。**

| 項目 | 内容 |
|---|---|
| 理由 | 上書き保存（`save`）は、どの場所にも書けるので、AI がオーナーの図面や別のファイルを消してしまえる。別名保存なら、すでにあるファイルを壊さない |
| 使えるコマンド | `save_copy {path}` |
| 書ける所 | `.sbr` の新しいファイルだけ。**すでにファイルがある所には書かない**（名前を変えてもう一度）。フォルダはあること。フルパスで |
| 開いているファイル | 変わらない。「保存した」扱いにもならない（オーナーが保存し忘れたままにならない） |
| 切り替え | メニュー「AI 連携 > AI に別名保存を許可（上書きはしない）」。**初めから ON**（オーナーの指示）。切り替えは覚えておく |
| ほかのファイルの操作 | 開く・上書き保存・書き出し・読み込みは、今まで通り AI からはできない |
| 下書き（preview） | 写しの中では、別名保存も動かない（ファイルを書かない） |
