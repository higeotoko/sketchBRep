# 開口を移動ツールでつかんで動かす（G-01 の残り、2026-11-14）

[docs/90](90_bim_operation_framework.md) の G-01 の残り。関係する約束は B-01（部品としてつかめる）・B-08（直接編集を止めない）。
オーナーの了承：2026-11-14（「開口のドラッグ移動」を進める）。

## 直す前

- 開口の位置は、プロパティの数値（左端から・腰高）でしか変えられなかった（[docs/91](91_opening_identity.md)・[docs/94](94_part_section_in_properties.md)）。
- 移動ツールで穴の所をクリックすると、壁が丸ごと動いた。

## 直した後

移動ツール（M）で、**何も選ばずに**、穴の内側の面か、穴のふちの線をクリックすると、**開口だけ**をつかむ。

| 操作 | 動き |
|---|---|
| クリック → マウスを動かす → クリック | 開口が壁に沿って動く。腰高はそのまま（マウスが上下にずれても変わらない） |
| 動かしている途中で距離を打つ | その距離だけ動く |
| 置いた直後に距離を打つ | 今の移動をその距離に置き換える（取り消しは 1 回分のまま）。マイナスは逆向き |
| ↑ | 上下に動かす（腰高を変える）。もう一度 ↑ で壁沿いに戻る |
| ↓ | 壁の面の中を自由に動かす（← → で壁沿いに戻る） |
| Esc | やめる（何も変わらない） |

- 動かしている間、穴の形を先に見せる。ステータスバーに「左端から ○○ ／ 腰高 ○○」を出す。
- **置けない所**（壁の外、ほかの開口に重なる）では、動かしている間に「ここには動かせません」と理由を出す。クリックしても何も変わらず、エラーを出す。
- 壁は同じ物のまま。開口の ID・幅・高さ・建具もそのまま。取り消し 1 回分。
- 他の物の端点などへの吸着は、今までの移動と同じ仕組みを使っている（開口を動かす時の吸着は、自動テストではまだ確かめていない）。

### どれが動くかの決まり

| 選んでいる物 | 穴の内側をクリックした時 |
|---|---|
| 何も選んでいない | 開口が動く |
| 穴の内側の面を 1 枚だけ | 開口が動く（前は、面を法線の向きに伸縮していた） |
| 壁を丸ごと | 壁が動く（開口も一緒に付いていく） |
| 穴のふちの線（辺） | 今まで通り、形を変える操作（角・辺をつかむ） |
| Alt を押しながら | 今まで通り、角・辺・面をつかんで形を変える |

穴の内側の面は画面では細いので、クリックがふちの線に当たりやすい。それで、何も選んでいない時は、ふちの線でも開口をつかむようにした。

平面（上から見た図）では、窓は腰の面（上を向いた面）が見えるので、そこをクリックする。扉（腰高 0）は平面でつかむ面がない（下の「まだやっていないこと」）。

### 置く前と後の言葉

ステータスバーの「左端から」「腰高」は、プロパティの開口の行と同じ言葉・同じ数値。

## AI から

変わらない。位置は今まで通り `move_opening`（docs/91）。

## 実装で決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| ドラッグか、クリック 2 回か | クリック → 動かす → クリック | このアプリの移動は全部この形（docs/07）。開口だけ別の手つきにしない |
| 初めの向き | 壁沿いに固定 | 窓を横にずらす時に、腰高が勝手に変わらない |
| 置けるかの判定 | コアに `canMoveOpening`（何も変えずに答える）を足し、移動と同じ判定を使う | 見せている答えと、置いた時の答えが食い違わない |
| つかむ相手の見つけ方 | クリックした時に 1 回だけ、面・辺を調べる | マウスを動かすたびに調べると、大きいモデルで重くなる。代わりに、開口のある壁を指した時に、ステータスバーで「穴の内側の面かふちをクリックすると、開口だけを動かせます」と知らせる |
| コピー（Ctrl） | まだ。押すと「まだできません」と出す | 開口のコピーは、建具の引き継ぎも含めて別に作る |

## まだやっていないこと

- 開口のコピー（Ctrl）・配列。
- 平面の建具記号をつかむこと。扉は、平面ではつかめない（3D か立面でつかむ。またはプロパティの数値）。
- 開口を選んだ状態（開口だけを選んで、プロパティにその開口だけを出す）。今は壁を選ぶと開口の行が出る。
- 別の壁へ移すこと。
- 壁の端・ほかの開口の手前で止める（今は、置けない所では断るだけ）。
- 選択ツールのまま引きずって動かすこと。
