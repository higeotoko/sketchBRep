# 天井を形として作る（N-02 の続き、2026-11-15）

[docs/115](115_room_finishes.md)（室の天井高）の「まだ」（天井を形として）。作業は Opus 5.5。
オーナーの指示：2026-11-15（「続けて」）。

## できること

| 項目 | 内容 |
|---|---|
| どこで | 室を選んで、プロパティの「天井を作る（作り直す）」（天井高を入れた室だけ押せる） |
| できる物 | 天井板：厚さ 10、**下の面が天井高**（室の床から）、**壁の面の内側**の形 |
| 中身 | 属性 `kind = ceiling`、`room = その室`。床（スラブ）とは別の物（床の表には入らない） |
| 作り直し | 同じ室の天井板があれば、消して作り直す（1 枚のまま） |
| 取り消し | 1 回 |
| AI | `make_ceilings {rooms}`（無ければ全部の室）。天井高が無い・壁の内側の形が分からない室は名前が返る |

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 壁や天井高を変えた時 | **自動では付いてこない**。もう一度押すと作り直す | 自動で付いてこさせると、壁を動かすたびに天井が作り直され、手で直した天井（下がり天井など）が消える。まずは押した時だけにした |
| 厚さ 10 | 線として見えればよい | 天井の仕上げの厚さは、仕上げ（文字）の方に持つ |

## まだやっていないこと

- 壁を動かした時に、天井板が付いてくること（今は押し直す）。
- 下がり天井・勾配天井。室の中の柱・吹抜けの穴を天井から引くこと。
- IFC の天井（IfcCovering）として書くこと（今は「その他の立体」）。
- 仕上げ表に天井板があるかを出すこと。
