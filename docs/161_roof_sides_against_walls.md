# 屋根：高い壁に当たって終わる辺（下屋と 2 階の壁の取り合い、2026-11-17）

[docs/106](106_handoff_and_roadmap.md) の「Fable に渡す物」の 2 の残り（高さの違う屋根の取り合い）の第 1 段。[docs/160](160_roof_sides_and_dented_gable.md) の続き。作業は Fable 5.2。
オーナーの指示：2026-11-17（「進めて」）。

## 直す前

1 階の屋根（下屋）を 2 階の壁の所で止める方法が無かった。外周を 2 階の壁の線まで描くと、その辺にも軒・けらばが出て 2 階の中へ入り、寄棟ではその辺からも面が上がって、壁の所で屋根が下がってしまう。

## できること

屋根の外周の辺に「**壁に付く辺**」の印を付けられる。切妻・寄棟・片流れのどれでも使える。

| 項目 | 内容 |
|---|---|
| 形 | 壁に付く辺では、軒もけらばも出さず、屋根を縦に切る。その辺から上がる面は作らない（ほかの辺から上がって来た面が、壁の所でいちばん高くなって終わる） |
| 画面から | 屋根のプロパティ「壁に付く辺」に辺の番号（「4,5」のように。1 番目の角から 2 番目の角までが 1）。隣の「**見つける**」で、当てはまる辺を探して入れる |
| 見つける決まり | 外周の辺のうち、長さの 9 割以上が壁（壁ツールの壁）に沿っていて、その壁が屋根の軒の高さより 500 以上高くまで立っている辺（壁の足元が軒の高さより 1000 を超えて上にある壁は数えない）。壁の厚さの中にある線なら、芯でも面でもよい |
| AI から | `create_roof`・`change_roof` の `wall_sides`：辺の番号の一覧（0 から）、または `"auto"`（見つける）。`roof_info` にも出る |
| 角を回る下屋 | 2 階の角を回る L 字の外周で、内側の 2 辺を壁に付く辺にすると、外の角に隅棟ができて、2 辺とも壁の所で終わる |
| 建築面積 | 壁に付く辺は、軒の出 0 として数える |
| 保存・取り消し | ファイルに残る（印の無い屋根は、保存の中身が前と同じ）。取り消し 1 回 |
| 断る時 | 番号が外周に無い。軒の辺が 1 つも残らない |

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| どこに持つか | 屋根の形の決まり（`wall_sides`）として屋根に持つ。壁とのつながりは持たない | 屋根だけで形が決まり、動かす・コピー・保存がそのまま効く。壁を消しても屋根は変わらない（もう一度「見つける」か、番号を消す） |
| 自動で付けるか | 付けない。「見つける」を押した時・`"auto"` を渡した時だけ探す | 屋根を描いた後で 2 階の壁を描く事が多い。知らない間に屋根の形が変わるのは困る |
| その辺に書いた出・勾配 | 使わない（出は 0） | 壁に当たる所に軒は無い |
| 切妻で妻を選ばない時 | 今までの決まりで妻を選ぶ（選べない外周でも、壁に付く辺があれば断らない） | 片側が壁の切妻（棟が壁に当たる）は、もう片側が妻になればよい |
| 作り方 | 壁に付く辺が 1 つでもあれば、斜めの外周と同じ作り方（docs/160）。その辺は「出 0 の、立つ辺」 | 妻の辺と同じ仕組みで足りる |

### 外周をどこに描くか

屋根は外周の線の所で切れる。外周を壁の芯に描くと、屋根は壁の厚さの半分だけ壁の中へ入る（図面では壁の線に隠れる所。体積・面積はその分だけ多い）。壁の外の面に描けば、面で止まる。

## まだやっていないこと

- **平面で重なっている屋根どうしを切ること**（下の屋根の外周が、上の階の下まで入っている時に、上の階の形で切り取る）。今は、外周を上の階の壁の線に合わせて描く。
- 高さの違う屋根の面どうしが当たる所（上の屋根の軒が下の屋根に重なる所、棟違い）。
- 壁を動かした・消した時に、屋根の「壁に付く辺」を見直すこと（知らせる事も含めて）。
- 壁に当たる所の水切り・雨押さえ。壁の側を屋根の形で切ること。
- 屋根ツールで描く時に、初めから見つけること。
