# 04. Phase 2 実装報告 — 実用モデリング基礎

![Phase 2](images/phase2.png)

*移動ツールのコピー + `x4` で並べた柱、ソリッドの差で開口を抜いた壁（開口寸法は後から変更可）、オフセットした床スラブの輪郭。*

## 実装内容

| 仕様書の項目 | 実装 |
|---|---|
| Move / Rotate / Copy | 移動 (M)・回転 (Q) ツール。基点クリック → 推論付きで移動先 / 回転は中心 → 基準方向 → 角度（15° 刻みの分度器スナップ）。数値入力、Ctrl でコピー、確定後に `x4`（同間隔の配列）・`/4`（等分割）、距離や角度の打ち直しで直前の操作を再編集。半透明の移動プレビュー |
| Offset | オフセット (F) ツール。平面プロファイル（押出前の面）の外周を内外にオフセットし、新しい面オブジェクトを作成（角は建築図面向けにシャープ）。距離はパラメータとして後から変更でき、押出もできる |
| Boolean | ソリッドメニューの和・差・積。**入力のレシピを保持するパラメトリック演算**で、演算後も入力の寸法（開口の高さなど）を変えると再計算。貫通して二分される結果にも対応 |
| Group / Component | Ctrl+G / Ctrl+Shift+G / Ctrl+K / 分解。グループは入れ子の配置を持ち、クリックでグループ全体を選択。コンポーネントは定義を共有し、定義のパラメータ変更で全インスタンスが更新 |
| スナップ・推論の強化 | 点から（追跡点を通る軸線）、起点の軸と追跡点の交点、エッジに平行 / 垂直。推論線（軸色の破線）と追跡点への点線を表示 |
| オブジェクト管理 | 階層ツリー（タグ列付き）、名前・タグ・色・位置の編集、表示/非表示（親が非表示なら子も非表示）、すべて選択 |
| パラメータ編集 | ブーリアン入力（`in<i>.…`）、オフセット距離、コンポーネント定義内パラメータをパネルで編集 |
| STEP 連携の安定化 | XCAF でオブジェクト名・色を保持。グループ・インスタンスの配置を反映。アセンブリ STEP の読込（配置合成・名前・色の継承） |
| ネイティブ形式 | version 2（階層・コンポーネント定義・ブーリアン・オフセット）。version 1 も読込可能 |

あわせて修正した既存の不具合:
- **ビューポートが起動直後に左下 320×240 だけ描画される**問題。OCCT は Qt とは別の X 接続でウィンドウサイズを取得するため、表示直後は古いサイズが見え、その後リサイズイベントが来ないことがあった。描画ごとに実サイズを確認して追従するよう修正。
- **全体表示（Shift+Z）が軸線（±1000 m）まで含めてズームアウトする**問題。モデルの正確な外接箱でフィットするよう修正。

## 動作確認方法

### 自動
```bash
cmake -S . -B build && cmake --build build
xvfb-run -a ctest --test-dir build --output-on-failure
```

### 手動シナリオ
1. `R` で 300×300 の矩形 → `P` で 3000 押出（柱）
2. 柱を選択 → `M` → 柱の角をクリック → `Ctrl` → X 方向に動かして `3000` Enter → `x4` Enter（柱が 5 本に）→ `/4` Enter で 12 m を 4 等分
3. 壁（14000×200×3000）と開口用の箱を作り、壁 → 箱の順に Shift+クリックで選択 → ソリッド → 差
4. 結果を選択し、右パネルで「Rectangle 3: 押出距離」（開口の高さ）を変更 → 壁が再計算される
5. 柱を 1 本選んで `Ctrl+K`（コンポーネント化）→ `M` + `Ctrl` で複製 → パネルの定義パラメータ（押出距離）を変更 → 全インスタンスが更新
6. 床の矩形を描いて `F` → 面の内側をクリック → `400` Enter（内側に 400 オフセット）
7. 複数選んで `Ctrl+G` → 移動・回転 → `Ctrl+Shift+G` で解除しても位置は維持
8. ファイル → STEP エクスポート → 他の CAD で名前・色・位置を確認 / 保存 → 開き直しても上記すべてを再編集できる

## 既知の制限

- **Windows 実機・CI でのビルドはまだ確認していない**（Phase 1 から継続。Linux / Xvfb では全テスト合格）。
- コンポーネントの **入れ子は未対応**（コンポーネントを含む選択からコンポーネントを作れない）。グループの入れ子は可。
- グループの「編集モード」（ダブルクリックで中に入る）は未実装。子要素はパネルのツリーから直接選択する。
- Boolean の入力はソリッドのみ。結果のレシピはワールド配置を固定で持つため、演算後に入力だけを個別に移動することはできない（数値パラメータは変更可）。
- オフセットは穴のない平面プロファイルのみ。ソリッドの面や曲面のオフセットは未対応。
- 移動・回転中、動かしている対象自身の頂点にもスナップする（SketchUp は除外する）。
- 推論の候補は全探索のまま（大規模モデルでは BVH などの空間インデックスが必要）。
- 回転の数値入力は度のみ（単位記号なし）。
- STEP 書出はオブジェクトを平坦な製品として出力する（グループ・コンポーネントのアセンブリ構造は保持しない）。
