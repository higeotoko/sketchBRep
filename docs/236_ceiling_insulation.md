# 236. 天井断熱（2026-11-21）

docs/221・222・228 の「まだ」：天井断熱の入口（天井に断熱を入れる）。日本の木造住宅でよく使う天井断熱を、壁・床・屋根と同じに入れられるようにした。

## 入れ方

- 天井（docs/123 の「天井を作る」で作った天井板、`kind = ceiling`）を選んで、「断熱を入れる...」（docs/215）。AI は `set_insulation` の `ids` に天井。
- 今までの「断熱は壁・床・屋根に」の断りを、天井も入れるように直した。

## 出る所

| 所 | 中身 |
|---|---|
| 断熱範囲図（平面、docs/221・222） | 天井のある階の平面に、天井の範囲を輪郭と ×、「天井断熱　グラスウール 16K 155 mm（充填）」の字（床の字の少し下）。凡例「×印の範囲：この階の天井の断熱　…」。どの階か：天井の下端が平面の切る高さより上で、一つ上のレベル＋600 より下 |
| 断熱範囲図（断面、docs/217） | 天井の切り口に、厚さの真ん中の波線（床と同じ）。凡例「波線：天井の断熱　…」 |
| 断熱仕様表（docs/223・228） | 「天井」の行（屋根と壁の間）。基準値(参考)：告示第266号 1(2)ロ(イ) の一戸建て・木造軸組構法の天井（充填 5.7・4.0・4.0・4.0・0.78、外張・内張は「屋根又は天井」の 5.7・4.0・4.0・4.0・0.78。docs/230 で告示の本文と照らした値） |
| 省エネ仕様の表（docs/210） | 「外皮：天井」の行 |

## 確認

**計算テスト済み**
- `Schedules.CeilingInsulation`：居間の天井高 2400 で天井を作り、グラスウール 16K 155 mm（充填、λ 0.038 → R 4.08）を入れる。1FL（切る高さ 1100）の断熱範囲に天井があり、2FL には無い。1FL の断熱範囲図の凡例に「×印の範囲：この階の天井の断熱　グラスウール 16K 155 mm（充填）（1 個）」。x = 1000 の断面に「波線：天井の断熱」。6 地域にすると、図面一式の断熱範囲図（1FL）の断熱仕様表に「天井」「R≧4.0」「満たす」。
- docs/216〜230 の断熱のテストもそのまま成功。Windows ローカル：コア全件 797 件成功・8 件スキップ。断熱・省エネ・天井・図面まわりの GUI 10 件が成功。

**Windows 実機確認（人の操作）**：まだ。docs/105 の 14-45。
