# 350. 間仕切りの壁と扉を、外皮の照合から外す

例題E（docs/346 の通し確認）に、階段・2階のホール・内部の扉を入れた（docs/351）。そのあと申請の段階9（省エネ・設備）で、外皮でない物まで「未入力」になった。

- 「壁の仕様：内壁 石膏ボード両面」が「未入力」で、「断熱の入っていない壁 5 枚（AI の set_insulation で入れます）」と出た。
- 「建具の性能」が「開口 14 件のうち、熱貫流率を入れた物 10」で「未入力」になった。足りない4件は、室内の扉。

省エネの書類（外皮の性能）で断熱や熱貫流率を問うのは、外気などに接する部位（外皮）。室内どうしの間仕切りの壁や扉ではない。

## 直したこと

壁の種類（create_wall / set_wall_type の type）が内壁の種類のとき、その壁は外皮でない、と扱う。内壁の種類とは、プリセットの外壁フラグが立っていない物で、今は `interior_board`（内壁 石膏ボード両面）。

- 段階9「壁の仕様：…」：
  - 内壁の種類の行は「対象外」にする。
  - 理由を書く：「室内の間仕切りの壁（壁の種類が内壁）。外皮でないので、断熱の有無は数えません。」
  - 断熱を求める文は出さない。
  - 外気に通じる所（車庫・物置など）に面する壁は、外壁の種類にするように書き添えた。種類で決めているので、そこは人が選ぶ。
- 段階9「建具の性能」：
  - 数えるのは外皮の開口だけ。内壁の種類の壁の開口は数えない。
  - 「間仕切り（内壁）の開口 N 件は外皮でないので数えません」と書く。

厚さだけの壁（種類の無い壁）は、今までどおり外皮かどうか決められない。だから「仕様の無い壁」として入力を求める。

## 確認

- `Schedules.PermitChecksReadTheEnergyAndElevationStages` に足した：
  - 内壁（interior_board）を1枚足すと「壁の仕様：内壁 石膏ボード両面」は「対象外」になり、「断熱の入っていない壁」は出ない。
  - その壁に扉を開けると「建具の性能」に「間仕切り（内壁）の開口 1 件」と出る。
  - 直す前（「未入力」）なら失敗する。
- コアの一覧表のテスト 100 本が通る。
