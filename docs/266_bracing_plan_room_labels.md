# 266. 耐力壁配置図の室名を読める位置に置く（2026-11-23）

[前回の修正](265_bracing_plan_labels.md)では耐力壁と側端の札の干渉を解消し、居間と洋室の札を図面の線が横切る箇所が残っていた。耐力壁配置図では、閉じた室の札が線や文字にかかるとき、用紙の縮尺で札と余白が同じ室の内側に収まる位置を探す。空きがない場合は元の位置に出す。切断線は移動後の札を避け、耐力壁・側端の札は最後に配置する。

BIMの約束は B-05・B-07。室の名前と面積はモデルから読み、PDF・DXF・JWWと図面のプレビューに同じ配置を使う。[BIMの操作と図面](90_bim_operation_framework.md)

## 確認結果

- **展開したWindows ZIP**で台本14-12・14-21が合格。居間・洋室の名前と面積を載せた耐力壁配置図の図面チェックは、1:50・1:100の両方で2件から0件。両縮尺のプレビューを確認した。画像付きレポートは配布フォルダの `outputs/room-label-layout/verified-ec28ef8/report.html`。
- **出力**では、図面一式のPDFと耐力壁配置図のDXF・JWWを作成。DXF・JWWに両室の名前と面積が入った。
- **Windowsコア**は関連4件に成功。全818件のうち810件成功、8件スキップ。側端の破線上に室の目印を置く例でも、両縮尺で札が残り、図面チェックに干渉が出ないことを確認した。
- **Windows GUI自動確認**は関連3件と、展開したZIPの通常18件・べた基礎4件が成功。
- **Linux CI**は831件すべて成功。[run 45075500065](https://github.com/higeotoko/sketchBRep/actions/runs/45075500065)
