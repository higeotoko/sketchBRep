# 324. 第五面 7.用途別床面積（用途が混ざる建物）

確認申請書（第二号様式）の第五面「7.用途別床面積」には、イ〜ヘの6行がある。docs/294 では、計画概要の主要用途で1行目（イ）だけを埋めていた。店舗併用住宅のように用途が混ざる建物でも書けるようにする。

## 入力

- 室ごとに「用途の区分」（様式の別紙の5桁の番号、例 08440）と「具体的な用途の名称」（例 物品販売業を営む店舗）を入れる。
  - MCP：`set_room_finish` の `use_code`・`use_name`。両方入れるか、両方空にする。
  - 番号が5桁の数字でないと入らない。
- 入れていない室は、計画概要の主要用途（`use_code`・`main_use`）とする。

## 第五面への書き方

- 階ごとに、用途を入れた室の壁芯面積を用途ごとに足す。
- 階の床面積から、用途を入れた室の合計を引いた残りを、主要用途とする（イ行）。廊下・階段などもここに入る。
- 合計は、第四面の階の床面積と一致する。
- 用途を入れた室の面積が階の床面積を超えるときや、用途が7つ以上で6行に入りきらないときは、書かずに確認表で知らせる。
- どの室にも用途が入っていなければ、これまでどおり主要用途の1行。

## 様式の雛形

- `tools/permit_forms/prepare_templates.py` で、イ〜ヘの6行すべてに差し込み欄を付けた。
  - イ行のキーはこれまでと同じ。
  - ロ行からは `fifth_use_code_1` のように番号が付く。
- 原本（横浜市の第二号様式、SHA256 3f19f066…）から作り直した。
  - 第二号様式の雛形：`a0749851…` から `7ca55692…` に変わった。
  - 第三号様式と協定等届出書の雛形：1バイトも変わらない（SHA256 一致）。

## 確認

GUI の `permitWordFormsTransferAndEmbedDrawings` で確かめた。

- 1階に間仕切りを入れて、半分（3 m × 7 m）を店舗にした。
- 第五面（1階）に、主要用途 08010 と店舗 08440 の2行が、それぞれ 21.00 m² で出る。
- 差し込み記号は残らない。
- 番号が4桁だと入らない。
- 確かめたあとは元に戻し、後のテストに影響させない。

## 残り

- アプリの室のプロパティに、用途区分の欄はまだ無い（MCP だけ）。
- 第四面・計画概要の用途の欄は主要用途のまま。
