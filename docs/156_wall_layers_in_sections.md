# 断面図に壁の層の線を出す（docs/124 の続き、2026-11-16）

[docs/124](124_wall_layer_lines.md)（平面の切断に壁の層の線）の「まだ」（断面図での層の線）。作業は Opus 5.5。
オーナーの指示：2026-11-16（「続けて」）。

## できること

| 項目 | 内容 |
|---|---|
| 対象 | 仕様（外壁 サイディングなど・内壁 石膏ボード両面）を付けた壁。平面の層の線（docs/124）と同じ壁 |
| 出る線 | 断面図で壁を切った所に、層の境目ごとに縦の細い線（外壁 サイディング：4 本）。壁の下から上まで |
| 開口 | 断面が開口を通る所では、腰の下と開口の上に分かれる |
| 出ない時 | 仕様の無い壁、層の厚さの合計と合わなくなった壁、壁に沿って切る断面（層の面と切る面が平行） |
| 出る所 | 画面の断面と、断面図（DXF・JWW・PDF） |

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 線の作り | 層の境目の縦の面と断面の面が交わる縦の線を、壁の立体の中だけ残す | 開口・壁の上端の形（屋根に合わせた三角の壁など）によらず、立体から決まる |

## まだやっていないこと

- 層ごとの塗り（ハッチ）、線の太さを層で変えること（壁・床・屋根とも）。
- 壁と床・屋根の層どうしの取り合い（今はそれぞれの立体の中だけ）。
