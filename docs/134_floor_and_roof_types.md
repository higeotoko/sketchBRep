# 床・屋根の種類をまとめて変える（N-08 の第 2 段、2026-11-16）

[docs/97](97_bim_gaps_and_priority.md) の N-08 の残り（床・屋根の種類）。第 1 段は建具（[docs/133](133_opening_types.md)）。作業は Opus 5.5。
オーナーの指示：2026-11-16（「続けて」）。

## できること

| 項目 | 内容 |
|---|---|
| 種類とは | 床（スラブ）・屋根に付けた**種類名**（例 F1、R1）が同じ物を、1 つの種類とする（属性 `type_name`） |
| 画面から | 床・屋根を選ぶと、プロパティに「種類名」の欄。入れると付く（空にすると外れる）。同じ種類名の物がほかにあれば「同じ種類（F1）のほか n 個を、これと同じにする」ボタン |
| 揃う物 | 床：**厚さ**（上の面はそのまま）。屋根：**勾配・厚さ・軒の出・けらばの出**（外周・軒の高さ・切妻／寄棟などの形はそのまま） |
| AI から | `set_type_name {ids, name}`、`change_type {name, thickness, pitch, eave, gable_eave}`（与えた物だけ変える）、または `{like: id}`（その物に揃える） |
| 断る時 | 床・屋根でない物に種類名、知らない種類名、種類名の無い物に揃える、1 つでも作れない値（何も変わらない） |
| 取り消し | 1 回 |

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 種類の持ち方 | 物に種類名を付け、同じ名前の物が 1 つの種類 | 建具の符号（docs/133）と同じ考え方。種類の入れ物を別に作らないので、ずれない |
| 揃う値 | 床は厚さ、屋根は勾配・厚さ・出 | 外周・高さはその場所の物。種類として同じにするのは「断面の仕様」の所 |

## まだやっていないこと

- 種類の一覧の表（どの種類が何個、値はいくつ）と、表から種類を直すこと。
- 種類を名前で登録しておいて、新しく描く床・屋根をその種類で作ること。
- 床・屋根の層（仕上げ・下地）を種類に持つこと（壁の仕様のように）。
