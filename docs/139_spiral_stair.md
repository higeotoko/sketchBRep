# らせん階段（決める事が多い物、2026-11-16）

[docs/106](106_handoff_and_roadmap.md) の「残り（決める事が多い）」のらせん階段。作業は Opus 5.5。
オーナーの指示：2026-11-16（「決める事の多い方」、自動で進めてよい）。

## できること

| 項目 | 内容 |
|---|---|
| 形 | 中心の丸い柱のまわりを、同じ角度の扇形の段で上がる階段 |
| 決め方 | 「歩く線」の 2 点を **中心** と **歩く線の始まり（足元）** にする（半径 = 2 点の距離）。**回る角度**（90〜720°、正：反時計回り、負：時計回り、初めは 270°） |
| 幅・柱 | 幅は歩く線の両側に半分ずつ。内側（半径 − 幅の半分）は 50 以上で、そこまでの太さの丸い柱を床から階高まで立てる |
| 段 | 段数は今と同じ決まり（蹴上の上限から、3 段以上）。1 段の角度 = 回る角度 ÷ 踏面の数。外側の弧は 5° ごとの折れ線 |
| AI | `create_stair`・`change_stair` の `shape: spiral`、`path: [[中心], [足元]]`、`sweep`。`stair_info` にも出る |
| 画面 | らせんの階段を選ぶと、プロパティに「回る角度」 |
| いっしょに使える物 | 手すり・側板（ささら桁）・蹴込み板・段鼻・親柱・平面の記号（弧の歩く線・矢印・破断線）・床の穴・レベルへの追従・保存 |

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 入れ物 | 新しい点の欄を作らず、歩く線の 2 点を「中心・足元」に読み替える | 保存・移動・レベルへの追従・回転が、今の階段のまま効く |
| ほかの機能 | 歩く線を 5° ごとの折れ線にして渡す | 手すり・側板・蹴込み板・平面の記号などが、作り直さずに使える |
| 法の照合 | 踏面は**狭い側から 300 の所**で測る（docs/103 の回り段と同じ決め事）。足りなければ「NG」と出す（作るのは止めない） | 住宅のらせん階段は、この寸法が足りない事が多い。黙って直さず、照合で知らせる |
| 柱の太さ | 内側の半径そのもの | 段が柱に付く形。柱を細くして段を浮かせる形は、別に決める |

## まだやっていないこと

- 階段ツールでらせんを描くこと（今は AI か、作った物のプロパティで回る角度を変える）。中心・足元を画面で動かすこと。
- 柱の太さを段と別に決めること、段の先の形（丸め）。
- 手すりを弧で作ること（今は段ごとの直線の棒）。
- 踊り場のあるらせん。
