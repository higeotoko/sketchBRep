# 262. 開口を手で選ぶ・コピーする・平面モードでつかむ（2026-11-22）

チェック表 9-1・9-2・10-3 を台本にした。台本を作る途中で、MCP から届かない所が 2 つと、アプリの不具合が 1 つ見つかった。

## MCP を太くした所

- **ui_type の `keys`**：文字の前に、3D ビューへキーを押して離す。Ctrl だけ（移動ツールのコピー）、Shift、Alt、↑↓←→（Up など）、Delete、Escape、Return、Tab。これまでは Ctrl だけを押す手が無く、コピーを AI から試せなかった。
- **ui_plan**：ツールバーの「平面で描く」メニューと同じ平面モード（上から、床から 1100 で切る。建具の記号の所で開口をつかめる）。`level` は get_levels の名前か id で、省くと地面（Z=0）。`off: true` で 3D に戻る。このメニューは開いた時に作られるので、ui_trigger では届かなかった。アプリの中では、メニューと同じ関数（showPlanAt）を使う。
- **状態の `message`**：ツールができなかった時の言葉（ステータスバーに数秒出る物）を、ui_windows などの答えに入れる。これまでは AI に見えず、「入らない時の言い方」を確かめられなかった。

ui_* と同じく、この PC の AI だけが使える。ChatGPT からは使えない。

## 直した不具合

- **開口のコピーの数を打ち直すと失敗していた。** 移動ツールで Ctrl コピーして「*3」と打った後に「*2」や「*20」と打つと、「既にある開口と重なります」で失敗していた。「*3」のコピーが 1 つずつ別の元に戻す手になっていて、打ち直しでは最後の 1 つしか取り消さず、残ったコピーにぶつかっていた。コピーを 1 つの元に戻す手にまとめた（API の copy_opening と同じ）。
- **入らない数の言い方。** 「*20」のように入らない時は、「4 つ目のコピーが入りません（この間隔で入るのは 3 つまで）: その位置では壁からはみ出します …」と、何個まで入るかを言う。何も変えない。
- **重なる時の言葉に英語が混ざっていた。** 「The opening 既にある開口と重なります … opening 2」のようになっていたのを、「開口 2 と重なります。…」と全部日本語にした。
