# 11. マテリアル（仕上げ）

建築の検討中に「形を作る」と「仕上げを確かめる」を行き来できるようにする。第 1 段は**名前付きの単色マテリアルを、描きながら気軽に塗れる**ところまで。画像テクスチャ・実寸・向きは、この構造の上に足していく（後述）。

## 使い方（GUI）

| 操作 | 内容 |
|---|---|
| 右の「素材」パネル | 素材の一覧（色見本）。クリックで「塗る素材」になり、ペイントツール（B）に切り替わる |
| ＋ 新規 / 定番 ▾ | 名前と色で新規作成 / 木・漆喰・コンクリート・タイル・ガラスなど定番から 1 クリックで追加 |
| 変更（ダブルクリック） | 名前・色を変更（使っている面・部材すべてが変わる） |
| 削除 | ライブラリから削除。使っていた面・部材は継承に戻る（元に戻すで復元） |
| ペイントツールでクリック | **その面だけ**を塗る |
| Ctrl+クリック | **部材全体**を塗る |
| グループ・コンポーネントをクリック | 編集中でなければ**それ全体**に割り当て（中の「素材なし」の面に効く） |
| Alt+クリック | その面の素材を拾う（スポイト）。パネルの選択も追従 |
| 「（素材なし：継承に戻す）」で塗る | 面の個別指定・部材の素材を外して、上位（部材全体 → グループ・配置）に戻す |
| 選択に適用 | 選んでいる面（なければ部材）に割り当て |
| プロパティパネル「素材」 | 部材の素材・継承元・面ごとの指定数（特定できず未適用の件数も） |

## データ構造

- **ライブラリ**：`Document::materials()`。`Material{id, name, color}`。id は作成時に `mat-<UUID>` で決まり、名前を変えても変わらない（参照は常に id）。古いファイル・取込み・色指定 API の単色は `rgb-RRGGBB`（同じ色は同じ素材）
- **割当**：`Object::material`（部材全体、空 = 継承）と `Object::faceMaterials`（面ごと）。面は編集参照と同じ同一性（支持平面・内部の 1 点・外接箱、曲面は面上の点）で、オブジェクトのローカル座標に持つ
- **継承規則**（具体的なものが勝つ）：面の個別指定 → 部材の素材 → 最も近い入れ物（グループ、コンポーネントの配置）の素材 → なし（従来の色・既定のグレー）
- **部品定義**：定義の中の部材の素材・面の素材は全配置に共通。配置（インスタンス）の素材は、定義の中で「素材なし」の面に効く（SketchUp と同じ）。配置ごとの違いは表示オブジェクトの色だけで、形状・メッシュ（表示コピー）は共有のまま（テストで共有数が変わらないことを確認）
- **Undo**：`Command::materialDeltas`（ライブラリの追加・変更・削除）と通常のオブジェクト差分。素材の作成と割当を含む AI の一括編集も 1 ステップで、失敗時は丸ごと戻る
- **変更差分**：`ChangeSummary` に `material` 観点（割当の変更）と `materials`（ライブラリの変更）。preview / propose / 確定で同じ差分

## 形の編集と引継ぎ

面の素材は、記録されるすべての編集（GUI・AI・一括）で `CommandStack` が新しい形の上に探し直す。決められないときは**どの面にも付けない**（別の面へ黙って移さない）。

| 編集 | 引継ぎ |
|---|---|
| Push/Pull（平面） | 押した面の素材は面と一緒に動く。新しくできた側面は部材の素材（継承） |
| 曲面の Push/Pull | 曲面の素材は同じ面（面上の点で再特定） |
| 面の分割 | 分かれたどちらの部分も元の素材を持つ |
| パラメータの再生成 | 同じ平面の面（伸び縮みしても）→ 平行に動いた同じ向きの面が 1 つだけならそれ。候補が複数なら未適用 |
| 尺度 | 面の参照も同じ倍率で変換 |
| Boolean（結合・切断） | 結果は最初の入力の素材。他の入力から来た面（同じ平面・同じ向き）はその入力の見た目（面の素材か部材の素材）を保つ。切断でできた面（向きが逆）は結果の素材を継承 |
| 開口（壁に描いて押し抜く／開口ツール） | 壁の素材・面の素材を保つ（穴のあいた面も）。抱き（開口の内側の面）は壁の素材 |
| コピー・貼り付け・配列・ミラー的な配置 | 割当はローカル座標なので配置が変わってもそのまま |
| グループ化・分解・コンポーネント化 | 素材ごと移る |

「反転」（鏡像・面の表裏の反転）は現在独立した操作がない。追加するときは、割当がローカル座標にあるため配置の鏡像では変わらず、面の向きを反転する操作では表裏（下記）を入れ替える規則にする。

## AI（共通の編集基盤）

`list_materials` / `create_material` / `update_material` / `delete_material` / `assign_material` / `paint_faces` / `clear_face_materials` / `material_at`（スポイト）。`query_objects` / `edit_each` の `material` 条件と項目、`aggregate` の `group_by: "material"`。

「選択した面と同じ素材を壁全部に」：
1. `get_selection` → `material_at {id, face}` で素材 id を得る
2. `preview {commands: [edit_each {where: {attributes: {kind: wall}}, commands: [assign_material {ids: ["$id"], material: <id>}]}]}` で差分（`material` 観点つき）を確認
3. 同じ内容を `batch`（`expected_revision`）で確定 → Undo 1 回で戻る。途中で失敗すれば素材の作成も含めて全部戻る

## 第 2 段：編集タブ（SketchUp 準拠）・テクスチャ・不透明度・レンダリング用の値

右の「マテリアル（素材）」パネルは SketchUp と同じく **「選択」「編集」** の 2 タブ。

| 項目 | 内容 |
|---|---|
| 選択 | 文書の素材（テクスチャ・透明度も見本に出る）と定番。クリックでペイントツールの素材に。ダブルクリック・「編集」・右クリックで編集タブへ |
| 名前・複製 | 名前の変更。「複製」は今の素材を新しい id でコピー（「レンガ 2」）して編集タブで開く：元の素材とそれを塗った面はそのまま、別名で保存して調整できる |
| 色 | 色の場（色相・彩度）と RGB / HSV の数値・色コードの埋め込みピッカー。**塗った後から**調整でき、名前と id は変わらない（塗った面はすべて追従）。ドラッグ中の連続した変更は **1 回の取り消し**にまとまる |
| テクスチャ | 「テクスチャイメージを使用する」→ 画像を選ぶと文書に埋め込み（内容の SHA-256 で参照、`.sbr` に保存）。**1 枚の実寸（幅・高さ mm）**、縦横比の固定、**着色**（画像の明暗を残して色で色付け）、**色をリセット**（着色をやめ、色を画像の平均に） |
| 不透明度 | 0〜100。面ごとに塗った素材も部材全体の素材も、その分だけ透けて見える（ガラス） |
| レンダリング用 | 金属感・粗さ・反射率（0〜1）を素材に保存。いまのモデリング表示には使わず、将来のレンダラーがそのまま使える（PBR：metallic / roughness / reflectance） |

- データ：`Material{id, name, color, opacity, texture{image, width, height, colorize}, metallic, roughness, reflectance}`
  - 変更は `Modeler::editMaterial`（値の範囲・画像の有無を検査）
  - 複製は `duplicateMaterial`
  - 画像は `addTextureImage`
- 表示
  - テクスチャのある面に、面の平面上の実寸 UV でタイル状に画像を重ねる（照明あり）
  - 壁は水平方向、床は世界 X 方向が横
  - 画像は（画像・着色の色）ごとに 1 回だけ読み込んで共有
- 保存
  - `.sbr` の `materials` に `opacity` / `texture` / `pbr` を追加
  - テクスチャ画像は、使われているものだけ `images` 表に埋め込む
  - 画像が壊れていたら、そのテクスチャだけ外して色のまま読み込み、警告を出す
- AI
  - `update_material {opacity, texture{width,height,colorize}|null, metallic, roughness, reflectance}`
  - `duplicate_material {material, name?}`
  - `set_material_texture {material, file, width, height, colorize}`
  - `list_materials` に各値を出す

## 次の段：面ごとの貼り方（位置・回転）

| 項目 | 設計 |
|---|---|
| 面ごとの貼り方 | `FaceMaterial` に `placement{origin, uDir, rotation, offset}`（その面の上での原点と向き）を追加。木目の方向を面ごとに回す・ずらす。未指定なら素材の既定（第 2 段の向き：壁は水平が u、床は世界 X が u） |
| 曲面 | 第 2 段は面の平均的な平面への投影。円筒・展開は後で |
| 表裏 | `FaceMaterial` に `back` を追加（面ソリッドでない単独の面・プロファイル用）。ソリッドの面は外向きが表 |
| 操作 | 面をクリックして素材の位置合わせ（移動・回転・縮尺）をモデル上で直接ドラッグ。数値でも入力（直後の数値で変更、の共通契約に乗せる） |

## 残る制約

- テクスチャの位置・回転は面ごとに変えられない（上の次の段）
- コンポーネントの配置を Alt+クリックしたとき、定義の中の面の素材ではなく配置の素材を拾う
- Boolean で、素材のない入力の面は結果の素材になる（「既定のグレー」を明示的に保つ指定はない）
- STEP / 3DM の書き出しは部材の色だけ（面ごとの色・テクスチャは未対応）
- 面の特定は幾何の同一性に頼る。演算の履歴による特定（レビュー §5 の本命）が入ると、より多くの場面で迷わず引き継げる
