# 太陽の位置（日時・場所・真北）（2026-11-06）

リアル表示（docs/81_realistic_display）の太陽を、SketchUp の影の設定と同じように、**日付・時刻・場所・真北の向き**から決める。設定はモデルと一緒に保存し、Undo でき、AI からも変えられる。

## 使い方

「表示 > 太陽の位置（日時・場所）...」。開くとリアル表示になる。

| 項目 | 内容 |
|---|---|
| 日付 | 月・日（年は使わない） |
| 時刻 | スライダー（10 分刻み、PageUp/Down で 1 時間）。**動かすと影がその場で動く** |
| 場所 | 札幌・仙台・東京・名古屋・大阪・広島・福岡・那覇から選ぶか、緯度・経度で指定 |
| 時差 | UTC から（日本は +9） |
| 真北の向き | モデルの +Y（奥）から真北まで、上から見て時計回りの角度。0 なら +Y が北（docs/50 の図面の方位と同じ） |
| 表示 | 「太陽：南の空、高さ 31.0°（方位 180°）」のように、今の太陽の位置 |

- OK でモデルに保存（Undo 1 回）。キャンセルなら元のまま。
- 夜（太陽が地平線の下）は太陽の光と影が消え、空の光だけになる。
- 初期値は 4 月 15 日 14:00、東京、真北 = +Y。

## 計算

- 太陽の高さと方位は、NOAA（アメリカ海洋大気庁）の太陽位置の式で求める（`src/core/src/Sun.cpp`）。誤差は 0.1° 程度で、影には十分。うるう日は考えない。
- 方位は真北から時計回り。モデルの中では、真北を +Y から真北の角度だけ時計回りに回した向きとして、太陽へ向かう単位ベクトル（Z 上）を作る。

## 地面が見えないようにする補正

リアル表示の地面は、影を受けるだけで見えないように、背景の地面と同じ明るさになる色にしている（docs/81_realistic_display）。太陽が高いほど地面は明るく照らされるので、そのままでは地面の板が見えてしまう。

- 描いた画面で、太陽の高さを変えて地面の明るさを測った（Linux・Mesa の描画）。明るさ（リニア）は「0.463 + 0.200 × 太陽の高さの sin」でよく表せた。
- これに合わせて地面の色を割り戻す（`kGroundLightBase`・`kGroundLightSun`）。高さ 17°〜77° のどこでも、地面 203〜204 ／ 背景 203（256 段階）になった。
- 光の強さを変えたら、測り直して定数を直す。GPU が違うと少しずれることがある（Windows 実機で要確認）。

## 保存と AI

| 項目 | 内容 |
|---|---|
| 保存 | `.sbr` の `sun`（month, day, hour, latitude, longitude, timeZone, northAngle）。無い古いファイルは初期値。おかしな値（2 月 30 日など）は読み込みで断る |
| Undo | `Modeler::setSun` が設定の変更として 1 回 |
| AI | `get_sun`（読むだけ。今の高さ・方位・太陽への向き・昼か夜かも返す）、`set_sun`（指定した項目だけ変える） |

## 確認

| 区分 | 内容 |
|---|---|
| 計算テスト済み | `Sun.PositionInTokyo`（夏至・冬至の正午、春分の朝、夜）、`Sun.DirectionFollowsNorthInTheModel`（真北の向き）、`Sun.CheckedSavedUndoneAndSetByTheAi`（値の検査、保存・読み込み、Undo、`set_sun` / `get_sun`、読むだけの扱い） |
| GUI 自動確認済み（Linux、Xvfb・Mesa） | `gui_phase1: realisticDisplay` に追加：太陽の光の向きが設定どおり、正午は南から、時刻を変えても地面が背景と同じ明るさ（差 4 以内）、夜は影なし、ダイアログの時刻でその場で光が動く、キャンセルで元のまま、OK で保存され Undo 1 回 |
| Windows 実機確認 | 未。GPU での地面の見え方、スライダーを動かした時の速さ |
