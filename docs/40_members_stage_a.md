# 部材の生成と基本編集：段階A（2026-10-29 JST）

利用者の仕様案「SketchBRep 部材生成・基本編集仕様案 v0.4」（2026-10-27）の**段階A**を実装した。
最終的な展望は、RC造と鉄骨造の両方を作れるようにすること。
段階Aでは、規格部材の「生成 → 人の直接操作 → AIの数値変更 → また直接操作」の往復が成り立つことを確かめる。

方針（仕様 §1）：自由に形を触れることが最優先。規格は形を素早く作る出発点であり、作った後の形を縛るルールにしない。

## できること

### 作る

- **部材ツール**（パレット「部材」、キー `I`）：始点と終点をクリックすると、その2点の間に部材ができる。
  - 終点の代わりに、方向を示して長さを入力してもよい。
  - 作った直後に数値を入力すると、その部材の長さが変わる（Undoは作成と合わせて1回）。
  - 同じ設定のまま、次の始点から続けて作れる。
- **ツール > 部材の設定…**：次の項目を選ぶ。
  - 断面：長方形（幅×せい）、H-200×100×5.5×8、H-400×200×8×13
  - 配置基準：上下（下端・芯・上端）と左右（右・中心・左）
  - 回転
  - 用途：なし・柱・梁・筋かい
  - 材料種別：未設定・木・鋼・RC
- **AI**：`list_sections` で断面を探し、`create_member` で作る。GUIと同じModelerの処理を通るので、同じ条件なら同じ形になる。

### 作った後

- 部材は普通の立体（Object＋Recipe）として扱う。移動・回転・コピー・プッシュプル・分割・ブーリアン・伸縮が、解除や変換の操作なしでそのまま使える。
- **端面を軸方向に押し引きすると、部材の長さの値が変わる**（仕様 §6.5）。加工の記録は増えず、AIが読む長さもすぐ新しい値になる。
- 側面の押し出しなど、それ以外の操作は通常の加工として記録される。そのあともAIは長さを読めて、指定した長さに変えられる。
- **AIの基本編集**（`member_info` / `change_member`、仕様 §10.2）
  - 編集できる項目と、それぞれの意味・単位・現在値・根拠を返す。根拠は「部材の値」か「形状から測った値」のどちらか。
  - 次の変更を**1つの操作でまとめて検証して確定**する。対象のIDは変わらない。
    - カタログ断面の交換（基準線・回転・長さはそのまま）
    - 幅・せいなどの独自寸法
    - 絶対長さ
    - 回転
    - 配置基準
  - 加工済みの部材でも、変更後にその加工を再適用する。再適用できない場合は**何も変えず**に理由を返す。直接編集はそのまま続けられる。

## 実装で決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| データ | Recipeに形の種類 `LinearMember` を1つ足しただけ（始点・終点・断面の上方向・回転・断面・配置基準・生成元） | 別のモデル・別の履歴を作らない（§2・§8.1）。1本あたり数十バイト |
| 断面の上方向 | 作った時に決めて保存する。カメラや形状からは計算し直さない | 鉛直付近で断面が回り出さないように（§5.2） |
| 柱の向き | 世界の上向きに沿う部材は、断面の上方向を +Y に決め打ちする。少し傾いても同じになる | 決まった結果にするため |
| 左右 | 始点から終点を見て左右 | 2点で入力する時に分かりやすい |
| 長さの変更 | 始点を固定する。鉛直で下向きに描いた柱だけは下端を固定する | §6.4「高さ変更は既定で下端」 |
| 端面の押し引き | 部材の長さの値に置き換える。作り直しに失敗した時だけ通常の押し引きにする | 長さを正しい値のまま保てる（§6.5の2案のうち「既存パラメータへ反映」） |
| 加工後の長さ | 部材の軸方向の実際の範囲を形状から測って返す。根拠は `shape` | 生成時の値を現在値として返さない（§7.2・§10.3） |
| 寸法の名前 | 幅 `width`、せい `depth`、長さ `length`。柱の「高さ」も中身は `length` | 「高さ」の曖昧さをなくす（§6.4） |
| 生成元 | `made_from`（作った時、最後に選んだカタログ）と `catalog`（今もカタログどおりか）を分ける。寸法を手で変えると `catalog` は空になる | 「生成元 H-400」と「今もH-400」を混同しない（§7.2・§6.6） |
| 用途・材料種別 | 既存の属性 `kind`（柱・梁）と `material_class`（steel / timber / rc）を使う。作るのと同じ操作で付ける | 専用の項目を増やさない。属性を後から足して履歴を増やさない（§7.1・§9.3） |
| H形の角 | 半径から正確な円弧を直接作る。`bulge` は経由しない | §11.1の「同じ名前で意味が違う」取り違えを避ける |
| カタログ | 起動して最初に使う時に1回だけ検証する。部材を置くたびには検証しない | §9.2 |
| 断面の種類 | 長方形とH形。種類を足せる作りにした | RC（丸柱）と鉄骨（□形鋼管・丸形鋼管・溝形鋼・山形鋼）を段階Bで追加する |

### 仕様に加えた改善

- **配置基準の変更**（`change_member` の `anchor`）：部材は動かさず、基準線だけを付け替える。そのあと断面を変えると、新しい基準が保たれる。仕様 §5.1の「対応可能な寸法再編集」を、使える操作として出した。
- **梁の既定は上端**：設定で用途を「梁」にすると基準の候補が上端になる（ダイアログ内に表示される）。その場で基準を変えていた場合は変えない（§4.4「無説明にリセットしない」）。
- **鋼の断面**：材料種別を指定しないでH形を選ぶと「鋼」が付く。

## 受入条件との対応（仕様 §13.4）

| # | 内容 | 確認したテスト |
|---|---|---|
| 1 | 上端基準のH形梁を手で移動・回転した後、AIが別サイズへ交換 → 上端の線・向き・長さを保ち、同じIDを返す | `Members.SwappedSectionKeepsTopLineAfterMoveAndRotate` |
| 2 | 端面を押し引き → AIが新しい長さを読み、指定の長さに直す。生成時の値に戻らない | `Members.PushedEndIsTheLengthTheAiReadsAndSets` |
| 3 | AIが柱の幅・せい・高さを変えた後、人がそのまま加工できる | `Members.AiChangedColumnStaysDirectlyEditable` |
| 4 | スラブの上面を固定して厚さを変える | 段階Bの範囲（今回は対象外） |
| 5 | 引き継げない加工の後に断面交換 → 加工を消さずに操作だけ取りやめ、直接編集は続けられる | `Members.SwapThatCannotKeepTheEditsChangesNothing`（フランジ外面を押し出した後のサイズ交換は、理由を付けて変更なし） |
| 6 | GUIとAIで同じ結果、Undo 1回、保存・再読み込み後も同じ基本編集 | `Members.SavedMembersStayEditable`、`Members.AiCommandsGoTheSameWay`、GUI `memberToolDrawsAndRetypes` |
| 7 | 1本を変えても関係ない部材を検査・作り直ししない | ベンチ（下の表）：1,000本の中の1本の変更が0.2〜0.3ms |

不正な要求（2点が同じ、NaN、寸法0、ウェブがフランジより広い等）は、モデルを変えずに失敗する（`Members.BadRequestsChangeNothing`）。

## 性能（Linux、OCCT 7.8.1、1,000本：長方形とH形を半々）

| | 作成 | 1本の変更 | 1本の移動 | 保存 | 読み込み |
|---|---:|---:|---:|---:|---:|
| 部材（用途・材料の情報なし） | 0.39秒 | 0.3ms | 0.03ms | 2.6秒 | 4.6秒 |
| 部材（用途・材料の情報あり） | 0.37秒 | 0.3ms | 0.02ms | 2.4秒 | 4.5秒 |
| 参考：同じ寸法の普通の箱（矩形＋押し出し） | 2.7秒 | 2.5ms | 0.01ms | 0.9秒 | 3.9秒 |

- **用途・材料の情報による差は、測定のばらつきの範囲**（§9.4の比較）。
- 保存・読み込みが普通の箱より遅いのは、H形の面の数が多い（円弧の面を含む18面。箱は6面）ため。保存する形状データが増える分で、部材の情報によるものではない。
- 1,000本を読み込むと約4.5秒かかる。大規模なモデルに向けて、次の2つを段階Bで測って検討する。
  - 同じ断面の部材で表示を共有すること（§13.2。今の共有はコンポーネントだけ）
  - 保存データを減らすこと
- 再現：`SBR_MEMBER_BENCH_N=1000 sbr_core_tests --gtest_filter=Members.Bench`
- Windows実機での時間は未計測。

## まだやっていないこと（段階B以降）

- Steel Member Generatorのカタログ取り込みと、断面検索の拡大。その際、DXF取込の円弧変換を共通化できるかも確かめる。
- 断面の追加：□形鋼管・丸形鋼管・溝形鋼・山形鋼・丸柱（RC）。
- 柱の「位置＋高さ」入力、鋼材・柱・梁の別入口。
- スラブ厚さ（上面固定）・直線壁の厚さ・高さを、意味の分かる基本編集につなぐ。
- 自由造形で作った立体に、用途だけを後から付けるプロパティ操作。今も `set_attribute` で付けられる。
- 同じ断面の部材の表示共有、保存の軽量化（上の性能を参照）。
- JIS寸法の確認：H形の角の半径（H-200×100×5.5×8 は r=8、H-400×200×8×13 は r=13）は、現行JIS G 3192の値として入れた。カタログを取り込む時に出典と照合すること。

## 保存形式

- 新しい形の種類 `{"type":"member", ...}` を追加した。部材を含むファイルは、この版以降のEXEで開くこと。
- 部材を含まないファイルの形式は変わらない。
