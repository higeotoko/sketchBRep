# 218. 断熱の印を、仕様（層）の中の位置に描く（2026-11-21）

docs/216・217 の「まだ」の「壁の層（docs/170）に断熱の層がある時は、その層の位置に描くこと」。

## 描く位置の決め方

壁（平面・断面とも、`insulationRuns` と `insulationBand` で同じ決め方）：

1. 壁の仕様（層、`wall_layers`）に、名前に「断熱」か断熱材の名前（例：「グラスウール 16K」）を含む層がある → その層の中。
2. それが無く、断熱の入れ方が「充填」 → 柱・間柱の層（`role: core`）の中。
3. どちらでもない（仕様が無い壁、外張り・内張りで断熱の層が無い仕様）→ 今まで通り、壁の厚さの真ん中。

- 波の大きさは、描く層の厚さで決まる（例：外壁 窯業系サイディングの充填なら、柱・間柱 105 mm）。
- 床・屋根の型（docs/151・152）に、名前に「断熱」か断熱材の名前を含む層がある時は、断面でその層の深さ（上から）に描く。無い時は今まで通り厚さの半分。
- `InsulationRun::place`・`InsulationBand::place`：`layer` / `core` / `middle`。`InsulationBand::depth`：床・屋根の印の深さ（上の面から）。

## 図の注（凡例）

位置の書き方を、使った決め方ごとに出すようにした（平面・断面とも）。

- 「仕様（層）に断熱の層がある物は、その層の中に描いています」
- 「充填の断熱は、仕様（層）の柱・間柱の層の中に描いています」
- 「仕様（層）で位置の分からない断熱は、厚さの中ほどに描いた印です（層の位置ではありません）」
- 「基準の値との比較はしていません」（いつも）
