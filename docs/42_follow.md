# 追従（明示的にONにした物だけ）（2026-10-29 JST）

「操作と部材生成の再精査 v0.4」§2・§3の追従を、最小の形で入れた。
「部材生成・基本編集仕様案 v0.4」§3.2が初期に入れないとしているのは「部材同士の自動追従・拘束網」で、今回のものはそれに当たらない。
**人が選んだ物だけ**が、**追従先1つ**に、**位置と向きだけ**付いていく。

## できること

| 操作 | 何が起きるか | 再精査の受入 |
|---|---|---|
| 何も設定していない | ホストを動かしても動かない。スナップや配置で勝手に追従は付かない | UX04・UX06 |
| 2つ以上選んで右クリック →「最初に選んだ『〇〇』に追従させる」 | 2番目以降の物が、最初の物（ホスト）に追従する | UX07 |
| ホストを移動・回転する | 付いている物が、ホスト上の同じ場所を保って一緒に動く（1回だけ） | UX07 |
| 付いている物を手で動かす（移動ツール、プロパティの位置入力など） | 追従は**解除しない**。置いた場所から追従を続ける | UX08・UX30 |
| ホストと付いている物を一緒に動かす（同時に選択、またはグループごと） | 1回だけ動く。二重には動かない | UX29 |
| 追従の連鎖（金物 → ボルト） | ホストを動かすと、順番にたどって全部動く | ― |
| ホストを削除する | 付いている物はその場に残る。状態は「参照なし」になる。Undoでホストが戻ると、また追従する | UX09 |
| AがBに、BがAに追従する指定 | その指定だけを断る。両方とも今のまま | UX32 |
| ホストの形を変える（せいの変更、伸縮、プッシュプル） | 付いている物は動かない。歪みもしない（位置と向きだけを追う） | UX39 |
| コピー | ホストも一緒にコピーした時：コピー同士で追従する<br>付いている物だけコピーした時：同じホストに、置いた場所から追従する | ― |
| 右クリック →「追従を止める」 | 追従を外す。以後ホストだけが動く | ― |
| Undo / Redo | ホストと付いている物の移動は、まとめて1回で戻る | UX28 |
| 保存・読み込み | 追従の設定も保存される | UX10 |

- プロパティの詳細に「追従：『〇〇』に追従中」または「追従先がありません」と表示する。
- AIからは `set_follow {ids, host}`（`host: null` で解除）で設定する。`get_object` の返り値に `follow: {host, state: active | suspended}` が入る。

## 実装で決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 持たせる情報 | オブジェクトに次の3つだけ持たせる<br>・追従先（ホスト）<br>・相対位置（ホストの世界座標の逆行列 × 自分の世界座標）<br>・「相対位置を取り直す」印 | §2.3の「希望と状態を分ける」を、いちばん少ない情報で実現した |
| 状態（有効／参照なし） | 保存しない。ホストがあるかどうかで毎回その場で判断する | Undoや削除で状態がずれない |
| 処理のタイミング | 位置が変わる操作（移動・回転・整列・位置入力）の確定時だけ | 常時の処理は増やさない（仕様案§9.1）。各オブジェクトで追従が設定されているかを見るだけ |
| 二重移動の防止 | 確定する1操作の中で、移動後の世界座標を先に出す。それをもとに、自分が動いた物は相対位置を取り直し、ホストだけ動いた物は1回動かす | §3の「1回の世界座標の変換として解く」 |
| ホストの中にある物、ホストを含む物 | 追従の指定を断る（グループで一緒に動くから） | 二重の指定を作らない |
| ロックした物 | ホストが動いても動かない | ロックの約束を守る |
| 取り直しの印 | ホストが無い間に手で動かした時に立てる。次にホストが動いた時、その時点の位置から相対位置を取り直す | 再精査§2.3のpending_rebase。ホストが戻っても元の場所へ跳ね戻らない |

## まだやっていないこと

- 移動中のプレビューでは、付いている物は動いて見えない。確定した時に動く。
- 複数の追従先を同時に満たす拘束、形への合わせ込み（梁幅に合わせて金物の幅を変える等）は対象外（再精査§3、§2.2）。
- 「関連付けだけ（追従なし）」の記録（UX05）は、既存の属性で持てる（例：`set_attribute host_of=...`）。専用の仕組みは作っていない。
- コンポーネント定義の中の物は、定義の外の物に追従できない。
