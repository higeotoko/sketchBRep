## できること

| 項目 | 内容 |
|---|---|
| 置き方 | 建築ツールバーの「階段」。下の階の平面で、**歩く線（幅の真ん中）**を上がり始めから順にクリックして Enter |
| 直階段 | 2 点 |
| かね折れ（L 字） | 3 点（直角の曲がり 1 つ） |
| 折り返し（U 字） | 4 点（直角の曲がり 2 つ）。間の長さを幅と同じにすると、**1 点を中心に回る**形 |
| 曲がり角の作り方 | 角の四角（幅 × 幅）を、**踊り場**か**回り段**にする。回り段は、内側の角から**三角の段**に分ける：2 段回り（45°）・3 段回り（30°。三角・たこ形・三角）・4〜6 段回り |
| 6 段回り | 折り返しの 2 つの角を、どちらも 3 段回りにする（間 = 幅）。6 枚の段が 1 点から広がる |
| 広い踊り場 | 折り返しの 2 つの角を、どちらも踊り場にする（間 = 幅）。幅 × 2 幅の 1 枚の踊り場になる |
| 角ごとに変える | AI からは角ごとに指定できる（例：1 つ目は踊り場、2 つ目は 3 段回り）。画面では、全部の角に同じものを入れる |
| 段数 | 自動（蹴上が上限以下になる、いちばん少ない数。初めの上限は 200）か、数を決める |
| 直の段の割り付け | 曲がり角の段を引いた残りを、直の部分に配る。**踏面がなるべくそろう**ように、いつも踏面がいちばん長い所へ 1 段ずつ足す |
| 形 | 段々の塊（1 つの立体。初め）か、踏板だけ |
| 上の床の開口 | 上がりきった高さにある床（スラブツールの床）に、**頭の上が 2000 より低くなる段の分だけ**開口をあける。作る時に一緒に（取り消し 1 回）、または後からプロパティで |
| 階高への追従 | 足元・上端がレベルの高さにあれば、そのレベルに付く。階高を変えると、**段数が自動なら数え直す**。数を決めてあれば、蹴上が変わる |
| 後から直す | 階段を選んで、プロパティで幅・上がる高さ・段数・蹴上の上限・曲がり角・形・厚さ |
| 寸法の照合 | 蹴上・踏面・回り段の踏面・幅を、住宅の階段の寸法と照らして出す（下の「寸法の照合」） |

## 寸法の決まり

- 線の終わりが、上の階の床の端。最後の蹴上を上がると、上の階の床（階段の段は「蹴上の数 − 1」枚）。
- 曲がり角の四角は、角の点を中心に幅 × 幅。直の部分は、線の長さから、角の側ごとに幅の半分を引いた長さ。
- 回り段の内側の角は、入ってくる側と出ていく側の辺が出会う角。そこから 90° を等分する線で切る。
- 段々の塊は、段ごとに「蹴上 ＋ 厚さ」の高さの塊（1 段目は床から）。裏は段々になる。

### 例（幅 800、階高 2800、蹴上の上限 200）

| 線 | 結果 |
|---|---|
| 直 2730 | 14 段（蹴上 200）、踏面 210 × 13 枚 |
| 東へ 2000 → 北へ 1500（3 段回り） | 14 段。直は 1600 と 1100 に 6 枚と 4 枚（踏面 266.7 と 275）、回り段 3 枚。回り段の踏面は 155.3（狭い端から 300） |
| 1500 → 幅 800 → 1500 で折り返し（3 段回り × 2） | 14 段。直 4 枚 ＋ 回り段 6 枚 ＋ 直 3 枚 |
| 同じ線で、踊り場 × 2 | 14 段。直 6 枚 ＋ 踊り場 1 枚（800 × 1600）＋ 直 6 枚（踏面 183.3） |

## 上の床の開口

- 見るのは、スラブツールで作った床で、厚さの中に階段の上端（上がりきった高さ）があるもの。
- あけるのは、段の上面から床の下面までが 2000（変えられる）より低い段の平面。段の形そのまま（回り段なら三角も）。
- 床は床のまま：外周・厚さを直せて、壁を動かすと外周が付いてくる（[docs/102](102_wall_slide_length_and_slabs.md)）。床の厚さを変えると、下面の高さで開口を作り直す。
- 階段を変える・動かす、床を動かす、階高を変える → 開口を作り直す（同じ取り消し 1 回の中）。
- 階段を消す → 開口が閉じる（同じ取り消し 1 回の中）。
- 床が無い時は、階段だけができて「上に床がまだ無い」とステータスに出す。後から「あける」でできる。

## 実装で決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 入力 | 外形ではなく、歩く線（幅の真ん中）と幅 | 直・L・U を 1 つの決まりで描ける。曲がり角の四角が線から決まる |
| 段数の決め方 | 線（平面の形）は描いた通りにして、段数は高さから決める。踏面は結果として出す | 住宅では階段室の大きさが先に決まる。階高を変えても平面が変わらない |
| 直の段の配り方 | いちばん踏面が長い所へ 1 段ずつ | 直の部分の長さが半端でも、差がいちばん小さくなる。部分ごとに踏面が違う時は、プロパティに幅で出す |
| 回り段の先 | 内側の角の 1 点に集める | オーナーの指示（踏面が三角形）。芯の柱・先を切った形はまだ |
| 部品の持ち方 | 屋根と同じ：1 つの立体 ＋ 寸法の記録（属性 `stair_spec`） | 形を直接変えたら、寸法の編集だけをやめる（B-08） |
| 床の開口 | 床の作り方（外周 ＋ 厚さ）の外側に「階段の分を引く」を重ねる。引く物に階段の id を持たせる | 床が床のまま読める。古いファイルの床はそのまま |
| 階高への追従 | 足元が動いた分は移動、上端との差の分は段を作り直す | 1 階の床を上げた時（階段が短くなる）も同じ決まりで動く |

## まだやっていないこと

- **斜めの曲がり、らせん階段、曲線の階段**。直角の曲がりだけ。
- 回り段の**芯の柱**、先を切った形（内側の角から少し離して切る）、回り段の割り方を角度で決めること。
- **手すり、ささら桁（側板）、蹴込み板、段鼻の出**。
- 平面図の記号（上り矢印・破断線・段の番号）、断面での見え方の整え。
- 画面で角ごとに回り方を変えること（AI からはできる）。
- 上の階に床が無い所へ自動で床を足すこと。開口のまわりの受け梁（木造架構の床開口とは別。docs/55 の架構には通していない）。
- 階段の下・上の壁との取り合い（壁に寄せる、壁の中に入った時に言う）。
- 住宅以外の用途の寸法。有効幅（手すりを引いた幅）。
- 階段を消した後に残したい開口（吹抜けにする）— 今は閉じる。取り消しで戻せる。
- 置く前の先読みは踏板の形だけ（段数・踏面の数値は、置いた後にステータスに出る）。
