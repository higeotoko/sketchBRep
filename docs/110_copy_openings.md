# 開口を選ぶ・コピー（順位 7 の一部、2026-11-15）

[docs/106](106_handoff_and_roadmap.md) の A の 1〜3 番（選ぶ・コピー）。作業は Opus 5.5。
オーナーの指示：2026-11-15（「選ぶ・コピーへ」）。

## できること

| 操作 | 内容 |
|---|---|
| 移動ツールで Ctrl | 開口の穴の内側をつかんで動かしている途中に Ctrl → **コピー**。置いた所に同じ開口ができ、元はそのまま |
| コピーされる物 | 幅・高さ・建具・**手で決めた符号と品番**。開口の id は新しい |
| 「*3」 | コピーを置いた直後に「*3」（「x3」でも）→ 同じ間隔で 3 つに。**全部入るか、何もしないか**（はみ出す時は理由を出して、1 つ目のコピーは残る） |
| 距離を打つ | コピーを置いた直後に距離を打つ → コピーの場所がその距離に変わる（取り消しは 1 回のまま） |
| ほかの壁へ | AI から `copy_opening {host, opening, to_host, at}`：その壁の `at` の所を真ん中に、同じ腰高で。元の開口と同じ向きの面からあける |
| AI | `copy_opening {host, opening, by:[dx,dy,dz], count}`（同じ壁の中。count で配列）。返り値は新しい id |
| 断る所 | 壁からはみ出す・ほかの開口に重なる・元と同じ所。理由を出して、何も変えない |

取り消しはどれも 1 回。

### 開口を選ぶ

| 操作 | 内容 |
|---|---|
| 選択ツールで穴の面をクリック | その開口を選んだことになる。プロパティの「開口」には**その開口だけ**が出る（「開口 1 を選んでいます」、幅・高さ・建具・符号・品番・位置・削除） |
| 下の欄（選んでいる物の説明） | 「開口 1（W1  1600 × 1200）」のように、符号と大きさが出る |
| Delete | その開口をふさぐ（壁はそのまま。前からある動き） |
| 移動ツール | 穴をつかんで動かす・Ctrl でコピー |
| 壁全体 | トリプルクリック（今まで通り） |

## 実装で決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| あけ方 | 開口ツールと同じ入口（`placeOpeningAt`）で、新しくあける | はみ出し・重なり・壁が 2 つに切れる、の検査がそのまま効く |
| 建具・符号 | あけた後に、元の開口のものを新しい id に写す（同じ取り消し 1 回の中） | 持ち方が id ごとなので、写すだけで済む |
| ほかの壁での向き | 壁ツールの壁なら、元の開口の向きに近い側の面 | 内開き・外開きが、元と同じ側になる |
| 配列 | 1 つでも入らなければ、全部やめる（AI） | 半分だけできると、何が起きたか分からない |

## まだやっていないこと

- 開口を選んだ時の **Ctrl+C / Ctrl+V**（今は移動ツールの Ctrl でコピー）。いくつかの開口をまとめて選ぶこと。
- 選んだ開口を、画面で光らせて見せること（今は、クリックした面だけが光る）。
- 平面の記号（建具の記号・符号）をつかんで動かす・コピーする。
- 画面で、ほかの壁へコピーする（移動ツールで別の壁の上に置く）。今は AI からだけ。
- コピーの途中の、置けるかどうかの先読み（今は、置いた時に断る）。
