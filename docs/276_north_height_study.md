# 276. 北側斜線の点の試算（2026-11-25）

建築基準法第56条第1項第3号の北側斜線について、平面上の点から真北方向の距離を求める。敷地輪郭と真北はSBRの登録済みの情報を使う。真北はモデルの+Yから時計回りに指定する。作図に使う軸とは独立している。

## 採用した条件

- 真北へ進み、敷地から最初に外へ出る境界を使う。境界に触れてもその先が敷地内なら、出口として数えない。
- 確認済みの隣地辺では出口までの距離を使う。登録された直線の前面道路辺では、平行な反対側の境界まで同じ方向に測る。斜めに横切るときは、道路幅員を「真北と道路の直角方向のなす角」の余弦で割って加える。
- 制限高さは確認した地盤面のモデルZ＋立上り＋1.25×距離。立上りは5 mまたは10 mを指定する。用途地域や日影規制による適用の有無、道路端部、複数道路、地盤差や空地の特例は個別確認が必要。
- 未確認の辺や幅員がない道路では高さを空欄にする。道路と隣地が接する頂点を通る場合は、確認済みの両方の候補のうち低い高さを返して「頂点条件要確認」とする。境界に沿って進む場合は値を空欄にする。

2026-11-25にe-Govの第56条第1項第3号の本文を確認した。横浜市の高度地区の北側斜線は法第58条に基づき、道路等の境界の取り方も異なることがある。高度地区は別の制限として扱う。 [建築基準法](https://laws.e-gov.go.jp/law/325AC0000000201) · [横浜市の建築確認Q&A](https://www.city.yokohama.lg.jp/business/bunyabetsu/kenchiku/tetsuduki/kakunin/qa-kakunin.html)

## MCP・CLIでの点の照合

`north_height_at` は `boundaries`（確認した隣地辺の `start` と `end`）、`points`、`ground_z_mm`、`base_height_mm` を受け取る。指定点のZは使わない。道路辺は敷地に保存済みの登録と採用幅員を読む。道路しか使わない場合、`boundaries` は空の配列にできる。

出口 `exit_point`、元の敷地辺 `exit_boundary`、実際に距離を測った先 `reference_point`、真北方向の距離と制限高さを返す。次に表示する制限面と部材の照合もこの計算を使う（B-05・B-09）。

| 状態 | 内容 |
|---|---|
| `calculated` | 試算値あり |
| `vertex_review` | 道路と隣地が接する頂点。低い方の試算値あり |
| `outside_site` | 敷地外 |
| `boundary_unconfirmed` | 出口の境界が未確認 |
| `road_width_missing` | 出口の道路幅員が未入力 |
| `parallel_review`・`calculation_review` | 境界に沿う場合や出口を決められない場合 |

## 3D表示の設計

参考プラグインの仕様書 §10.4とISSUESのLEGAL-02を参考にする。真北へ伸ばした線がどの辺から出るか切り替わる位置で面を分ける。道路辺と隣地辺の切替箇所には別々の面を描き、異なる制限高さを一枚の三角形でつながない。平面と3Dで真北の方向、出口、距離の終点を同じ位置に示す。現段階は点の計算で、工程10の操作画面と3D面は未実装。

## 検算

- 20 m×30 mの敷地。真北は+Y、北の道路幅員6 m、高さの立上り5 m、地盤モデルZは0。点(10 m, 26 m)から敷地出口まで4 m、反対側の境界まで10 m。制限高さ17.5 m。
- 同じ敷地と道路で真北がモデル+Yから15度。真北方向の距離は10 m÷cos 15°。道路反対側でのYは36 m。
- 凹敷地の下側部分から真北に進み、一度敷地を出た後で上側部分へ入る形でも、最初の出口を採用する。

## 確認と配布

- 参考プラグイン `580bbf3` の北側斜線テスト4件・33アサーションが通った。本体では矩形で道路を正面・斜めから横断する場合、道路と隣地の共有頂点、凹敷地での最初の出口、未確認の辺と道路幅員、敷地外を検証した。
- 展開したWindows版のCLIで真北15度のSBRを開き、敷地出口がY 30,000 mm、反対側の境界がY 36,000 mm、真北方向の距離10,352.762 mm、制限高さ17,940.952 mmとなることを確認した。
