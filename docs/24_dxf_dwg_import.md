# DXF・DWG の2D図面取り込み

## 操作

- 「ファイル > インポート...」で選ぶ。種類欄からDXF／DWGを選択でき、「対応するすべてのファイル」からも拡張子で自動判別する。
- モデル空間の線図を、編集・スナップ可能な B-rep の辺・ワイヤとして追加する。
- レイヤ名はタグになる。座標はそのまま保持し、単位は mm に換算する。
- 単位指定がない図面では、1 図面単位が何 mm かを入力する。
  - mm は `1`、cm は `10`、m は `1000`、inch は `25.4`。
- 未対応の要素があると、種類と個数を表示する。
- 「いいえ」で取りやめる。「はい」で読める線図だけを取り込む。
- 取り込み全体を Undo 1 回で戻せる。
- 閉じた輪郭も線図のまま取り込む。自動で面を張らない。
- 図面の色・線種・線幅は再現しない。文字・寸法の再現機能ではない。

## DWG の準備

1. [ODA File Converter の公式配布元](https://www.opendesign.com/guestfiles/oda_file_converter)から、利用条件を確認して別途インストールする。
2. 「ファイル > DWG 変換ソフトの設定」で実行ファイルを指定する。
   - Windows はインストール先の `ODAFileConverter.exe`。
3. DWG を選ぶと、一時フォルダーのコピーを DXF に変換して読み込む。

- ODA のプログラムは SketchBRep に同梱しない。
- 元の DWG と同じフォルダーの別ファイルは変更しない。
- 変換はモデルに触れない。失敗・中止では何も追加しない。
- 変換の待機上限は 120 秒。進捗画面から中止できる。
- 変換後も DXF と同じ対応範囲になる。DWG の全要素の再現は保証しない。
- 実行ファイルの設定は、その PC の Qt 設定 `import/odaConverter` に保存する。

## 対応範囲

ASCII DXF を読む。バイナリ DXF は対象外。

| 種類 | 対応 |
|---|---|
| LINE | 水平面上の線分 |
| CIRCLE / ARC | 円・円弧。折れ線に近似しない |
| ELLIPSE | 楕円・楕円弧 |
| LWPOLYLINE / POLYLINE | 2D の開いた線・閉じた線。bulge の円弧も保持 |
| SPLINE | 制御点・ノットがある非周期の NURBS。フィット点のみのものは対象外 |
| INSERT | 配置・Z 軸回転・正の均等倍率のブロック。入れ子は最大 16 段 |
| レイヤ名 | UTF-8、または ASCII の `\U+XXXX` 表記 |

次は読み込めない要素として通知する。

- TEXT、MTEXT、DIMENSION、HATCH、POINT、3D形状など。
- 幅のあるポリライン、曲線フィット済みの旧ポリライン。
- XY 平面以外の押し出し方向、厚み、非水平の3D曲線。
- 非均等倍率・鏡像・配列・属性付きのブロック。
- 制御点がないスプライン、周期スプライン。

ペーパー空間は対象外。終了時に対象外の個数を表示する。
旧形式で Shift-JIS などの生の文字を含む場合は拒否する。AutoCAD 2007 以降の UTF-8 DXF に変換してから読む。
入力上限は 64 MiB、200 万グループ、展開後 10 万要素。上限超過ではモデルを変更しない。

## CLI / AI

ヘッドレス CLI の `import_dxf` を使う。

```json
{"command":"import_dxf","args":{"path":"plan.dxf","unitless_scale_to_mm":1000,"allow_partial":false}}
```

- 単位指定があるファイルでは、`unitless_scale_to_mm` は使わない。
- `allow_partial` の既定は false。欠落があれば取り込まない。
- 成功時は `ids` と `report` を返す。単位・除外要素・対象外のペーパー空間の個数を含む。
- アプリ内の AI 連携では、他のファイル操作と同様に禁止する。
- DWG の自動変換は GUI の機能。CLI では先に DXF に変換する。

## 検証の区別

- コア：単位・正確な曲線・レイヤ・ブロック配置・Undo/Redo・保存再読込・不正入力・部分取り込み・API のファイル制限を検証する。
- GUI：DXF の取り込み、単位と部分取り込みの取消、変換プロセスの呼び出し契約・失敗・タイムアウト・中止を検証する。
- 変換プロセスの自動テストは専用の代替実行ファイルを使う。実 DWG を解読するテストではない。
- 実際の ODA File Converter と Windows 実機での確認は別途必要。

## 大きな図面の取り込み

- 1000 本を超える場合、確認画面で「レイヤごとにまとめる」を初期選択する。チェックを外すと従来どおり個別オブジェクトになる。
- まとめる場合も正確な辺・円弧・ワイヤを保持する。選択・移動はレイヤのオブジェクト単位になる。
- CLI の `import_dxf` は `group_by_layer: true` で同じ方式を選べる。省略時は従来どおり個別。
- 取り込み中の段階と、完了時の線図本数・オブジェクト数を表示する。未対応の要素は確認画面で列挙する。
- 重複名の採番も改善し、大量の LINE を登録する際に先頭から番号を探し直さない。
- 実図面のファイルはリポジトリ・配布 ZIP に含めない。
