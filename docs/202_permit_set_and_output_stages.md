# 202. 申請図の工程：第11工程（一式の突合せ）と第12工程（申請用出力）（2026-11-20）

docs/201 の続き。これで「申請図の工程」の12工程すべてに、モデルから読んだ行が出るようになった。

## 第11工程（一式の突合せ）

| 行 | 出す物 |
|---|---|
| 工程ごと（2 通り芯、3 平面、5 階段、6 屋根・庇・バルコニー、7 耐力壁、8 基礎、9 省エネ・設備、10 立面・断面） | その工程の、見る必要のある行（要確認・要修正・未入力など）の数と状態ごとの内訳、最初の4つの項目名。無ければ「残りなし」（未評価の行は残る、と書く） |
| 建具の符号 | 手で付けた同じ符号なのに、種類・建具・大きさ・品番が違う開口があれば「要確認」と符号の一覧（建具表では最初の物の値が出る、docs/109） |
| 室名 | 同じ階に同じ名前の室があれば「要確認」（表と図で見分けられない）。ボタンでその室を選ぶ |
| まだ確かめていない事 | 図面と表と外部の添付資料の版、図番と図面リストの突合せ、法令の根拠と確認日、担当者の確認。図面一式で同じモデルから図と表をそろえて出し、申請先の図書一覧と照らす |

第1工程（敷地）と第4工程（居室・採光・換気）は、パネルの中でそれぞれの行を見る形なので、このまとめには入れていない。

図面一式そのものを作って図番を照らす事は、パネルを開くたびに全部の図を作り直す事になって重いので、ここではしない。

## 第12工程（申請用出力）

| 行 | 出す物 |
|---|---|
| 申請用出力 | いつも「保留」。申請先・適用法令・必要図書を確かめるまで、申請用の出力はしない。残りのある工程とその数 |
| 検討用の出力 | 「出せます」。図面一式、配置図のプレビュー、各図面の書き出しは、検討用としていつでも出せる（未評価・要再照合の注が付く所がある） |
| 申請先で確かめる事 | 申請先（確認検査機関・特定行政庁）、申請の区分と適用法令、必要な図書と様式、提出の方法（「未評価」） |

AI からは `permit_checks` の `stage: 11`・`stage: 12`。
