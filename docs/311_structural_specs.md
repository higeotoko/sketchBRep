# 311. 構造詳細図（3）仕様の表

規則第1条の3 表2（令第3章第3節が適用される建築物）は、構造詳細図に6つの事項を求める（docs/310）。そのうちモデルに入っていない事項を入力で受け取り、**構造詳細図（仕様）** の表にまとめる。

## 表の行

| 事項 | 条文（e-Gov で本文を確認、2026-11-27） | 中身 |
|---|---|---|
| 屋根ふき材の種別 | 令第39条 | 入力 |
| 柱の有効細長比 | 令第43条第6項（150 以下） | モデルから。柱の表の最大値と、規定内／規定外 |
| 構造耐力上主要な部分である軸組等の構造方法 | 令第46条 | 入力 |
| 継手又は仕口の構造方法 | 令第47条 | 入力 |
| 外壁のうち、軸組が腐りやすい構造である部分の下地 | 令第49条第1項 | 入力 |
| 地面から1m以内の部分の防腐又は防蟻措置 | 令第49条第2項 | 入力 |

入力した行は「入力済み」、入力していない行は「未入力」と書く。注記には資料と条文の出典を入れる。

## 使い方（MCP）

- `set_structural_specs`：`roofing`・`frame_method`・`joints`・`wall_base`・`decay` と `source` を入れる。
  - どれか1つでも入れるときは、資料（`source`）が要る。
  - 推測で入れない。
  - 1回で元に戻せる。保存される。
- `structural_spec_table`：表を読む（読むだけ）。
- 図面一式：木造の柱があるか仕様が入っていると、構造詳細図（基礎の断面）の次に入る。その次が柱の表。

## 確認

`Quantities.StructuralSpecTableTakesTheGivenSpecifications`：

- 6行がそろう。入れていない行は未入力になる。
- 柱の有効細長比の行は、モデルから照合が付く。
- 資料が無いと入らない。
- 入れた行は「入力済み」になる。
- 保存して開き直しても残る。元に戻せる。MCP で入れて読める。

## 残り

- 令第43条第1項の小径の割合（告示の本文を読んでから）。
- 継手・仕口と金物を図で示すこと（モデルに接合部の入力が無い）。
- 施工方法等計画書：木造住宅の基礎に令第3章第6節を当てはめるかを、審査機関に確かめる。
