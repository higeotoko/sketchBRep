# MCPで調べた区間の考え方と、実部材の対応表示（2026-11-05）

基準コミットは `8472e6d`。docs/64の幾何区間を、実在する柱と上下材へ対応付ける段階。

## 墨CADのMCPから確認したこと

接続済みのSumiCAD 0.7.1へ読み取り接続し、64ツールの一覧とスキーマを取得した。
`project_info`、`list_actions`、`get_elements`、`get_element`、`structure.wallBays`、
`structure.levels`、`structure.offGridPosts`、`structure.runChecks`と構造・作業順のガイドを読んだ。
作業モデルに対する追加・編集・削除・自動修正・保存は行っていない。
認証情報やプロジェクトの生データはリポジトリへ入れない。

取り込む対象として確認できたのは次の流れ。

- 壁の仕様を壁全体ではなく、柱や開口で区切られた区間に結び付ける。
  実際に開口のない壁でも、柱の接続位置で複数区間を返すことを読取り確認した。
- 区間の上下でどの横架材を参照するかを示し、計算・部材・図面の対象を対応付ける。
- 問題の一覧から対象へ進み、変更後に診断をやり直す。
- 自動配置から外れた柱の採否を人が判断できる状態として扱う。

今回はこのうち、区間の分割・四辺の実部材参照・対象選択・変更後の無効化を独立に実装した。
墨CADのソースコード、計算式、地域の仮定値、法令値、幅の配置ルール、自動修正は移植していない。
それらを追加する場合は別途原典と適用範囲を確認する。

## SketchBRepで実装したこと

### 柱の位置で区切る

既存の開口除外区間を、壁の範囲に存在する木の柱・通し柱の断面基準中心位置で分割する。
通り芯を引いただけでは柱があると見なさず、柱や筋かいを新しく生成することもない。
柱が壁厚の範囲に届くことを実形状で確認する。左右寄せの壁では、基準線が端にあっても壁内の柱を検出する。壁から外した柱は分割対象から外れる。
開口の横幅の中にある柱から、開口内の候補を作ることもない。

通常の線形部材と、単一の線形部材を持つ共有部品の現在の寸法・配置に対応する。
共有部品の役割・材料属性は、配置側の指定を優先し、省略時は定義から引き継ぐ。
親グループの移動・回転、断面の基準位置、部品定義の寸法編集も現在の実形状から読み直す。

### 四辺の部材と接触を調べる

候補ごとに始端柱・終端柱・下材・上材のIDと名前を返す。
下材・上材は、壁の下端・上端面に届き、その区間全体を覆う水平の土台・梁等の役割の材。
間柱、根太、まぐさ、窓台や表示専用の材を、これらの部材へ読み替えない。
構造部材を非表示にしても読取り対象には含める。

四辺に一つずつ対応する材があれば、四つの柱と横材の実形状間の最短距離を調べる。
表では次を分けて示す。

|表示|意味|
|---|---|
|四辺接触・仕様未確認|四辺の候補が一意で、実形状間の距離がモデルの検出許容差以内|
|部材間に隙間|四辺の候補はあるが、柱と横材の間に検出許容差を超える隙間がある|
|対応が曖昧|同じ端部の柱や同じ辺全体の横材に複数候補がある|
|未確認の辺あり|一部の材を検出できない、または複数の材が辺の一部ずつを覆っている|
|形状判定未完了|距離の判定を完了できない|

許容差は既存の木造概略チェックの `tolerance_mm` を共用する（同梱初期値1mm）。
小さな位置差をまとめるためのモデル上の許容差で、耐力壁の最小幅や接合の許容値ではない。
候補ごとのツールチップに材名と検出できた隙間を示す。

### 実部材を選ぶ

「壁の区間候補」の行を選ぶと区間を強調する。
「始端柱」「終端柱」「下材」「上材」のボタンで、その実部材を選択して強調できる。
複数候補や辺の一部の材も、対応するボタンからまとめて選んで確認できる。
壁・開口・部材・部品定義を編集したら、古い一覧と強調・部材選択ボタンを無効化し、再抽出する。
診断と選択は形状・壁量入力・Undo履歴を変更しない。

## 評価の範囲

実形状が触れていても、仕口・金物・接合耐力・荷重伝達・施工仕様の確認は別に必要。
壁量へ自動計上せず、`verified:false` のまま返す。筋かいの算定高さも自動設定しない。
壁の高さが仕上げ等のため横材の面と異なるときは、この段階では未検出・未確認となる。
複数の梁を継いで辺を覆う場合、その継手を自動で成立とせず「一部のみ」として残す。
任意B-repへ編集された材・傾いた柱等は未評価の部材として名前を報告する。

## AI・CLI

`list_wall_bays` は `wall-bays-2` を返す。既存の壁ID・世界座標・t0/t1に加えて、
`supports.{start_post,end_post,bottom,top}`、`frame_geometry`、`joint_distances_mm`、
`support_signature`、`tolerance_mm`、`unassessed_members` を持つ。
各辺はdetected / missing / ambiguous / partialの区別、ID・名前・一部の材のIDと名前を持つ。
`source_signature`にも対応する実部材の状態を含め、柱や上下材の変更を識別する。
候補IDは引き続き返却スナップショット内だけで有効。
SketchBRepのt0/t1は従来どおり壁長に対する0〜1の比率で、座標・長さ・距離の単位はmm。
墨CADの壁端からの距離としてのt0/t1を、そのまま転用したものではない。

```json
{"command":"list_wall_bays","args":{"elevation":0}}
{"command":"list_wall_bays","args":{"split_at_posts":false}}
```

後者は柱位置では分割せず、従来の開口除外区間を取得する。どちらも読み取り専用。
