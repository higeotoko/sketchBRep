# 屋根の種類にも層を持たせる（N-08 の第 7 段、2026-11-16）

[docs/151](151_floor_type_layers.md)（床の種類の層）の「まだ」（屋根の層）。作業は Opus 5.5。
オーナーの指示：2026-11-16（「進めて」）。

## できること

| 項目 | 内容 |
|---|---|
| 層 | 登録した**屋根**の種類にも、上から順に層（名前と厚さ）。例：ガルバリウム 20・野地板 12・垂木 88（計 120） |
| 厚さ | 層の合計が屋根の厚さ（**勾配に直角**の厚さ。屋根の寸法と同じ） |
| 断面図 | その種類の屋根を縦に切った所に、層の境目ごとに細い線。**屋根の面に平行**で、面から直角に層の厚さだけ下。棟・隅など 2 つの面が合う所では、線どうしが交わる所で止める（留め） |
| 床 | 床の層の線（docs/151）も同じ作りで描くようにした（結果は同じ） |
| AI から | `define_type {part: roof, layers: [...]}` |

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 線の作り | 上を向いた面（法線が上向き）ごとに、切った線を面の内側へ直角に動かす。2 つの面の線が端でつながっていれば、動かした線が交わる所まで伸ばす・縮める | 屋根の形（切妻・寄棟・片流れ・斜めの外周）によらず、面から決まる |
| 軒先 | 線は軒先の端の面まで（軒先の面は勾配に直角なので、そこで合う） | 屋根の形の作り（docs/90 G-08）どおり |
| 厚さが合わない屋根 | 線を出さない（床・壁と同じ） | 黙って違う線を出さない |

## まだやっていないこと

- 層ごとの塗り（ハッチ）、画面から層を入れる窓、IFC・数量への層。
- 棟と平行に切った断面（妻側から見て、面を斜めに切る時）の確かめ（作りは同じだが、テストは棟に直角に切る所だけ）。
