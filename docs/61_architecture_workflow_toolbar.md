# 平面から始める建築操作の入口（2026-11-05）

追記：この後、優先1の平面からの開口配置を [docs/62](62_plan_opening_placement.md) で実装した。以下はツールバー追加時点の記録。

基準コミットは `11fc22c`。既存の開発ブランチを継続する。
所有者の「SketchBRepの思想に合う墨CADの使いやすさを取り込む」という方針を受け、
まず散在していた建築操作の入口を揃えた。

## 実装したこと

上部の「建築」ツールバーに、次の操作をまとめた。

1. 「平面で描く」で地面または登録レベルを選ぶ。平行投影の平面へ切り替え、作業面の高さを設定する。
   吸着した点もその作業面へ投影するため、別の高さの頂点へ吸着して階を取り違えにくい。
   現在の作業面名と高さを表示し、手動で作業面を変更した場合も表示を更新する。
2. 同じメニューからレベルの編集と通り芯の作成へ進む。
3. 壁・スラブ・開口を選んで作図する。各ボタンの右矢印から既存の寸法・配置設定を開く。
4. 柱・梁の専用入口を選ぶ。「3D」で自由な立体表示へ戻る。
5. 「木造」から架構生成・再生成、架構チェック、壁量比較、拾い出しを開く。

ツールパレット・メニューと同じQAction、同じツール、同じModelerを使う。
新しい形状表現や、別の編集履歴は増やしていない。従来のショートカットとUndoを共用する。
「表示 > 建築」で隠せる。ツールバーを動かすこともできる。
F1の「建築の機能」に操作方法を追加した。

レベルメニューは開くたびに現行のレベルから作り直す。
メニューを開いたままレベルが変更された場合も、選択時にIDから現在の高さを調べる。
削除済みのレベルを選んでも、古い高さへ切り替えない。

## 今回の範囲

- レベルの選択は、その時点の高さを作業面へ設定する操作。既存部材への階属性の割当てや、
  レベルへの追従関係を自動で付ける操作ではない。レベルの高さを後で変えたら選び直す。
- 開口の配置は従来どおり壁面をクリックする。3Dまたは立面で使うことをツールチップとヘルプに示す。
  平面上の壁をクリックする開口配置は次の独立した実装課題。
- 壁量計算の入力・係数・判定は変更していない。実部材との未連携についてはdocs/60を参照。
- 起動済みのポータブル版の置換は行っていない。

## 次に取り込む順序とSketchBRep側の条件

|優先|取り込む使い方|実装時に守る条件|
|---|---|---|
|1|平面上で壁を選び、窓・扉の位置を決める|壁の基準線と元形状から配置先を求め、プレビューと既存の開口編集へつなぐ。任意形状では面選択へ戻れる|
|2|開口を除いた壁区間を耐力壁指定の候補にする|壁ID・区間・階・左右柱・横架材・仕様の関連を保持。形状から仕様確認済みとは推測しない。変更時は再確認を促す|
|3|壁の端部・交点・開口周囲を見ながら柱を追加する|既存柱との重複を避け、支持材の自動削除はしない。人の修正を再生成で保持する|
|4|診断から問題の部材へ移る|一覧の理由とモデルの対象を対応させ、修正前後と未評価の範囲を見せる。作図を禁止する仕組みにはしない|
|5|閉じた平面輪郭から室名・面積を扱う|既存の正確な輪郭・注記・図面を使う。室境界が開いた場合は不明として扱い、部屋の形を勝手に補わない|

これらは今後の実装順序であり、今回すべて実装済みという意味ではない。
墨CADから参考にするのは、平面・階・壁区間を基点にした操作の流れ。
SketchBRepでは既存のB-repを正規データとして維持し、通常の直接編集と同じ操作経路へ組み込む。
