# 横浜市の確認申請書・建築計画概要書への転記

敷地メニューの「確認申請のWord様式」または申請工程1の「Word様式を開く」から、確認申請書（第二号様式）と建築計画概要書（第三号様式）を選ぶ。転記する値、転記元、記入が残る欄を一覧で読み、編集できるWord文書（.docx）に保存する。

- 「計画概要」の建築主氏名、地名地番・住居表示、都市計画区域、防火地域、その他の区域、主要用途・区分、工事種別、単一の構造、許可・認定等、日付、その他必要な事項を対応する欄に書く。確認申請書には構造計算適合性判定・省エネ適判の選択も入る。法第22条区域は防火地域の「指定なし」を選び、区域名を「その他の区域」に入れる。
- 幅員と接道長さは、現行の敷地境界に対応する道路の登録値を使う。敷地面積、用途地域、建築面積、延べ面積は、単一棟の新築で用途地域の区分がない場合に候補を選んで転記する。敷地境界、用途地域の設定、面積の根拠図と同じモデルを参照する。未算定の値、申請以外の部分、建蔽率・容積率、高さと階数、棟数は様式側に残す。
- 資格・事務所・氏名などが一つの欄に入力されている場合は、元の入力を一覧に出す。様式ではそれぞれの欄に記入する。確認申請書の第四面以降、特定工程、概要書の定期報告・防火設備なども様式に残る。
- 概要書の第三面では、登録済みの敷地から配置図（検討用）を組み込める。付近見取図は読み込みを選択すると、登録した地点の国土地理院地図を既存の地図機能で取得して組み込む。地図タイルが不足した場合は図の枠を空欄で保存し、結果を表示する。図は枠に収め、寸法の目安を印刷サイズに追従するスケールバーで示す。

## 様式の版

2026-11-24に掲載された第二号様式と、2026-04-16版の第三号様式を使用する。配布用の様式は原本のページ構成を保持し、転記箇所と図の挿入位置を指定して同梱する。アプリで書き出す際にWordのインストールは不要。様式の改定時は原本を取り直し、`tools/permit_forms/prepare_templates.py` の原本ハッシュと対応箇所を確認して再生成する。 [横浜市の法定様式](https://www.city.yokohama.lg.jp/business/bunyabetsu/kenchiku/tetsuduki/kakunin/dl/dl-hotei.html) · [建築基準法施行規則](https://laws.e-gov.go.jp/document?lawid=325M50004000040_20260401_506M60000800068)
