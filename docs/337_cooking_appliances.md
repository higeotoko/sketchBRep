# 337. こんろ等（火を使用する設備器具）と、告示第1826号の本文を探した記録

国交省マニュアルの平面図チェックリスト（docs/334 と同じ）を、うちの対応と照らした。まだ扱っていなかったのは、火を使用する室（令第20条の3）の3項目。

- 3-8 かまど、こんろその他設備器具の位置、種別及び発熱量
- 3-9 火を使用する室に関する換気経路
- 3-10 換気設備の有効換気量

作成例の平面図には「検討Ⅱ 台所換気設備計算」の囲みがあり、必要換気量＝30×K×Q を出して、有効換気量と比べている。

## 入れたこと（3-8）

3-8 は図に書く事項で、法の数値は要らない。そこで設備（docs/334 の `place_device`）に種類を1つ足した。

- `cooking_appliance`（凡例の言葉は「こんろ等（火を使用する設備器具）」）：
  - 注記（note）が必須。種別と発熱量を書く（例：「ガスこんろ 都市ガス 10.78kW」）。注記が無いと断る。
  - 平面図の記号：四角に3つの口の丸。凡例には言葉と注記が出る。
- 申請の段階3（平面）のチェック：こんろ等があると「火を使用する設備器具：要確認」の行が出る。
  - 位置・種別・発熱量は平面図に書く。
  - 有効換気量（告示第1826号 第三）は計算していないので、別に確かめる。

## まだ入れないこと（3-10 の計算）と、その理由

必要換気量の式（V＝N×K×Q、K は燃料ごとの理論廃ガス量、N はフードの形による係数）は、昭和45年建設省告示第1826号 第三 にある。係数は法の数値なので、推測では入れず、本文を見てから入れる（docs/323 の告示1349号と同じ扱い）。今回、現行の本文を確かめられなかった。

- 国交省の PDF（https://www.mlit.go.jp/jutakukentiku/build/s2004/pdf/k051.pdf）：
  - 平成12年の改正の新旧対照の案（日付 00/04/14）。
  - 文字の取り出しも化けていた。
  - 改正の案なので、今の本文の証拠にはならない。
- 札幌市消防局の資料（告示の全文を載せているという検索結果）：PDF の場所が 404 で、読めなかった。
- 検索結果の解説記事には、次のような値が出ていた。どれも告示そのものではないので、使っていない。
  - 都市ガス・LP ガス 0.93 m³/kWh
  - 排気フードⅠ型 30、Ⅱ型 20、フード無し 40、煙突 2
- 国交省マニュアルの作成例（30×K×Q、K＝0.93）も、例であって告示の本文ではない。

告示の現行の本文が手に入ったら、次の流れで入れる。

1. こんろ等に燃料の種類と発熱量（kW）を数値で持たせる。
2. レンジフードにフードの形（Ⅰ型・Ⅱ型など）と有効換気量を持たせる。
3. 必要換気量と比べる行を足す。

## 確認

- `Schedules.CookingAppliancesCarryKindAndHeatOutput`：
  - 注記の無いこんろ等は断られる。
  - 置くとチェックに「火を使用する設備器具：要確認」の行が出て、告示第1826号を名指ししている。
  - 平面図と凡例に「こんろ等（火を使用する設備器具）　ガスこんろ 都市ガス 10.78kW」が出る。
- コアのテスト 869 本が通る。
