# 321. 室ごとの FL

熊本県の作成例（docs/296）の平面図では、室名の下に「(FL±0)」「(FL−180)」のように室の床の高さが書いてある。docs/298 で、室名の下に面積・天井高を出すようにした。それに FL を足す。

## 入力

- 室の床の高さは、その階の FL から mm で入れる。例：玄関 -180、同じ高さなら 0。
- 入力は人がする。入っていない室には何も書かない。「±0」を推測で書くことはしない。
- 入れ方：
  - MCP：`set_room_finish` の `floor_offset`（null で消す）
  - アプリ：室のプロパティの「床の高さ（FL から）」（空欄で消す）
- 1回で元に戻せる。室の仕上げと一緒に保存される。
- ±5,000 mm を超える値は入らない。

## 平面図

室名・面積・天井高の下に、もう1行で書く（`(FL±0)`、`(FL-180)`、`(FL+100)`）。文字の大きさと行の間は、面積・天井高の行と同じ。

## 確認

- `PermitIntake.RoomFloorLevelIsWrittenUnderItsName`：
  - 入れていないと書かない。
  - 玄関 -180・居間 0 を入れると、平面図に (FL-180) と (FL±0) が出る。
  - 9,000 は入らない。
  - null で消すと、玄関の行が消える。
- GUI（`schedulesAreReadFromTheModel…`）：室のプロパティに -180 を入れると、モデルに入る。

## 残り

- 仕上げ表に FL の列を足すか。
- 室の FL を、床の形（段差のある床）に反映すること。今は表記だけ。
