# 平面図で、同じ仕様の壁の継ぎ目の線を消す（Fable に渡す物の 7 の一部、2026-11-17）

[docs/106](106_handoff_and_roadmap.md) の「Fable に渡す物」の 7。[docs/140](140_layer_line_mitres.md)・[docs/159](159_mitred_wall_corners.md) の「まだ」（平面図で、同じ仕様の壁の継ぎ目の線を消すこと）。作業は Opus 5.5（オーナーと決めた分担で、Opus でこなせる物から）。
オーナーの指示：2026-11-17（「進めて」）。

## 直す前

平面図（DXF・JWW・PDF）で、壁は 1 枚ずつ切った線を出していた。そのため、同じ仕様の壁どうしが合う所に、太い切断線が残っていた。

- 突き付けの角：片方の壁の端の線（壁の厚さの分）。
- 留めの角（docs/159）：角の対角線。
- 一直線に 2 枚に分かれた壁：分かれ目の線。

## 直した後

| 項目 | 内容 |
|---|---|
| 消す線 | **同じ仕様**（壁の層が同じ）の壁どうしが平面の切断で接している所の、間の線。両方の壁から消す |
| 残す線 | 仕様の違う壁どうし（外壁と間仕切りの T 字など）の間の線。仕様の無い壁どうしの線（今まで通り） |
| 層の線 | 今まで通り（角では留め、docs/140）。継ぎ目が消えたので、角で層の線が入れ子の L 字につながって見える |
| 下に見える線 | 切った壁の上の面の継ぎ目（上から見えていた細い線）も出さない |
| 出る所 | 平面図（DXF・JWW・PDF、図面一式）。**画面の平面モードは変えていない**（画面は 3D の切断表示で、継ぎ目は表示の仕組みが描いている） |

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 「同じ仕様」の決め方 | 壁の層（`wall_layers`）が同じ | 層の線の留め（docs/140）と同じ決まり |
| 何を見て消すか | 2 枚の壁の切断線のうち、同じ線の上で重なっている部分 | 立体どうしが接している所だけが消える。少し離れている・重なっている壁は消さない（そのまま見える方が、直す所が分かる） |
| T 字の層の線 | **今の突き付けのまま**（外壁の内側の面・ボードが通り、間仕切りの層の線は外壁の面で止まる） | 「間仕切りの層が外壁の内側の層へ回り込む形」にするには、図面の線だけでなく壁の立体（外壁のボードを間仕切りの所で切る）を変えることになる。壁のつながりの中心で、Fable に残すと決めた所（docs/106 の 6） |

### T 字の間仕切りの描き方（確かめていて分かった事）

T 字の間仕切りは、相手の壁の**面まで**描く決まり（今までのテスト・壁ツールと同じ）。外壁の線（柱の芯）まで描くと、間仕切りの立体が外壁の中へ入り込み、平面図で外壁の内側の面の線が間仕切りを横切って見える。これは今回の変更の前からで、壁のつながり（6）の残りと一緒に見直す。
