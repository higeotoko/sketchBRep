# 層の塗り（ハッチ）（2026-11-18）

[docs/106](106_handoff_and_roadmap.md) の「残り（Opus で可）」の「層の塗り（ハッチ）」。[docs/124](124_wall_layer_lines.md)（壁の層の線）・[docs/151](151_floor_type_layers.md)（床の種類の層）の「まだ」。作業は Opus 5.5。
オーナーの指示：2026-11-18（「層の塗り（ハッチ）」）。

## できること

| 層 | 塗り |
|---|---|
| 構造材：壁の「芯」の層（柱・間柱）、床・屋根の種類で名前に 柱・間柱・根太・垂木・大引・梁・土台 を含む層 | **交差線（×）**、紙の上で 3 mm おき |
| 合板：名前に 合板・野地板 を含む層 | **斜線**、紙の上で 1.5 mm おき |
| 仕上げ（サイディング・モルタル・フローリング）・胴縁・石膏ボードなど | 塗らない |

| 項目 | 内容 |
|---|---|
| 出る所 | 平面図・断面図の、仕様のある壁の切り口と、層を登録した種類の床の切り口（断面図）。図面の窓・AI の `export_drawing`・図面一式 |
| 間隔 | 紙の上の間隔で決める（縮尺を変えても見た目は同じ）。図面の窓で縮尺を変えると図を作り直す |
| 向き | 紙の上で 45°。隣の壁の切り口と線がそろう（同じ格子） |
| 出ない所 | 画面の平面モード（縮尺が無い）、屋根の斜めの層、骨組みの図、層の厚さが合わなくなった物 |
| AI から | `export_drawing` の `hatch`（初めは入れる。false で入れない） |

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 記号 | 構造材は交差線、合板は斜線、ほかは白 | 柱を × で表す書き方に寄せた。全部の層を塗ると図が黒くなる。JIS の材料記号を細かく全部は入れていない（「まだ」） |
| 層の見分け方 | 壁は層の役割（芯）と名前、床・屋根は名前の言葉 | 床・屋根の層は名前しか持っていない。当てはまらない名前は塗らない（黙って違う記号にしない） |
| 計算の仕方 | 切り口の多角形と層の帯を、紙の上の 2 次元で切り取る | 線 1 本ずつを立体の計算にかけると重い。例題 A（2 階建て）の 1:20 の平面図でも 1 秒くらいで変わらない |

## まだやっていないこと

- 屋根の斜めの層のハッチ（層の線は出ている、docs/152）。
- 断熱材（波線）・モルタル（点）など、JIS の材料記号を層ごとに選べるようにすること。
- 画面の平面モードのハッチ。
