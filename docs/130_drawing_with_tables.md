# 1 枚の用紙に図と表を並べる（docs/125 の続き、2026-11-15）

[docs/125](125_drawing_set.md)（図面一式）の「まだ」（1 枚の用紙に、図と表を並べて置くこと）。作業は Opus 5.5。
オーナーの指示：2026-11-15（「続けて」）。

## できること

| 項目 | 内容 |
|---|---|
| 画面から | ファイル → 図面の書き出しの窓に「建具表を並べる」「室の表を並べる」「面積の表を並べる」「仕上げ表を並べる」。付けると、プレビュー・PDF・DXF・JWW で同じ用紙に表が並ぶ |
| AI から | `export_drawing` の `tables`（openings / rooms / areas / finishes のリスト）。返り値の `tables` は置いた数 |
| 置き方 | 図（見出し・通り芯・レベル込み）を枠の**左上**に。表は**図の右**に上から縦に並べる。右より**下**に置いた方が小さい用紙で済む時は下 |
| 方位 | 平面図の方位記号は、図の右上のすぐ外に（用紙の角ではなく） |
| 用紙 | 「自動」なら、図と表が全部入るいちばん小さい A4〜A1。用紙を決めた時に入らなければ、はみ出すと注意に出す |
| 中身の無い表 | 置かない（建具が無い、仕上げが空など）。AI には「○○ の表は空なので置かない」と返す |
| 表が無い時 | 今までの 1 枚の図と同じ |

建具表・室の表などは、どれも今のモデルから読む（表の窓・`export_schedule`・図面一式と同じ中身）。

## まだやっていないこと

- 図面一式（docs/125）で、平面図に表を並べた 1 枚を作ること（今は表は別の 1 枚）。
- 表の置き場所（右・下）や順番を選ぶこと。
- 1 枚に図を 2 つ以上並べること。
- 表が長い時に 2 段に分けること。
