# 引違い窓の框と、開き戸の取っ手（建具の形の第 3 段、2026-11-18）

[docs/146](146_fitting_solids.md)（建具の形）・[docs/157](157_fitting_sizes.md)（建具の寸法）の「まだ」（框・取っ手）。[docs/106](106_handoff_and_roadmap.md) の「残り（Opus で可）」。作業は Opus 5.5。
オーナーの指示：2026-11-18（「続けて」）。

## できること

| 物 | 形 |
|---|---|
| 引違い窓の框（障子） | 障子 2 枚それぞれに、見付 35・見込 30 の框（四方）。ガラスは框の内側。2 枚は今まで通り 2 本のレールに、召し合わせで 50 重なる |
| 框の見付 | 建具の `sash`（10〜100、初め 35）。AI は `set_opening_fittings` の `fitting` に `sash`。建具の型（docs/171）にも入る |
| 開き戸の取っ手 | 片開き・両開きの扉の両面に、台座（50 角・厚さ 50）とレバー（長さ 120・20 角、吊元の方へ向く）。床から 900、閉まる側の端から 60。両開きは、2 枚とも合わせ目の側 |
| 出る所 | 3D・立面図・断面図（建具の形が出る所は全部。部品の名前は `sash`・`handle`） |

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 框を付ける窓 | 引違いだけ | はめ殺しの窓（「窓」）はガラスを枠に直接入れることが多い。片引き・片開きの窓は種類にまだ無い |
| 取っ手の向き | 平面の記号と同じ吊元の決まり（開く側から見て左右） | 平面と 3D で吊元が食い違わないように |
| 取っ手の高さ | 900 | 住宅の開き戸のよくある高さ。扉の高さが足りない（上端が取っ手より 30 以内）時は付けない |
| 引戸 | 引手は付けない（「まだ」） | 彫り込みの引手は、扉の板を削る形になる |

## まだやっていないこと

- 框戸（扉の板を框と鏡板・ガラスにする）、引戸の引手、開いた状態の扉。
- 片引き・上げ下げ・すべり出しなど、窓の種類を増やすこと。
- 取っ手の高さ・形を変えること。
