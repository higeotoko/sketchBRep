# STL 書き出し（2026-10-26 JST）

## 操作

1. 書き出すオブジェクトを選択する。何も選ばなければ表示中のモデル全体が対象。
2. **ファイル → エクスポート...** を開き、種類を **STL ファイル** にして保存先を選ぶ。
3. 続く設定画面で曲面の近似精度を指定する。既定は0.1 mm。小さな値ほど細かく、ファイルも大きくなる。

出力はバイナリSTL。座標はmmの値なので、読み込み先でもmmを選ぶ。
STL自体には単位情報、マテリアル、テクスチャ、オブジェクト名、編集履歴は格納されない。
元のSketchBRepの形状・素材・履歴はそのまま残る。

面やソリッドを出力し、線図・寸法・ガイド・独立した下敷き画像は含めない。
面だけの形状も出力できるが、厚みのない開いたメッシュになる。3Dプリント用なら閉じた立体を使用する。
DXFの場合は、輪郭を選んで右クリックから面を生成し、プッシュ／プルで厚みを付けてから書き出せる。
非表示のオブジェクトやタグは出力対象外。グループ・コンポーネントの配置を反映する。コンポーネントは生成済みの形状を出力する。
複数の立体は同じSTL内の形状として出力し、面の修復や立体同士の自動合体は行わない。

## 確認用ファイル

Windows ZIP の `examples/stl/box_10x20x30.stl` は、同梱CLIで作った10×20×30 mmの箱。
3Dプリントソフトなどで開き、mm単位で寸法を確認できる。
この例は配布ZIPを作るCIで生成し、ファイル長684バイト・三角形12枚を確認する。

## CLI / MCP

```json
{"command":"export_stl","args":{"path":"model.stl","linear_deflection_mm":0.1}}
```

`ids` にオブジェクトID配列を渡せば、そのオブジェクトだけを対象とする。
近似精度の最小値は0.001 mm。内部の既定角度は0.35ラジアン。
ファイルI/Oとして扱い、アプリ経由の制限付きAIブリッジ、preview、原子的batchでは書き出さない。

## 実装と検証

- STLは80バイトのヘッダー、little endianの三角形数、法線と頂点のIEEE754 float32、属性0で記録。
- 形状のコピー上でOCCTの三角形分割を行う。正規B-repにメッシュや変更を残さず、Undo履歴も増やさない。
- 複合形状に子を加える際も、元のTShapeのFreeフラグを変えないようトポロジーのコピーを使用する。
- 球の極でOCCTが出す面積0の三角形は除外する。実面の全三角形が失われる場合はエラーにする。
- 有効な三角形がfloat32の精度でつぶれる場合は、原点に近づけるかSTEPで出力するよう案内する。勝手に原点移動しない。
- メッシュ生成と検証が完了するまで出力先を開かない。既存ファイルの上書き確認は、選んだ形式に拡張子を合わせた最終的なファイル名に対して行う。
- 独立したバイナリSTLパーサーで、寸法、体積、頂点・法線、空洞と鏡像の向き、精度による分割数を確認。
- 選択・グループ・配置・非表示、日本語パス、上書き、面だけの出力、線だけの場合の拒否、無効設定、I/Oエラー、AI経由の制限を確認。
- GUIで保存ダイアログから精度を指定して出力し、拡張子の自動補完とキャンセルも確認する。
