# 341. 高さ制限の線を文字の所で切る

断面図の高さ制限（道路斜線・北側斜線などの合成、docs/317〜319）の線が、高さの寸法の数値や名前を通ると読みにくくなる。断面の切断線では、文字の所で線を切っている（docs/250）。高さ制限の線も、シートに置くときに、通る文字の手前で切るようにした（高さ制限の線自身の名前は除く）。

## 途中で見つけたこと

最初の作りでは切れていなかった。原因は、文字の一覧（ポインタ）が、シートの部品を移していく途中で中身が空になった部品を見ていたこと。文字は先にコピーしてから切るようにした。

## 確認

- `Drawing.HeightLimitLineIsBrokenAtAWord`：
  - 「最高の高さ 7,764」の真ん中を通る高さ制限の線が、シートで文字の両側の2本に切れる。
  - それぞれ文字に重ならない。
  - ほかの線（切断線）は切れない。
  - 直す前のコードでは、このテストは落ちた（線が1本のまま文字を通っていた）。
- `Drawing.HeightLimitLinesStopShortOfWords`：
  - 道路斜線の入った図面一式の断面図で、高さ制限の線がどの文字も通らない。
  - この作り物の敷地では、直す前でも文字を通っていなかった。だから、これは仕組みの証拠ではなく、全体のつながりの確認。
- コアのテスト 877 本、図面・シートの GUI テストが通る。

## 残り

例題で、北側斜線が寸法に重なる場面を画像で確かめること。例題E に敷地境界が入っていないので、高さの検討を入れられなかった。
