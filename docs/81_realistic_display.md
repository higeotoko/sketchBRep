# リアル表示（材質・太陽・影）（2026-11-06）

高品質なビジュアライゼーションの検討（docs/reviews/2026-11-06_visualization_engine_study.md）の段階 1 の最初の一歩。Rhino の「シェーディング ↔ レンダリング表示」の切り替えのように、普段の CAD 表示と、材質・太陽・影のある表示を切り替える。Unreal Engine などの外部エンジンは使わず、今の表示エンジン（OCCT）の機能だけで作った。

## 使い方

「表示 > リアル表示（材質・太陽・影）」、または **F9**。もう一度押すと CAD 表示に戻る。

| 項目 | リアル表示でこうなる |
|---|---|
| 材質 | 材質の「金属感」「粗さ」を、物理ベースの描き方（PBR）で表示に使う。今までは保存されていても表示には使っていなかった。材質の無い物は、つやの無い非金属（粗さ 0.6） |
| 光 | 南東の高い所からの太陽（影を落とす）、反対側からの弱い光、空からの光（全体） |
| 影 | 太陽の影を、物どうしと地面に落とす |
| 地面 | SketchUp と同じく、**地面そのものは見せず、影だけを GL（z = 0）に落とす**。影を受ける面を、背景の地面と同じ明るさに見える色で置いている（描いた画面で測って合わせた）。モデルを変えると大きさが付いてくる。「表示 > リアル表示で地面に影を落とす」を外すと、地面は作らない（設定は次回も残る） |
| 軸の線 | 隠す（百万 mm まで伸びていて、影の計算の範囲が広がりすぎるため。レンダリング表示では普通は出さない） |

変わらないこと：

- 選択・スナップ・ツール・Undo は CAD 表示と同じ。地面は表示だけの物で、選べない・吸着しない・モデルに入らない。
- 保存するファイルの中身は変わらない（表示の設定で、保存しない）。
- CAD 表示に戻すと、照明・軸・描き方は元どおり。

## 実装

- `Viewport::setRealistic`（`src/app/Viewport.cpp`）：ビューの描き方を PBR に、照明を入れ替え（環境光・影を落とす太陽・補助光）、影を有効（影の解像度 2048）、軸を隠し、地面を出す。戻す時は既定の照明とビューの既定の描き方に戻す。
- `Viewport::applyPhysicalMaterial`：物の材質（受け継いだ物も）の金属感・粗さを、表示の材質の PBR の値に入れる。CAD 表示（Phong）はこの値を使わないので、表示の切り替えで物を描き直さずに済む。
- `Viewport::updateRealisticGround`：表示している物の外形から地面を作る。描き直しのたびに大きさを合わせる。
- OCCT 7.6 では、照明を一度に全部消す `V3d_Viewer::SetLightOff()` が例外になることがあった。1 つずつ消して外す。
- 「表示 > リアル表示」（`realisticAction`、F9）、ヘルプのキー一覧に追加。
- 「表示 > リアル表示で地面に影を落とす」（`groundShadowsAction`、`Viewport::setShadowsOnGround`、QSettings の `view/groundShadows`）。影を受ける面の色は、光の当たり方を含めて背景の地面（sRGB 0.80, 0.80, 0.78）と同じに見えるよう、描いた画面の画素で合わせた（地面 204 / 背景 203）。光の強さを変えたら合わせ直す。
- 面 1 枚なので、描画の負担はほぼ無い。
