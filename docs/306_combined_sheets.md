# 306. 図面表現の見直し（9）1枚に複数の図

熊本県「確認申請図書の作成例」（docs/296）では、1階と2階の平面図を1枚に、立面図と断面図を1枚にまとめている。図面一式に、同じまとめ方を選べるようにする。

## 使い方

- MCP の `export_drawing_set` と `render_drawing_set` に `combine_views: true` を渡す。
- 初期値はオフ（これまでどおり1枚に1図）。受付先によって、図面の分け方の好みが違うため。
- アプリでは、ファイルメニューの「図面一式を書き出す（平面図・立面図と断面図をそれぞれ 1 枚にまとめる、1 つの PDF）」（`c7bacdc`）。

## まとめ方

- **平面図**：各階の平面図を1枚にまとめる。表が横に付く平面図（`tables_with_plan`）と、架構図は除く。シート名は「1FL 平面図・2FL 平面図」。
- **立面図・断面図**：並んでいる立面図と断面図を1枚にまとめる。シート名は「立面図・断面図」。
- それぞれの図は、これまでどおり1枚の図として作る（題名・縮尺・レベル・通り芯・寸法付き、枠は無し）。それを左から右へ、行を折り返して並べる（間隔 15 mm）。
- 用紙は、全部が入る一番小さい A4〜A1。入らなければ A1 に注記を付ける。
- 枠・表題欄・凡例（docs/303）は、まとめたシートに1つ。平面図のシートには方位記号を1つ付ける。
- 図番は、まとめた後の順に詰めて振る。次の2つも同じ図番を指す。
  - 平面図の切断位置記号に書く図番
  - 断面図の「切る位置」
- 図面リストにも、まとめた後のシートが並ぶ。

## 線の考え方

図は絵として貼るのではなく、ペンの付いた線と文字のまま並べる。DXF・JWW に書き出しても、ペンごとのレイヤーで分かれたまま。

## 確認

- `Drawing.DrawingSetCombinesViewsOnOneSheet`：
  - シートが減る。
  - 1FL・2FL が1枚、立面図4つと断面図が1枚に入る。
  - 凡例は1つまで、図番は連番。
  - 平面図の切断位置記号が、立面図・断面図のシートの図番を指す。
- 例題（docs/295）：33枚が27枚になった。
  - 平面図2つは A2 に入った。
  - 立面図4つと断面図3つは A1 に入った。
  - 画像は `outputs/drawing-expression-combined/` の 06.png・07.png。
- `reviewDrawingSetOfAModel` は、`SBR_REVIEW_COMBINE` が設定されていると、まとめた一式を画像にする。

## 残り

- A1 で1:100の図が7つ並ぶと、1つ1つは小さい。立面図と断面図を別々のシートに分けるかは、例題で見て決める。
- 道路斜線（勾配 1.25 の線）を立面図に重ねる。
