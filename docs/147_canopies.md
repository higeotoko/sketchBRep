# 庇（ひさし）（N-03 の第 1 段、2026-11-16）

[docs/97](97_bim_gaps_and_priority.md) の N-03（手すり・庇・バルコニーなどの付属物）。手すりは階段（docs/116）で済。ここでは庇。作業は Opus 5.5。
オーナーの指示：2026-11-16（「とりあえず実装を進めて」）。

## できること

| 項目 | 内容 |
|---|---|
| 画面から | 開口の穴の面を選ぶ（プロパティが「開口 n」だけになる）→「この開口に庇を付ける（出 600）」 |
| AI から | `make_canopy {host, opening, depth, thickness, extra, above}` |
| 形 | 開口をあけた面の側に出る板。初めは：出 600・厚さ 60・開口の両側に 150 長い・下の面は開口の上端より 100 上 |
| 中身 | 属性 `kind = canopy`、`host`・`opening`（どの開口の庇か）、`canopy`（壁からどれだけ出ているか） |
| 建築面積 | 壁の中心線から **1 m 以上**出る庇は、その先から 1 m 下がった線まで建築面積に入れる（令 2 条 1 項 2 号、docs/141）。表の注に出る |
| 取り消し | 1 回 |
| 断る時 | 出 100〜5000・厚さ 10〜500・両側の長さと高さ 0〜2000 の外、無い開口、壁の縦の面でない開口 |

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 壁の中心線 | 開口の面から、壁の厚さの半分うしろ | 開口は壁の厚さを抜くので、その半分が中心。壁の線が中心でない（片寄せの）壁では、少しずれる |
| 開口・壁を動かした時 | 庇は付いてこない（今は別の物） | まず置けるように。付いてくる作りは次 |

## まだやっていないこと

- 開口・壁を動かした時に庇が付いてくること、庇の大きさをプロパティで変えること（今は形の寸法として変える）。
- バルコニー（床・手すり・壁で囲まれていない所の面積の扱い）。
- IFC で庇を屋根・板の種類として書くこと（今は「その他の立体」）。
