# 壁を動かすと、つながっている壁が付いてくる（G-05、2026-11-14）

[docs/90](90_bim_operation_framework.md) の G-05。関係する約束は B-04（つながりが保たれる）・B-08（直接編集を止めない）。
オーナーの了承：2026-11-14（「第 2 段（G-05〜）へ」）。動きは docs/90 の G-05 の行の通り。細かい決まりは下の「実装で決めたこと」。

## 直す前

- 壁ツールで描いた壁は、描いた時だけ角がつながっていた。
- 壁を 1 枚動かすと、角が離れるか、食い込んだ。T 字で当たっている間仕切りも置いていかれた。
- 付け直しは、壁の仕様を変えた時だけ動いていた（docs/79）。

## 直した後

壁を**横へ**（壁の線と違う向きへ）動かすと、その壁に**当たっている壁の端**が付いてくる。

| 相手 | 動き |
|---|---|
| 角でつながっている壁 | 長くなる・短くなる（角がつながったまま） |
| T 字で当たっている壁（間仕切りなど） | 長くなる・短くなる（当たったまま） |
| 動かした壁が当たっている相手（動かした壁の方が T 字の足） | 何も変わらない（動かした壁が、相手の面に沿ってすべる） |
| つながっていない壁・別の階の壁 | 何も変わらない |

- 付いてくる壁は、**動かした壁に当たっている端だけ**が動く。反対の端・高さ・厚さはそのまま。
- 付いてくる壁の**開口は、元の位置のまま**（ID・建具・腰高もそのまま）。動かした壁の開口は、壁と一緒に動く。
- 動かした壁と、付いてきた壁を合わせて、取り消し 1 回分。
- 付いてきた壁は、壁のまま（プロパティで長さ・高さ・仕様を直せる）。
- ステータスバーに「つながっている壁 n 枚の長さを合わせました」と出す。

### 付いてこられない時

次の壁は、**そのまま残す**。動かす操作そのものは止めない（B-08 が B-04 より先）。ステータスバーに名前を出す。

- 開口が、縮んだ壁の外に残ってしまう
- ロックしてある
- 長さがなくなる（動かした壁が、反対の端を越えた）
- 壁ツールの形でなくなっている（形を直接変えた壁）。これは、つながりの相手として見ない

### 付いてこない動かし方

| 動かし方 | 理由 |
|---|---|
| 壁の線に沿って動かす（すべらせる） | 相手を伸び縮みさせても合わない。動かした壁だけが動く（角は離れる） |
| 上下に動かす | 平面のつながりは変わらない |
| 回転 | 相手を伸び縮みさせても合わない |
| つながっている壁を全部一緒に動かす | 伸び縮みさせる相手がいない |
| コピー（Ctrl） | 元の壁は動かない |

### 切り替え

「ツール > 壁を動かすと、つながっている壁も付いてくる」のチェックを外すと、動かした壁だけが動く。アプリを閉じると、付いてくる設定に戻る（ファイルには保存しない）。

## AI から

`move` が同じ動きをする。

- 返り値に `joined_walls: {followed: 枚数, left: [付いてこられなかった壁の名前]}` が付く（つながっている壁があった時だけ）。
- `keep_joins: false` を付けると、動かした物だけが動く。

## 実装で決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 「つながっている」の決め方 | 壁の端が、相手の壁の面の上（1 mm 以内）にある時。相手の探し方は、仕様変更の時の付け直しと同じ（端にいちばん近い壁の線） | つながりを別のデータとして持たない。壁ツールで描いた角も、後から当てた間仕切りも、同じ決まりで見つかる。古いファイルにもそのまま効く |
| 端の行き先 | 動かす前に当たっていた面（手前の面か、奥の面か）と同じ面へ | 角の勝ち負け（どちらが角を通るか）が、動かした後も変わらない |
| 付いてこられない時 | その壁だけ残して、動かす操作は通す | 止めると、直接編集の邪魔になる（B-08）。名前を出すので、後から直せる |
| 連鎖 | しない（付いてきた壁の、さらに先の壁は動かさない） | 伸び縮みは線の向きにしか動かないので、先の壁との当たりは変わらない |
| 設定の置き場所 | アプリの設定（閉じると初期値に戻る） | モデルの中身ではなく、操作のしかた |

## まだやっていないこと

- **壁の長さを変えた時**（プロパティの長さ・端の面の push/pull）に、その端でつながっている壁を付いてこさせること。相手は「伸び縮み」ではなく「移動」になるので、別の仕組みがいる。
- 斜めに動かした時（横と、線に沿う向きの両方）：横の分は付いてくるが、線に沿う分で角がずれる。
- 壁に沿ってすべらせた時に、角を保つこと（相手を一緒に動かす）。
- 直角でない角の納まり（今は突き付け。直角の時に正しい）。
- 床（スラブ）の外周が壁に付いてくること。室の面積（G-07）。
- 柱・梁と壁のつながり。
- 動かしている途中の表示（相手の壁が伸びる様子の先読み）。今は、置いた後に形が変わり、ステータスバーに出る。
