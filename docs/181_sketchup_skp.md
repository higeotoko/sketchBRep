## SDK の扱い（いちばん大事）

[docs/53](53_handover_2026-11-04.md) の決まり「SketchUp SDK のファイルは、Trimble から書面の許可が来るまで、どこにも置かない」は**そのまま守る**。

| 置き場所 | SDK のファイル（ヘッダ・DLL・見本） |
|---|---|
| Git（リポジトリ） | 入れない。コードは SDK の関数を名前で呼ぶだけ |
| ZIP（配布物） | 入れない。exe は SketchUp の DLL に依存しない（`dumpbin /dependents` で 0 件を確かめた） |
| docs | 入れない（関数の名前と使い方の説明だけ） |
| この PC | オーナーが置いた SDK のフォルダ（例：`C:\Apps\SDK_Win`）をそのまま使う |

### 仕組み

1. ビルドの時：CMake に SDK のフォルダを教える（`-DSBR_SKETCHUP_SDK_DIR=C:/Apps/SDK_Win`。ビルド用フォルダの設定に残るだけで、Git には入らない）。`Skp.cpp` だけが SDK のヘッダを読む。**リンクはしない**。
2. 動く時：初めて SKP を使う時に、SDK のフォルダの `binaries\sketchup\x64\SketchUpAPI.dll` を読み込む。探す順：環境変数 `SBR_SKETCHUP_SDK`（SDK のフォルダ）→ ビルドした時のフォルダ。
3. SDK が無い時（CI、ほかの PC、SDK を指さずにビルドした版）：メニューに SketchUp が出ない。AI の命令は「SketchUp SDK が見つかりません」と断る（何も変えない）。

→ 2026-11-18 のオーナーの決定で、DLL は ZIP に入れることになった（docs/182）。exe の隣の DLL を最初に探す。

## できること

「ファイル > エクスポート / インポート」に **SketchUp (*.skp)** が出る（SDK がある PC だけ）。AI：`export_skp {path, ids?, deflection_mm?, angle_deg?}`、`import_skp {path}`。

### 書き出し

| モデルの物 | SketchUp での形 |
|---|---|
| 物 1 つ | グループ 1 つ（物の名前） |
| 平らな面 | 面 1 枚（穴もそのまま）。継ぎ目の線は出ない |
| 曲面（円柱・らせんの手すりなど） | 三角形。間の線はソフト・スムーズ（SketchUp で滑らかに見える） |
| 離れた立体がいくつもある物（階段の踏み板・側板・手すり） | 物のグループの中に、立体ごとのグループ（同じ名前）。SketchUp の中で、触れ合う面どうしがくっつかないように |
| 色 | 物の色はグループの材質、面ごとに塗った色はその面の材質（`SBR_RRGGBB`）。透明度も |
| 線だけの物 | 線（エッジ） |
| 単位 | SketchUp の中はインチ。mm から直す |
| 版 | SketchUp 2021 以降の形式（2021 から版の無い形式） |

### 読み込み

| SketchUp の物 | SketchBRep での形 |
|---|---|
| モデルの直下の面 | 物 1 つ（「SketchUp」） |
| グループ・コンポーネント | 置き方を mm に直して配置する。入れ子がなく、移動・回転だけのコンポーネントは同じ定義を共有し、面ごとの色も保存する（[docs/183](183_sketchup_tags_and_information.md)） |
| 自分の面が無く、同じ名前の子グループだけのグループ | 物 1 つにまとめる（上の「立体ごとのグループ」を戻す） |
| 面 | 平らな面（穴も）。縫い合わせて、閉じていれば立体（離れた立体がいくつあっても、全部閉じていれば立体） |
| 色 | 面の表の材質の色、無ければグループ・コンポーネントの材質の色。テクスチャは色で（数を報告） |
| 隠した物 | 読まない（数を報告） |
| 線だけ | 線の物 |

取り込みは取り消し 1 回。報告：グループ・コンポーネント・面・線・立体・作れなかった面・隠した物・テクスチャの数。

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| SDK の使い方 | 動く時に DLL を読み込む（リンクしない） | ZIP に SDK を入れないため。リンクすると exe が DLL を要求し、ZIP の検査で止まる |
| 物の単位 | グループ | 名前と材質を持て、SketchUp で選びやすい。コンポーネントにすると、同じ物の共有を考えることになる |
| 平らな面 | 三角形に分けずに 1 枚 | SketchUp で編集しやすい（プッシュプルできる）。DAE は三角形だった |
| 曲面と隣の平らな面の境 | メッシュの点を共有 | 隙間が出ない（SketchUp が点をつなぐ） |
| 立体ごとのグループ | 立体が 2 つ以上ある物だけ | SketchUp は 1 つのグループの中で触れ合う面をくっつけるので、階段が閉じた立体で戻らなかった |
| 取り込みの面のつなぎ方 | DAE と同じ処理（`joinFaces`）に共通化 | 縫い合わせ・立体・同じ平面の面をまとめる・色を、同じ決まりで。いっしょに、離れた立体がいくつもある物も立体にするように直した（DAE も良くなる） |

## まだやっていないこと

- テクスチャ（画像）の書き出し・読み込み（色だけ）。
- 寸法・文字・ガイド・シーン・タグ（レイヤ）。タグは SketchBRep のタグと対応させられる。
- SketchUp 本体で、書き出したファイルを開いて見ること（SDK で読み戻して確かめた）。
- ~~ZIP に DLL を入れる形~~ → 済（docs/182）。
