# リモートMCP接続：利用条件と接続手順（2026-10-26 JST）

この文書は配布ZIPでは **CHATGPT_CONNECTION.md** という名前です。ファイル名は既存の配布との互換性のため残し、画面名と説明はサービス中立の「リモートMCP接続」に変更しました。

## AI連携の基本方針

SketchBRepはMCP（Model Context Protocol）を通じた外部AIからのモデル操作に対応します。SketchBRep自身が特定のAIモデルや有料AI APIへの接続を必須とすることはなく、AIクライアントは利用者自身が選択できます。OpenAI APIキーは不要で、アプリ内AIチャットを実装した機能ではありません。

GUIとMCPは同じ操作APIを使用します。モデルの作成・編集・状態取得・Undo、形状チェックと操作制限、接続の開始・停止は維持しています。この表記・文書変更で通信機能・編集API・セキュリティ機構は変更していません。

## 主な接続方式

| AIクライアント | 接続方式 |
|---|---|
| Claude Code | ローカルMCP |
| Codex CLI | ローカルMCP |
| ローカルLLM | MCP対応クライアント経由 |
| ChatGPT | 対応するプラン・クライアント環境に応じたMCP接続 |

ローカルLLMでは、利用するモデルとMCPクライアント双方のツール呼び出し対応が必要です。MCP対応クライアントが、モデルのツール選択とSketchBRepのコマンド実行を仲介します。ローカルLLMを起動するだけで接続できるという意味ではありません。

### ローカル接続とHTTPS経路

- 同一PCのClaude Code／Codex CLI等は、従来の `sbr_mcp` によるローカルstdio MCPを使います。通常はHTTPSトンネル不要です。
- 外部のクラウドサービスからローカルPCへ接続する場合は、HTTPSで到達できる経路が必要になることがあります。ngrok等のトンネルはそのための手段です。すでに適切なHTTPS経路がある環境で、必ず追加のトンネルが必要という意味ではありません。
- **HTTPSトンネルはAIサービス側のMCP利用制限を解除しません。** 到達可能であること、登録可能であること、ツールで編集可能であることは別です。

## AIサービスの対応状況について

SketchBRepは標準MCPによる外部AI接続に対応しています。ただし、利用可能な操作はAIサービス、契約プラン、クライアント環境によって異なります。
一部のAIサービスでは、MCPサーバーを登録できても、通常チャットからのモデル作成・編集が利用できない場合があります。詳細は利用するAIサービスの公式ドキュメントをご確認ください。

### 混同しない条件

| 確認すること | それだけでは確認できないこと |
|---|---|
| MCPサーバーを登録できる | ツールを会話から呼び出せる、編集権限があるとは限らない |
| MCPツールを列挙・読み取りできる | モデルを作成・編集できるとは限らない |
| MCPツールによる作成・編集が許可される | 別のプラン、別のクライアント、通常チャットでも同じ操作が使えるとは限らない |
| Codex等の開発環境から利用できる | ChatGPTの通常チャットの利用条件を満たすとは限らない |
| ChatGPTの通常チャットから利用できる | 任意のアプリ／ツールに書き込み権限があるとは限らない |

## HTTPS・認証・アクセス制御

**HTTPSによる暗号化と、アクセス認証・操作権限の制御は別です。** HTTPSトンネルを起動するだけでは、誰がCAD編集命令を出せるかは制御できません。認証なしでインターネットへ公開すると、不正な編集・状態取得等につながる危険があります。

現在の実装には、ループバック待受、256ビットの秘密を含むURL、Host／Originの検証、要求上限等があります。しかし、**接続URLを秘密にするだけでは十分なアクセス制御とは限りません**。URLの所持を利用者本人の認証、利用者ごとの認可、権限の分離や監査と同一視しないでください。URLが漏れたときは、そのURLを使われるおそれがあります。

今回、認証方式や通信コードは変更していません。アプリ自体にOAuth認証や利用者別の認可を実装したわけではありません。一般のインターネットへ認証なしで公開する運用は推奨しません。外部公開する場合は、MCPクライアントが利用可能な認証方式・接続元や許可対象の制限等を含め、公開経路全体のアクセス制御を確認してください。その認証方式との接続可否も別途確認が必要です。

ChatGPT等で「認証なし」を選べることは、その設定による公開が安全であることを意味しません。本書のURL設定例は、権限を確認した管理環境で既存機能を検証するための例であり、安全な公開設定を自動で用意する機能ではありません。秘密URLは共有・公開せず、不要になったら接続を停止してください。

## リモートMCPの設定手順（ChatGPTはクライアントの一例）

1. 利用するAIサービスのMCP対応・操作権限と、外部アクセスの認証・アクセス制御を先に確認する。条件を満たさない環境で、モデル編集ができると判断しない。
2. 更新版の `SketchBRep.exe` を起動し、検証用の小さいモデルを用意する。
3. **AI連携 > リモートMCP接続...** を開き、**接続を開始**を押す。「外部AIからの操作を許可」もONになる。
4. 外部クラウドから到達させる場合は、必要なHTTPS経路を用意する。ngrokを使用する例では、別途インストール・アカウント設定を済ませ、画面のコマンドをこのPCのPowerShell等で実行する。
   ```text
   ngrok http http://127.0.0.1:51234
   ```
   ポートは画面の値を使う。このコマンドだけで認証・認可が完備するものではない。
5. その経路の公開URL（例 `https://...ngrok-free.app`）を **公開HTTPS URL** に入力する。ホストまでを入力し、`/mcp/...` はまだ付けない。
6. **接続URLをコピー** で生成したURL全体を、対応するMCPクライアントの設定へ渡す。クライアントごとの登録・認証設定は、その公式手順と実際のアクセス制御に合わせる。
7. ChatGPTを例にする場合は、対応するアカウント・クライアント環境でカスタムMCPを登録し、会話で使用可能かを確認する。登録できただけでは編集可能とは判断しない。既存の秘密URL方式を管理された検証環境で試す場合、ChatGPT側の「認証なし」はOAuthを設定しないという意味に留まり、安全性の保証ではない。
8. 最初はモデルを変更せず、状態取得ができるかを確かめる。編集は、その操作権限があるクライアントでのみ、小さいモデルを用いて検証する。
9. 成功した編集はアプリの画面へ反映され、**Ctrl+Z** で取り消せる。

画面の受信リクエスト数は接続口への通信到達の目安です。増加してもモデル作成・編集の利用権限を保証しません。画面を閉じても接続口は継続します。必要な経路も起動したままにします。

## 停止と既存の操作制限

- **接続を停止** または **外部AIからの操作を許可をOFF** でHTTP接続口を閉じる。
- 停止・アプリ終了で秘密URLは失効する。再開時は新しいURLをクライアントへ設定し直す。
- **すでに始まった形状計算は切断だけでは中断・巻き戻しされない**。タイムアウト後は同じ編集を再送する前にモデルを確認する。
- アプリ経由のファイル保存・開く・取り込み・書き出しの禁止は従来どおり。保存は利用者が行う。
- GUIとMCPが共通の操作APIを使い、既存の形状検証・操作制限・Undoを適用する設計は変更していない。

## 接続できない場合の切り分け

- 登録画面がない／会話でツールを利用できない／編集できない：サービス・プラン・クライアント・モード・管理設定を個別に確認する。トンネルやSketchBRepでサービス側の制限は解除できない。
- localhostのURLをクラウド側へ登録した：外部クラウドからPC内のlocalhostへ直接届くとは限らない。適切なHTTPS経路を確認する。
- 古いURL／ポートを使った：停止や経路の再起動後は現在の設定を確認する。
- 404：接続URLの末尾の欠落、古い秘密URL、別サービスへの転送などを確認する。
- 403：公開ホストの入力やHost／Originの一致を確認する。
- ブラウザーで405：この接続口はMCPのPOST用で、Webページではない。
- 接続できても通常チャットから編集できない：サービス側の操作権限は別条件。PlusのWindowsデスクトップで登録は成功しても通常チャットで固有ツールを検出できなかった実測も上記のとおりで、登録から編集成功を保証しない。

## 実装と検証範囲（引き継ぎ用）

- `McpHttpServer` は既存の `api::McpServer` をHTTPへ接続する。ループバックIPv4のみで待ち受ける。外部公開・トンネル実行は自動化しない。
- MCPはセッションなしのJSON応答。POSTを使用し、任意のSSE GETは405とする。HTTP/1.1のContent-Length・chunked・100-continueを処理する。
- 秘密パスの照合、HostとOriginの検証、CORS未許可、重複ヘッダーや余分な要求の拒否、リクエストサイズと接続数の上限を持つ。
- ヘッダー32 KiB、デコードした本文2 MiB（生の要求全体は2 MiB＋32 KiB）、応答64 MiB、接続16、受信10秒／待機120秒／応答送信10秒。完了済みの演算をこれらのタイマーで取り消すものではない。
- `AiBridge::execute` を経由し、GUIと同じ検証・失敗時の取り消し・Undoを使う。重い操作中は待機し、HTTP要求も直列実行する。
- MCPのツール注釈にreadOnlyHint・destructiveHint・openWorldHintを明示。読み取りと表示操作以外は破壊的変更の可能性ありと保守的に扱う。
- ビュー画像はMCPのimageコンテンツで返す。Windowsの日本語を含む一時画像パスも読めるようにした。
- 実モデルへのHTTP操作、Undo、ファイル操作拒否、画像バイト列、秘密URL／Host／Origin、形式不正／過大要求、chunkedと100-continue、停止・再開と秘密の更新をネットワークテストで確認する。
- GUIでリモートMCPの接続開始・公開URL入力・接続URLのコピー・グローバルOFFによる切断を確認し、従来のローカル接続と操作中の要求待ちも再確認する。
- **ChatGPTの実アカウントと利用者のPCへのHTTPSトンネルを通した実接続は、このクラウドでは未実施。** ローカルHTTP／MCPの検証と、ChatGPT実画面からの接続成功は区別する。
