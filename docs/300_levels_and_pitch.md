# 300. 図面表現の見直し（4）レベル記号と屋根勾配

熊本県「確認申請図書の作成例」の立面図・断面図（docs/296）に合わせ、高さと屋根の勾配を、日本の図面の書き方で示す。

## レベル記号（▽）

レベル線の左端に、線に頂点を付けた小さな三角を置き、その横に名前、下に高さを書く（▽2FL、+3500）。地盤（名前が GL、頭に何か付いた GL、「平均地盤面」を含む）は塗りつぶした三角（▼）。作成例の「▽2FL」「▼GL」と同じ考え方で、線の太さ・色はレベルのペン（細い一点鎖線）のまま。

## 屋根勾配の記号（4/10）

図面一式の立面図・断面図で、屋根の上向きの斜面のうち、その図で斜めに見える面（見る向きと斜面の向きがほぼ直角）ごとに、斜面の少し上へ小さな直角三角形を描き、底辺の下に「10」、立ち上がりの横に寸勾配（屋根の `roof_spec` の pitch）を書く。三角の斜辺は斜面と同じ向きに傾く。同じ向きに落ちる斜面は1つの屋根に1つだけ。

- 正面から見える斜面（平の立面）には付けない。
- 地盤面の入力が無いモデルにも付ける。
- 線は寸法のペン（細線）。勾配の表し方は JIS A 0150 8.2（分母を10とした分数）に合う。

## 気づいたこと（例題）

例題（docs/295）は外壁を桁天端（6200）までしか立てていないため、妻側の立面図で屋根の三角の部分に架構の束・垂木が見える。壁を屋根まで伸ばす機能（docs/100）で例題側を直せる。
