# 297. 線の選定（図面表現の見直し 2）

図面の線は、役割（ペン）ごとに線種・太さ・色・CADのレイヤーを1か所の表で決めている（`src/core/src/Drawing.cpp` の `penWidth`・`penDashes`、DXF・JWWの対応、画面・PDFの色）。図はモデルから毎回作るベクトルの図で、表を直せば図面一式がそろって変わる。今回は、その表の決め方を、見た目ではなく「その線が何を伝えるか」から整理した。

## 根拠（2026-11-26 に本文を確認）

- JIS Z 8312:1999（製図－表示の一般原則－線の基本原則）4.1：線の太さは 0.13、0.18、0.25、0.35、0.5、0.7、1、1.4、2 mm から選ぶ（公比 約1.4）。極太線・太線・細線の太さの比は 4 : 2 : 1。 [規格の本文](https://jis.eomec.com/jisz83121999)
- JIS A 0150:1999（建築製図通則）10.1：基準線は通常は実線、はっきりさせる必要がある所は一点鎖線。太さは細線・太線・極太線の順で選び、比は1:2:4。10.2：基準線の端には細線で円をかき、円の中に基準記号を書いてよい。12.1：断面の位置と見る向きは切断位置を示す線と矢印で示す。 [規格の本文](https://jis.eomec.com/jisa01501999)
- JIS A 0150 の13章（極太線は強調する部分に用いる 等）は、このページで本文を読めなかった。検索結果の要約によるもので、本文とは未照合。
- 熊本県「確認申請図書の作成例（熊本県版）」：配置図の敷地境界は実線、道路中心線・道路後退線は一点鎖線、建物の軒先は破線。平面図・立面図に通り芯の丸はなく、寸法の列で位置を示す。 [熊本県のページ](https://www.pref.kumamoto.jp/soshiki/115/224932.html)

## 考え方

1. 図の主役から順に太くする。切断された部分（その図で切って見せている物）が主役、その奥に見える物が次、位置や大きさを読むための補助（通り芯・レベル・寸法・隠れ線）がいちばん細い。
2. 太さは JIS の系列から 細 0.13・太 0.25・極太 0.5（1:2:4）を使う。3段にそろえると、印刷しても段の違いが分かる。
3. 線種は意味で分ける。実線＝実在する物の線、破線＝隠れて見えない物、一点鎖線＝位置の基準（通り芯・レベル）と境界。白黒で印刷しても、色ではなく線種と太さで役割が分かるようにする。
4. 色は画面とPDFの読みやすさのための補助。色だけで区別させない。
5. 役割ごとにペンを分けておく。作成例と違う選び方をした所も、表の1か所を直せば変えられる。

## 役割ごとの線

| 役割（ペン） | 線種 | 太さ (mm) | 理由 |
|---|---|---|---|
| 切断（Cut） | 実線 | 0.5 極太 | その図の主役（平面図・断面図で切った壁・床など） |
| 見えがかり（Visible） | 実線 | 0.25 太（0.18 から変更） | 切断の次に読む情報。補助線（0.13）と1段違える |
| 隠れ線（Hidden） | 破線 | 0.13 細 | 見えない物。補助 |
| 通り芯（Grid） | 一点鎖線 | 0.13 細 | 基準線（A 0150 10.1.2） |
| 通り芯の丸と記号（GridLabel） | 実線の円 | 0.13 細（0.18 から変更） | A 0150 10.2「細線でかいた円」。直径6 mm（docs/296） |
| レベル（Level） | 一点鎖線 | 0.13 細 | 高さの基準線 |
| 寸法（Dimension） | 実線 | 0.13 細 | 補助 |
| 敷地境界（Boundary、今回追加） | 一点鎖線（長め） | 0.25 太 | 境界は補助線より重い情報だが、建物の線（実線）とは区別したい。これまで通り芯と同じペンで、通り芯と見分けがつかなかった |
| 道路側の境界 | 実線 | 0.5 | これまでどおり（配置図で強調） |
| 図枠（Frame） | 実線 | 0.7 | これまでどおり |
| 表題欄・高さ制限・延焼・防火区画 | これまでどおり | — | 役割ごとに線種が違うので白黒でも区別できる |

### 作成例と違う所

- 熊本県の作成例は敷地境界を実線でかいている。ここでは、建物の実線と区別するため一点鎖線にした。実線にしたい時は `penDashes(Pen::Boundary)` を空にするだけでよい。
- 通り芯の丸は作成例にはないが、モデルの通り芯と図をつなぐために残し、小さく細くした（docs/296）。

## 書き出し

- DXF：レイヤー `BOUNDARY`、線種 DASHDOT、色 7。
- JWW：レイヤーグループ0の16レイヤーを使い切っているため、グループ1のレイヤー0「敷地境界」に置く。
- 図面の読みにくさの点検（`check_drawing_set`）では「敷地境界線」と呼ぶ。

## 残り

- レベル記号を「▽1FL」の形にするか（作成例の書き方）。今はレベル線の左端に名前と高さ。
- 断面図の地盤（ハッチング）と道路、配置図の道路中心線・道路後退線。
- 室名の複数行表示（CH・FL）、屋根勾配の記号、軒の出の寸法、凡例。
