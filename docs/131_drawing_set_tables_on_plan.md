# 図面一式で、表を 1 階の平面図に並べる（docs/130 の続き、2026-11-15）

[docs/130](130_drawing_with_tables.md) の「まだ」（図面一式で、平面図に表を並べた 1 枚を作ること）。作業は Opus 5.5。
オーナーの指示：2026-11-15（「つづけて」）。

## できること

| 項目 | 内容 |
|---|---|
| 画面から | ファイル →「図面一式を書き出す（表は 1 階の平面図に並べる、1 つの PDF）」。前からの「図面一式を書き出す（図番つき、1 つの PDF）」は今までどおり表が別の 1 枚 |
| AI から | `export_drawing_set` の `tables_with_plan: true` |
| 中身 | 中身がある表（建具表・室の表・面積の表・仕上げ表）を、**いちばん下の階の平面図**の 1 枚に並べる（docs/130 の並べ方：図の右、入らなければ下）。表だけの 1 枚は作らない |
| 名前 | その 1 枚は「1FL 平面図・建具表・室の表」のように、図と表の名前。図面リスト・表題欄・ファイル名もこの名前。図の下の見出しは「1FL 平面図 S=1:100」のまま |
| 用紙 | その 1 枚は、図と表が入る大きさ（自動なら、ふつう A3 以上） |

## まだやっていないこと

- どの表をどの図に並べるかを選ぶこと（今は全部を 1 階の平面図に）。
- 図面一式の書き出しで、縮尺・用紙を画面から選ぶこと（AI からは選べる）。
