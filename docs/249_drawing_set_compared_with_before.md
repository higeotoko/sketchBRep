# 249. 図面一式を前の物と比べ、変わった所だけを出す（2026-11-22）

docs/241〜248 の続き（6 番目、最後）。意図しない図面の変化（docs/247 の室名が立面に出ていた、のような物）を、push した時点で CI が見つける。

## 道具

- コアのテスト `GoldenSheets.TheDrawingSetSaysWhatItSaidBefore`（`tests/test_golden_sheets.cpp`）：台本（docs/246）の家の見本に、壁・床・天井の断熱、窓の U・η、設備、計画概要を入れた図面一式（17 枚）を作り、`tests/data/golden_sheets.json`（基準）と比べる。
- 比べる物（パソコンが変わっても同じになる物）：シートごとの番号・名前・用紙・縮尺・注、線・円弧・折れ線・字・塗りの数（ペンごと）、紙の上の広がり（10 mm 単位）、字の全部（表題欄の日付は除く）。
- 違いがあれば、シートごとに「字が消えた／増えた」「数 前 → 後」を出して落ちる。
- 意図した変化の時：`SBR_UPDATE_GOLDEN=1` で流して基準を書き直し、コミットする（JSON の差分が「図面の言うことがどう変わったか」のレビューになる）。

## 確認

- Windows：基準を作り、もう一度流して一致（成功）。
- CI（Linux）：このコミットで確かめる（パソコンが違っても同じ数・字になるか）。
