# オーナーの初回の実機確認で出た 3 件の修正（2026-11-05）

`05e5400` の ZIP をオーナーが Windows で触って見つけた 3 件を直した（`907f3b6`）。

## 1. 妻側の間柱の向き

- 症状：Y 方向の壁（切妻の妻側）の間柱が、30×105 の薄い面を壁の厚み方向に向けていた。
- 原因：レシピが、どの方向の壁の間柱も同じ向き（部材の回転なし）で置いていた。X 方向の壁では正しく、Y 方向では 90° ずれる。
- 修正：レシピの部材に回転（`Piece.roll`）を持たせ、Y 方向の壁の間柱は 90° 回して配置する。
- 確認：全ての間柱で「壁の方向の寸法＜壁の厚み方向の寸法」（X 壁・Y 壁とも）を計算テストで確認。修正前は Y 壁で 30（X）×105（Y）になっていた。

## 2. 平面で階を選んでも屋根伏せのまま

- 症状：建築ツールバーで 1FL・2FL を選んでも、真上から屋根まで全部見えていた。
- 原因：階を選ぶと作業面（描く高さ）が変わるだけで、画面の切断をしていなかった。
- 修正：階を選ぶと、その FL＋1100 mm より上を隠す平面図の表示にする（表示だけのクリップ面、切り口は塗りつぶし）。
  隠れた部分には吸着しない。「3D」・立面に切り替えると戻る。ツールバーの表示に「FL+1100 で切断」と出る。
  1100 mm は平面図の慣例としての切断高さで、法令の値ではない。断面ツールの断面とは別で、断面が有効な時は吸着の判定は断面を優先する。

## 3. 土台を画面から引けない

- 症状：土台は木造架構をまとめて作るか、AI／API でしか作れなかった（「部材を引く」は鋼材・柱・梁だけ、部材の役割にも土台が無い）。
- 修正：
  - 建築ツールバーと「ツール > 部材を引く」に「土台」を追加。押すと、架構の「土台天端」のレベルがあればその平面
    （土台天端のすぐ上で切り、床組を隠した表示）に切り替わり、通り芯の交点を 2 点クリックで土台を引ける。
  - 初期値：木造の手引きの土台の初期断面（120 角）、木、役割「土台」、上端基準（上端が土台天端）。断面は部材パネルで変更。
  - 土台天端のレベルが無い時は、今の作業面の高さに引き、そのことを表示する。
  - 部材の設定の「役割」に「土台」を追加。
  - 引いた土台は布基礎・べた基礎の計画の対象になる（基礎計画は作り直す）。
