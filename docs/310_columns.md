# 310. 構造詳細図（2）柱の小径・有効細長比

## 何が要るか（施行規則の本文で確認）

e-Gov の建築基準法施行規則（2026-11-27 取得）の第1条の3 表2 を読んだ。令第3章第3節（木造）が適用される建築物で、構造詳細図に書く事項は次の6つ。

1. 屋根ふき材の種別
2. 柱の有効細長比
3. 構造耐力上主要な部分である軸組等の構造方法
4. 継手又は仕口の構造方法
5. 外壁のうち、軸組が腐りやすい構造である部分の下地
6. 地面から1m以内の部分の防腐又は防蟻措置

使用構造材料一覧表に書くのは「木材の品質」。

施工方法等計画書（コンクリートの強度試験方法、調合及び養生方法）は、令第3章第6節（鉄筋コンクリート造）が適用される建築物の欄にある。木造の欄には無い。木造住宅の鉄筋コンクリートの基礎に第6節を当てはめるかは、審査機関に確かめる事項として残す。

## 作ったもの

モデルから計算できる「柱の有効細長比」を表にする。表の名前は **構造詳細図（柱の小径・有効細長比）**。

- 対象：木造架構の柱（take_off の column・through_column）。断面と横架材間の垂直距離ごとにまとめる。
- 横架材間の垂直距離：柱の長さ。通し柱は、各階の床レベルの間の最も長い部分。これを座屈長さとする。
- 小径／距離：小さい辺に対する距離の割合（1/x）。
- 有効細長比：座屈長さ ÷（小さい辺 ÷ √12）。令第43条第6項の 150 以下と照合する。
- 令第43条第1項：小径の割合は「国土交通大臣が定める割合」で、数値は告示にある。告示の数値を読んでいないので照合しない（未評価）。
- 令第43条の本文は e-Gov で確認した（2026-11-27）。

MCP は `column_table`（読むだけ）。木造の柱があると、図面一式で構造詳細図（基礎の断面）の次に入る。

## 確認

`Quantities.ColumnTableGivesSlendernessOfTheFrameColumns`：

- 架構（2×2スパン）の柱が表に入る。
- 有効細長比の式が合う。
- 6項の照合が付き、1項は未評価になる。
- MCP で読める。
- 手計算と合う（105 角で 2,700 → 89.1）。

## 残り（構造詳細図）

- 屋根ふき材の種別、軸組等の構造方法、継手・仕口、外壁の下地、防腐・防蟻。モデルに入力が無いものは、入力の欄を作るところから。
- 令第43条第1項の割合：告示の本文を読んでから入れる。
