# 199. 申請図の工程：第7工程（耐力壁）を壁量の計算から埋める（2026-11-20）

docs/194・197・198 の続き。「申請図の工程」の「7 耐力壁」に、在来軸組の壁量の比較と四分割の結果を出す。中身は今ある計算（`construction::checkWallQuantity`、docs/58・76。AI の `check_wall_quantity` と同じ）そのもの。新しい法令の値や判定は足していない。係数表と確認日は、計算が保存している写し（告示1100号、令和6年国交省告示447号改正、施行 2025-04-01、表の確認日 2026-11-04）がそのまま出る。

## 画面

| 行 | 出す物 |
|---|---|
| （入力が無い時）壁量の入力 | 「未入力」と、階・荷重・耐力壁の仕様を入れる案内 |
| ○階 X／Y 方向の壁量 | 存在壁量と必要壁量（m）、計算の理由。計算の pass は「参考値内」、fail は「要確認」、それ以外は「未評価」。ボタンで、数えた壁のうちモデルにある物を選ぶ |
| ○階 X／Y 方向の四分割 | 壁率比、どちらの決まりで見たか、側端部分ごとの存在／必要／充足率、理由。状態は上と同じ言い方 |
| 係数表（古い時だけ） | 保存した係数表が今の版と違う時は「要確認」 |
| 照らした値 | 計算の注（「意匠・概略の検討用…法適合の判定ではありません」、告示と表の確認日） |
| まだ確かめていない事 | 計算が評価していない物（N値、柱頭柱脚、準耐力壁等、下屋のある側端、断面、基礎）と、耐力壁の配置図・壁量計算表・側端の図の書式は申請先の様式で確かめること |

「適合」とは書かない。計算に入れた壁がモデルの物でない時（手で入力した壁）は、ボタンで選ぶ物が無い。

AI からは `permit_checks` の `stage: 7`。
