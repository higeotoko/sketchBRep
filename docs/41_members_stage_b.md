# 部材の生成と基本編集：段階B（2026-10-29 JST）

[段階A](40_members_stage_a.md)に続けて、仕様案「部材生成・基本編集仕様案 v0.4」の段階Bを実装した。
目標はRC造と鉄骨造の両方を作れること。今回の段階Bで入ったものは次のとおり。

- 鋼材カタログ：12種類、1,204断面
- RC・木の断面：長方形と円形
- 柱の「位置＋高さ」入力
- 断面の検索（GUIとAI）
- スラブと壁の基本編集

## できること

### 鋼材カタログ（1,204断面）

- Steel Member Generator 1.10.0（`higeotoko/steel-member-generator`、commit `de3d789`）の断面データを取り込んだ。
- 12種類：H・I・角形鋼管（BOX）・鋼管（PIPE）・山形鋼（等辺・不等辺）・溝形鋼・リップ溝形鋼・CT形鋼・平鋼・角鋼・丸鋼・六角鋼。
- 輪郭はSMGのデータのまま、直線と正確な円弧で作る。曲線を折れ線に置き換えない。
  - 中空断面（角形鋼管・鋼管）の穴も同じように作る。
  - 段階Aで入れたH形2サイズの角の半径（r=8、r=13）は、SMGのデータと一致していた。
- カタログは実行ファイルに組み込んだ。EXEの隣に別のファイルを置く必要はない。
- 部材を保存すると、断面の輪郭もファイルに入る（§8.1：外部カタログがなくても形を保てる）。
  - 読み込み時、組み込みカタログと同じ輪郭なら、カタログのものを共有する（1本ごとに複製しない）。
  - 輪郭が違えば、その部材だけの断面として読み込み、「カタログどおり」とは表示しない。

### RC・木の断面

- 長方形（幅×せい）：柱・梁・木材。
- 円形（直径）：RCの丸柱など。直径は後から変更できる。

### 部材の設定（ツール > 部材の設定…）

- **断面の種類 → サイズの検索 → 一覧**の順に選ぶ。検索欄に「400x200」「BCP-350」などと入れると、一覧が絞り込まれる。
- 長方形は幅・せい、円形は直径を入力する。
- 柱の高さを設定できる（下の「柱の入力」で使う）。
- ダイアログには、カタログの出典（リポジトリ・版・commit）も表示する。

### 柱の入力（§5.3）

用途が「柱」のときは、次の3通りで作れる。

| 操作 | できる柱 |
|---|---|
| 脚部をクリック → **Enter** | 設定した高さの鉛直の柱 |
| 脚部をクリック → **高さを入力** → Enter | 入力した高さの鉛直の柱（マウスの位置には関係しない） |
| 脚部をクリック → 頂部をクリック | 傾けた柱。「柱」だからといって鉛直を強制しない |

### 断面の検索（AI、§10.2・§10.4）

- `list_sections` は、名前やIDが完全に一致したもの（`exact`）と、部分一致したもの（`matches`）を分けて返す。
- 種類で絞り込める（`family`）。結果はページ単位で受け取れる（`limit` / `offset`）。
- 存在しないサイズを、近い別サイズに置き換えることはしない。
- 返すのは寸法と外形の大きさだけ。輪郭の全データは返さない（§10.3）。

### スラブ・壁の基本編集（§6.4、§13.4-4）

`member_info` / `change_member` が、壁（`create_wall`）とスラブ（`create_slab`）にも使えるようになった。

| 対象 | 変えられる値 | 変更しても動かない基準 |
|---|---|---|
| スラブ | 厚さ | 既定は上面。`keep` で bottom・center も選べる |
| 壁 | 厚さ | 描いた線。左右どちらの面かは作成時に記録してある。`keep` で left・right・center を指定することもできる |
| 壁 | 高さ | 下端 |
| 壁 | 長さ | 始点 |

- 上面固定で厚さを変えた後も、上面をプッシュプルすれば普通に動く。専用の操作の基準が、直接操作を縛ることはない。
- 新しく作る壁は、どの線で描いたかを属性 `wall_line`（left / right / center）として持つ。
  - 前からある壁にはこの記録がないので、中心線を保つ。別の線を保ちたい時は `keep` で指定する。

## 実装で決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 断面の形 | 種類ごとに形の処理を書かず、「頂点と bulge の輪郭」を正確な直線・円弧にする1つの仕組みで12種類すべてを扱う | 種類が増えても形の処理が増えない |
| bulgeの計算 | DXF取込と同じ式を1つの関数（`bulgeArcMiddle`）にまとめ、両方から使う | §11.1。DXF取込の円弧変換と共通化した |
| 断面の中心 | 輪郭の正確な外接矩形（円弧のふくらみも含む）の中央を原点にして取り込む | 配置基準（芯・上端・角など9点）を、どの種類でも同じ意味にするため。山形鋼の外側の角や脚の先端も、この9点で指定できる |
| カタログ断面の寸法 | 寸法を1つずつ直すことはできない。サイズを変えるときはカタログの別サイズを選ぶ。直接の形状編集はいつでもできる | 輪郭は寸法から計算できないので、ウソの寸法変更を作らない |
| 速さ | 穴の向きは輪郭の回る向き（符号付き面積）から決める。同じ輪郭の形状検査は最初の1回だけにする | 1本あたり1.75ms → 0.33ms（1,204断面の作成が2.6秒 → 0.4秒） |
| 材料種別 | カタログの鋼材は、指定がなければ「鋼」 | 生成元から分かる情報だけを付ける |

## 続き：保存・読み込みの軽量化と入口（2026-10-29）

### 保存・読み込みの軽量化（仕様 §9・§13.2）

原因を測ったところ、ほぼすべてが**正確な体積の計算**だった（H形1本で約4ms、箱で0.65ms）。

- 読み込み：作り直した形と保存されていた形を比べるために、1オブジェクトあたり2回。
- 保存：参考値としてファイルに書く体積で、1回。
- 押し出し：向きの確認と立体の検査で、2回。

このうち、作り直しの中の検査と保存は、どれも「正負を確かめるだけ」か「参考値」だった。だから、次のように変えた。

- **読み込み**：作り直した形と保存されていた形で、面・辺の数と角の位置がすべて一致すれば同じとみなす（積分をしない）。違う時だけ、今までどおり体積と外形で比べる。
- **保存・検査**：ガウス積分（`roughVolume`）を使う。平らな面だけの形なら正確で、曲面を含む形でも計算が約4分の1の時間で済む。
- **正確な体積はそのまま**：プロパティ画面とAI（`get_object` など）に表示する体積は、今までどおり正確な計算で出す。

| 1,000本／1,000個 | 変更前 | 変更後 |
|---|---:|---:|
| 部材：読み込み | 4.8秒 | 0.5〜0.7秒 |
| 部材：保存 | 2.7秒 | 1.0秒 |
| 普通の箱：読み込み | 3.9秒 | 1.5秒 |
| 押し出した箱の作り直し（1個） | 3.5ms | 1.4ms |

壁・スラブ・普通の立体のファイルを開く時間や、寸法を変えた時の作り直しにも同じように効く。測定はLinux。Windows実機は未計測。

### 用途・材料種別を後から付ける（仕様 §7.3）

- 立体・シェル・面を選ぶと、プロパティの詳細に「用途」と「材料種別」の欄が出る。用途は柱・梁・筋かい・壁・スラブ、材料種別は木・鋼・RCから選べる。
- 変わるのは属性（`kind` / `material_class`）だけ。形を作り直したり、寸法の決まりを足したりはしない。
- 「なし」を選ぶと、その属性は消える。

### 鋼材・柱・梁の入口（仕様 §4.2・§4.4）

- **ツール > 部材を引く**の中に「鋼材」「柱」「梁」を並べた。パレットのボタンは「部材」1つのまま。
- 入口ごとに前回の設定を覚えている。柱を丸柱にしても、梁の断面は変わらない。
- 初めて使う時の設定：

| 入口 | 初期の断面 | 初期の配置基準 | 用途・材料種別 |
|---|---|---|---|
| 鋼材 | H-400×200×8×13（SMGと同じ） | 芯 | 材料種別：鋼 |
| 柱 | そのとき使っていた断面 | 芯 | 用途：柱 |
| 梁 | そのとき使っていた断面 | 上端 | 用途：梁 |

GUIテスト：`roleAddedToAnyShapeInProperties`、`memberEntriesKeepTheirOwnSettings`。

### 部材パネル（2026-10-30）

パレットの「部材」を押しても、何が描かれるのか、どこで変えるのかが画面に出ていなかった（初期設定の105×105の角材が、説明なしに描けていた）。そこで、部材ツールを使っている間だけ、小さなパネルを出すようにした。

- **入口のボタン**：汎用・鋼材・柱・梁。押すとその入口の設定に切り替わる。メニューの「ツール > 部材を引く」と同じ動きで、どちらで切り替えても、パネルのボタンの状態は揃う。
- **今の設定**：断面、材料、用途、基準、回転、操作の手順（柱なら「脚部をクリック → Enter で高さ3000」）。
- **「断面・基準の設定...」**：今までの設定ダイアログを開く。
- ほかのツールに替えると消える。置いた場所は次回も使う。

| 項目 | こうした | 理由 |
|---|---|---|
| パネルの形 | 断面パレットと同じ、浮いた小窓 | 3D画面は特別な描き方をしていて、その上に普通の部品を重ねると隠れてしまうため |
| 画面の端へのドッキング | させない | 出たり消えたりするたびに3D画面の大きさが変わらないように |
| ボタンのキーボード操作 | 受け取らない | 長さの数値入力が3D画面に届くように |
| 「汎用」の入口 | 加えた | パレットのボタンから始めた時の設定（初期は105×105の角材）に戻れるように |

GUIテスト：`memberPanelShowsWhileDrawingMembers`。
