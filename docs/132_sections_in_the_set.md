# 図面一式に断面図と、平面図の切る位置の記号（docs/125 の続き、2026-11-15）

[docs/125](125_drawing_set.md)（図面一式）の「まだ」（断面図を一式に入れること、別の図面の図番を指す記号）。作業は Opus 5.5。
オーナーの指示：2026-11-15（「つづけて」）。

## できること

| 項目 | 内容 |
|---|---|
| 断面図 | 図面一式に、平面図のあと・立面図の前に断面図が入る |
| 切る位置 | モデルに**有効な縦の断面**（断面ツール・`set_section`）があれば、それぞれ 1 枚（「A-A 断面図」「B-B 断面図」…、断面の向きどおりに見る）。無ければ**建物の真ん中**で 2 枚：A-A（東西に切って南から見る）、B-B（南北に切って東から見る） |
| 平面図の記号 | どの階の平面図にも、切る位置の線（一点鎖線）を図の外まで。両端に見る向きの太い線と矢印、記号（A・B）と、**その断面図の図番**（A-04 など） |
| 止める | AI の `export_drawing_set` は `sections: false` で断面図も記号も入れない。画面の図面一式は入る |

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 断面が無い時 | 真ん中で 2 方向 | 切る位置を入れずに一式を出しても、建物の高さ関係が分かる図が入るように。切りたい所があれば断面ツールで決めると、そちらが優先 |
| 図番の記号 | 平面図の切る位置にだけ | まずは一番よく使う所から。展開図・詳細図の記号はまだ図が無い |

## まだやっていないこと

- 断面図の上に、平面図の図番を書くこと（逆向きの参照）。
- 切る位置を画面の図面一式の書き出しで選ぶこと（今は断面ツールで決める）。
- 矩計図・展開図。
