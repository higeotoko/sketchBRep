# 床・屋根の種類を登録する（N-08 の第 4 段、2026-11-16）

[docs/134](134_floor_and_roof_types.md)（床・屋根の種類）の「まだ」（種類を名前で登録しておいて、新しく描く床・屋根をその種類で作ること）。作業は Opus 5.5。
オーナーの指示：2026-11-16（「続けて」）。

## できること

| 項目 | 内容 |
|---|---|
| 登録 | 種類名・部位（床／屋根）・値（床は厚さ、屋根は勾配・厚さ・軒の出・けらばの出。与えた物だけ）を、**図面といっしょに**持つ（保存・取り消しに入る） |
| 名前を付けると | 登録した種類名を床・屋根に付けると、**その値になる**（名前を付けるのと同じ取り消し 1 回）。床は上の面そのまま、屋根は外周・高さ・形そのまま |
| 種類を直すと | 「同じ種類の…にする」・AI の `change_type` で直すと、登録も同じ値に変わる |
| 画面から | 床・屋根に種類名がある時、プロパティに「種類 F1 を、これの値で登録する」（登録済みなら「種類 F1 の登録を、これの値にする」）。種類名の欄で、登録した名前が候補に出る |
| AI から | `define_type {name, part, thickness, pitch, eave, gable_eave}` または `{like: id}`、`list_types`、`remove_type {name}` |
| 種類の表 | 登録した種類は登録の値を出し、注に「登録済み」。まだ使っていない種類は数 0 で「登録だけ」。登録と違う値の物があると「登録した値と違う物があります」 |
| 登録を外す | `remove_type`。床・屋根の種類名と寸法はそのまま |
| 断る時 | 床・屋根でない部位、床に勾配・軒の出、値が 1 つも無い、厚さ 10〜2000・勾配 0 より上 30 まで・出 0〜3000 の外、もう一方の部位の物が使っている名前、床の種類名を屋根に付ける（逆も）。断った時は何も変わらない |

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 登録の置き場所 | 図面の設定（壁の数量の入力と同じ所） | 保存・取り消し・元に戻すの作りがもうある |
| 新しく描く床・屋根 | 描いた後に種類名を付けると、その値になる（ツールの設定に種類の選び方は足していない） | 描くツールを変えずに済む。名前を付けるのと値になるのが 1 回の取り消し |
| 登録だけの値 | 与えた値だけ持つ（例：屋根の勾配だけ） | 種類として揃えたい所だけを決められる。与えていない値は、その物のまま |

## まだやっていないこと

- 床・屋根の層（仕上げ・下地）を種類に持つこと（壁の仕様のように）。
- 床・屋根を描くツールで種類を選んで描くこと（→ docs/150）。登録の一覧を画面で直す窓（今は AI か、物から登録）。
