# 3D で 1 つの階だけ見せる（N-09、2026-11-15）

[docs/97](97_bim_gaps_and_priority.md) の N-09（順位 8 の 1 つ）。作業は Opus 5.5。
オーナーの指示：2026-11-15（「出先なので、とりあえず進めて」）。

## できること

| 項目 | 内容 |
|---|---|
| どこで | 建築ツールバーの階のボタン →「3D で 1 つの階だけ見せる」→ 階を選ぶ |
| 見える物 | その階の床から 300 下〜上の階の床の 300 下までに**始まる**立体（壁・柱・階段・その階の床スラブ） |
| 隠れる物 | 下の階の物、上の階の床スラブ・壁・屋根 |
| いつも見える物 | 線・文字・寸法・通り芯 |
| 戻す | 同じメニューの「全部の階を見せる」 |
| モデル | 変わらない（見せ方だけ。取り消しの数も増えない） |

同じ高さのレベル（GL と 1FL など）は 1 つの階としてまとめる。

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| どの階の物か | 立体の**下の端**の高さで決める（レベルの付き方は見ない） | 手で描いた箱や柱にも効く。古いファイルにも効く |
| 300 の余裕 | 床の下 300 から、次の床の下 300 まで | 床スラブ（上面がレベル、厚さ 200 前後）は上の階に入り、屋根（軒の高さの少し下に下面）も上の階に入る |

## まだやっていないこと

- 2 つ以上の階をまとめて見せる、上の階を半透明にするなど。
- 平面図・立面図（書き出し）を 1 つの階だけにすること（平面は前から階ごと）。
- 吹抜けの壁のように、2 つの階にまたがる物は、下の端の階に入る。
