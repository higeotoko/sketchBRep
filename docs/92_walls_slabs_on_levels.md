# 壁と床をレベルに付ける（G-02、2026-11-14）

[docs/90](90_bim_operation_framework.md) の G-02。関係する約束は B-02（基準に付く）・B-03（後から同じ言葉で直せる）・B-06（階で考えられる）・B-08（直接編集を止めない）・B-09（人と AI が同じ言葉）。

## 直す前

- レベルに付いてくるのは「通り芯に柱・梁を配置」で置いた柱と梁だけだった（docs/45）。
- 壁と床は、描いた高さに置かれるだけ。**階高を変えると、壁と床が取り残された**。

## 決めたこと（オーナーの了承：2026-11-13）

> 建築ツールバーの壁・床ツールで描いた物は、最初からレベルに付ける。線やプッシュプルで作った物は付けない。

今までの「頼んだ物だけ付く」（docs/42・45）のうち、**壁ツール・床ツールで作った物だけ**を変えた。追従（docs/42）と柱・梁（docs/45）はそのまま。

## 直した後

| 場面 | どうなるか |
|---|---|
| 壁を描く（壁ツール・`create_wall`） | 足元の高さにレベルがあれば、そのレベルに付く。上端の高さにもレベルがあれば、上端もそのレベルに付く |
| 床を描く（床ツール・`create_slab`） | 上面の高さにレベルがあれば、そのレベルに付く |
| レベルのない高さに描く | どこにも付かない（今まで通り） |
| 線・箱・プッシュプルで作った形 | レベルと同じ高さにあっても付かない |
| レベルの高さを変える（階高の変更） | 足元が付いている壁は、足元が同じだけ動く。上端が付いている壁は、高さが伸び縮みする。上端が付いていない壁は、高さを保って足元と一緒に動く。床はまるごと動く（厚さは同じ） |
| 壁の開口 | 腰高（壁の足元からの高さ）はそのまま。幅・高さ・建具・ID も変わらない |
| 手で動かした壁 | 動かした分のずれを保ったまま、その後もレベルに付いていく |
| レベルを消す | 付いていた壁・床は、その場に残る。プロパティには「（削除されたレベル）」と出る |
| ロックした壁・床 | 動かない |
| 付いていけない時 | 上のレベルを足元より下げた等で、壁の高さが無くなる時：その壁は**そのままにする**（壊さない）。レベルの変更そのものは行う |
| 取り消し | レベルの変更と、付いていった物は、まとめて Undo 1 回 |

同じ高さにレベルが 2 つある時（GL と 1FL が同じ等）は、名前が「…FL」のレベルに付く。

### 画面（プロパティパネル）

- 壁：「下端のレベル」「上端のレベル」
- 床：「上面のレベル」

選ぶと、**その端が今そのレベルへ動いて**、以後付いていく。「なし」を選ぶと、今の位置のまま外れる。

- 下端を別のレベルにした時：上端がレベルに付いていれば上端はそのまま（壁が伸び縮み）。付いていなければ、高さを保ってまるごと動く。
- 上端を足元より下のレベルにする等、成り立たない指定は断り、何も変えない。

### AI から

| コマンド | 内容 |
|---|---|
| `attach_to_levels` | `{ids, base?, top?}`。レベルは ID でも名前でも。`null` で外す。床は `top` だけ |
| `set_levels` | 今まで通り。壁・床も付いてくる |
| 属性 | `base_level`・`top_level`（レベルの ID）。`get_object` / `query_objects` で読める |

## 実装で決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 持たせる情報 | 物の属性 `base_level`・`top_level`（レベルの ID）だけ | 保存・コピー・AI からの検索が、今ある属性の仕組みでそのまま動く。G-03（階だけ表示）もこの属性を使える |
| 動かし方 | レベルが動いた**差分**だけ動かす（位置を計算し直さない） | 手で付けたずれが残る。柱・梁（docs/45）と同じ考え方 |
| 壁の高さの変え方 | 壁ツールが作った「長方形＋押し出し」の押し出し量を変える。開口のある壁（引き算の中）にも届く | 開口は壁の足元からの位置で持っているので、腰高が変わらない |
| 直接編集した壁 | 押し出し以外の編集をした壁は高さを変えられないので、足元の移動だけ付いていく | 直接編集を止めない（B-08）。形を壊さない |
| 付けるかどうかの判断 | 作った時の高さが、レベルの高さと一致（0.000001 mm 以内）した時 | 画面のツールも AI も、同じ規則になる（B-09） |

## まだやっていないこと

- 壁の設定に「上端：上の階のレベルまで」を足すこと。今は、高さを階高と同じにして描くか、描いた後にプロパティで「上端のレベル」を選ぶ。
- 直接編集で高さが付いていけなくなった壁を、その場で知らせること（docs/90 G-10）。
- 屋根・階段・柱（手で引いた柱）のレベル。柱・梁は「通り芯に配置」の仕組み（docs/45）のまま。
- 立面でレベルの線をドラッグして階高を変えること（docs/90 G-14）。
