## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 軒の高さ | 勾配・出を変えた辺でも、屋根の下面は外周の線の上で「軒の高さ」を通る | 壁・桁の上端の高さが屋根の基準。出が長い辺・勾配が急な辺は、軒先がその分だけ下がる（隣の辺と軒先の高さが違う角には、小さな段ができる） |
| 妻の辺に書いた値 | 出は、その妻・けらばの出。勾配は使わない（断らない） | 妻は面が立つ所で、勾配が無い |
| 片流れ | 面は 1 枚なので、辺ごとの勾配は使わない（プロパティに欄を出さない）。辺ごとの出は使う | |
| 直角だけの外周に、辺ごとの値を入れた時 | 斜めの外周と同じ作り方に切り替える。長方形は今までと同じ形。**L 字・T 字・コの字の切妻は、翼の先が妻、外の角が隅棟**になる（辺ごとの値が無い時は、今までどおり長方形ごとの切妻） | 今までの作り方（いちばん大きな長方形ごとの屋根）は、左右で同じ勾配・同じ出が前提。辺ごとの値があると使えない |
| へこんだ角がある外周の切妻で、妻を選ばない時 | **翼の先**を妻にする：両側の角が出っ張っていて、両隣の辺がほぼ平行に戻って行き（30° 以内）、両隣より長くない辺。1 つも無ければ「妻の辺を選んでください」と断る | 「向かい合う平行な 2 辺」では、L 字のどの組を妻にするか決まらない。翼の先なら形で決まる |
| へこんだ角がある外周の片流れ | 流れる向きにいちばん向いた辺（同じ向きが幾つもあれば、いちばん先にある辺）から上がる 1 枚の面を、外周を出だけ広げた形で切る | 直角だけの外周の片流れと同じ |
| 切り分けた所 | へこんだ角で外周を出っ張った形に切り分ける時、**切り口には出を付けず、縦に区切る**ことにした（寄棟も） | 前は切り口にも軒の出を付けていたので、切り口が外周に当たる所で、軒の角から小さな耳が外へ出ることがあった（docs/138 の寄棟でも起きうる形だった） |

### 妻と軒が隣り合う時

妻の辺と軒の辺が浅い角（まっすぐに近い角）で隣り合うと、けらばの面と軒の面の高さが合わず、その角の所に小さな段ができる（妻を手で選んだ時。たとえば下の絵の L 字で、西の辺 7 を妻にした時）。形として決まらない所なので、そのまま出している。

## 作り方

[docs/108](108_hip_roof_on_slanted_outline.md)・[docs/138](138_slanted_gable_shed_and_dented_hip.md) の作り方を、辺ごとの決まり（妻か軒か・勾配・出）で組み直した。

1. 外周を、へこんだ角の所で出っ張った形に切り分ける（今までどおり、切り方を全部試して、いちばん大きい形だけ残す）。切り分けた形の辺は、元の外周のどの辺の線の上にあるかを覚えておく。
2. 形ごとに、軒の辺からは「その辺の勾配で上がる面の下」、妻の辺と切り口は縦の面で囲んだ立体を作る。
3. 全部の形の立体を足す（谷ができる）。
4. 勾配が全部同じなら、今までどおり厚さの分だけ持ち上げた写しから元を引く。違うなら、面ごとに厚さの分だけ上げた立体を別に作って、そこから元を引く。

## まだやっていないこと

- **高さの違う屋根の取り合い**（下屋が 2 階の壁・上の屋根に当たる所など）。Fable に渡す物の 2 の残り。
- 辺ごとの軒の高さ（桁の高さを辺ごとに変えること）。
- 屋根ツールで描く時に、辺を押して妻・勾配・出を選ぶこと（今はプロパティに番号で入れる）。3D で辺の番号を見せること。
- 屋根の種類の登録（docs/149）に、辺ごとの値を入れること（番号は外周ごとに違うので入れていない）。
- へこんだ角は 4 つまで。本当のまっすぐな骨組み（直線スケルトン）ではない（Fable に渡す物の 3）。
- 外周が自分と交わる形を、斜めの外周の作り方では調べていない（前から）。
