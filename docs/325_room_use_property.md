# 325. 室のプロパティに「用途の区分」の欄

docs/324 の室ごとの用途（第五面 7.用途別床面積）は、MCP でしか入れられなかった。アプリの室のプロパティにも欄を足す。

## 欄の作り

- 欄は1つで、「用途の区分」という名前。
  - 様式の5桁の番号と具体的な用途の名称を、続けて入れる（例 `08440 物品販売業を営む店舗`）。
  - 番号と名称は両方そろわないと入らない。欄を2つに分けると、片方だけ入れた途中で必ず失敗するので、1つにした。
- 区切りは半角・全角のスペース。
- 空欄で主要用途に戻る。
- 番号が5桁でない、名称が無いときは、これまでどおりエラーで入らない（モデルの検査はそのまま）。
- 1回で元に戻せる。

## 確認

GUI の `schedulesAreReadFromTheModel…` で確かめた。

- 全角スペースで区切った `08440　物品販売業を営む店舗` を入れると、番号 08440・名称「物品販売業を営む店舗」としてモデルに入る。
- 空欄にすると番号が消える。
