# 土台からべた基礎を計画する（2026-11-05）

布基礎（[docs/66](66_foundation_planning.md)）・束石（[docs/68](68_foundation_pads.md)）に続き、
実在する土台から **べた基礎**（立上り＋耐圧盤）の計画形状を作れるようにした。
人通口（床下を点検で通るための立上りの開口）も、内部の立上りに開けられる。
形を作る機能で、地盤・構造・配筋の照査はしない。GUI も AI も同じ Modeler・Undo の経路。

## SumiCAD から学んだこと

接続した SumiCAD 0.7.1 の MCP で、読み取りだけを行った（`guide {topic:"foundation"}`、
`list_actions {query:"foundation"}`、`attributes.list {collection:"foundationProfiles"}` の初期の断面設定）。
SumiCAD の生成・修正・保存は実行していない。プロジェクト情報はリポジトリと ZIP に入れていない。

| SumiCAD の考え方 | SketchBRep での取り込み |
|---|---|
| 基礎は「断面設定（profile）」の種別で、布基礎（strip）とべた基礎（mat）を切り替える | 同じ画面・同じ API の `type` で切り替える（strip / mat。束石は pads） |
| べた基礎＝耐力壁・土台の下の立上り＋外周の内側の耐圧盤（slab） | 実在する土台の下に立上り、その外周の輪郭の内側全体に耐圧盤 |
| 人通口（fdpass）は内部の立上りの開口。標準 600×330 | 内部の立上りだけに開ける。初期値 600×330。外周・交差部は拒否 |
| 床下地盤・防湿・換気・配筋・告示 1347 の検査は別の操作 | 今回は取り込まない。未照査として結果に出す |

SumiCAD の初期設定には、立上りの下の地中部分（フーチング）もある。今回はまだ作らない（下の「未対応」）。
数値や法規の正しさを SumiCAD で確かめたという記録ではない。

## 画面から使う

1. 木造架構を作るか、矩形断面の水平な木造土台を選ぶ。べた基礎は、外周の土台が一周つながっている必要がある。
2. 建築ツールバーの「木造」→「べた基礎計画（土台から作成・作り直し）...」。布基礎の画面で「種別」をべた基礎にしても同じ。
3. 立上り幅・立上り高さ（**耐圧盤の上面から**基礎天端まで）・耐圧盤の厚さ・パッキン高さを指定する。
4. 人通口は「人通口の位置」に、内部の立上りの上の点を `X,Y`（mm）で入れる。複数はセミコロン区切り。幅・高さは共通。
5. プレビューで形とコンクリート量を見て「適用」。却下はモデルを変えない。適用は Undo 1 回で戻る。
6. 作った後は種別を変えられない。布基礎にしたい時は、べた基礎計画を削除してから作る。

## 形と数量

- 基礎天端＝土台の下面−パッキン（布基礎と同じ。手入力の `top_z` も可）。
- 立上り：土台の芯に沿った幅 `stem_width` の帯を和演算でつなぐ（端は幅の半分だけ延長）。耐圧盤の上面から基礎天端まで。
- 耐圧盤：立上りの帯を一つにつないだ下面の **外側の輪郭**（穴＝部屋の内側は埋める）を多角形にし、厚さ `slab_thickness` で下へ。
  立上りとは上下で接するだけで、体積は重ならない。外周の輪郭は直線だけ（曲がった土台は未対応）。
- 初期値：立上り 150×400、耐圧盤 150、パッキン 20、人通口 600×330。**形を作るための仮の値**で、設計値ではない。
- 検算例（120 角の土台、3000×2000 の外周、土台下面 Z=420）：
  天端 400、耐圧盤 3.15×2.15×0.15＝1.015875 m³（Z=−150〜0）、立上り 1.5 m²×0.4＝0.6 m³。
  中央に 3000 の内部土台を足すと立上りだけ 0.171 m³ 増え、耐圧盤は変わらない。
  その内部立上りに 600×330 の人通口を開けると 0.0297 m³ 減る。L 字の外周も外側の輪郭どおりになる。

## 拒否すること（どれもモデルを変えない）

| 状況 | 理由として出すこと |
|---|---|
| 外周が閉じていない（土台 3 辺だけ等） | 閉じた外周を作っていない |
| 離れた土台の組が混ざっている | 一つにつながっていない |
| 高さの違う土台が混在 | 段差基礎は未対応（布基礎と同じ） |
| 人通口が外周の立上り／交差部にかかる／立上りのない位置／高さが立上り以上／人通口どうしが重なる | それぞれの理由 |
| 布基礎の項目（底盤幅など）を指定 | 不明な項目 |
| 同じ土台に別の種別の計画がある | 使わない方を削除してから作る |
| 置換で種別を変える | 種別は置換で変えられない |

## 変更の検知・支持先との連携

- 布基礎と同じ仕組み：元の土台・生成した部材の状態を保存し、`check_foundation` で current / needs_regeneration /
  modified / source_missing_or_unsupported を返す。保存再読込後も同じ。
- 未照査の項目はべた基礎用に出す：地盤・支持力・沈下、耐圧盤・立上りの構造計算、配筋、荷重伝達、
  外周の根入れ・凍結深度・地形、防湿・断熱・床下換気、人通口の補強・床下の点検経路、配管の貫通。
- 「基礎までの支持先」（docs/67）は耐圧盤もコンクリートの支持先として数える。
  耐圧盤の上に立つ実在の床束は「detected」になる（形が接しているという意味で、耐力の合格ではない）。

## API / MCP

```json
{"command":"generate_foundation","args":{"inputs":{"type":"mat","frame":"架構グループID"}}}
{"command":"generate_foundation","args":{"inputs":{"type":"mat","sources":["土台ID",...],
  "stem_width":150,"stem_height":400,"slab_thickness":150,"packing_mm":20,
  "passages":[{"at":[1500,1000],"width":600,"height":330}]},"preview":false,"expected_revision":123}}
```

生成の初期動作は読み取り専用のプレビュー。適用・置換・`on_modified` は布基礎と同じ。
数量は `quantities.foundation_stem` と `quantities.foundation_slab`。

## 未対応（次の候補）

- 立上りの下の地中部分（外周の根入れ・フーチング）、地中梁。
- 土台のない耐力壁の下、外周の外の玄関・ポーチ・テラス、段差・傾斜地、床下地盤・防湿・断熱・換気口。
- 人通口の補強・床下の点検経路の確認、配管の貫通、アンカー。
- 木造レシピの土台は外周だけ。内部の土台が無い家では、内部の立上り・人通口は作られない
  （内部の耐力壁の下に土台を置く機能は別途）。
- 配筋設計はオーナーの方針どおり対象外。
