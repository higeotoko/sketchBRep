# 層の数量（壁・床・屋根の層ごとの面積・体積、2026-11-18）

[docs/106](106_handoff_and_roadmap.md) の「残り（Opus で可）」の「層を数量に」。[docs/170](170_layers_in_ifc.md)（層を IFC に）の「まだ」。作業は Opus 5.5。
オーナーの指示：2026-11-17（「続けて」）。

## できること

| 項目 | 内容 |
|---|---|
| 出す物 | 部位（壁・床・屋根）× 層の名前 × 厚さごとに、部材の数・面積（㎡）・体積（㎥） |
| 対象 | 仕様のある壁（外壁 サイディングなど）、層を登録した種類の床・屋根 |
| 面積 | 部材の体積 ÷ 厚さ（開口の分は引かれる。屋根は勾配なりの面積） |
| 体積 | 面積 × その層の厚さ（部材の層を全部足すと、部材の体積にちょうどなる） |
| 同じ層が 2 枚 | 石膏ボード両面など：面積を 2 回数え、部材の数は 1 つ |
| 出る所 | 表の窓の 6 つ目のタブ「**層の数量**」（CSV・図面にも保存できる）。AI の `layer_quantities`（`include_csv` で CSV）。`export_schedule`・図面の表の `table`／`tables` に `layers` |
| 入らない物 | 層の無い壁・床・屋根、厚さを変えて層の合計と合わなくなった物（数を注に出す） |

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 面積の出し方 | 体積 ÷ 厚さ | 開口・屋根合わせ・留めの形がそのまま効く。壁の線の長さ × 高さと同じ考え |
| 角の差 | 見ない（注に「概算」と書く） | 外側の層は出隅で長く、内側は短い。層ごとに形を切り出すと重くなる。拾いの元としての概算 |
| 行の分け方 | 部位・名前・厚さ | 同じ名前で厚さの違う材料（合板 9 と 12 など）を混ぜない |
| ロス・割付 | 入れない | 発注の数量ではない（`take_off` と同じ考え） |

## まだやっていないこと

- 角の差（入隅・出隅）を層ごとに正しく出すこと。
- 天井の板（docs/123）の数量、建具の数量（建具表にある）との一覧。
- 単価を掛けた見積もり。
