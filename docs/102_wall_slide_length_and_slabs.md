# 壁をすべらせた時・長さを変えた時のつながり、床の外周（G-05 の残り・N-04、2026-11-14）

[docs/97](97_bim_gaps_and_priority.md) の順位 4。[docs/96](96_wall_joins_follow_a_move.md)（壁を横へ動かした時）の続き。
関係する約束は B-04（つながりが保たれる）・B-08（直接編集を止めない）。
オーナーの指示：2026-11-14（「4 位進んで」）。

## 直す前（docs/96 の時点）

| 操作 | 動き |
|---|---|
| 壁を横へ動かす | 角・T 字の相手が伸び縮みして付いてくる |
| 壁を線に沿ってすべらせる | 動かした壁だけが動き、**角が離れた** |
| 壁の長さを変える | その壁だけが変わり、**角が離れた** |
| 床（スラブ） | 壁を動かしても、**そのまま** |

## 直した後

| 操作 | 動き |
|---|---|
| 壁を横へ動かす | 今まで通り（相手が伸び縮み） |
| 壁を線に沿ってすべらせる | **両端の角の壁が、そのままの形で一緒に動く**。その先につながる壁は伸び縮み |
| 斜めに動かす | 横の分は伸び縮み、線に沿う分は角の壁を運ぶ（両方が同時に効く） |
| 壁の長さを変える | **動く側の端の角の壁が、一緒に動く**。その先につながる壁は伸び縮み |
| 床（スラブ） | 外周の角が壁の中にある時、**その壁の横への動きに付いてくる** |

- どれも、元の操作と同じ取り消し 1 回の中で行う。
- T 字の途中に当たっている壁（間仕切りなど）は、相手がすべっても動かない（当たったまま）。
- 付いてこられない壁（ロック中・開口が外に残る・長さがなくなる）は、そのまま残して名前を出す。操作は止めない。
- ステータスバーに「角の壁 n 枚を一緒に動かしました。つながっている壁 n 枚の長さを合わせました。床 n 枚の外周を合わせました」と出す。
- 「ツール > 壁を動かすと、つながっている壁も付いてくる」のチェックを外すと、全部やめる（動かした壁・変えた壁だけが変わる）。

### 長さを変えた時に動く端

壁の長さを数値で変えると、**壁を描き終えた側の端**が動く（描き始めた側は動かない。今までと同じ）。
その端の角の壁が、伸びた・縮んだ分だけ一緒に動く。

### 床の外周

- 見るのは、スラブツールで作った床（外周の多角形を持つもの）。
- 外周の角が、動いた壁の中（厚さの中。角の所は、相手の壁の厚さの分まで）にあれば、その壁の**横への動き**の分だけ動く。
- 角が 2 枚の壁の角にある時は、両方の動きを合わせる（角のまま付いてくる）。
- 床の上面の高さ・厚さは変わらない。
- 壁と一緒に床も選んで動かした時は、床はそのまま動くだけ（形は変えない）。
- 壁に触れていない床（デッキなど）は、変わらない。

## 例（6000 × 4000 の部屋）

| 操作 | 結果 |
|---|---|
| 南の壁を東へ 700 すべらせる | 東・西の壁が 700 動く。北の壁も両端が付いてきて 700 ずれる。間仕切りはそのまま。床も 700 ずれる |
| 南の壁を 1000 長くする | 東の壁が 1000 東へ動く。北の壁が 1000 長くなる。室が 1000 広がる。床の東側の角も 1000 動く |
| 南の壁を外へ 455（横へ） | 東・西・間仕切りが 455 伸びる（docs/96）。床の南側の角が 455 動く |

## AI から

- `move` の返り値 `joined_walls` に、`carried`（一緒に動かした角の壁の数）と `slabs`（外周を合わせた床の数）を足した。
- `change_member {id, length}` で壁の長さを変えた時も、同じ動きをする。

## 実装で決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 仕組み | 「どの壁が、どれだけ動くか」を壁ごとに持ち、端が当たっている相手との**動きの差**で、その端の行き先を決める | 横・すべり・斜め・長さの変更を、1 つの決まりで扱える。docs/96 の決まり（当たっていた面と同じ面へ）がそのまま使える |
| 角の壁を「運ぶ」か「伸ばす」か | 相手の動きが、自分の線に直角なら運ぶ（そのままの形で動かす）。線に沿っていれば伸び縮み | 直角の角では、これで角が必ず保たれる |
| 連鎖 | 運んだ壁の、その先につながる壁は伸び縮みまで。運んだ壁の先の角を、さらに運ぶことはしない | 直角の間取りでは、これで閉じる。斜めの角は下の「まだ」 |
| 動かした壁そのもの | 形を変えない（使う人が動かした通りに動く） | 動かした壁が勝手に伸び縮みすると、何をしたか分からなくなる |
| 床の角の見つけ方 | 壁の厚さの中にあるか（平面）と、高さが重なるか | 床と壁のつながりを別のデータとして持たない。古いファイルにも効く |

## まだやっていないこと

- **直角でない角**：運んだ壁の先で、角がずれることがある（運ぶ動きが、相手の線に沿う分を持つため）。
- 壁の**描き始めた側の端**を動かすこと（長さを変える時に、どちらの端を動かすか選ぶ）。端の面を push/pull した時の追従。
- 壁の厚さを変えた時の、相手の付け直し（仕様の変更ではできる。docs/79）。
- 壁を回した時。
- 床の外周が、壁の「面」（内法）に合わせてある時の扱い（今は、角が壁の厚さの中にあれば付いてくる）。床の穴（吹抜け）の外周。
- 柱・梁・屋根が、壁に付いてくること（屋根の外周は、今は壁と別）。
- 動かしている途中の先読み表示（今は、置いた後に形が変わる）。
