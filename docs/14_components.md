# 14. コンポーネントの配置を個別に直す

同じ窓・建具を何十個も置いたあとで「この 1 か所だけ幅が違う」「左右反転したものが欲しい」「原点がずれていて回しにくい」となるのはよくあること。
分解して別物にすると、共通の変更が届かなくなる。そこで、共有を保ったまま配置ごとに直せる手段を用意した。

## 操作

プロパティパネル（コンポーネントの配置を選択）:

- 見出しに「コンポーネント「名前」（配置 N 個）」。**変えると何個に効くか**が常に見える
- **寸法の変更**: 「すべての配置（N 個）に反映」/「この配置だけ変更」を切り替えてから寸法を編集
  - この配置だけの寸法には **＊** が付く（ツールチップに共通の値）。共通の値をもう一度入れると＊は消える
  - ＊の付いた寸法は、共通寸法を変えてもこの配置では変わらない（注記に件数を表示）
- ボタン: **独立**（この配置だけ別のコンポーネントにする）/ **寸法を戻す** / **鏡像**（赤軸方向）/ **軸…**

編集 > コンポーネントの配置:

- この配置だけ独立、この配置だけの寸法を戻す
- 鏡像: 赤・緑・青軸方向（その場で反転、外形の範囲は動かない。複数選択可）
- 軸を変更（原点・赤軸）: 新しい原点をクリック → 赤軸を向ける点をクリック（Enter で向きはそのまま、Esc で原点を選び直す）。**どの配置も動かない**

コンポーネント編集（ダブルクリック）中は、定義そのもの（個別寸法・鏡像なし）が表示される。終了すると、その配置の個別寸法と鏡像はそのまま戻る（編集中ラベルに注記）。

## グループ・コンポーネントの選択と編集終了

- 外側から選ぶと、一つのまとまりとして青い輪郭線で表示。内部の面すべてを点々で塗る表示にはしません。元の面の色やテクスチャはそのまま見えます。
- ダブルクリックで中に入ると、内部の面・線を個別に選べます。面を選んだときは従来の青い点の表示です。
- **選択ツールで何もない場所を左ダブルクリック**、またはEscで編集終了。コンポーネントは編集内容を共通定義へ反映して終了します。
- 空白の1クリックは選択解除だけ。Ctrl等を押した空白ダブルクリックでは編集を終了しません。
- 線・曲線・壁などの作図中は、それぞれのダブルクリックによる確定操作を維持します。選択ツールへ戻ってから空白をダブルクリックしてください。
- 空白の左ダブルクリックでカメラは動かしません。中ボタンのダブルクリックによるフォーカスは従来どおりです。

## なぜ「伸縮」ではなく「個別パラメータ」か

SketchUp の非一様スケールで窓を横に伸ばすと、枠の見付も一緒に太くなる。
ここではレシピの寸法そのもの（幅・押出量など）を配置ごとに上書きする。だから枠は太らず、Push/Pull の結果やほかの寸法との関係も保たれる。

## データ

- `ComponentInstance{definitionId, overrides[{object, key, value}], mirrored}`
  - overrides は「定義内のオブジェクト id + パラメータキー + 値」
  - 定義の編集でオブジェクトやキーが無くなった上書きは、その編集で取り除く
- **鏡像は形状側で持つ**
  - 定義の YZ 面について鏡像にした**コピー**（`BRepBuilderAPI_Transform` copy）を作る
  - 配置の変換（`TopLoc_Location`）は常に剛体のまま。OCCT は鏡像・拡大縮小を含む location を嫌う（ブーリアン・メッシュ・選択が不安定）ため
  - 緑・青軸方向の鏡像は「赤軸の鏡像 + 回転」に分解するので、保存するのは `mirrored` の 1 ビットだけ（2 回鏡像にすると回転に戻る）
- 個別寸法や鏡像がある配置の形状は、ドキュメントが「定義の形状 + 設定」ごとにキャッシュする
  - 同じ設定の配置どうしは同じ形状を共有するので、表示メッシュも共有される（定義の編集時も同様）
  - 設定が何もない配置は、これまでどおり定義の形状そのもの
- **独立**: 定義を複製し、その配置の個別寸法をレシピに書き込んでから付け替える
  - 名前は「名前 #2」、オブジェクト id は新規。鏡像は配置側に残る
  - 配置が 1 個しかない定義では不要なので断る
- **軸の変更**
  - 定義のルートオブジェクトを新しい座標系へ移し、すべての配置の変換を逆に補正する
  - 鏡像の配置は鏡像を通して補正するので、全配置が 1 mm も動かない
  - 回転は青軸まわり（赤軸の向き）だけ
- **分解**は個別寸法を書き込んだ部品になる。鏡像の配置は分解を断る（剛体の配置では鏡像の部品を表現できないため）
- `.sbr`
  - instance に `overrides` / `mirrored` を保存する
  - コンポーネント編集中のグループにも同じ情報を保存する（編集中に自動保存・復旧しても失われない）
- すべて 1 回の取り消し単位で、AI とも同じ経路（下記）

## AI コマンド

- `placement_parameters {id}`（読み取り）: 各寸法の `value`（この配置）/ `shared`（共通）/ `own`、配置数、鏡像
- `set_placement_parameter {id, object, key, value}`, `clear_placement_parameters {id}`
- `make_unique {id}` → `{definition}`
- `mirror_placement {ids, axis: red|green|blue}`
- `set_component_axes {id, origin, x_axis?}`
- `query_objects` の `fields: ["definition"]` に `mirrored` / `own_parameters`（件数）が付く

## 制限と次の段

- 個別寸法の配置では、定義内の面に塗った素材は面番号で対応させている。寸法を変えても面の数が同じ形（矩形の押し出しなど）なら正しいが、面の数が変わる形では面の素材がずれることがある
- 軸の変更は青軸まわりの回転まで。青軸そのものを傾ける（斜め屋根に沿った部品など）は次の段
- 入れ子のコンポーネント（コンポーネントの中のコンポーネント）は未対応のまま
- 配置ごとの素材の上書き（同じ建具で色違い）は、素材の個別上書きとして同じ仕組みで足せる
