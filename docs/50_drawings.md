# 図面の書き出し（平面図・断面図・立面図）（2026-11-02 JST）

モデルから2Dの図面を作り、図面枠と表題欄を付けて、**PDF・DXF・JWW（Jw_cad）・DWG**で書き出す。

## 使い方

1. 「ファイル > 図面を書き出す（平面・断面・立面）...」を開く。
2. 種類、切る位置、縮尺、用紙、書き出すもの、表題欄を選ぶ。右側のプレビューは、選ぶたびに変わる。
3. 「書き出す（PDF・DXF・JWW・DWG）...」を押して、形式を選んで保存する。

| 項目 | 選べるもの | 初期値 |
|---|---|---|
| 種類 | 平面図 / 断面図 / 立面図 | 平面図 |
| 平面図の切る位置 | レベル（1FL など）＋そこからの高さ | 1200 mm（前回の値を覚える） |
| 断面図の位置 | 今の断面（断面ツールで作った垂直な断面）、通り芯（X2通りなど）、モデルの中央。見る側を2つから選ぶ | 一覧の最初 |
| 立面図の向き | 南（正面）/ 東 / 北 / 西 | 南 |
| 縮尺 | 1:20 / 1:30 / 1:50 / 1:100 / 1:200 / 1:300 / 1:500 | 1:100（前回の値を覚える） |
| 用紙 | 自動（収まる一番小さい用紙）/ A4〜A1 横 | 自動 |
| 書き出すもの | 切った面の塗り、隠れている線（破線）、通り芯と符号・スパン、レベル、寸法・文字、図面枠と表題欄 | 隠れ線だけ「なし」 |
| 表題欄 | 工事名・図面名・図番・作成者・日付 | 工事名と作成者は前回の値、図面名は種類から自動、日付は今日 |

- 図面名は、種類や位置を変えると自動で変わる。自分で打つと、そのあとは打った名前のままになる。
- 北は +Y（モデルの奥）の方向。平面図の右上に方位マークを付ける。

## 図面の中身

| 要素 | 作り方 | 線 |
|---|---|---|
| 切断線 | 立体を平面で正確に切る。円や円弧は、円・円弧のまま出す | 太線 0.5 mm |
| 切った面の塗り | 切り口の面をグレーで塗る（立体だけ） | — |
| 見えている線 | 切った面の向こう側を、OCCT の隠線処理で正確に計算する。物どうしの重なりも隠れる | 細線 0.18 mm |
| 隠れている線 | 選んだときだけ出す | 破線 0.13 mm |
| 単独の線 | 床に描いた線などは、隠れずにそのまま出す | 細線 |
| 通り芯 | 平面図では全部の通り芯。断面図・立面図では、見る方向に走る通り芯（縦の線になる）。丸の符号（直径 10 mm）とスパン寸法を付ける | 一点鎖線 0.13 mm |
| レベル | 断面図・立面図で、横の線と名前・高さ（±0、+3100 など）を出す。同じ高さのレベルは「GL・1FL」のように1本にまとめる | 一点鎖線 |
| 寸法・文字 | 図の面と平行な寸法、見える側の文字 | 細線 |
| 図の名前 | 図の下に「1FL 平面図  S=1:100」 | 文字 5 mm |
| 図面枠 | 左 20 mm（綴じしろ）、ほかは 10 mm の枠 | 太線 0.7 mm |
| 表題欄 | 右下 130×32 mm。工事名・図面名・縮尺（用紙）・日付・図番・作成者 | 0.25 mm |

- 文字や符号の大きさは、縮尺を変えても紙の上で同じ大きさになる。
- 図が用紙に収まらない時は、プレビューの下に表示する（例：A1 に収まらないので、縮尺を小さくする）。

## 形式ごとの中身

| 形式 | 座標 | 線の太さ・種類 | レイヤー | 文字 |
|---|---|---|---|---|
| PDF | 用紙どおり（縮尺どおりに印刷できる） | 上の表の太さ | — | そのまま |
| DXF（R12） | 実寸（mm） | 色と線種で分ける（太さは印刷時の色の設定で決める） | CUT、VISIBLE、HIDDEN、FILL、GRID、GRID_LABEL、LEVEL、DIMENSION、TEXT、FRAME、TITLE | Shift_JIS（Jw_cad と日本語版 AutoCAD で読める） |
| JWW | Jw_cad のやり方どおり、紙の上の mm（用紙の中心が原点）。縮尺はレイヤグループに記録する | Jw の線色（印刷の太さは 1/100 mm 単位）と線種 | グループ0のレイヤ0〜A に、断面・見え掛かり・隠れ線・断面塗り・通り芯・通り芯符号・レベル・寸法・文字・図面枠・表題欄 | MS ゴシック、大きさは図寸 |

JWW の線色の割り当て：

| 線色 | 印刷の太さ | 使い道 |
|---|---|---|
| 5 | 0.50 mm | 断面 |
| 2 | 0.18 mm | 見え掛かり・符号・文字 |
| 1 | 0.13 mm | 隠れ線（点線1）・通り芯とレベル（一点鎖1）・寸法 |
| 6 | 0.70 mm | 図面枠 |
| 3 | 0.25 mm | 表題欄 |
| 任意色（グレー） | — | 断面塗り（ソリッド） |

## DWG

DWG は、DXF を **ODA File Converter** で変換して作る。DWG の取り込み（docs/24）と同じ変換ソフトを使う。

- ODA File Converter は SketchBRep に同梱していない。公式配布元から別途インストールする。
- 未設定のまま DWG を選ぶと、案内のあとで実行ファイルの場所を聞く。設定は取り込みと共通（「ファイル > DWG 変換ソフトの設定...」）。
- 形式は AutoCAD 2018。中身（レイヤー・線種・文字）は DXF と同じ。
- 保存先のファイルは、変換に成功した時だけ置き換える。変換は120秒で打ち切り、途中で中止もできる。
- 自動テストでは、本物の代わりの変換プログラムで呼び出し方を確かめている。本物の ODA File Converter での確認はまだ。

## JWW を作るときに決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 形式の資料 | Jw_cad の作者が公開している「Jw_cad のデータ形式」（jwdatafmt.txt）どおりに書く | 公式の資料だから |
| 確かめ方 | Jw_cad 8.25a に付いているサンプル図面15個を、同じ手順で最初から最後まで読めることを確かめた。そのうえで、書き出したファイルも同じ手順で読み戻すテストにした | 資料の読み違いを防ぐため。サンプル図面はリポジトリには入れていない |
| バージョン | データは Ver.6.00 の形式で書く | サンプルと同じ形式で、Jw_cad 7・8 で読めるから |
| 塗り | 三角形のソリッドに分けて書く | Jw のソリッドは4点の形だから |

## まだ確かめていないこと

- **Jw_cad の実機で開いて、見た目を確かめること。** 形式の読み書きはテストで確かめたが、表示や印刷はまだ。
- 日本語版 AutoCAD など、ほかの CAD で DXF を開くこと。

## AI から

`export_drawing`：DXF か JWW を書く（PDF はアプリのメニューから）。指定するものは次のとおり。

- `kind`：plan / section / elevation
- 平面図：`cut_z`
- 断面図：`point` と `look`
- 立面図：`side`
- 共通：`scale`、`paper`、`frame`、表題欄の各項目

返り値は、選んだ用紙と注意（用紙に収まらない、など）。
