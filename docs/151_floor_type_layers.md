# 床の種類に層（仕上げ・下地）を持たせる（N-08 の第 6 段、2026-11-16）

[docs/134](134_floor_and_roof_types.md)・[docs/149](149_registered_types.md) の「まだ」（床・屋根の層を種類に持つこと、壁の仕様のように）。まず床。作業は Opus 5.5。
オーナーの指示：2026-11-16（「続けて」）。

## できること

| 項目 | 内容 |
|---|---|
| 層 | 登録した**床**の種類に、上から順に層（名前と厚さ）を持たせる。例：フローリング 15・合板 24・床梁 105 |
| 厚さ | 層の厚さの合計が種類の厚さ（与えた厚さと合わない時は断る） |
| 断面図 | その種類の床を縦に切った所に、層の境目ごとに細い線（床の上の面から 15・39 の所など）。画面の断面と、断面図（DXF・JWW・PDF） |
| 種類の表 | 注に「F1 の構成（上から）：フローリング 15・合板 24・床梁 105（計 144）」 |
| AI から | `define_type` の `layers: [{name, thickness}]`（`[]` で外す）。`list_types` に層が出る |
| 断る時 | 屋根の種類に層、厚さ 0 以下・1000 より上の層、名前の無い層、与えた厚さと合計が合わない |

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 厚さが層と合わない床 | 層の線を出さない。種類の厚さが層の合計と合わなくなったら、表の注に「厚さと合いません」 | 壁の層の線（docs/124）と同じ。黙って違う線を出さない |
| 屋根 | まだ層を持たせない（断る） | 屋根の層は勾配に直角で、切る向きで線の出方が変わる。床で作りを確かめてから |
| 層の値 | 名前と厚さは使う人が入れる（決まった仕様の一覧は作っていない） | 床の構成は家ごとに違う。壁の仕様のような目安の一覧は、オーナーに聞いてから |

## まだやっていないこと

- 屋根の層。層ごとの塗り（ハッチ）。
- 画面から層を入れる窓（今は AI の `define_type`）。
- 層を IFC（`IfcMaterialLayerSet`）や数量に出すこと。
