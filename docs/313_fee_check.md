# 313. 確認申請手数料の区分を横浜市のページと照合

docs/286 で様式3（2026-10-29 掲載）から入れた確認申請手数料の12区分は、手数料条例と照らしていなかった。そこで横浜市の「建築確認申請・検査等の手数料」のページ（https://www.city.yokohama.lg.jp/business/bunyabetsu/kenchiku/tetsuduki/kakunin/tesuryoudir/tesuryou.html 、最終更新 2026-09-30、令和7年4月1日改正の表）を 2026-11-27 に読み、照らし合わせた。

## 結果

確認申請手数料の12区分は、30 m² 以下の 15,000 円から 50,000 m² 超の 900,000 円まで、すべて一致した。手数料の注記にもそう書いた（条例の本文そのものとは、まだ照らしていない）。

## ページにあって、まだ使っていないこと

- ※2：計画の変更・移転・大規模の修繕・大規模の模様替・用途の変更は、床面積に 0.5 を掛けた面積の区分になる。
  - 今は新築以外を「工事種別を確認」にしているので、誤った額は出ない。
- 中間検査・完了検査の手数料。
- 法第6条の3第1項ただし書の審査の加算。
- 省エネ適合判定等建築物の完了検査の加算。仕様基準で適合を確かめたものは対象外。

## 確認

`PermitIntake.ConfirmationFeeMatchesTheCityPage` で確かめた。

- 各区分の上限で、その区分の額になる。
- 上限を少し超えると、次の区分に移る。
- 50,000 m² 超は 900,000 円。
