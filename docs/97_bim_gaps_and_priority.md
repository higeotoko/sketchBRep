# BIM として足りない要素の整理と、進める順番（2026-11-14）

- 文書の種類：足りないものの一覧 ＋ 進める順番
- 元になる枠：[docs/90](90_bim_operation_framework.md)（約束 B-01〜B-09、足りないもの G-01〜G-14）
- オーナーの指示（2026-11-14）：「BIM として足りていない要素を整理して洗い出し、その上で複雑な部分を優先タスクとして順位をつけて上からこなす」
- 根拠：docs とコード（コマンドの一覧・Modeler.h）を読んだ結果。人が操作して確かめたものではない

## 1. 今あるもの（2026-11-14）

| 分け方 | あるもの |
|---|---|
| 基準 | 通り芯、レベル（GL・FL）、作業面、平面の切断（上は FL+1100、下の階は隠す） |
| 部品 | 壁（仕様つき・層の情報）、開口（ID・建具の種類・移動・削除）、床スラブ、柱・梁などの部材、木造架構、基礎 |
| つながり | 壁と開口、壁・床とレベル、柱・梁と通り芯・レベル（置いた時）、壁の角・T 字（仕様変更と横への移動） |
| 図面 | 平面・立面・断面の書き出し、建具記号、通り芯、寸法、伏図 |
| 数える | 木材の拾い出し、壁量、四分割、構造の補助、基礎の確認 |
| 渡す | DXF・JWW の読み込み、STEP・IGES・glTF・DAE・STL の書き出し |

## 2. 足りないもの（整理）

docs/90 の G 番号に、今回の洗い出しで見つけたもの（N 番号）を足した。

### A. 部品そのものが無い

| 番号 | 何が無いか | 無いと困ること |
|---|---|---|
| G-07 | **室（部屋）** | 面積・室名・仕上げ・採光などの計算の入れ物が無い。室の表・床面積の表が作れない |
| G-08 | **屋根**（1 つの部品として） | 木造架構の一部としてしか作れない。壁の上端を屋根に合わせられない |
| G-09 | **階段** | 手で形を作るしかない。階高が変わっても段が変わらない |
| N-01 | 建具の「物」としての形（枠・障子・扉） | 3D・立面で穴しか見えない。建具表に品番・材質を持てない |
| N-02 | 天井、床・壁・天井の仕上げ（室ごと） | 仕上げ表が作れない。断面に天井が出ない |
| N-03 | 手すり・庇・バルコニーなどの付属物 | 手で形を作るしかない |

### B. つながりが足りない

| 番号 | 何が足りないか |
|---|---|
| G-05 残り | 壁の**長さ**を変えた時・線に沿って動かした時に、角の相手が付いてくること |
| G-06 | すでにある柱・梁・壁を、後から通り芯に付けること |
| N-04 | 床スラブの外周が、壁に付いてくること |
| N-05 | 壁の上端を、屋根・上の床に合わせること（G-08 と組） |
| N-06 | 柱と梁、梁と梁の端の納まり |
| N-07 | 階をまるごと上の階へ写すこと（B-06 の「上の階へ写す」） |

### C. つかむ・伝える

| 番号 | 何が足りないか |
|---|---|
| G-01 残り | 開口だけを選ぶこと、平面の建具記号をつかむこと、開口のコピー |
| G-10 | 直接編集で「壁として扱えない形」になった時に言うこと |
| G-14 | 立面でレベルの線をつかむこと |
| N-08 | 種類（タイプ）の一覧：建具・床・屋根の種類を登録し、種類を直すと使っている全部が変わること（今あるのは壁の仕様だけ） |
| N-09 | 3D で 1 つの階だけを見ること |

### D. 図面・表・渡す

| 番号 | 何が足りないか |
|---|---|
| G-11 | 建具表・室の表（G-07 が先） |
| G-12 | 平面の切断に、壁の層の線を出すこと |
| G-13 | **IFC の書き出し**（壁・床・柱・梁・開口・階・通り芯・室） |
| N-10 | 床面積・建築面積の表（階ごと。G-07 が先） |
| N-11 | 室名・建具番号などの札（タグ）が、部品から自動で出ること |
| N-12 | 図面の枚（シート）と、図番つきの参照（SketchUP building tools の考え方を持ってくる） |

## 3. 順位の付け方

次の 3 つを掛け合わせた。

1. **土台になるか**：ほかの足りないものが、これを待っているか。
2. **むずかしさ**：形や つながり の理屈を間違えると、黙って違う答えを出す種類の仕事か（強いモデルで、試験を厚くして作る値打ちがあるか）。
3. **毎日の操作で効くか**（docs/90 の並べ方）。

## 4. 優先タスク（上から順に進める）

「むずかしくて、土台になるもの」を上に置いた。小さい直し（G-10・G-14 など）は、関係するタスクの中で一緒に片づける。

| 順位 | タスク | 番号 | むずかしい所 | これを待っているもの |
|---|---|---|---|---|
| 1 | **室（部屋）**：壁で閉じた所を見つけて室にする。壁芯の面積と内法の面積。閉じていない時は、どこが開いているかを言う | G-07 | 壁の線から閉じた形を見つける（T 字・行き止まり・入れ子・壁の厚さの違い）。面積を黙って間違えない | G-11・N-02・N-10・N-11・IFC の室 |
| 2 | **屋根**：外周・勾配・軒の出から、切妻・寄棟・片流れを置く。壁の上端を合わせる | G-08・N-05 | 寄棟の稜線の割り出し（凹のある外周）、壁の上端を斜めに切る時に「壁のまま」にしておくこと | 断面・立面・IFC の屋根 |
| 3 | **IFC の書き出し** | G-13 | 規格の決まり（階層・位置・単位・開口と壁の関係）を守った書き出し。ほかのソフトで開けること | ほかの BIM・確認申請の道具へ渡すこと |
| 4 | **壁の長さ・すべらせた時のつながり**、床の外周 | G-05 残り・N-04 | 相手が「伸び縮み」ではなく「移動」になり、その先へ連鎖する | BIM-AC-06 の残り |
| 5 | **階段** | G-09 | 段の割り付け（法の寸法）、床の開口との組、階高への追従 | 断面・IFC |
| 6 | 建具表・室の表・面積の表・札 | G-11・N-10・N-11 | （1 が済めば、ふつうの仕事） | BIM-AC-09 |
| 7 | 開口だけを選ぶ・記号をつかむ・コピー、建具の形 | G-01 残り・N-01 | 選ぶ仕組みに「物の中の物」を足す | 建具表の品番 |
| 8 | 後から通り芯に付ける、階を写す、3D で 1 階だけ | G-06・N-07・N-09 | — | — |
| 9 | 種類の一覧、仕上げ、層の線、シート | N-08・N-02・G-12・N-12 | — | — |

順位 3 の IFC は、1・2 を先にすると、室と屋根も一緒に渡せる。

## 6. 決まり

- 各タスクは docs/90 §6 の決まり（約束のどれに関係するか、§3 の表を直す、BIM-AC をテストにする）に従う。
- 法の数値（階段の寸法、面積の算入など）を使う時は、根拠の条文と日付を書く。足りない情報は「未評価」にして、合格にしない（CLAUDE.md）。
- 細かい決まりで枠に書いていないものは、作る側で決めて記録に書き、オーナーが後から直せるようにする。
