# 開口を「物」にする：ID・移動・削除（G-01 の第 1 段、2026-11-13）

[docs/90](90_bim_operation_framework.md) の G-01。関係する約束は B-01（部品としてつかめる）・B-03（後から同じ言葉で直せる）・B-09（人と AI が同じ言葉）。

## 直す前

- 開口は「壁の開口 1、2、3…」と**あけた順の番号**で覚えていた。建具（窓・扉の種類）も番号に付いていた。
- 開口を 1 つ消す手段がなかった。消せたとしても、後ろの開口の番号が 1 つずつ前にずれ、建具が隣の開口に移る作りだった。
- 開口の位置を後から変えられなかった（幅・高さだけ）。
- 開口をあけるたびに、**壁が別の物（新しい ID）に入れ替わっていた**。壁を覚えていた物（選択・AI が持っている ID）が切れていた。

## 直した後

| 項目 | こうした | 約束 |
|---|---|---|
| 開口の ID | 開口ツール・`place_openings` であけた開口は、1 つずつ変わらない ID を持つ。保存・読み込み・Undo でも変わらない | B-01 |
| 建具 | ID に付ける。ほかの開口を消しても、動かしても、その開口の建具のまま | B-01 |
| 壁の ID | 開口をあけても壁は同じ物のまま（ID・タグ・属性・追従がそのまま） | B-01 |
| 開口を動かす | 壁の中で、壁に沿って・上下に動かせる。壁からはみ出す位置、ほかの開口と重なる位置は断り、何も変えない。幅・高さ・建具・ID はそのまま | B-03・B-04 |
| 開口を消す | その開口だけふさぐ。全部消すと、開口をあける前の壁（のレシピ）に戻る。壁を動かした後でも位置はそのまま | B-01 |
| 取り消し | どれも Undo 1 回 | docs/07 P-06 |

### 画面（プロパティパネル）

壁を選ぶと、開口ごとに 2 行出る。

- 「開口 n」：幅・高さ・建具（今まで通り）
- 「位置」：**左端から**（壁の左端から開口の左の縁まで。開口をあけた面の側から見て）、**腰高**（壁の下端から開口の下の縁まで）、**削除**ボタン

### 画面（穴の内側の面を選んで Delete）

開口の穴の内側の面（左右のたて枠の面・上・下）を選んで Delete を押すと、**その開口がふさがる**。
今までは、その面だけが壁からはがれて、壁が開いた形になっていた。

- 穴の内側の面だけを選んでいる時に限る。壁のほかの面や線と一緒に選んでいる時は、今まで通りの削除。
- 1 つの面で、その開口まるごとが対象になる。ステータスに「開口を 1 つふさぎました」と出る。
- AI の `delete` の `elements` でも同じ（返り値の `openings` にふさいだ数）。

### AI から

| コマンド | 内容 |
|---|---|
| `list_openings` | 各開口の `id`・`offset`（左端から）・`sill_height`（腰高）を返す。`index`（番号）も今まで通り返すが、前の開口を消すと変わる |
| `set_opening_size` / `set_opening_fittings` | `openings` に ID でも番号でも渡せる |
| `move_opening` | `{host, opening, by:[dx,dy,dz]}`（壁に沿う成分と上下だけ使う）または `{host, opening, offset, sill_height}` |
| `delete_openings` | `{host, openings:[...]}` |
| `place_openings` | 返す ID は元の壁と同じ |

## 前からある開口（ID のない開口）

- 前のファイルの開口と、長方形を描いてプッシュプルで抜いた開口には ID がない。`list_openings` の `id` は番号の文字（"1"、"2"）になる。
- その壁の開口を**次に編集した時**（建具を付ける・動かす・消す・開口を足す）に、全部の開口へ ID を付け、番号で覚えていた建具を ID へ移す。同じ Undo の中で行う。
- プッシュプルで抜いた直後の開口は、ID が付くまで番号のまま。プッシュプルは壁を新しい物に入れ替える（ふつうの形の編集なので、今まで通り）。

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| ID の置き場所 | 引き算の相手（`BooleanOperand`）に `id` を足した。空なら保存しない | 開口は壁のレシピの一部のまま。別の物にすると、壁の厚さ・仕様の付け替えの仕組みを作り直すことになる |
| 番号も残す | `index` は消さない | 画面の「開口 n」と前からのコマンドがそのまま使える |
| 最後の開口を消した時 | 引き算をやめて、元の壁のレシピに戻す | 「開口が 0 個の引き算」を残すと、壁の厚さ・高さの変更（docs/41）が効かなくなる |
| 動かせる範囲 | 壁の形の外形（頂点の範囲）の中。斜めに切った壁の欠けた所までは見ない | まず矩形の壁で正しく。はみ出した時は引き算の結果で分かる |

## まだやっていないこと（G-01 の第 2 段）

- **画面で開口を直接動かすこと**：穴の内側の面や平面の記号を移動ツールでドラッグして、開口を動かす。今はプロパティパネルの数値（Delete で消すのは画面でできる）。
- 開口を別の壁へ移すこと、開口のコピー。
- プッシュプルで抜いた開口に、その場で ID を付けること。
- 斜めの壁の面にある開口の移動。
