# 通り芯の編集と、通り芯に乗せた柱・梁（2026-10-30 JST）

前の通り芯は、作った瞬間に線・符号・寸法がバラバラの物になっていた。
線は移動ツールで動かせたが、符号と寸法は付いてこなかった。間隔を直す方法もなかった。
これを、作った後でも直せる通り芯に作り替えた。あわせて、通り芯の交点に柱・梁をまとめて置けるようにした。置いた柱・梁は通り芯に付いていくので、通り芯を直せば骨組みも追いかけてくる。

参考にしたのは ARCHICAD と Revit の通り芯（記憶にもとづく。版によって細部は違う）。

- 線・符号・寸法がひとまとまりになっている。
- 作った後で、位置や間隔を数字で直せる。
- 通り芯に乗せた部材は、通り芯と一緒に動く（Revit のロック）。

## できること

| 操作 | 何が起きるか |
|---|---|
| ツール > 通り芯を作成... | 通り芯が1つのまとまり（グループ「Grid」）としてできる。作った直後は選択された状態になる |
| 通り芯を右クリック →「通り芯を編集（間隔・名前・本数）...」 | X方向・Y方向の表で、名前と間隔（前の通りから）を直せる。「通りを追加」「選んだ通りを削除」もできる |
| 通り芯の中に入って（ダブルクリック）、線を移動ツールで動かす | 動かした所が、その通りの新しい位置になる。符号と寸法も付いてくる |
| 通り芯の中で、線（または符号）を消す | その通りが無くなる。ほかの通りの寸法はつなぎ直される |
| 通り芯を右クリック →「通り芯に柱・梁を配置...」 | 交点に柱、通りに沿って隣の交点まで梁を、まとめて置く。断面と基準は、部材パネルの「柱」「梁」の設定を使う |
| 通り芯の間隔を直す、線を動かす | 乗っている柱・梁が一緒に動く。梁は伸び縮みする |
| 通り芯をまるごと移動する | 乗っている柱・梁もまるごと付いてくる。通り芯と柱を一緒に選んで動かしても、柱は1回しか動かない |
| 柱を手で上にずらす、長さを変える | そのずれや長さは残したまま、通り芯に付いていく |
| 通りを消す | その通りに乗っていた柱・梁は、その場に残る（固定は外れたまま） |
| 通り芯と柱をまとめてコピー | コピーした柱は、コピーした通り芯に付く。柱だけコピーすると、元の通り芯に付く |
| Undo | 通り芯の変更と、付いていった柱・梁が、まとめて1回で戻る |
| 保存・読み込み | 通り芯の情報と、柱・梁の固定も保存される |

AIからは次のコマンドで同じことができる。

- `create_grid`：結果の `grid` が通り芯のまとまり。
- `set_grid`：通りの名前・位置（`position`）・間隔（`spacing`）・本数を直す。
- `place_members_on_grid`：柱は `columns`、X通りの梁は `x_beams`、Y通りの梁は `y_beams`。範囲を `x` / `y`、高さを `base` / `height` で指定する。
- `get_object`：通り芯なら各通りの id・名前・位置・間隔、柱・梁なら `grid_pin` を返す。

今までの `place_on_grid` や `create_member` の `"X1/Y2"` 指定も、そのまま使える。

## 実装で決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 通り芯の持ち方 | グループに「通りの一覧（id・名前・位置）」を持たせる。線・符号・寸法は、この一覧からいつでも作り直せる部品にした | 直す場所を1か所にするため。表示や吸着の仕組みは今までの線・符号・寸法のまま使えるので、新しい描き方を増やさずに済む |
| 通りの見分け方 | 名前とは別に、変わらない id を持たせる | 「X1」を「A」に名前を変えても、乗っている柱・梁の固定が外れないように |
| 線を手で動かした時 | 動かした量を、その通りの位置の変更として受け取り、線の置き方は元に戻して作り直す | どう直しても、最後は「一覧どおり」の形にそろうように |
| 柱・梁の固定 | 両端それぞれを「どの通りとどの通りの交点か」で覚える。通り芯が変わったら、交点が動いた分だけ端を動かす | 高さ、手で付けたずれ、伸ばした長さが消えないように。梁の両端はそれぞれの交点に付いていくので、伸び縮みする |
| 固定の付け方 | 「通り芯に柱・梁を配置」で置いた物だけ | 今までの追従（docs/42）と同じく、勝手に関係を作らない |
| 同じ所に2回置いた時 | 同じ交点・同じスパンに固定済みの柱・梁があれば飛ばす | 二重配置を防ぐため |
| 符号を消した時 | その通りごと消す | 符号だけ無い通りは、図面として意味がないため |

## まだやっていないこと

- 前に作った通り芯（今回より前のファイル）は、今までどおりバラバラの線のまま。編集はできない。必要なら作り直す。
- 配置する範囲を画面で選ぶこと（「X2〜X4だけ」など）。AIからは `x` / `y` で指定できる。
- すでにある柱・梁を、後から通り芯に固定すること。
- 梁を柱の面で切り詰めるなどの、端の納まり（端部加工）。
- 斜めの通り、円弧の通り。
- 符号を手で動かしても、次に作り直すと元の位置に戻る。消した寸法も、次に作り直すと戻る。
