# 柱・梁・屋根が壁についてくる（壁のつながりの残りの一部、2026-11-18）

[docs/102](102_wall_slide_length_and_slabs.md)（壁をすべらせた時・床の外周）の「まだ」のうち、柱・梁・屋根が付いてくること。[docs/106](106_handoff_and_roadmap.md) の「Fable に渡す物」の 6 の一部。作業は Opus 5.5（オーナーと決めた分担で、Opus でこなせる物）。
オーナーの指示：2026-11-17（「進めて」「続けて」）。

## 直す前

壁を横へ動かすと、つながっている壁と床（スラブ）の外周はついてきた（docs/96・102）。柱・梁・屋根はそのままだったので、壁から外れて残った。

## 直した後

壁を**横へ**動かした時（壁の線と違う向き。床と同じ決まり）、次の物も同じ取り消し 1 回の中でついてくる。

| 物 | ついてくる時 | 動き方 |
|---|---|---|
| 柱（縦の部材：柱・通し柱・束など、`create_member` で作った物） | 芯が動いた壁の厚さの中にあって（角では相手の壁の厚さまで）、高さが壁と重なる | 壁の横への動きの分だけ平行に動く。2 枚の壁の角にある柱は、両方の動きを足す（同じ向きの壁は 1 回だけ） |
| 梁（横の部材） | 両端が同じ壁の厚さの中にあって、壁に沿っている。高さは壁の中か、壁の上端から 600 まで（壁の上に載る梁） | 平行に動く |
| 屋根（屋根ツールの屋根） | 外周の角が動いた壁の厚さの中にあって、軒の高さが壁の高さの範囲 | その角だけ動く（床の外周と同じ）。屋根に合わせた壁は、あとで屋根に合わせ直る（今まで通り） |

- ステータスバーに「柱・梁 n 本を一緒に動かしました」「屋根 n つの外周を合わせました」と出す。AI の `move` の返り値 `joined_walls` に `members`・`roofs`。
- 「ツール > 壁を動かすと、つながっている壁も付いてくる」のチェックを外すと、これもやめる（`keep_joins: false`）。
- 壁と一緒に選んで動かした物は、そのまま動くだけ。ロックした物は動かない。

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 壁に直角に当たる梁（壁から壁へ渡る梁） | **動かさない**（今回はやらない） | 端だけが動くと梁の長さが変わる。仕口・継手の決め事（どこまで伸ばすか、継ぐか）があるので別にする |
| 壁の線に沿ってすべらせた時・長さを変えた時 | 柱・梁・屋根はついてこない | 床と同じ（床も横への動きだけ）。すべらせると角の壁が運ばれるので、その壁の中の柱は運ぶ方がよいが、決め事が増えるので次にする |
| 屋根で合わない時 | 屋根はそのまま残し、ステータスバーに名前を出す | 動かす操作そのものは止めない（docs/96 の B-08） |

## まだやっていないこと

- 壁に直角に当たる梁の長さを合わせること。
- 壁をすべらせた・長さを変えた時に、運ばれた角の壁の中の柱を一緒に運ぶこと。
- 骨組みの作成（docs/90 の構造の流れ）で作った部材（組み立ての定義から作る物）は、今回の対象外（`create_member` で作った部材だけ）。
- 壁のつながりの中心（直角でない角で運んだ先のずれ、描き始めた側の端、厚さを変えた時、回した時）は、Fable に残す（docs/106 の 6）。
