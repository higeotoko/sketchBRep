# 平面の切断に、壁の層の線を出す（G-12、2026-11-15）

[docs/97](97_bim_gaps_and_priority.md) の G-12（順位 9 の 1 つ）。作業は Opus 5.5。
オーナーの指示：2026-11-15（「続けて」）。

## できること

| 項目 | 内容 |
|---|---|
| 対象 | 仕様（外壁 サイディングなど・内壁 石膏ボード両面）を付けた壁（壁ツールの「仕様」、`create_wall` の `type`、`set_wall_type`） |
| 出る線 | 平面で切った所に、層の境目ごとに壁に沿った細い線（外壁 サイディング：仕上げ・胴縁・合板・柱・石膏ボードの境目 4 本） |
| 開口 | 平面が通る開口の所では、線が切れる |
| 出る所 | 平面モード（画面）と平面図（DXF・JWW・PDF） |
| 出ない時 | 仕様の無い壁。厚さを手で変えるなどして、層の厚さの合計と合わなくなった壁（黙って違う線を出さない） |

## まだやっていないこと

- 角・T 字での層の線のつながり（今は壁ごとに、壁の端まで。角では重なったり、すき間ができたりする）。
- 開口の枠（建具の枠が層を見ること）。
- 層ごとの塗り（ハッチ）、線の太さを層で変えること。
- 断面図での層の線。
