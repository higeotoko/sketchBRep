# 208. 壁量の申請書式：壁量計算表・耐力壁の一覧・四分割・耐力壁配置図（2026-11-20）

調査資料（第2.8版）§3 の順番の「3 壁量の申請書式」。壁量の計算（docs/58・76、`check_wall_quantity`）はもうあったが、申請図書の形（表と図）で出す所が無かった。計算の中身は変えずに、その結果を表3つと図1つにした。係数表と確認日は、計算が保存している写し（告示1100号、令和6年国交省告示447号改正、施行 2025-04-01、表の確認日 2026-11-04）のとおり。

## 表（`scheduleTable` の 7・8・9）

| 番号 | 名前 | 中身 |
|---|---|---|
| 7 | 壁量計算表 | 階・方向ごとに、床面積、地震の係数（cm/m2）と必要量、見付面積、風の係数と必要量、必要壁量（大きい方）、存在壁量、照合（参考値内／要確認／未評価）、理由 |
| 8 | 耐力壁の一覧 | 壁ごとに、階・方向・符号・仕様（係数表の名前）・長さ・倍率・高さの係数・有効長さ・計算に入れたか・条件（係数表の条件）または理由 |
| 9 | 四分割（側端部分） | 階・方向・側端（下側／上側）ごとに、面積・必要・存在・充足率、その階と方向の壁率比・照合・見た決まり（壁率比 0.5 以上か、両側端の充足率が 1 を超えるか） |

注には、計算の注（意匠・概略の検討用で、法適合の判定ではない、告示と表の確認日）と、入力が `set_wall_calculation` のとおりである事を書く。

## 図（耐力壁配置図）

平面図（`ViewSpec::bracingFloor` に壁量の計算の階の ID）の上に、次を重ねて描く。

- 計算に入れた耐力壁を太線で、符号・方向・倍率・有効長さの札（例「a X 倍率2.0 4.00m」）。計算に入れていない壁は破線。
- 四分割の側端部分を破線の四角で、方向と必要・存在の札（例「X 側端 必要2.00m 存在4.00m」）。
- 凡例を図の注に書く（太線・破線の意味）。

モデルに形がまだ無くて計算の入力だけある時も描ける。

## 出し方

- 表の窓：「壁量計算表」「耐力壁」「四分割」のタブ（8〜10番目）と CSV。
- 表だけの紙：AI の `export_schedule` の `table` に `wall_quantity`・`bracing_walls`・`quarters`。図面に並べる：`export_drawing` の `tables`。
- 図：`export_drawing` の `kind: "plan"` に `bracing_floor`（計算の階の ID）。
- 図面一式：壁量の計算の入力がある時、表3つの紙と、計算の階ごとの「耐力壁配置図（○階）」が入る。計算の n 番目の階は、モデルの n 番目の「…FL」のレベルの平面に描く（レベルが足りなければ地面の高さ）。

## 確認

**計算テスト済み**
- `WallQuantityForms.TablesFollowTheCalculation`：四分割の手計算のテストと同じ入力（X：45×90 の筋かい 2 m と 0.5 m、Y：4 m×2）で、壁量計算表の X が「床面積 50.00・地震 10.00・見付 30.00・風 15.00・必要 15.00・存在 5.00・要確認」、Y が「存在 16.00・参考値内」。注に告示1100号。耐力壁の一覧の a が「長さ 2.00・有効 4.00」で仕様名に 45。四分割の X が「充足率 2.00 と 0.50・壁率比 0.25・要確認」。3つとも `export_schedule` で書き出せる。
- `WallQuantityForms.BracingPlanShowsTheWallsAndTheSideParts`：形の無いモデルでも、1階の配置図に太線4本・側端の破線の四角4つ・札8つ（「a X 倍率2.0 4.00m」「側端 必要2.00m 存在4.00m」を含む）と凡例が出る。`export_drawing` の `bracing_floor` が通る。図面一式に「耐力壁配置図（1階）」がある。
- Windows ローカル：コア全件 773件成功・8件スキップ・失敗0。
