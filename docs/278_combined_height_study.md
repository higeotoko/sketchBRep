# 高さ制限の合成試算

工程10「立面・断面」の「高さ制限の合成」で、確認した制限にチェックを入れる。「合成面を3Dで見る」を押すと、選んだ制限のうち、敷地の各位置で最も低い面が現れる。画面下の凡例で面の由来を確認し、その場で表示を解除できる。

| 色 | その位置の上限を決めたもの |
|---|---|
| 青 | 道路斜線 |
| 紫 | 隣地斜線 |
| 緑 | 法第56条の北側斜線 |
| ピンク | 横浜市の最高限高度地区 |
| オレンジ | 選んだ制限の算定条件が未確認の範囲 |

## 入力

- 道路斜線は敷地側の道路境界での高さZ（建物後退の補正前）、勾配、幅員、適用距離、採用した後退距離を指定する。登録した道路幅員を初期表示する。 [道路側の試算](274_road_height_plane_preview.md)
- 隣地斜線は地盤面、立上り、勾配と、敷地図で選んだ隣地辺を使う。北側斜線は登録した真北と採用した立上りを使い、北側の出口が登録道路に面する範囲にはその登録幅員を用いる。地盤面には登録したGLを初期表示する。 [隣地斜線](275_neighbor_height_study.md) · [北側斜線](276_north_height_study.md)
- 横浜市の高度地区は、敷地に登録した単一の最高限高度地区で試算する。第1〜5種で北側の出口が登録道路に面する場合は、条件を確認した単独の平行な道路をチェックする。 [横浜市の最高限高度地区](277_yokohama_height_district_study.md)

敷地図と一覧のどちらからでも、通常の隣地として確認した境界辺を選べる。各制限の適用と採用値を確認した上で入力する。法規の適合は未評価。

## 部材の余裕・超過を調べる

屋根や壁などをモデルで選び、「高さ制限の合成」の「選択部材を照合」を押す。最大鉛直差と、その差を決めた制限を部材ごとに表示する。正は超過、負は余裕。条件を確認できていない範囲にかかる場合は「要確認」を併記し、数値が出る場合は確認済み範囲での差を示す。敷地内で今回の条件がかからない部材は「適用面なし」と表示する。

結果の行を選んで「選んだ部材を3Dで見る」を押すと、合成面と該当部材が表示される。照合は、3Dに表示する範囲でB-repを切り分け、面との最大鉛直差を測る。隣地斜線を合成に含めた場合は近似面との比較になる。法規の適合は未評価。

結果の「CSVに保存」から、部材ID、鉛直差、決め手の制限、確認範囲と採用条件を一緒に保存できる。照合や表示をもう一度開くと、同じ敷地条件で前回採用した入力が戻る。建物の変更後は後退距離などを見直して再試算する。前回の入力は同じ作業中に利用できる。

## 断面と計算を図面で追う

部材照合の行を選んで「根拠図・計算表」を開く。通常は選択部材の範囲の中心を通り、登録道路があれば道路に直交する縦断面を使う。「有効な鉛直断面を使う」を選ぶと、モデルに登録した鉛直断面で試算する。

H-H断面図では、敷地境界、地盤面、前面道路、建物、合成制限線を同じ縮尺で示す。地盤面に地盤のハッチングを添え、前面道路は両側の道路境界線と、両端につながる幅員寸法で読む。制限線は青い実線、未確認の範囲は橙の破線。計算表は断面距離で位置を示し、上限を決めた制限、制限高さ、照合対象部材の高さと鉛直差を記す。部材照合表は部材全体の最大鉛直差を示す。採用条件表に試算で使った値と境界を記す。

道路境界と幅員の描き方は熊本県の実際の申請図書作成例と国交省の道路斜線図を参照した。地盤のハッチングはSketchBRepで採用した断面表現。 [熊本県「立面図・断面図」](https://www.pref.kumamoto.jp/uploaded/attachment/269198.pdf) · [国交省「道路斜線制限」](https://www.mlit.go.jp/jutakukentiku/house/content/001854167.pdf)

根拠図だけのPDFを保存できる。「図面一式に入れる」を押すと、次の図面一式の末尾に断面図・計算表・部材照合表・採用条件表が入り、通常の図面リストに図番が付く。平面図にはH-Hの断面位置が入る。モデルの変更や合成条件の再試算後は、根拠図を作り直して組み込む。

斜めの断面では断面方向の距離と採用幅員を併記する。図示用の路面Zを入力した場合はその高さに路面線が出る。路面Zが未入力の場合は道路の範囲と幅員を示す。地盤は採用した高さの参照線で、高低差や舗装の形状は現地資料から確認する。断面位置の直上に照合対象部材がなければ部材高は空欄。隣地斜線を含む場合は近似面との比較で、法規の適合は未評価。

## 表示の範囲

道路斜線は採用した適用距離の端で止まる。北側斜線と高度地区は真北方向の出口が同じ範囲ごとに算定する。隣地斜線は個別の3D表示と同じ三角形・高さのサンプルを使う近似で、曲面部分や他の制限との切替位置も近似になる。

適用範囲と各面の交線で敷地を分割し、各範囲で低い方の面を使う。選んだ制限の条件が未確認なら、その範囲は敷地面付近をオレンジで示す。今回の入力で適用される面がない範囲は空白にし、面積を表示する。モデル条件の変更時は、古い試算を消す。

敷地境界、真北、道路辺、GL、用途地域・高度地区を個別の試算と同じモデルから読み、根拠となる面を工程10で確認できる点は [操作感の枠](90_bim_operation_framework.md) の B-05・B-09 に対応する。
