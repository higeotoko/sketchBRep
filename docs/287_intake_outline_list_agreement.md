# 287. 受付チェックシートの欄の候補、図書の種類つき図面リスト、協定等届出書

docs/286 の残りのうち、まとめて進められる3つを1回の検証で実装した。

## 様式1-2 の欄の候補（計画概要から）

`permit_intake_review` と提出図書の照合画面のタブに、次の行を加えた。計画概要の値を候補として示すだけで、チェックシートの「レ」は設計者が付ける。

| 区分 | 行 | 計画概要からの候補 |
|---|---|---|
| １ 添付書類 | 建築計画概要書 | Word様式の第三号様式で出力 |
| １ 添付書類 | 消防定型同意依頼書 | 様式の条件（一戸建住宅で防火・準防火地域内、または長屋）を主要用途と防火地域で照合する。どちらかが未入力なら要確認 |
| １ 添付書類 | 建築協定等手続状況届出書 | 第一面をWordで出力（下記） |
| ２ 設計者等 | 委任状 | 代理者があれば必要（候補）、なければ該当しない（候補） |
| ２ 設計者等 | 工事監理者の記載 | 記載あり／要確認（未定の場合は未定と記載） |
| ５ 構造計算適用等 | 構造計算適合性判定 | 申請済・未申請・申請不要。特定木造建築物、ルート2、特定天井、土砂災害特別警戒区域は設計者が記入 |
| ６ 省エネ適判等 | 省エネ適判 | 提出済なら通知書等の添付を確認。提出不要なら、仕様基準（住宅のみ）か他制度の活用かを確認 |

「２」の建築士法第3条の資格の表は、様式の表を文字で取り出すと崩れたので、行を作っていない。法令の本文で確かめてから扱う。

## 図面リスト（図書の種類つき）

様式1-2 別紙「図面リストの記載例」の列（図面番号、規則第1条の3による「図書の種類」、設計者）に合わせ、図面一式の各図面に対応する図書の種類を付けた。照合画面の「図面リストCSV…」で保存する（UTF-8、BOMつき）。MCP では `drawing_list` と `drawing_list_csv` で返す。設計者の列は空欄のまま出す。図面一式の中の「図面リスト」の図面そのものは変えていない。

## 建築協定等手続状況届出書（第１号様式）の第一面

照合画面の「協定等届出書（Word）…」で、市の原本（0766_20240329.docx、2026-11-26取得、SHA256 `42fd2f92…816f`）に次の値を入れて保存する。

- 地名地番：「横浜市　区」の間に区名を入れ、残りは「区」の後ろに続ける（次の行は様式上表示されなかった）。横浜市の住所でなければ全体を「区」の後ろに入れ、「地名地番の区」を未記入として知らせる。
- 用途地域：高さの制限に登録した用途地域にレを付け、第一種・第二種は「第　種」に一・二を入れる。田園住居地域、指定なしは様式に欄がないので未記入として知らせる。
- 市街化調整区域：計画概要の都市計画区域が市街化調整区域の場合。
- 敷地面積・延べ面積・建築面積・最高の高さ・階数・主要用途・工事種別：確認申請のWord様式と同じ値。面積は、単一棟の新築で面積が読める場合に限って入れる。
- 確認申請提出先：横浜市にレを付ける（横浜市に直接申請する画面のため）。

建築主・代理者の欄（テキストボックスの中にスペースで配置されている）、届出日、第二面（手続の要否と状況）は様式に手で記入する。保存後、モデルから埋められなかった欄を画面に表示する。

雛形は `tools/permit_forms/prepare_templates.py --agreement` で作る。第二号・第三号の雛形は今回の変更で1バイトも変わらないことを確かめた（SHA256 一致）。テキストボックス内の段落も数える段落の対応表（`nested_spans`）を加えた。
