# 348. 土台の継ぎ目に乗る柱を「一部だけ支えに乗る」と分ける

通し確認（docs/346）で見つけた残りの2つ目。

例題E に基礎を作った後も、申請の段階8の「土台・柱の支え」で、柱 49 本が「一部だけ支えに乗る」と出ていた。

原因は2つ重なっていた。

- 架構の作り方（generate_frame）は、土台を柱間ごとに分けて作る。だから柱は、2本の土台の端と端が突き合う所（継ぎ目）に立つ。
- 支えの照合（check_foundation_supports、Codex の設計）は、柱の下面を1本で全部覆う支えだけを「支えあり」とする。半分ずつの支えを足し合わせない。テストでも、半分ずつの束石2つは「partial」のまま、と決めてある。

足し合わせない、という判断は束石については正しい（半分ずつ乗る束は支えとして弱い）。それに、柱の直下に土台の継手を置くのは、施工の仕様では避けることが多い。なので「全部乗っている」と言い切ることもしない。ただ、「一部だけ支えに乗る」という言葉は、柱が土台からはみ出しているように読めて、状態と違う。

## 直したこと

- 柱・通し柱の下面を、同じ高さの土台2本以上が隙間なく覆うとき（覆う割合の和が 1、どれも高さが合う）は、状態を「on_joint」（2本の土台の継ぎ目に乗る）にする。
  - 「detected」（支えあり）にはしない。基礎までの経路も「要確認」のまま。
- 申請の段階8の文：「2本の土台の継ぎ目に乗る（継手の位置は仕様書で確かめる）」。
- 束石（floor_post など）の半分ずつの支えは、今までどおり「partial」。

継手を柱の直下に置かないことは、法の本文で確かめていない。なので断定せず、仕様書で確かめる、とだけ書いた。架構の作り方で、土台を通しにして継手を柱からずらす改良は、別にやる。

## 確認

- `FoundationSupports.ColumnOnASillJointIsToldApartFromAPartialOne`：
  - 2本の土台の継ぎ目に立つ柱は「on_joint」。支えの候補は2つで、覆う割合の和は 1。経路は「要確認」。
  - 土台の端から半分はみ出した柱は「partial」のまま。
- 今までのテスト（半分ずつの束石2つは partial）もそのまま通る。
- コアのテスト 883 本と、基礎の GUI テストが通る。
