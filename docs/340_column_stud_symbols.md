# 340. 平面図の管柱・間柱の記号

docs/328 のとき、オーナーから柱の記号の見本の画像をもらった。

- 通し柱：× の入った四角を丸で囲む
- 管柱：× の入った四角
- 間柱：斜線1本の長方形

docs/327・328 では、そのうち通し柱の丸だけを入れていた。管柱と間柱の記号は残り（docs/327「残り」、docs/330 の後の残りの一覧）になっていた。

平面図の切り口の斜線（docs/173・326）は、壁の層（壁の構成）にだけ付く。架構の部材の物（柱・間柱）は、切っても塗りだけだった。

## 描き方

- 平面図（架構図・壁量の図は除く）で、切断の高さを通る部材に、切り口の外形の対角線を見えがかり線のペンで描く。
  - 柱（column）：対角線2本（×）。
  - 通し柱（through_column）：対角線2本と、今までどおりの丸。
  - 間柱（stud）：対角線1本（／）。
- 凡例：
  - 「管柱」：切り口の四角に ×。
  - 「間柱」：細い長方形に ／。
  - 「通し柱」：今までどおり。
  - 図に出たものだけ並ぶ。

## 例題で見たこと

例題E（1:100）の 1FL 平面図を描かせた。保存はしていない。凡例には「通し柱」「間柱」が出た。例題の外周の柱は全部通し柱なので、管柱の行は出ていない。

1:100 では、柱（105 mm 角）の切り口は紙の上で約 1 mm。その中の × や ／ はほとんど見えない。1:50 以上の図で読める大きさになる。凡例の見本も最初は柱の大きさに近くて読めなかったので、紙の上で 2.8 mm 角（間柱は 1.4×2.8 mm）に大きくした。

## 確認

- `Quantities.PlansMarkColumnAndStudCuts`：
  - 架構（2×2スパン）の 1000 mm の平面図で、切断の高さを通る柱・通し柱には、外形の角どうしを結ぶ対角線が2本ある。
  - 間柱には1本だけ。
  - 凡例に「間柱」が出る。
- コアのテスト 875 本、図面・シート・平面・架構の GUI テストが通る。
