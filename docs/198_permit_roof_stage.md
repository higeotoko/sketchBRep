# 198. 申請図の工程：第6工程（屋根・庇・バルコニー）をモデルから埋める（2026-11-20）

docs/194・197 の続き。「申請図の工程」の「6 屋根・庇・バルコニー」に、モデルにある屋根・庇・バルコニーと建築面積を出す。新しい法令の値は足していない。建築面積は面積の表（docs/141、令 2 条 1 項 2 号を e-Gov で確認済み）と同じ計算を使う。

## 画面

| 行 | 出す物 |
|---|---|
| 屋根ごと | 形（切妻・寄棟・片流れ）、勾配（寸）、軒の出、けらばの出、辺ごとの勾配・出、壁に付く辺、種類名、屋根まで立ち上げた壁の数。出が 1 m 以上なら「先から 1 m を除いた部分が建築面積に入る」と書く。立ち上げた壁が無い屋根は「要確認」（妻壁が三角にならず、壁と屋根の間が空いて見えるため）。ボタンで、屋根と立ち上げた壁をまとめて選べる |
| （屋根が無い時）屋根 | 「未入力」と屋根ツールの案内 |
| 庇 | 枚数と、5枚までの出・幅。1 m 以上出た庇の数（建築面積に入る分） |
| バルコニー | 個数と、5個までの出・幅・柱、床面積の入り方（通達どおり（自動）／入れる／入れない、docs/163・175） |
| 建築面積 | 面積の表の建築面積（「参考値」）と、その注の最初の4行。出せない時は「未評価」 |
| まだ確かめていない事 | 屋根の構造・材料（防火の区域による屋根の性能）、高さの制限（斜線など）、採光に効く軒・庇の出（第4工程）、屋根の排水（「未評価」） |

形を直接変えた屋根は、屋根ツールの寸法を読めないので「未評価」。

AI からは `permit_checks` の `stage: 6`。
