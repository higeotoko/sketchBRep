# IFC の書き出し（G-13、2026-11-14）

[docs/90](90_bim_operation_framework.md) の G-13。[docs/97](97_bim_gaps_and_priority.md) の順位 3。
関係する約束は B-07（数えられる・渡せる）・B-05（どこから見ても同じ物）・B-09（人と AI が同じ言葉）。
オーナーの指示：2026-11-14（「つづけて」。前の報告で、次にこれを進めると伝えた）。

## 直す前

- ほかのソフトへ渡せるのは、形だけ（STEP・IGES・glTF など）。「これは壁」「これは 2 階」「この穴はこの壁の窓」という情報は渡せなかった。

## 直した後

「ファイル > エクスポート」で「IFC」を選ぶと、建物の部品を **IFC4** のファイルに書き出す。

| モデルの物 | IFC での扱い | 一緒に書くもの |
|---|---|---|
| レベル | 階（IfcBuildingStorey） | 高さ。レベルが無い時は、高さ 0 の階「GL」を 1 つ |
| 壁ツールの壁 | 壁（IfcWall） | 仕様つきの壁は、仕様の名前と「外壁かどうか」。長さ・厚さ・高さ・体積 |
| 壁の開口 | 壁の穴（IfcOpeningElement）。壁との関係つき | — |
| 建具を付けた開口 | 窓（IfcWindow）か扉（IfcDoor）。穴との関係つき | 幅・高さ、開き方の種類 |
| スラブ | 床（IfcSlab） | 厚さ・体積 |
| 屋根 | 屋根（IfcRoof） | 種類（切妻・寄棟・片流れ）、屋根面積・水平投影 |
| 柱・通し柱・束 | 柱（IfcColumn） | 役割の名前 |
| 梁・桁・土台・大引・母屋・棟木・まぐさ | 梁（IfcBeam） | 役割の名前 |
| 根太・垂木・間柱・筋かい | その他の部材（IfcMember） | 種類 |
| 室 | 空間（IfcSpace） | 壁芯の面積・内法の面積・周長・高さ |
| 通り芯 | グリッド（IfcGrid） | 通りの名前 |
| その他の立体 | 種類の無い部品（IfcBuildingElementProxy） | — |

- 階ごとに、その階の部品をまとめる。壁は、付いているレベル（無ければ下端の高さ）の階。床は、上面のレベルの階。
- 部品の形は、**その階の床からの高さ**で書く（IFC の決まり）。
- 単位は mm、面積は ㎡、体積は m³。
- 部品の ID（GlobalId）は、モデルの中の ID から決まる。**もう一度書き出しても変わらない**（相手のソフトで、同じ部品として更新できる）。
- 日本語の名前（室名など）は、IFC の決まりの書き方に直して書く。
- 作った人・会社の名前は書かない。

### 窓か、扉か

建具を付けた開口の**腰高が 0** なら扉、それより上なら窓。「窓」の建具は、いつも窓。

| 建具 | 扉の時 | 窓の時 |
|---|---|---|
| 片開き | 片開き（吊元の左右つき） | 1 枚 |
| 両開き | 両開き | 2 枚 |
| 片引き | 片引き（引く向きつき） | 1 枚 |
| 引違い・両引き | 引違い | 2 枚 |

### 黙って決めない

書き出した後に、入れた数と、**仮に決めたこと・入れなかった物**を出す。

- レベルが無いので、全部を 1 つの階に入れた
- 上にレベルが無い室は、高さ 2400 の空間にした
- 閉じていない室・ほかの室と同じ場所の室は、書き出していない
- 体積の無い物（線・面・注記）は、書き出していない（個数つき）
- 曲がった面は、三角形に分けた

書き出す物が何も無い時は、ファイルを作らずにエラーを出す。

## AI から

`export_ifc {path}`。入れた数（階・壁・開口・窓・扉・床・屋根・柱・梁・部材・室・通り芯・その他）と `notes` を返す。

## 実装で決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 版 | IFC4 | 室・屋根の種類・窓と扉の種類を、そのまま書ける。今の多くの BIM ソフトが読める |
| 形の書き方 | 面で囲んだ立体（IfcFacetedBrep）。平らな面は、外形と穴をそのまま。曲がった面は三角形 | どんな形でも書ける。相手のソフトで、開口の引き算などの演算ができる |
| 壁の形 | 開口をあけた後の形（屋根に合わせた壁は、切った後の形） | 見た目が必ずモデルと同じになる。開口は、穴の部品としても別に書く（関係のため） |
| 室の形 | 内法の外形（未評価の時は壁芯）を、上のレベルまで立ち上げる | 面積と合う形。天井高は、まだモデルに無い |
| 窓・扉 | 初版は位置・幅・高さ・種類を出力。配布版 `4dbf133` で建具の形も追加 | [例題Aでの確認](268_ifc_external_review.md#建具形状の追加確認) |
| ID | 物の ID から、決まった計算で作る | 書き出すたびに変わると、相手のソフトで別の部品になる |
| 外のライブラリ | 使わない（自分で書く） | 配布物を増やさない。書く内容を全部自分で確かめられる |

## 確かめ方と、その限り

**ほかの BIM ソフトで開く確認は、まだしていない。**（手元に IFC を読むソフト・ライブラリが無い。）
代わりに、書いたファイルを、テストの中の小さな読み取りで読み直して確かめた。

| 確かめたこと | 方法 |
|---|---|
| 参照が全部つながっている | どの `#番号` も、ファイルの中にある |
| 項目の数が規格どおり | 書いている 47 種類の実体ごとに、IFC4 の項目数と合わせた（数は、規格の定義から手で表にした） |
| ID が正しい形で、重ならない | 22 文字、決まった文字だけ、先頭は 0〜3 |
| 形が正しい | 書いた面から計算した体積が、モデルの立体の体積と合う（面が外を向き、すき間なく閉じ、穴が引かれている証拠） |
| 関係が正しい | 穴は自分の壁に、窓・扉は自分の穴に付く。どの部品も、ちょうど 1 つの階に入る |

この確かめ方では分からないもの：**規格の細かい決まり（列挙の値のつづり、任意の項目の型など）の間違い、相手のソフトごとの読み方の違い**。
オーナーの手元に IFC を読めるソフト（無料のビューアなど）があれば、開いて見てもらうのが、次の確認になる。

## まだやっていないこと

- **ほかの BIM ソフトで開く確認**（上の通り）。
- IFC の読み込み。
- 建具の材質。建具の品番は [docs/117](117_ifc_marks_and_finishes.md)、枠・障子・扉の形は [docs/268](268_ifc_external_review.md) で追加した。
- 材料・壁の層（仕上げ・下地）を、IFC の材料として書くこと。色。
- 部品の「種類」（IfcWallType など）としてまとめること。
- 柱・梁を、断面の押し出し（軸と断面）として書くこと（今は、面で囲んだ形）。構造の解析用の情報。
- 屋根の下の壁・室の天井高など、空間の正確な形。
- 敷地（緯度・経度・真北）、建物の住所。
- 選んだ物だけを書き出すこと。階ごとに分けて書き出すこと。
- IFC2x3 での書き出し。
