# SketchUp で直した物を戻す（行って来い）（2026-11-18）

SketchUp 連携の案の 5。[docs/181](181_sketchup_skp.md)・[docs/183](183_sketchup_tags_and_information.md) の続き。作業は Opus 5.5。
オーナーの指示：2026-11-18（「むしろ SketchUp のいってこいを優先したいね」）。

## 使い方

1. SketchBRep で「ファイル > エクスポート > SketchUp (*.skp)」。
2. SketchUp で開いて直す（グループを動かす・回す、消す、新しく描く、形を変える）。保存する。
3. SketchBRep で「**ファイル > SketchUp で直した物を戻す...**」でそのファイルを選ぶ（AI：`sync_skp {path, replace_edited?, remove_missing?}`）。

| SketchUp でしたこと | SketchBRep で |
|---|---|
| グループ・コンポーネントを**動かした・回した**（形はそのまま） | その物を同じだけ動かす・回す。**壁は壁のまま**で、つながっている壁・柱・梁・屋根も、SketchBRep で動かした時と同じように付いてくる（docs/102・169） |
| **新しく描いた**グループ・コンポーネント・面 | 新しい物として足す（SketchUp の読み込みと同じ） |
| グループの中の**形を変えた**（プッシュプルなど） | 聞く：「SketchUp の形に置き換える」と、その物の形を置き換える（壁ツールの壁などではなくなり、前の情報は `skp_attributes` に残る）。「いいえ」なら、そのまま（AI：`edited` に出る） |
| **消した** | 聞く：「消す」と、こちらでも消す。「いいえ」なら残す（AI：`missing` に出る） |
| 何もしていない | そのまま |

全部まとめて取り消し 1 回。鍵をかけた物は変えない（`locked` に出る）。

## 作り

- 書き出し（`writeSkp`）で、物ごとのグループ・コンポーネントの属性「SketchBRep」に、書き出した時の置き方 `sbr_placement`（グループは置いたまま＝単位行列、コンポーネントは置いた所）を足した。モデルの属性「SketchBRep」の `exported_ids` に、書き出した物の id の一覧。
- 読み込み（`readSkp`）で、グループ・コンポーネントの移動・回転と、共有コンポーネントの等方拡大縮小を部品に持たせる（`ColladaPart::placed`・`placement`）。
- `Modeler::syncSkp`：物ごとに「今の置き方 × 書き出した時の置き方の逆」がずれ（動かした分）。SketchUp の形をそのずれだけ戻して、今の物の形と比べる（外形が 1 mm 以内、立体の体積が 2 % 以内なら同じ形）。同じなら `transform` で動かす（同じだけ動いた物はまとめて 1 回で）。回っていない時は平行移動にする（インチと mm の行き来で回転に小さなずれが出ると、壁のつながりが付いてこなかった）。
- 画面：「SketchUp で直した物を戻す...」は、まず見て（動かす・足す）、形を変えた物・消した物があれば取り消してから聞き、選んだとおりにもう一度、取り消し 1 回でする。

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 形を変えた物 | 聞く（初めは置き換えない） | 置き換えると壁・屋根などのパラメータが無くなる。黙って消さない |
| 消した物 | 聞く（初めは消さない） | 一部だけ書き出したファイルもある（`exported_ids` に無い物は「消した」と見なさない） |
| 同じ形かどうか | 外形 1 mm・体積 2 % | SketchUp の曲面は三角形なので、体積は少し違う。プッシュプルなどは外形が変わる |
| 倍率を変更した・ゆがめた置き方 | 形が変わったと見なす。書き出し時の倍率のまま移動・回転した場合は位置の変更として扱う | 配置の移動と寸法の変更を判別する |

## まだやっていないこと

- グループの中で一部だけ動かした（例：窓の位置）を、開口として戻すこと（形が変わった、として扱う）。
- SketchUp で新しく描いた物を、壁・床などとして戻すこと（形として足す）。
- 同じファイルに 2 回戻した時の区別（2 回目も同じ動きをもう一度しない作り：今は、1 回目の後に戻した物の置き方とファイルの置き方がずれていれば、またその分動かす。戻した後は書き出し直してから SketchUp で直す）。
