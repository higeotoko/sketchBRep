# 227. 開口の日射熱取得率 η を入れる（2026-11-21）

docs/225 の「まだ」：日射熱取得率 η を入れる所と、その列。熊本県の記載例の開口部の仕様表は、熱貫流率と並べて「η=0.51」（日射取得型）・「η=0.32」（日射遮蔽型）のように書いている。

## 入れ方

- AI：`set_opening_performance` に `solar_gain`（0〜1）。省くと η は無し（入れ直すと消える）。1 を超えると断る。
- 画面：開口の「性能...」ダイアログ（docs/215）に「日射熱取得率 η」の欄（0.00〜1.00、「未入力」あり）。
- 熱貫流率 U と同じ所（壁の属性 `opening_performance` の開口ごとの `eta`）に入る。Undo 1 回。

## 出る所

- 開口部仕様表（docs/225）の性能値：「U=2.33　η=0.51」。
- 省エネ仕様の表（docs/210）：「熱貫流率 2.33 W/(m2K)　日射熱取得率 0.51　Low-E 複層」。
- 基準値との照合はしていない（今まで通り）。

## 確認

**計算テスト済み**
- `Schedules.OpeningSolarGainBesideItsU`：η 1.5 は断られる。南の窓に U 2.33・η 0.51 を入れると、開口の表の行に 0.51、断熱範囲図（1FL）の紙に「U=2.33　η=0.51」、省エネ仕様の表に「日射熱取得率 0.51」。η 無しで入れ直すと消える。
- Windows ローカル：コア全件 789 件成功・8 件スキップ。

**GUI 自動確認済み**
- `energyInputsInTheirDialogs` を広げた：開口の性能のダイアログで η に 0.51 を入れると、開口の表の行に 0.51 が入る。

**Windows 実機確認（人の操作）**：まだ。docs/105 の 14-37。
