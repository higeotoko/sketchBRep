## できること

| 項目 | 内容 |
|---|---|
| 形 | 壁の端の**外の角**で、角でつながっている隣の壁にまたがる L 字のバルコニー。床は L 字、手すりは壁に付いていない 4 辺（腰壁・手すり・なし）。柱を付ければ、外の角と 2 つの先の角の 3 本 |
| 画面から | バルコニーのプロパティ「角を回る」：回らない・描き始めの端で回る・描き終わりの端で回る。「回った先の長さ」（初め 1820）。取り消し 1 回 |
| 長さの決まり | 壁に沿っては、「幅」の向こうの端（真ん中から幅の半分）から角まで。隣の壁には、角から外の面に沿って「回った先の長さ」 |
| AI から | `create_balcony`・`change_balcony` の `wrap`（`"start"`・`"end"`・`""`）と `wrap_length`。`balcony_info` にも出る |
| ついてくる | どちらの壁を動かしても、作ったままのバルコニーは L 字のまま作り直される（同じ取り消し 1 回の中で） |
| 建築面積 | まっすぐな物と同じ決まりを L 字に当てる（柱なし：両方の足の、壁の面から「出 − 1 m」まで。柱あり：柱の中心線まで） |
| 床面積・IFC | 床の面積は L 字の面積。IFC は今まで通り床・手すり・柱に分ける |
| 断る時 | 内側の面（部屋の中）に付いている、その端に角でつながる壁が無い、角までが 300 より短い、回った先が 300〜20000 の外 |

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| どの角を回れるか | 外の角だけ（隣の壁の遠い方の端が、バルコニーと反対の側にある） | 内の角（入隅）に回るバルコニーは、2 枚の壁の面に挟まれた別の形になる |
| 外形の持ち方 | 作った時の L 字の外形と、建築面積に数える形を覚える | 壁を動かした時、外形が変わったかで作り直すかを決める。建築面積も作った時の形で数える（まっすぐな物も同じ仕組みにした。前と同じ値になることをテストで確かめた） |
| まっすぐな物の作り | 今まで通り（手すりの柱の並びなど） | 今までのファイル・テストの形を変えない |
| 手すり（笠木と柱）の柱 | 辺ごとに 1000 以内の間隔 | まっすぐな物と同じ考え |

## まだやっていないこと

- 内の角に回る形、3 枚以上の壁にまたがる形（コの字に回る）。
- 角を直角でなく、斜めに切った形。
- 床面積を形から決めること（通達の原文を読んでから。docs/163）。
