# 309. 構造詳細図（1）基礎の断面詳細図

構造詳細図のうち、モデルから描ける **基礎の断面詳細図** を図面一式に入れる。docs/308 の基礎・地盤説明書で比べた寸法を、図で示すもの。

## 描き方

- 対象：モデルの最初の布基礎またはべた基礎の計画（`generate_foundation`）。束石だけの計画には描かない。
- モデルを切って取る断面ではない。その計画に入っている数値から描く外周部の標準断面。基礎を作り直せば、図も一緒に変わる。
- 描くもの：
  - べた基礎：立上り・耐圧盤・外周の根入れ部
  - 布基礎：立上り・底盤
  - 基礎パッキン
  - 土台（参照している土台の断面から。構造材の断面なので × を入れる）
  - GL（地盤線のペンと地盤記号）
- 寸法：
  - 立上りの厚さ、立上りの高さ
  - 耐圧盤／底盤の厚さ、根入れ部・底盤の幅
  - GL から立上りの天端まで、GL から基礎の底まで（根入れ）
- 線は役割のペンで描く。
  - 断面：極太、灰色の塗り
  - 土台の ×：見え掛かり線
  - GL：地盤線
  - 寸法・注記
- 縮尺は 1:20 で、図面一式では基礎・地盤説明書の次のシートになる。
- シート名は「構造詳細図（べた基礎の断面）」（布基礎なら「布基礎の断面」）。受付チェックシート（docs/286）は「構造詳細図」の名前で図書を探すので、最初の「べた基礎 断面詳細図」から次のコミットで変えた。受付照合で構造詳細図と基礎・地盤説明書が「図面あり」になることもテストに入れた。
- 注記：
  - 配筋・かぶり・定着はモデルに無いので「別途」と書く。
  - 告示との照合は基礎・地盤説明書に示す、と書く。

## 確認

- `FoundationMat.SectionDetailIsDrawnFromThePlan`：
  - 基礎計画が無いと描かない。
  - 寸法 150・400・300、地盤線、「土台 120×120」がある。
  - 図面一式に 1:20 で入る。
- 試験用のモデル（`SBR_FOUNDATION_SBR` で保存）の図面一式を画像にして、見た目を確かめた。
  - 文字が寸法の引出線と重なっていたので、土台とパッキンの文字を土台の上に移した。
  - 画像は `outputs/permit-foundation-detail/`（15.png、detail_crop.png）。

## 残り（構造詳細図）

- 土台・柱・梁の継手と仕口、金物（令47条）、柱の小径（令43条）。モデルに接合部の入力が無い。
- 屋根ふき材・外装材の取付け（令39条）。
- 配筋の入力。
