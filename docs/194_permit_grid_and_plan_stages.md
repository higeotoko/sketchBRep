# 194. 申請図の工程：第2工程（通り芯）・第3工程（平面）をモデルから埋める（2026-11-19）

docs/192 で取り込んだ「申請図の工程」ドックは、第1工程（敷地）と第4工程（居室・採光・換気）だけ中身があり、ほかの工程は案内の1行だった。調査資料（第2.8版）§4 の表のうち、今のモデルにあるデータだけで確かめられる第2・第3工程を埋めた。法令の判定は足していない。見つかった物と足りない物、その理由を出すだけ。

## 画面

「ファイル → 申請図の工程...」で左の「2 通り芯」「3 平面」を選ぶ。行を選ぶと下に詳しい内容が出る。対象の物がある行は「モデルで n 個を選択」ボタンで、その壁・柱・梁・室をまとめて選べる。モデルを直すと行が取り直される（ドックが見えている時。隠れている間の変更は、次に出した時に反映）。

### 第2工程（通り芯）

| 行 | 出す物 |
|---|---|
| 階（レベル） | 階の数と名前・床の高さ。無ければ「未入力」 |
| 通り芯 | 通り芯ごとの X・Y の本数。無ければ「未入力」 |
| 壁と階 | どの階の高さにも立っていない壁の数と名前（「要確認」、選択できる）。階が無ければ「階待ち」 |
| 壁と通り芯 | 通り芯に付いていない壁（`wall_grid_pin` が無い壁）の数と名前（「要確認」）。通り芯が無ければ「通り芯待ち」 |
| 柱・梁と通り芯 | 通り芯に付いていない柱・梁（`gridPin` が無い物）の数と名前（「要確認」） |

通りから外れた壁・柱があるのは普通のことなので、状態は「要修正」ではなく「要確認」にした。付ける操作（階のボタン →「柱・梁・壁を通り芯に付ける」）は案内の文に書いている。

### 第3工程（平面）

| 行 | 出す物 |
|---|---|
| ○○ の平面（階ごと） | 壁で閉じた範囲の数と壁芯面積、室の数と壁芯・内法面積（面積の表と同じ値）。室を置いていない範囲、内法を出せない室、形を直接変えた壁（壁として読めない）があれば「要確認」 |
| 室の閉じ方 | 輪郭が閉じていない室、ほかの室と同じ範囲にある室（「要修正」、選択できる） |
| 開口 | 開口の数。建具（窓・扉）を決めていない開口があれば、その数と壁（「要確認」、選択できる） |
| 面積の根拠 | 面積の表で式と注を確かめる案内（「室の一覧を開く」） |

## AI から

読み取りコマンド `permit_checks`（`stage` は 2 か 3）。行ごとに `item`・`state`・`details`・`targets`（物の ID）・`attention` を返す。中身はドックと同じ関数（`doc::permitGridChecks` / `doc::permitPlanChecks`、`Schedules.cpp`）。

BIM 操作の約束（docs/90）との関係：同じモデルの壁・柱・室を ID でたどり、表から元の物を選べる。法令上の判定は「未評価」のまま（申請先・適用ルートの確認が先）。

## 確認
