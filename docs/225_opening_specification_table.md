# 225. 断熱範囲図の紙に「開口部仕様表」を載せる（2026-11-21）

docs/223 の「まだ」：開口部の仕様表。熊本県「省エネ仕様基準適合説明図」の記載例（2025 年）の「仕様表 外皮基準 開口部」（部位・番号・仕様又は使用材料等・性能値・基準値(参考)。例：居室開口部 ①【建具】金属製建具【ガラス】Low-E 二重複層ガラス U=4.1 η=0.51／玄関扉 ③ U=2.9）に合わせた。

## 表（`openingSpecTable`）

| 列 | 中身 |
|---|---|
| 部位 | 窓・ドア・開口（建具なし） |
| 符号 | 建具表と同じ符号（AW1 など、docs/176） |
| 仕様又は使用材料等 | 建具の名前（引違い等）、品番（あれば）、ガラス（docs/210 で入れた物） |
| 性能値 | 入れた熱貫流率「U=2.33」。無ければ「未入力」 |
| 数 | 同じ符号・仕様・性能値の数 |
| 資料 | 性能を入れた時の資料 |

- 外壁（内壁の仕様でない壁）の開口だけ。建具の無い開口も外皮の一部なので入れる。
- 窓・ドアのどれにも性能（U）が入っていない時は、表を出さない（建具表に全部ある。入れ始めたら出る）。
- 記載例の「日射熱取得率 η」と「基準値(参考)」の列は無い。η を入れる所がまだ無いのと、基準値との照合をしていないため。注に書いた。
- 図面一式：断熱範囲図の紙に、断熱仕様表と機器表の間に並べる。
