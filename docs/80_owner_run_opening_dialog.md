## 修正（`fa16029`）

- 「開口の設定」に「建具」を追加。開口ツールはその建具付きで開口をあけ、記号がすぐ出る（1 回の取り消し単位）。
  ステータスにも建具の名前が出る。あけた後はプロパティパネルでも変えられる。
- API：`place_openings` に任意の `fitting` を追加（新しい開口に、同じ操作で建具を付ける）。
- 建具の選択肢は 1 つの一覧（`draw::fittingChoices`）にまとめ、ダイアログとパネルで共有。
- 建築ツールバーの壁の仕様の選択で、最初の項目を「壁の仕様：厚さ指定」にした（何を選ぶ欄か分かるように）。
  オーナーの画面幅（1920 px・175% ≒ 1097 論理 px）でも、選択と「外⇄内」がツールバーに出ることを画像で確認した。
- 5〜7 が出なかった理由は、画面からは特定できていない。どの操作で何が出なかったかをオーナーに確認する。
