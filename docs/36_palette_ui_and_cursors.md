# パレットとカーソルの操作仕様

2026-10-28。優先するのは、狙う場所が分かり、幅を変えても同じ操作を続けられることです。

## パレット

| 操作・状態 | 挙動 |
| --- | --- |
| 初期表示 | アイコン24px、ボタン36px角。通常パレットは3列を基準に開始 |
| 幅を狭める | 列数を減らす。最低でも1列と必要なスクロールバーが完全に収まる幅を確保 |
| 幅を広げる | 列数を増やす。ボタン・アイコンは引き伸ばさない |
| 高さが足りない | 縦スクロール。横スクロールや省略ポップアップにはしない |
| 名前を知りたい | ホバーで名前とショートカット。「表示 → ツール名を表示」で常時表示も可能 |
| 名前を常時表示 | 同じ文字サイズで全名称が収まる共通ボタン寸法を使い、列数を再計算 |
| ツールを選ぶ | 選択中のボタンだけアクセント色で表示。メニュー・ショートカットと同じ操作 |
| Tabで移動 | フォーカスを枠で示し、対象ボタンまで自動スクロール |
| 独立ウィンドウにする | タイトルバーをドラッグ、またはダブルクリック。通常パレットは左右、断面は上下の端へ戻してドック可能 |
| 断面パレットの独立表示 | 4つの固定寸法ボタンが1行に収まる小さなウィンドウ。不要な拡大縮小をさせない |
| 配置を戻す | 「表示 → パレットの配置を初期化」。通常ツールを左側、断面パレットを作業領域左上へ戻す |

配置の初期化は断面パレットの開閉状態を維持し、モデルや断面表示の設定を変えません。断面パレットを閉じてもカットは解除しません。

旧版の名前付き表示は初期値だったため、新しい設定ではまずコンパクト表示で開始します。新しい名前表示の選択は保存します。旧版のフロート位置を保持しつつ、過大なサイズは一度補正します。

## アイコンとカーソル

アイコンは24単位のグリッド、共通の線幅・角の処理で描く独自ベクターです。明暗テーマでは前景色を合わせ、選択中・無効時の色を区別します。回転矩形、通常矩形、各断面表示は別の図柄です。

- **移動カーソル**：四方向矢印を維持し、中央に透明な空間を設け、その中央に小さな点を表示。実際のクリック位置は点の中心（32pxカーソルの16,16）です。明暗の背景で見失わないよう白い縁取りを付けます。
- **ほかの作図カーソル**：矢印の先端が操作位置（3,2）。右下の小さな図柄で現在のツールを示します。選択は標準の矢印です。
- スナップの説明ラベルは、操作点だけでなくカーソル全体から離して配置します。
- 画面倍率に合わせて描画し、100%・150%・200%でも論理寸法と操作位置を維持します。

## 参照と実装範囲

ユーザー提供のSketchUp画面と操作上の要望に加え、Qt公式の実装・仕様を確認しました。

- [Qt公式 Flow Layout例](https://github.com/qt/qtbase/blob/dev/examples/widgets/layouts/flowlayout/flowlayout.cpp)：項目の自然な寸法を保ち、幅に合わせて次の行へ折り返す配置。
- [Qt公式 QDockWidget](https://github.com/qt/qtbase/blob/dev/src/widgets/widgets/qdockwidget.cpp)：サイズ制約は子ウィジェットに置く。ドック中と独立表示中でフレーム寸法が異なるため、ドック自体に固定の最小・最大寸法を設定しない。
- [Qt 6.4 QIcon](https://github.com/qt/qtbase/blob/v6.4.2/src/gui/image/qicon.cpp) / [Qt 6.8 QIcon](https://github.com/qt/qtbase/blob/v6.8.2/src/gui/image/qicon.cpp)：高倍率アイコンの要求寸法の違いに対応。

パレット配置、表示アイコン、カーソル、説明ラベルの配置に限定した変更です。形状演算、スナップの採用規則、カメラ操作、MCP通信・認証・モデル編集APIは変更しません。

## 確認

- 100%・150%・200%の独立したウィジェットテスト：幅を1〜1100pxに変更し、最小幅制約・列の折り返し・スクロール・全25ボタンのクリックを検証。高さを戻したときの列数復帰も確認。
- 断面パレットの拡大縮小制限、ドック復帰、再フロートを確認。
- 全アイコンの各倍率での画像寸法、移動カーソルの透明な中央と操作位置を確認。明暗テーマの画像を目視確認。
- 実際のMainWindowでも全25ツールの切り替え、配置初期化、カーソル切り替え、スナップ説明、断面4ボタンを確認。
- 描画を伴わないパレットのテストをLinux/Windows共通のCIに追加。既存の形状・MCP・GUI回帰テストは引き続き実行。
