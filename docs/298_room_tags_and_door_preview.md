# 298. 図面表現の見直し（3）室名と下の階の壁

## 室名を行ごとに書く

熊本県の作成例の平面図は、室名・(CH2400)・(面積)・(FL±0) を1行ずつ書く。図面一式の平面図でも、室名、その下に (面積 m²)、天井高を入れた室は (CH天井高) を1行ずつ書く（室名 3 mm、ほか 2.5 mm、行の間 3.2 mm）。1行にまとめると長くなって壁にかかった（docs/296 で一度試して戻した）。

- 閉じていない室・数に入らない室は、これまでどおり1行（「居間（閉じていない）」）。
- 耐力壁配置図（室名を室の中で動かす図）は、これまでどおり1行。
- 画面（3D・平面）の室名は変えていない。
- FL（床高）は、室ごとの床高の入力がまだないので書いていない。

## 下の階の壁を描かない

docs/295 で平面図から木造架構の床組を外したところ、2階の平面図に1階の壁が床を透かして見えるようになった。上端がその階の床以下の壁は下の階のものとして、平面図に描かない（`ViewSpec::wallsBelow`）。

# 299. 開き勝手を選ぶ間、今の扉の記号を隠す

オーナーの指摘（2026-11-26）：扉を置いて開き勝手ツールで向きを選んでいる間、最初に置いた向きの記号が残り、新しい向きと二重に見える。決めると消える。片開き・折れ戸など、ほかの扉も同じ。

原因：開き勝手ツールは、マウスを乗せると新しい向きの記号をプレビューとして上に足して描いていたが、平面の開口記号はそのままだった。

直し方：開口記号の描き方に「この開口は描かない」指定（`SymbolOptions::skipOpening`）を加え、画面にプレビュー中だけ1つの開口の記号を隠す仕組み（`Viewport::setOpeningSymbolHidden`）を足した。開き勝手ツールは、マウスを乗せている間その扉の今の記号を隠し、離れた時・決めた時・取り消した時に戻す。記号の作り方は全種類で共通なので、片開き・両開き・親子開き・折れ戸・片引きのどれにも効く。

確認：GUIテスト `doorSwingToolPicksInPlan` に、平面で切った表示で、プレビュー中はその扉の記号が0本になり、決めた後に描き直されることを加えた。
