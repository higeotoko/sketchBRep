# 階の平面で、下の階を隠す（G-03、2026-11-14）

[docs/90](90_bim_operation_framework.md) の G-03。関係する約束は B-06（階で考えられる）・B-08（直接編集を止めない）。

## 直す前

- 建築ツールバーで階を選ぶと、床面 +1100 mm で切るので、**上の階と屋根は見えない**（docs/79・88）。
- **下の階は隠れなかった**。2 階の平面で、床を張っていない所から 1 階の壁・柱が見えた。1 階の平面では基礎が見えた。

## 決めたこと（オーナーの了承：2026-11-14）

> 案 A：下の階は隠す（うすく見せない）。

## 直した後

建築ツールバーで階を選ぶと、その階の平面では、**下の階の物を表示しない**。

| 物 | 2 階の平面で |
|---|---|
| 1 階の壁・柱（1FL〜2FL） | 隠す |
| 基礎 | 隠す（1 階の平面でも） |
| 2 階の床（上面が 2FL） | 見える |
| 2 階の床梁・胴差（床面のすぐ下） | 見える |
| 通し柱など、床を貫いて上に出る物 | 見える |
| 2 階の壁・柱 | 見える（床面 +1100 で切れる） |
| 線・通り芯・寸法・文字・下絵 | 隠さない（地面に描いた線も見える） |

- 隠した物は、クリックで選べず、吸着もしない。
- モデルは変えない（取り消しの履歴は増えない。物の「表示・非表示」も変わらない）。
- 「3D」に戻すと、全部見える。
- 階のメニューの「下の階を隠す」のチェックを外すと、平面でも下の階が見える。付け直すとまた隠れる。
- 平面にいる間に下の階に作った物も、その平面には出ない。

### 隠す物の決め方

次の 3 つを全部満たす物を「下の階の物」とする。

1. 面を持つ形（立体・面・コンポーネントの配置）である
2. 下端が、床面から **400 mm より下**にある
3. 上端が、床面より上に出ない（1 mm まで許す）

400 mm は「床と床梁は見せる」ための深さ。床の厚さ・床梁のせいが 400 を超える建物では、床梁が隠れることがある（下の「まだやっていないこと」）。

## 実装で決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 隠し方 | 物ごとに「この平面では出さない」と判断する（表示から外す）。切断面で切らない | 切断面で下を切ると、地面に描いた線・通り芯まで消える。吸着の計算にも別の切断を足すことになる。物ごとなら、表示・選択・吸着が今ある「非表示」と同じ経路で一度にそろう |
| 階の判断 | 物の高さ（外形の上下）から決める。レベルの属性は使わない | 手で描いた物・木造の架構・基礎など、レベルの属性を持たない物にも効く |
| 設定の置き場所 | 画面の設定（アプリを閉じると初期値の「隠す」に戻る）。ファイルには保存しない | 見え方であって、モデルではない |

## まだやっていないこと

- 深さ 400 mm を変える設定。
- 3D で 1 つの階だけを見ること。
- 作業面の高さを手で打ち直した時に、隠す基準の高さを追従させること（今は、階を選び直した時に決まる）。
- 図面の書き出し（平面図）で下の階を隠すこと。書き出しは今まで通り、切断面より下を全部描く。
