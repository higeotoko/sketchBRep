# 331. 筋かいの印を国交省マニュアルの凡例に合わせる

docs/330 では、筋かいの印を熊本県の作成例から作った。その印は、壁の上に置いた塗りつぶしの直角三角形だった。オーナーから「書き方のルールがあるものは則って」と言われたので、国の資料で決まった描き方があるか確かめた。

## 拠り所

国土交通省のマニュアル「改正建築基準法 2階建ての木造一戸建て住宅（軸組構法）等の 確認申請・審査マニュアル（経過措置対応版）」を見た（https://www.mlit.go.jp/common/001860611.pdf）。見たのは、第2章の作成例「(8) 壁量判定 ① 1階耐力壁図」（冊子 28 ページ）の凡例。

- 筋かいシングル：
  - 塗らない直角三角形。
  - 凡例では、立った側に「柱頭」、とがった側に「柱脚」と添えてある。
- 筋かいダブル：塗らない二等辺三角形が1つ。
- 三角は壁の線の上ではなく、壁の脇に少し離して置く。図の中では、壁の内側に置いたり外側に置いたりしている。
- 柱は番号入りの四角、通し柱はその四角を丸で囲む（docs/327・328 の丸と同じ考え方）。
- 耐力壁は太線、一般壁は細線、開口部は二重線。耐力壁の脇に、壁の種類の記号（A、B）を書く。

同じマニュアルのチェックリストでは、「壁及び筋かいの位置及び種類」と「通し柱及び開口部の位置」が、平面図から耐力壁図に写す項目になっている（8-13、8-14）。だから平面図と耐力壁図の両方に、同じ記号を使う。

JIS A 0150（建築製図通則）の平面表示記号には、筋かいの記号は無い。そこでこのマニュアルの凡例を、筋かいの描き方の決まりとして使う。

## docs/330 から変えたこと

| | docs/330 | 今回 |
|---|---|---|
| 三角の塗り | 灰色で塗る | 塗らない（縁だけ、見えがかり線のペン） |
| 置き場所 | 壁の線の上 | 壁の脇（壁芯から 100 mm＋紙の上で 0.8 mm） |
| たすき掛け | 直角三角形を2つ | 二等辺三角形を1つ |
| 置く側 | 筋かいの向きで変わる | どの壁も同じ側（壁の向きを +u、u に沿わない壁は +v にそろえて、その左） |
| 凡例 | 「筋かい（三角の立った側が上端）」 | 「筋かいシングル」（見本の両端に「柱頭」「柱脚」）と「筋かいダブル」 |
| 出る図 | 平面図だけ | 平面図と壁量の図（耐力壁図）。架構図には出ない |

たすき掛けは次のように見分ける。同じ壁の区間に筋かいが2本あって、一方の下の端ともう一方の上の端が、平面で 200 mm 以内に重なっていれば、たすき掛けとみなす。

大きさは、紙の上で底辺 4 mm、高さ 1.4 mm。マニュアルの凡例の三角（横長で背が低い）に近い比率にした。

## まだ合っていないこと

- うちの壁量の図は、耐力壁を太線にして、符号・方向・倍率・有効長さを文字で添えている（docs/208）。マニュアルの耐力壁図は、壁の種類の記号（A、B）と仕様一覧の表を使う。ここはまだそろえていない。
- 一般壁を細線、開口部を二重線にする描き分け。
- 柱に番号を振ること。

## 確認

- `Quantities.PlansMarkTheBraces`：シングル2か所とたすき1か所の架構の平面図で、次を確かめる。
  - 直角三角形が2つ、二等辺三角形が1つ出る。
  - 塗りは出ない。
  - 底辺は 4 mm。
  - 図に「筋かいシングル」と「筋かいダブル」の両方が記録される。
  - 架構図には出ない。
- コアのテスト 864 本、図面・シート・架構・壁の GUI テストが通る。
