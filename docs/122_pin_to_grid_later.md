# 柱・梁を後から通り芯に付ける（G-06、2026-11-15）

[docs/97](97_bim_gaps_and_priority.md) の G-06（順位 8 の最後）。作業は Opus 5.5。
オーナーの指示：2026-11-15（「出先なので、とりあえず進めて」）。

## できること

| 項目 | 内容 |
|---|---|
| どこで | 階のボタン →「柱・梁を通り芯に付ける（選んだ物、無ければ全部）」 |
| 付く物 | 部材ツール・`create_member` で描いた柱・梁などで、**両端が通り芯の交点**（平面で 10 mm 以内）にある物 |
| 付いた後 | 通り芯の間隔を変える（`set_grid`）と、交点と一緒に動く。端の高さにレベルがあれば、レベルの高さを変えると上下する。`place_members_on_grid` で置いた物と同じ |
| 付かない物 | 両端が交点に無い物、壁（壁ツールの壁は、壁のつながりで動く）。ステータスに名前を出す |
| 通り芯が 2 つ以上 | AI からは `grid` で選ぶ。画面からは断る（「付ける通り芯を選んでください」） |
| 取り消し | 1 回 |
| AI | `pin_to_grid {ids, grid, tolerance}` |

## まだやっていないこと

- **壁**を通り芯に付けること（壁の端が交点にある時、通り芯の間隔を変えると壁も伸び縮みする）。
- 画面から付ける通り芯を選ぶこと（通り芯が 2 つ以上ある時）。
- 交点ではなく、通り芯の**線の上**（交点の間）にある物を付けること。
- 付けた物を外すこと（今は取り消しだけ）。
