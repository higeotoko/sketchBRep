# 235. 付近見取図に目標物を書き込む（2026-11-21）

docs/233・234 の「まだ」：目標物（駅・道路名など）の書き込み。

## 入れ方

- 付近見取図の位置の設定（`vicinityMap`）に、目標物（名前・緯度・経度）を 20 個まで足した。
  - 画面：「敷地 > 付近見取図の位置...」の「目標物」の欄に、1 行に 1 つ「名前, 緯度, 経度」（区切りは「,」「、」「，」）。書き方が違う行があると、どの行かを出して何も変えない。
  - AI：`set_vicinity_map` の `marks`（`[{name, lat, lon}]`）。**名前や住所から位置を調べない**（人が言った位置だけ）と説明に書いた。
- 名前は 1 行・40 字まで、位置は日本の範囲。違う物は断る。Undo 1 回（位置と一緒）。

## 描き方

- 敷地からの東・北の距離（`doc::vicinityOffset`：地図のタイルと同じ Web メルカトル、そのズームで）に、小さい丸（紙で半径 1.2 mm）と名前を描く。
- 地図の外に出る目標物は描かず、注に数を書く：「○：目標物（入れた緯度・経度に描いた）。地図の外の n 個は描いていない」。
