# 358. 柱頭・柱脚の接合方法（N値計算法）

2025年4月の改正で、2階建ての木造住宅も確認申請に構造の図書を出すようになった。柱頭・柱脚の接合方法（令第47条第1項、平12建告第1460号）は、その中心の一つ。

今までは「N値・柱頭柱脚は未評価」だった。設計書（docs/52 §7）の方針は次のとおり。

- 柱頭・柱脚の金物は、N値計算の結果から選ぶ。
- 計算していない柱は未選定とする。
- 表の値は原典で1つずつ確かめてから入れる。

### 表3-14（補正値）

筋かいの区分は、木材15×90以上又は鉄筋φ9以上／木材30×90以上／木材45×90以上／木材90×90以上の4つ。

- 柱の片側のみ：
  - 筋かいの上端がこの柱に付く（柱頭）：0／0.5／0.5／2.0
  - 下端が付く（柱脚）：0／−0.5／−0.5／−2.0
  - たすき掛け：0
- 柱の両側：
  - 両側とも上端がこの柱：4×4 の表（0, 0.5, 0.5, 2.0 ／ 0.5, 1.0, 1.0, 2.5 ／ 0.5, 1.0, 1.0, 2.5 ／ 2.0, 2.5, 2.5, 4.0）。
  - 一方が上端・他方が下端：4×4 の表（行：上端の側、列：下端の側。0, −0.5, −0.5, 2 ／ 0.5, 0.5, 0, 1.5 ／ 0.5, 0.5, 0.5, 1.5 ／ 2.0, 1.5, 1.5, 2.0）。印刷のとおりに入れた。
  - たすき掛けと、上端が付く片筋かい：片筋かいの区分で 0／0.5／0.5／2.0（たすき掛けの区分によらない）。
  - 両側とも下端・たすき掛けと下端・両側たすき掛け：0。

## 作り

`construction::columnNValues(document)`（ConstructionNValue.cpp）と、MCP の `column_n_values`。

- 壁倍率：
  - 壁量の計算の入力の壁（区間・仕様の倍率）を使う。高さによる低減（αh）の前の倍率。
  - 準耐力壁等は、倍率 1.5 以下なら 0、超えればその倍率。
- 柱：架構の柱（column・through_column）。
  - 階は部材の層（1階軸組・2階軸組）で決める。
  - 通し柱は両方の階に数える。
- 各階・各柱・X/Y 方向で：
  - その柱の位置を通る、その方向の壁を探す。
  - 柱の左右の壁倍率の合計と、その差を出す。
- 筋かいの補正：
  - 架構の筋かいの部材のうち、同じ通りにあって、この柱に端が付く物を数える。
  - 上の端なら柱頭、下の端なら柱脚。同じ側に両方あればたすき掛け。
  - 部材の断面から区分を決める（厚さ 15・30・45・90、幅 90 以上）。
  - 表3-14 で補正値を決め、A ＝ 壁倍率の差 ＋ 補正値。
- 出隅：壁量の計算の各階の平面の範囲（長方形）の角。
- 2階の有無：1階の柱の位置が2階の平面の範囲の中なら、「上に2階がある」式で、2階の同じ位置の A2・B2・H2 を使う。
- H：その柱に付く壁の横架材上端間の高さ（height_mm）の最大。3.2 m 以下は 2.7。
- N は X・Y の大きい方（図3-19 ④）。表三で接合方法を選ぶ。
  - 通し柱は、1階の柱頭と2階の柱脚を「通し柱（接合なし）」とする（作成例の「無（通し柱）」）。
- 未評価にするもの（理由つき。0 として計算しない）：
  - 壁量の計算の入力が無い。
  - 架構の柱が無い。
  - 筋かいの壁に架構の筋かいが無い。逆に、架構の筋かいが壁量の計算の壁に入っていない。
  - 筋かいの断面が区分に当たらない。
  - 高さが無い。
  - 出隅を決める平面の範囲が無い。
  - N が 5.6 を超える。
- 金物の製品は選ばない。同等以上の接合方法（Zマーク金物・同等認定金物等、p.100）を使う旨を書く。

画面・図面：

- 申請の段階7に「柱頭・柱脚の接合（N値計算）」の行を足した。計算した柱の数、接合方法ごとの本数、未評価の柱と理由、拠り所を書く。
- 図面一式に「柱頭柱脚金物算定表」（作成例の 10-1 N値計算表にあたる表）を足した。存在壁量の算定の後に置く。export_schedule の `column_joints` でも出せる。
- 壁量の計算の注記と未評価の一覧から「N値・柱頭柱脚」を外した。構造の点検（LAT-03）と診断の一覧には、「N値で選んだ接合方法と架構の金物の実物との照合」を未評価として残した。

## やっていないこと

- 架構の柱頭・柱脚の金物（column_connection）に、選んだ接合方法を付けること。金物の実物との照合。
- 長方形でない平面の出隅の判定。
- 面材の耐力壁と筋かいの併用の細かい扱い（今は壁量の計算の仕様の倍率をそのまま足す）。
- 告示1460号 第二号イの仕様による方法（表一〜表三の壁倍率による選び方）。
- 画面の表のタブへの追加（図面一式と書き出しにはある）。

## 確認

- `TimberWorkflow.ColumnNValuesFollowTheManualsFormula`：
  - 架構（2階建て、4×2 スパン）の2階に 45×90 の片筋かいを1本入れた。
  - 手で計算した値になる。
    - 2階の出隅の柱（筋かいの下端）：補正 −0.5、N 0.8 →（は）
    - 隣の柱（上端）：A1 2.5、N 0.65 →（ろ）
    - 1階の出隅（上に2階）：N 0.2 →（ろ）
  - 壁量の筋かい壁に架構の筋かいが無いと、理由つきで未評価になり、全体は partial になる。
  - 段階7に行が出る。算定表の行と、図面一式のシートがある。
- `PermitIntake`・四分割のテスト：「まだ確かめていない事」から N値 が外れ、N値の行が出る。
- コアのテスト 902 本（スキップ 8）が通る。壁・図面・架構の GUI テストが通る。
