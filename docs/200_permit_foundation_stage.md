# 200. 申請図の工程：第8工程（基礎）をモデルから埋める（2026-11-20）

docs/199 の続き。「申請図の工程」の「8 基礎」に、今ある基礎の検査（`construction::checkFoundation`、AI の `check_foundation`）と、土台・柱の下の支えの検査（`construction::foundationSupports`、AI の `check_foundation_supports`）の結果を出す。新しい判定は足していない。

## 画面

| 行 | 出す物 |
|---|---|
| 基礎の計画ごと | 土台から作った基礎が今の土台と合っているか（合っている／手で直されている／土台が変わったので作り直す／元の土台を読めない）。理由と、立上り・フーチング・耐圧盤・束石のコンクリート量（m³）。合っていれば「入力済み」、それ以外は「要確認」。ボタンでその基礎を選ぶ |
| （基礎が無い時）基礎 | 「未入力」と、土台から基礎を作る案内。外部の基礎詳細図を使う時は図番を図書に付ける |
| 土台・柱の支え | 照らした土台・柱の数と、下の面が支えに乗っている数。乗っていない物（支えが無い・一部だけ乗る・未評価）は5つまで名前と理由。全部乗っていれば「形の上で支えあり」、それ以外は「要確認」で、ボタンでその物を選ぶ。土台・柱が無ければ「未評価」 |
| 照らした事 | 支えの検査の注（実形状の下面と支持面の重なり・高さの診断で、接合・アンカー・支持耐力・地盤は未照査） |
| まだ確かめていない事 | 基礎の検査と支えの検査が評価していない物（地盤・支持力・沈下、基礎断面の構造計算、配筋・かぶり・定着など）と、地盤の資料・基礎伏図・配筋・人通口の記載、または外部の詳細図への参照 |

「形の上で支えあり」は、形が重なっているという事だけで、荷重が伝わる・強さが足りるという意味ではない。

AI からは `permit_checks` の `stage: 8`。
