# へこんだ角のある屋根を、辺を内へ進めて作る（直線スケルトン、Fable に渡す物の 3、2026-11-17）

[docs/106](106_handoff_and_roadmap.md) の「Fable に渡す物」の 3。[docs/138](138_slanted_gable_shed_and_dented_hip.md)・[docs/160](160_roof_sides_and_dented_gable.md) の「まだ」（本当のまっすぐな骨組み）。
作業は Fable 5.2（計算・つなぎ込み・テストの大部分）。Fable の利用枠が途中で切れたので、残り（勾配の違う辺どうしの段の面、記録）を Opus 5.5 で仕上げた。
オーナーの指示：2026-11-17（「fable じゃないと絶対にダメそうなところからこなして」→ 途中から「ここから引き継げる？」）。

## 直す前

へこんだ角がある外周（斜めの辺があるもの、辺ごとの勾配・出・壁に付く辺を入れたもの）の切妻・寄棟は、外周をへこんだ角で出っ張った形に切り分け、いちばん大きな形それぞれの屋根を足して作っていた。
この作り方は、幅の違う翼が付く所など細い所で本当の形と違う（細い翼の寄棟の端が、太い翼の屋根の中に残るなど）。

## 直した後

| 項目 | 内容 |
|---|---|
| 作り方 | 外周の辺を、それぞれの勾配の速さで内へ進める（軒の出の所から、その辺の軒先の高さで動き出す）。辺が縮んで消える所・へこんだ角が向かいの辺に当たる所（屋根が 2 つに分かれる所）を順に追い、**辺ごとに、その辺の屋根面が受け持つ平面の形**を出す |
| 屋根の立体 | 勾配が 1 つなら：辺ごとに「その面の形の上で、その辺の勾配の面より下」の立体を作って足し、厚さの分だけ持ち上げた写しから引く（今までと同じ）。勾配が辺ごとに違えば：下の面・上の面（それぞれ面ごとの厚さだけ上げて計算し直した形）・外周の縦の面・**段の面**を直接つないで 1 つの板にする |
| 段の面 | 隣り合う辺で軒先の高さが違う角（勾配か出が違う）では、高い方の軒の線に沿って小さな縦の段ができる。その段を縦の面でふさぐ（docs/160 で書いた「小さな段」） |
| 妻・壁に付く辺 | 動かない辺として扱う（そこで屋根が縦に終わる） |
| 確かめ | 面の合計が「外周を出だけ広げた形」に合うか、立体が 1 つで正しいか、足した時に体積が減ったり増えたりしないか、を毎回見る。どれか合わなければ、**今までの作り方（出っ張った形に切り分けて足す）に戻す**（黙って変な形は出さない） |
| 使う時 | へこんだ角があって、斜めの外周の作り方になる屋根の切妻・寄棟（片流れは 1 枚の面なので今まで通り）。直角だけの外周で辺ごとの値が無い屋根は、今まで通り長方形ごと（docs/99） |
| 屋根の「部分の数」 | 屋根面の数（妻・壁に付く辺を除いた辺の数）になる。前は切り分けた形の数 |

### 例

| 外周 | 形 |
|---|---|
| L 字（翼の奥行き 4000 どうし） | 外の角に隅棟、内の角に谷。棟は y 2000 と x 2000、隅棟・谷と 1 点で会う（手計算と一致） |
| 幅 2000 の翼が奥行き 4000 の翼に付く L 字 | 細い翼の棟（x 1000）は、谷が上がって来る (1000, 3000) で終わり、そこから (2000, 2000) へ線が続く。前の作り方では、細い翼の寄棟の端が太い翼の屋根の中に残っていた |
| 北から V 字に切り込んだ 12000 × 6000 | 切り込みの先が南の辺の前線に当たって、屋根が 2 つに分かれる（その点の高さ t は t = 2000 − t√17 の解） |
| 十字・コの字・T 字・Z 字 | 形の対称どおりの面になる。面の間に段が無い |

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 計算の置き場所 | 立体の計算（OCCT）を使わない 2 次元の計算として、別のファイル（`RoofSkeleton`）にした | 面の形だけを先に出して、別に確かめられる。立体のブール演算の弱い所（薄い膜・小さなかけら）に左右されない |
| 勾配が辺ごとに違う時 | 立体の引き算をやめ、面を直接つなぐ | 上の面と下の面の立体の引き算が、この形では地面の下まで垂れる薄い膜（体積 0 に近い面）を残し、「1 つの立体」にならなかった |
| 合わない時 | 今までの作り方に戻す | 計算の決まりで扱えない形（同じ向きの辺どうしが違う動きをするなど）でも、屋根は作れるようにする |
| 小さなかけら | 体積が屋根の 1000 万分の 1 以下のかけらは捨てる | ブール演算が、面がほとんど触れる所に体積ほぼ 0 の立体を残すことがある |

## まだやっていないこと

- 平面で重なる屋根どうしを切ること、高さの違う屋根の面どうしが当たる所（docs/161 の「まだ」）。
- 片流れ・直角だけの外周を、この作り方にそろえること（今は今まで通りで、形は合っている）。
- 段の面の見え方（立面・3D で、軒先の角に小さな三角が見える。納まりとしてどうするか）。
- へこんだ角は 4 つまでのまま（今までの作り方に戻る時のため）。
