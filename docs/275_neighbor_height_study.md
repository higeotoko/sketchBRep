# 275. 隣地斜線の試算と3D表示の設計（2026-11-25）

工程10で、敷地のどの辺が隣地斜線を決めるか追えるようにする。敷地輪郭と道路辺は既存の登録を使う。斜線は配置・断面・3Dで同じ境界と高さを使う（B-05）。画面とMCPは同じ計算を呼ぶ（B-09）。

## 境界と高さ

| 条件 | SketchBRepでの扱い |
|---|---|
| 測量図の敷地輪郭 | 登録済みの水平な外周と各辺の両端を使う。凹敷地も輪郭で内外を区別する |
| 隣地の境界 | 設計者が実際に確認した辺を指定する。道路登録と一致する辺は隣地として受け付けない。未分類の辺は試算に加えない |
| 地盤面 | 確認済みの高さをモデルZで受け取る。測点から求めた基準点相対の参考平均は、モデルZと対応が取れた場合に使う |
| 立上りと勾配 | 初段は確認値を入力し、どの規定を採用したか確認する。法第56条第1項第2号の一般的な区分には20 m・1.25と31 m・2.5がある。用途地域ごとの適用や指定区域は別途評価する |
| 2項道路 | 現況幅員・中心線・みなし境界・調査資料を記録する設計とし、現況の敷地辺から自動でみなし境界を作らない |
| 緩和 | 建築物の高い部分の後退距離、空地等による境界のみなし、隣地地盤との高低差には、それぞれ根拠と条件が要る。初段は入力した境界と地盤のまま試算する |

2026-11-25に、建築基準法第56条第1項第2号および施行令第135条の3をe-Govの本文で確認した。横浜市の判断事例には、境界が確定した法の道路に該当しない公道など、空地等として扱う場合が示されている。接道の登録だけから、敷地外が何に当たるかは判断できない。 [建築基準法](https://laws.e-gov.go.jp/law/325AC0000000201) · [建築基準法施行令](https://laws.e-gov.go.jp/law/325CO0000000338) · [横浜市建築主事判断事例集](https://www.city.yokohama.lg.jp/business/bunyabetsu/kenchiku/tetsuduki/kisoku/20210219.files/0007_20230831.pdf)

## 計算と3Dの接続

jp_volume_studyの開発仕様書 §10.3・§10.4・§10.6、§13、§21.2、ISSUESのLEGAL-01・02・03、ROAD-42、GEOM-03を設計の参考にした。有限線分への最短距離、北側は真北に向けた出口、合成上限はその位置で有効な制限の最小値、という考え方を採る。既存のSBRの敷地・道路・地盤・真北を正本にする。旧プラグインのRuby、表示・操作、手入力の例示値、メッシュ精度の目安は本体の法規判定や描画精度に流用しない。

1. 確認した隣地辺ごとに、対象位置のXYをその線分に射影する。射影が端を越える場合は端点を使う。その点までの水平距離が最も小さい辺と、敷地地盤面Z＋立上り＋勾配×距離を返す。
2. 3Dは敷地内の制限面を半透明で表示する。辺の正面は平面、端部は端点から等距離の曲面になる。凹敷地の欠けた部分を面でつながず、複数の辺があるときは各位置で低い制限を表示する。制限面を決めた辺を平面と3Dで確認できるようにする。
3. 部材全体の最大超過は、部材のB-repと制限面の位置関係から検証する。頂点や表示メッシュの数点だけから「余裕」と判定しない。曲面や極小部材で誤差を保証できる方法が決まるまでは、点の試算と部材全体の照合を区別する。
4. 申請に使う適用判断を保存する段階では、敷地輪郭、採用辺、地盤面、用途地域と資料を判断の前提として記録する。後から前提が変わったら確認し直す。番号や近い辺だけから再割当てしない。

## 独立した検算値

| 敷地・確認辺 | 照合点と期待値 |
|---|---|
| 20 m×30 m、南は道路、他3辺は隣地 | (4 m, 15 m) では西辺まで4 m。地盤Z 0、立上り20 m、勾配1.25で25 m |
| 凹敷地で対象の垂直辺の一端が (8 m, 6 m)、もう一端は (8 m, 10 m) | (6 m, 4.5 m) では端点まで2.5 m。同条件で23.125 m。延長線で近似すると22.5 mになり、差を検出できる |
| 同じ凹敷地の欠けた領域 | 敷地外として高さを返さない |
| 矩形で南の道路辺を隣地として指定 | 入力エラーになる |

最初の2件は同じ幾何の考え方を検証するための値。用途地域や緩和の適用可否の評価には使わない。

## 点の試算の操作

MCPの `neighbor_height_at` に、採用する `boundaries` の両端（`start` と `end`）、`points`、`ground_z_mm`、`base_height_mm`、`slope` を渡す。モデル座標はmm。点の高さにはXYだけを使う。敷地内または境界上では、決め手となった隣地辺、水平距離、制限高さを返す。敷地外は `in_site: false` とし、制限高さは空欄。保存状態やモデルは変えない。工程10の3D表示は同じ点の試算を使う。部材との照合にはB-repから得た鉛直差の範囲を使う。

## 工程10で隣地斜線を表示する

工程10「立面・断面」の「隣地斜線」を開く。平面の番号と一覧を見比べて、確認した辺だけを選ぶ。登録した道路辺は青で表示し、選択できない。敷地の地盤面（モデルZ・mm）、立上り（m）、勾配を入力し、「3Dで見る」を押す。紫の線は採用辺、紫の半透明面は隣地斜線の試算面。「表示 → 斜線の試算面を消す」で解除でき、モデルを編集した場合も表示は解除される。

表示面は登録敷地を三角形に分け、各頂点の高さを点の試算で求めてつなぐ。頂点間の高さは表示用の近似。分割は三角形の辺が約1 m以下を目安とし、描画する面は4,096枚以下。凹敷地の外に面を張らない。法令上の適否は未評価。

## 選んだ部材と照合する

1. モデルで屋根・壁などを選び、工程10の「隣地斜線」を開く。
2. 隣地辺と高さの条件を指定し、「選択部材を照合」を押す。表の正の鉛直差は超過、負の値は余裕を示す。行を選んで「3Dで見る」と、その部材と紫の試算面を一緒に確認できる。
3. 数値が幅で出る場合は、部材の最大鉛直差がその範囲に入る。「要確認」は、求めた範囲から超過または余裕を決められない状態や、敷地内の照合点を部材上に確かめられない状態を示す。

表示用の三角形で照合する代わりに、隣地辺への距離を下から抑える平面を使ってB-rep全体の最大鉛直差の上限を求める。敷地内にあるB-repの頂点で求めた差は下限になる。部材の範囲全体が敷地内かつ境界辺の正面で、距離を平面で表せる場合は、B-rep全体からその辺に対する最大差を求める。複数辺では、各辺の差のうち大きい方が制限を決める。上限と下限が0.01 mm以内で一致した場合は一つの値を表示する。この精度は法令上の許容値を表さない。

MCPの `compare_neighbor_height` は `neighbor_height_at` と同じ斜線条件と、`points` の代わりに部材の `ids` を受け取る。`lower_excess_mm`・`upper_excess_mm` と照合状態を返す。部材の一部が敷地外に出る場合も、上限は部材全体の形状から保守的に求める。法令上の適否は未評価。
