# 平面で開口をつかむ（順位 7 の残り、2026-11-15）

[docs/106](106_handoff_and_roadmap.md) の A の 5 番（平面の記号をつかむ）。作業は Opus 5.5。
オーナーの指示：2026-11-15（「続けて」）。

## できること

平面モード（平面で切っている時）に、移動ツールで、**建具の記号や符号が描かれている所**をクリックすると、その開口をつかめる。

| 項目 | 内容 |
|---|---|
| つかめる所 | 開口の幅の中（両側 50 の余裕）で、壁の外側の面から 150 外まで、壁の内側の面から 150 内まで |
| 条件 | 平面で切る高さが、その開口の下端と上端の間にある（その平面に開口の記号が出ている） |
| つかんだ後 | 今まで通り：壁に沿って動かす、↑で上下、Ctrl でコピー、「*3」で増やす |
| 何も選ばずに | 選んでいる物がある時は、今まで通り選んだ物を動かす |
| 壁を動かしたい時 | 開口の所以外をつかむ（または壁を選んでから） |

前からの、穴の内側の面をつかむ動き（3D）は、そのまま。

## 実装で決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 当たりの取り方 | 画面の点を、平面で切る高さの面に落として、建具表と同じ開口の一覧（中心・向き・幅・厚さ）と比べる | 平面では穴の面が線にしか見えず、面ではつかめない。記号は描くだけの線で、選べない |
| 範囲 | 幅の中 ＋ 壁の外 150・内 150 | 記号（壁の厚さの中の線）の所でつかめれば足りる。符号の文字（壁の外 300）まで広げると、壁の近くに置いたほかの物を取りにくくなる |
| いくつも当たる時 | いちばん近い開口 | — |

## まだやっていないこと

- 平面の符号の文字（壁の外 300）の所をクリックしてつかむこと（範囲の外）。
- 扉の振り（円弧）の先の方をクリックしてつかむこと。
- つかめる所にカーソルが来た時に、開口を光らせて見せること。
