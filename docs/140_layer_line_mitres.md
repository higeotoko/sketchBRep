# 壁の角の留め（図面の層の線、決める事が多い物の第 1 段、2026-11-16）

[docs/106](106_handoff_and_roadmap.md) の「残り（決める事が多い）」の壁の角の留め。[docs/124](124_wall_layer_lines.md)（層の線）の「まだ」（角での層の線のつながり）。作業は Opus 5.5。
オーナーの指示：2026-11-16（「決める事の多い方」、自動で進めてよい）。

## できること

| 項目 | 内容 |
|---|---|
| 留め | **同じ仕様**の壁どうしの角（L 字、直角でなくても）で、外の面から数えて同じ番目の層の線どうしが、交わる所で止まる（45° の留めの見え方）。今までは壁ごとに壁の端までで、角で重なったり、すき間ができたりしていた |
| 出る所 | 平面モード（画面）と平面図（DXF・JWW・PDF）。どちらも同じ線 |
| 留めない所 | T 字（間仕切りが壁の面に当たる所）、仕様の違う壁どうし、外の面が角の同じ側にそろっていない壁どうし（今まで通り、壁の端まで） |
| 開口 | 角の近くに開口があっても、開口で切れた所はそのまま。壁の端の線だけが留めになる |

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| どこを留めるか | **図面の層の線だけ**。壁の立体は今まで通り突きつけ（片方の壁が相手の外の面まで伸びる） | 立体まで留めにすると、壁のつながり（端が相手の面の上にあるか、docs/102・107）の作りが全部変わる。まず見え方を直した |
| 層の対応 | 外の面から数えて同じ番目どうし | 同じ仕様なら、層の順番と厚さが同じ |

## まだやっていないこと

- 壁の**立体**を留めにすること（今は角に、2 枚の壁の継ぎ目の線が残る）（→ docs/159）。
- 平面図で、同じ仕様の壁の継ぎ目の線を消すこと。
- T 字での層の線のつながり（間仕切りの層が外壁の内側の層へ回り込む形）。
