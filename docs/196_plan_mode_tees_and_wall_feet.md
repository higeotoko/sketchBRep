# 196. 平面の T字の線と、色を塗った床が壁から透ける件（チェック表 2-8 ほか、2026-11-19〜20）

オーナーの実機確認で返ってきた次の2つを直した。

- 2-8「間仕切りが外壁とくっつく所に、内側の線が残る」。
- 「スラブに色を塗ると、平面で壁が見えなくなる」。

## 1. 画面の平面モード：T字で外壁の面の線が間仕切りの端を横切る（`f7b163a`）

画面の平面モードでは、壁ごとに切り口の太線を描く（docs/195）。外壁の内側の面の線は1本の長い線なので、間仕切りが T字でくっつく所でも、その端を横切って通っていた。

- 壁の切り口の直線の途中に、別の壁の切り口の直線がすっぽり重なる時（両端から離れた所。T字の間仕切りの端）、外壁の線をその幅だけ切る。間仕切りの端の線も描かない。図面（docs/165・177）と同じ見え方になる。
- 端どうしが重なる線（一直線につないだ別の仕様の壁、L字の突き付け）は今まで通り残す（材料の境目）。

## 2. 外壁の柱の面の線が、間仕切りの柱を横切る（`abcedab`）

T字（docs/177）では、間仕切りの柱が外壁のボードを抜けて外壁の柱の面まで入り、外壁はその分ボードを譲る。層の線のうち、外壁の「面と柱の間」の線は間仕切りの柱の上で切れていた。でも「柱の面」の線は、端の扱いで対象から外れていて、間仕切りの柱を横切って通っていた（docs/177 では「その側はボードだけなので通す」としていた）。

オーナーに画像で確認した（2026-11-20）：「石膏ボードの線は残してよい。内壁の真ん中の線は消してよい」。そこで柱の面の線も、間仕切りの柱の幅だけ切るようにした（`Modeler::wallLayerLines`、図面と画面の両方）。ボードの線はそのまま。

T字の立体どうしの切り口（外壁の切り欠きの底と、間仕切りの柱の端が重なる線）は今のまま残している。オーナーと相談して、T字には普通は柱を置くので、そこまでは変えないことにした。

## 3. 色を塗った床が、切った壁から透ける（`f7b163a`）

平面モードの壁は、中の柱が見えるようにふたなしで切っている（docs/71 の頃から）。そのため、壁の中を通して下の床が見えていた。床が白い時は気付かないけど、色や木目を塗ると壁の帯がその色になって、壁が無いように見えていた。

- 切った壁ごとに、切り口と同じ形の白い面を壁の足元（下の面の 1 mm 上）に敷く。光の当たり方で色が変わらず、選べない。下の床の色は透けない。壁の中に立つ柱・間柱はその上に出るので、今まで通り見える。
- 壁の下の辺（足元の線）もこの面で隠れる。
