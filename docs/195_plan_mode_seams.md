# 195. 画面の平面モードで、同じ仕様の壁の継ぎ目を描かない（チェック表 2-5、2026-11-19）

オーナーの実機確認（docs/105 の 2-5）で「平面上、留めの角のラインが残っている」と返ってきた。docs/165 では平面図（DXF・JWW・PDF）から同じ仕様の壁の継ぎ目を消した。ただし「画面の平面モードは変えていない」と「まだ」に残っていた。その残りを直した。

## 線が出ていた所

画面の平面モードでは、壁をふたなしで切る（中の柱が見えるように）。そのうえで、壁ごとの切り口の線を太線で描いている。留めの角の対角線は、次の2か所から出ていた。

1. 壁ごとの切り口の太線（`Viewport::syncWallOutlines`）。2枚の壁が対角線を1本ずつ持つ。
2. 壁の立体そのものの辺。ふたなしで切っているので、留めの面の下の辺（足元の対角線）が上から見える。

## 直したこと（`02a86fa`）

- 切り口の太線：同じ仕様（`wall_layers` が同じ）の壁どうしで重なる直線部分を、両方から抜く（docs/165 の図面と同じ決まり）。
- 壁の立体の辺：同じ仕様のほかの壁にも同じ辺があって、立っていない（水平・斜めの）辺は描かない。留めの面の上下の対角線、一直線につないだ2枚の壁の上の継ぎ目がこれに当たる。縦の辺（本当の角）は描く。3D の表示でも同じなので、留めの角の上の面に継ぎ目の線が出なくなる。
- 仕様の違う壁（外壁と間仕切りなど）、仕様の無い（厚さだけの）壁は今まで通り。

壁を1枚だけ直した時、隣の壁の表示は、その壁も変わった時に取り直される。角でつながる壁は、動かすと隣も付いてくるので、普通はそろう。
