# 355. 断面図・立面図の文字と線の重なり

docs/354 のあと、例題Eの図面一式で残った重なりは断面図と立面図に多かった。

| 図 | 件数 |
|---|---|
| A-A 断面図 | 5（枠外 1） |
| B-B 断面図 | 8（枠外 1） |
| 南立面図 | 4 |
| 北立面図 | 4 |
| 東立面図 | 8＋文字どうし 1 |
| 西立面図 | 9＋文字どうし 3 |

中身を分けて、順に直した。どれも例題だけでなく、断面図・立面図を描くモデルすべてに効く。

## 1. レベル線は文字の所で止める

いちばん多かったのは、レベル線（1FL・基礎天端・桁天端など）が文字を通るもの。通っていた文字は次のとおり。

- 敷地境界線・道路境界線の名前
- 高さの寸法の値（「600」「軒の高さ 6,200」「最高の高さ 7,764」）
- 他のレベルの名前

通り芯（docs/353）と同じく、レベル線を図の中の文字の所で止める。レベル自身の名前は線の 1 mm 上にあるので、かからない。

## 2. 断面図の題名に並べるのは平面図だけ

断面図の題名は「A-A 断面図（切る位置：A-06・A-07・A-26・A-27・A-28・A-29）」だった。切る位置の線が描かれた図の番号を全部並べるので、耐力壁配置図・断熱範囲図まで入り、枠からはみ出していた。

切る位置を探すときに見るのは平面図なので、名前が「…平面図」の図だけを並べる。例：「（切る位置：A-06・A-07）」。

図面一式の見本（GoldenSheets）は、断面図と断熱範囲図（断面）の題名だけが変わったので更新した。

## 3. 道路が見える側を避けて高さの寸法を置く

立面図・断面図の高さの寸法（階高・軒の高さ・最高の高さ）は、いつも建物の右に置いていた。道路が右に見える図では、道路境界線・「前面道路」・道路斜線とぶつかっていた。

道路を横から見る図（道路の縁が見る向きと平行、docs/305 と同じ条件）で道路が建物の右にあるときは、高さの寸法を左に置く。

それに合わせて、次の2つも直した。

- 寸法を敷地境界の外まで出す範囲を、建物から 30 mm 以内から 40 mm 以内に広げた。
  - 右側では、境界の名前（境界線の右に立つ）の幅 4 mm 分も外に出す。
  - 30 mm を少し超えた所の境界の名前に、最高の高さの値が重なっていた。
- 高さの名前（▽2FL など）を、左に置いた寸法のさらに左に置く。左に寸法を移すと、高さの名前とぶつかった。

## 4. 道路斜線の高さの入力を確かめる（段階10）

西立面図の道路斜線が、地盤の下から始まって図の右下へ抜けていた。原因は例題の入力の取り違え。

- set_height_study の road.edge_z は、敷地側の道路境界での道路斜線の高さ（路面の基準の高さ＋幅員×勾配）。
- 例題では路面の高さのつもりで 0 を入れていた。幅員 6 m・勾配 1.25 なら 7,500 mm。

この取り違えは誰でもしやすい。そこで、段階10（立面・断面）に「道路斜線の高さの入力」の行を足した。

- edge_z が敷地の地盤（ground_z）以下なら「要確認」にする。
- 意味（路面の高さではなく道路斜線の高さ）と式を書く。
- 道路が敷地よりそれだけ低い場合もあり得るので、断らずに確かめを求める。

例題は 7,500 に直した。直す前の値で、この行が「要確認」になることを確かめてから直した。

### 戻したこと

最初は、道路斜線の名前が「前面道路」に重なるのは、斜線の真ん中に名前を置くせいだと考えた。そこで、斜線に沿って名前をずらす直しを書いた。しかしテストを書くと、直す前のコードでも重ならなかった。例題を画像で見直すと、本当の原因は 3 と 4 だったので、この直しは入れていない。

## 例題で見たこと

例題Eの図面一式を描き直した。断面図2枚・立面図4枚の重なりは、西立面図の1件だけになった。残りは、平均地盤面・GL の名前に寸法線が1本かかる物。

西立面図を画像で見て、左から次の順に並ぶことを確かめた。

1. 高さの名前
2. 高さの寸法
3. 敷地境界線
4. 建物
5. 道路
6. 道路斜線（地盤より上から始まる）

## 確認

- `Drawing.GridLevelsSheetAndTitleBlock`：
  - レベル線を、本数ではなく高さの違う線の数で数えるようにした（文字の所で途切れて本数が増えるため）。
  - 2FL の上に置いた「敷地境界線」に、レベル線が通らないことを足した。
- `Drawing.SectionsShowTheStudysLowestLimit` に足した：
  - 道路を横から見る立面図では、「最高の高さ」の寸法が前面道路と反対の向きに出る。
  - 東と西で道路が逆に見えるので、いつも右に置く直す前のコードでは、どちらかで失敗する。
- `Schedules.RoadSlantGivenAtTheRoadsLevelIsAskedAbout`：
  - edge_z 0（地盤 0、幅員 6 m）では「道路斜線の高さの入力」が「要確認」になる。
  - 7,500 では出ない。
- GUI の `drawingDialogPlanSectionElevationAndExport` も、レベル線を高さで数えるようにした。
- コアのテスト 898 本（スキップ 8）が通る。図面・シート・断面・立面・レベルの GUI テストが通る。
