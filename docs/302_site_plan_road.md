# 302. 図面表現の見直し（6）配置図の前面道路

作成例の配置図は、前面道路を「向こう側の境界線・道路の中心線・幅員」で示している。これまで配置図は接道する辺と離れの寸法だけだったので、道路そのものを描く。

## 描くもの（道路の幅員が入力されているとき）

- 道路の向こう側の線（外形線）。敷地の両側へ 1,500 mm 延ばす（道路は先へ続くため）。接道する辺の延長も同じく延ばす。
- 道路の中心線（通り芯と同じ細い一点鎖線のペン）。道路斜線・後退の基準になる線。
- 幅員の寸法（3桁区切り、例 5,200）。
- 「前面道路（種別）」の文字。種別は `set_site_road` の kind。

## 線の考え方

- 敷地境界は境界線のペン（docs/297）、道路の端は外形線、中心線は基準線（一点鎖線）と、役割ごとのペンで描く。ペン表の太さ・色・DXF/JWW のレイヤーを変えれば全部追従する。
- 幅員が未入力のときは何も描かない（推測で道路を描かない）。

## 確認

- `SiteRoadUsesTheSelectedEdgeAndSavedInput`：選んだ辺の向こうに道路が描かれ、寸法が2つ（離れ・幅員 5,200）になること。

## 残り

- 道路後退線（2項道路の中心から 2 m）、断面図の道路と地盤ハッチング。
