# 四分割法（壁の配置のつり合い）（2026-11-05）

構造の診断（docs/74）で「未評価」だった四分割法を、壁量の入力から計算し、側端部分を「四分割の帯」として画面に重ねる。
法令の値は推定しない。根拠を確かめられたところだけ計算し、それ以外は未評価のまま出す。

## 根拠（確認した原文）

| 内容 | 根拠 |
|---|---|
| 側端部分＝各階・各方向で、もう一方の方向の両端からそれぞれ 1/4 の部分 | 平成12年建設省告示第1352号 一号（国交省掲載の平成19年告示1227号改正までの版、https://www.mlit.go.jp/notice/noticedata/pdf/201703/00006444.pdf） |
| 存在壁量＝壁倍率×側端部分の軸組の長さの和。必要壁量＝床面積に乗ずる数値×側端部分の床面積 | 同 一号 |
| 階数は側端部分ごとに独立して数える | 同 一号 後段 |
| 壁量充足率＝存在÷必要。壁率比＝小さい方÷大きい方 | 同 二号 |
| 壁率比が 0.5 以上。ただし両方の充足率が 1 を超えればよい | 同 三号 |
| 「床面積に乗ずる数値」（令46条4項）は新しい式（Lw）になった | 国交省資料（001746169）6 ページ |
| 筋かいの高さの低減 αh は四分割法にも使う | 同 10 ページ |
| 準耐力壁等が必要壁量の 1/2 以下なら、四分割法は耐力壁のみで検証 | 同 7 ページ |

- 2025 年 4 月 1 日から、四分割法の規定は昭和56年建設省告示第1100号 第四へ移った（SumiCAD のルール資料による）。
  **移行後の条文そのものは今回照合できていない**（国交省の補足資料・審査マニュアルは文字の取り出し・取得ができなかった）。
  結果にも `quarter_balance_basis.note` で明記する。内容（側端部分・充足率・壁率比の考え方）は告示1352号と同じものとして扱う。
- SumiCAD（0.7.1）のルール資料も同じ考え方（読むだけ。保守的な独自の扱い＝2 階のはね出しの面積の加算などは取り込んでいない）。

## 入力

「木造の壁量...」の階の表に、**平面の範囲**（世界座標の矩形。X 最小・最大、Y 最小・最大 mm）の列を足した。
API では `floors[].plan:{x:[min,max],y:[min,max]}`。矩形でない階は `floors[].side_areas_m2:{X:[低い側,高い側],Y:[...]}` で
側端部分の床面積を直接指定できる（範囲の矩形は壁の振り分けに使う）。4 つのうち一部だけの入力は拒否する。

## 計算

- X 方向の壁（X 方向の力に抵抗）は、Y 方向の両端の 1/4 の帯で見る。Y 方向の壁は X 方向の両端の帯。
- 帯の必要壁量＝帯の面積（m²）×その階の地震の Lw（cm/m²）÷100。風は使わない（告示1352の「床面積に乗ずる数値」は地震用）。
- 帯の存在壁量＝その階・その方向の、仕様確認済みの耐力壁のうち、壁の線が帯の中（境界±1 mm を含む）にあるものの
  有効長さ（長さ×倍率、αh の低減後）の和。準耐力壁等は入れない。
- 判定：両方の充足率が 1 を**超える**か、壁率比が 0.5 **以上**なら「つり合い OK（四分割法のみ）」。それ以外は「つり合い不足」。
  比較には壁量と同じ許容差 1e-10 を使い、丸め誤差でちょうど 1.0 を「1 超」、ちょうど 0.5 を「0.5 未満」にしない（次のコミットで追加）。
- **未評価にするもの**：平面の範囲が無い、その階の Lw が未評価、耐力壁の入力完了が未確認・未評価の壁がある、
  上の階の平面の範囲が無い、**上の階が載っていない側端部分（下屋）**（平屋としての Lw が入力に無い）、
  **上の階が一部だけ載る側端部分**（階数の数え方を決められない）。

検算（平面 10 m×4 m、1 階建て、Lw＝98/(0.0196×50)×0.2＝20 cm/m²）：

| 条件 | 結果 |
|---|---|
| X の帯の面積・必要壁量 | 各 10 m²・2.0 m |
| 低い側 2 m・高い側 0.5 m の 45×90 片掛け（倍率 2） | 充足率 2.0・0.5、壁率比 0.25 → 不足 |
| 高い側 1 m | 充足率 2.0・1.0、壁率比 0.5 → OK（0.5 ちょうど） |
| 低い側 9 m・高い側 1.2 m | 両方 1 超 → OK（壁率比 0.13 でも） |
| 中央の壁 | どちらの帯にも入らない |
| 2 階が西半分だけ | 1 階 X の帯は「一部だけ」、1 階 Y の東の帯は「下屋」→ 未評価 |

## 画面

- 「木造の壁量...」：結果の下に「四分割法」の表（階・方向・両側の充足率・壁率比・評価と理由）。根拠は但し書き欄に表示。
- 「構造の診断」：四分割法の表と、側端部分を色付きの半透明の帯で 3D に重ねる（緑＝OK、赤＝不足、橙＝未評価）。
  「四分割の帯」で表示を切り替えられる。帯の高さはその階の nFL レベル（無ければ Z=0 と明記）。

## まだ作っていないこと

- 下屋・一部だけ上階が載る側端部分（平屋の Lw の入力・計算方法を決めてから）。
- 斜めの壁、矩形でない平面での帯の形（面積は手入力できる）。
- 直す候補の提示（弱い側に足せる壁の位置）。
