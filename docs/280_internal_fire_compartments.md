# 建物内部の防火区画と開口部の確認

申請工程10「立面・断面」の「防火区画・開口部」を開く。モデルで壁・床を選び、「選択部材を登録・編集」で区画符号、種類、開口部の条件、適用条項・確認資料を記録する。面積区画・竪穴区画・異種用途区画・その他を選べる。区画の種類と開口部の条件は適用条項や設計資料から入力する。同じ区画を構成する部材には同じ符号を使える。

- **3D**では登録した壁・床を青緑、壁の開口と床上面の開口を橙で表示する。表で行を選ぶと該当箇所が黄色で強調される。3D表示はパネルで切り替えられる。
- **平面・断面**では、切断した区画部材を青緑の二点鎖線と区画符号で示す。各階平面図では、区画壁の開口に建具符号を併記し、その階の床上面にある開口を表示する。
- **防火区画・開口部確認表**では、区画符号、部材・建具、設計上の条件、製品等の記録と確認事項を照合する。開口条件は「条項確認中」「防火設備」「特定防火設備」「開口なし」から選ぶ。「設備仕様」には壁開口ごとの設備種別と、認定番号・告示仕様・製品資料などを記録できる。

## 確認の状態と保存

「仕様記録あり」は、設計で入力した設備種別と製品の記録が同じで、開口寸法や建具の設定がその記録時点から変わっていない状態。登録した製品の適用寸法、支持部、施工条件、常閉・自閉・連動や遮煙は認定仕様と設計資料で照合する。区画の必要性、例外、区画の閉鎖性、床開口・風道・配管等の防火措置は個別の確認事項として残す。

壁・床の登録は部材に保存する。壁開口の仕様は安定した開口IDと、その時点の幅・高さ・奥行き、製品番号、建具設定を記録する。他の開口を消した場合も記録の対象は同じ。開口寸法や製品が変わった場合は「開口寸法・建具の変更を照合」とする。床はB-repの水平な上面の閉じた内側輪郭を開口候補として拾う。縁が開いた欠込みや設備の形状・材質は別途確認する。

BIM操作の約束では、3D・図面・表で符号を共有する B-05、画面とMCPで条件を共有する B-09 に対応する。MCPでは `set_fire_compartment_boundary` と `set_fire_compartment_equipment` で記録し、`fire_compartment_review` で対象、設備、状態を読む。登録・解除はそれぞれ取り消せる。
