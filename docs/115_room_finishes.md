# 室の用途・仕上げ・天井高と仕上げ表（N-02、2026-11-15）

[docs/97](97_bim_gaps_and_priority.md) の N-02（天井、床・壁・天井の仕上げ）のうち、**仕上げを持って表に出す**ところ。作業は Opus 5.5。
オーナーの指示：2026-11-15（「続けて」）。

## できること

| 項目 | 内容 |
|---|---|
| 入れる所 | 室を選んで、プロパティの **用途・床・壁・天井**（文字）と **天井高**（床から mm） |
| 書き方 | 仕上げ表に書く言葉のまま（例：フローリング t15、PB t12.5 クロス貼り）。1 つ 60 字まで、1 行 |
| 天井高 | 1000〜10000。0 で消す（「未入力」） |
| 出る所 | 表の窓の「**仕上げ表**」タブ（室名・階・用途・床・壁・天井・天井高）、室の表の CSV の右の列 |
| 保存 | 仕上げ表も、CSV と図面（PDF・DXF・JWW）に保存できる |
| AI | `set_room_finish {id, use, floor, wall, ceiling, ceiling_height}`（渡したものだけ変える。空の言葉で消す）。`room_schedule` に出る。`export_schedule table: finishes` |
| 取り消し | 1 回 |

## 持ち方

- 室の目印（室名の文字）の属性 `room_finish`（JSON）。何も入れていない室には付かない。
- 室の面積は今まで通り、壁から毎回読む。仕上げは室の目印に付いているので、壁を動かしても消えない。

## まだやっていないこと

- **天井を形として作る**こと（天井の板・断面に天井の線が出ること）。今は天井高の数字だけ。
- 仕上げの選び方の一覧（よく使う仕上げを選ぶ）。今は文字を打つ。
- 幅木・腰壁・建具枠など、ほかの欄。
- 仕上げの面積（床・壁・天井の㎡）の拾い。
- 用途から、法の決まり（居室の採光・換気など）を見ること。
- IFC の室（IfcSpace）に仕上げを書くこと。
