# 壁を通り芯に付ける（docs/122 の続き、2026-11-15）

[docs/122](122_pin_to_grid_later.md)（柱・梁を後から通り芯に付ける）の「まだ」（壁を通り芯に付ける）。作業は Opus 5.5。
オーナーの指示：2026-11-15（「続けて」）。

## できること

| 項目 | 内容 |
|---|---|
| どこで | 階のボタン →「柱・梁・壁を通り芯に付ける（選んだ物、無ければ全部）」。AI は `pin_to_grid`（返り値に `walls`） |
| 付く壁 | 壁ツール（`create_wall`）の壁で、**線の両端の近く**（壁の厚さ＋10 以内）に通り芯の交点があり、その 2 つが別の交点の物。両端をそれぞれ近い交点に付ける |
| 付いた後 | 通り芯の間隔を変える（`set_grid`・通り芯の線を動かす）と、**両端が交点と同じだけ動く**。壁の線の上の通り芯が動けば壁は横へ（開口も一緒に）、端の通り芯が動けば壁が伸び縮みする（開口は動かない） |
| つながる物 | 横へ動いた壁につながっている壁（付けていない間仕切りなども）は、壁を動かした時と同じように伸び縮みしてつながったまま。その壁の中に角がある床（スラブ）の外形もついていく。室の面積は今の壁で数え直す |
| 付かない物 | 交点の間にない壁（ステータスに名前を出す） |
| 取り消し | 付けるのに 1 回、通り芯を変えるのに 1 回 |
| 保存 | 属性 `wall_grid_pin` としてファイルに残る |

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 何に付けるか | 壁の**線の端**を、いちばん近い交点に | 壁ツールの角は、片方の壁がもう片方の面まで伸びている（端が交点から厚さの半分ほどずれる）。ずれの分はそのまま保つ |
| 斜めになる時 | 両端が横へ別々に動く（壁が回る）時は動かさない | 壁の向きを変えると開口・つながりの直しが大きくなる。直交の通り芯の間隔の変更では起きない |
| 伸び縮みでつながった壁 | 横へ動いた壁につながる壁だけがついてくる | 伸び縮みした壁の端にさらにつながる壁は、たいてい同じ通り芯に付いた壁で、自分で動く |

## まだやっていないこと

- 付けた壁を外すこと（今は取り消しだけ）。
- 画面で、付けた壁・付けていない壁の見分け。
- 通り芯が回る時（壁の向きが変わる時）についていくこと。
- 交点ではなく、通り芯の**線の上**だけにある壁（端が交点にない）。
