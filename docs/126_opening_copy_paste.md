# 開口の Ctrl+C / Ctrl+V（docs/110 の続き、2026-11-15）

[docs/110](110_copy_openings.md)（開口を選ぶ・コピー）の「まだ」（開口を選んだ時の Ctrl+C / Ctrl+V）。作業は Opus 5.5。
オーナーの指示：2026-11-15（「続けて」）。

## できること

| 項目 | 内容 |
|---|---|
| コピー | 開口の穴の面を選んで（プロパティが「開口 n」だけになる状態）Ctrl+C。ステータスに「開口 n をコピーしました」 |
| 貼り付け | Ctrl+V のあと、壁の上をクリック。**同じ壁**なら壁に沿ってそこへ（腰高は同じ）、**別の壁**ならそこを中心に（腰高は同じ） |
| 平面で | 真上から見ている時は、カーソルを開口の高さで読む。平面の切断の高さが開口の高さと違っても、壁が見つかる |
| 一緒に来る物 | 幅・高さ・建具・符号・品番（docs/110 のコピーと同じ） |
| 1 回の操作 | 取り消し 1 回。もう 1 つ置く時は、もう一度 Ctrl+V |
| 断る時 | 壁の無い所、元の開口と重なる所、元の開口が消えた後（何も変わらない。理由を出す） |
| Ctrl+X | 開口は切り取らない（「移動ツールで動かすか、Ctrl+C で」と出す） |
| Ctrl+Shift+V | 開口は「同じ位置に貼る」ができないので断る |
| 普通の物を Ctrl+C | 開口のコピーは消え、今までどおりの貼り付けになる |

コピーは開口の id で覚える。間にほかの開口を足したり消したりして番号がずれても、同じ開口を貼る。

## まだやっていないこと

- 貼る前に、貼った後の開口の形を薄く見せること（今はステータスに壁の名前だけ）。
- いくつかの開口をまとめてコピーすること。
- アプリの外（ほかのファイル）へ開口を持っていくこと。
