# 登録した種類で床・屋根を描く（N-08 の第 5 段、2026-11-16）

[docs/149](149_registered_types.md)（種類の登録）の「まだ」（床・屋根を描くツールで種類を選んで描くこと）。作業は Opus 5.5。
オーナーの指示：2026-11-16（「進めて」）。

## できること

| 項目 | 内容 |
|---|---|
| スラブの設定 | 「種類」の欄（なし＋登録した床の種類）。選ぶと厚さの欄に登録の厚さが入る |
| 屋根の設定 | 「登録した種類」の欄（なし＋登録した屋根の種類）。選ぶと、登録にある勾配・軒の出・けらばの出・厚さが欄に入る（登録に無い値はそのまま） |
| 描くと | 描いた床・屋根に種類名が付き、登録した値になる。**描くのと名前を付けるので取り消し 1 回** |
| ステータス | ツールの設定の文に「種類 F1・」が前に付く |
| 登録が無い時 | 種類の欄は「なし」だけで選べない。ヒントに登録のしかた |

## 決めたこと

| 項目 | こうした | 理由 |
|---|---|---|
| 値の欄 | 種類を選ぶと欄に入れるだけ。欄を直してから描いても、描いた後は登録の値になる | 種類で描くと決めた物は種類の値。欄はプレビューの大きさの目安 |

## まだやっていないこと

- 床・屋根の層（仕上げ・下地）を種類に持つこと。登録の一覧を画面で直す窓。
