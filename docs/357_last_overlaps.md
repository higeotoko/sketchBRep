# 357. 図面一式の最後の重なり

docs/356 のあと、例題Eの図面一式（49 枚）で、シートの点検に残った重なりは2件だった。

- 耐力壁配置図（2階）：「ホール・階段」（910 幅の部屋）の名前に線がかかる。
- 西立面図：「平均地盤面・GL」の名前に、高さの寸法の線がかかる。

どちらも例題だけの話ではないので、一般の形で直した。

## 1. 耐力壁配置図で部屋に入らない部屋名

docs/356 の順（通り芯を避けない → 小さい字 → 破線だけまたぐ）でも入らない部屋がある。たとえば階段の上のホール。そういう部屋名は、平面図（docs/354）と同じく、シートの空いた所に置いて部屋の印へ引出線を引くようにした。

最初はこれだけ入れて描き直した。すると、ホールの名前が図の上の外まで飛ばされ、長い引出線が平面を縦断した。わけは、四分割の側端部分の破線を障害物と数えていたこと。部屋が破線で細かく区切られ、近くに空きが無いと判定されていた。点検の数には出ないが、読みにくい。

そこで次の2つも入れた。

- 外に出す部屋名は、破線（隠れ線）を避けない。
- 破線（線と折れ線）も、通り芯・レベル線・引出線（docs/353・355・356）と同じく、文字の所で止める。折れ線は、文字にかかる辺があるときだけ辺に分けて止める。

描き直すと、「ホール・階段 3.31 m²」はホールのすぐ横に短い引出線で出た。

## 2. 左に寸法があるときの高さの名前

立面図で道路が右に見えるとき、高さの寸法は左に置く（docs/355）。高さの名前（▽1FL など）は寸法のさらに左から書くが、名前は書き出しの位置から右へ伸びる。そのため、長い名前（「平均地盤面・GL」）が寸法の線に食い込んでいた。

左に寸法があるときは、書き出しの位置を名前の幅の分（＋2 mm）だけ左にした。

## 例題で見たこと

例題Eの図面一式 49 枚を描き直した。シートの点検（文字と線、文字どうし、枠外）の重なりは 0 件。

docs/346 の通し確認の始めには、平面図・伏図・軸組図・断面図・立面図に、1 枚あたり十数件〜五十件ほどの重なりがあった。docs/349〜357 で原因ごとに直した結果、全部消えた。

画像でも次を見た。

- 耐力壁配置図2階：「ホール・階段」の名前と引出線。
- 西立面図：高さの名前が寸法の手前で止まっていること。

## 確認

- `Drawing.DashedLinesAndLevelNamesKeepOffTheWords`：
  - 破線の枠の辺の上に書いた部屋名に、破線が通らない。
  - 左に寸法がある図で、「平均地盤面・GL」に寸法の線が通らない。
  - 直す前の版（125c1eb の前）の DrawingSheet.cpp に一時的に戻すと、どちらも失敗する。確かめてから元に戻した。
- コアのテスト 901 本（スキップ 8）が通る。図面一式の見本（GoldenSheets）は変わらない。図面・シート・壁の GUI テストが通る。
