# 209. 表紙・計画概要（2026-11-20）

調査資料（第2.8版）§3 の順番の「6 表紙・計画概要」。図面一式は、もともと「図面リスト」（01）から始まっていた。その次に「計画概要」の紙を入れて、敷地・建物の数字を、図面と同じモデルのデータから出すようにした。

## 計画概要（`scheduleTable(document, 10)`）

| 項目 | 内容 | 出どころ |
|---|---|---|
| 物件名 | 図面一式の物件名（表題欄）。無ければ未入力 | 図面一式の設定 |
| 主要用途 | 未入力（まだ入れる所が無い） | — |
| 敷地面積 | 敷地境界の輪郭の面積と確認資料 | docs/191 |
| 用途地域の区分 | 住居系・工業系・商業系と確認資料 | docs/205・206 |
| 道路 | 種別・幅員・接道長と確認資料。法上の道路・接道は未評価 | docs/191 |
| 真北 | モデルの +Y からの角度と確認資料 | — |
| 建築面積、建蔽率（参考） | 面積の表の建築面積と、敷地面積で割った割合 | docs/141 |
| 延べ面積、容積率の算定の延べ面積、容積率（参考） | 面積の表の値と割合 | docs/141・162 |
| 階数 | 壁で閉じた範囲のある階の数（地下を分けて） | 面積の表 |
| 最も高い所（参考） | 第10工程と同じ値（法の高さではない） | docs/201 |
| 構造 | 壁量の計算の入力があれば「木造（在来軸組）」 | docs/58 |

注に、法の制限（建蔽率・容積率の上限、高さの制限など）との比較はしていない事と、申請書の様式（第二面〜）と照らして足りない項目を足す事を書く。

## 出し方

- 図面一式：「図面リスト」（01）、「計画概要」（02）、その後に配置図・平面図…の順。これまでの図番は1つずつ後ろにずれる。
- 表の窓：「計画概要」のタブ（11番目）と CSV。
- 表だけの紙：`export_schedule` の `table: "summary"`。図面に並べる：`export_drawing` の `tables` に `summary`。
