# 272. 窓の左縁からの移動と、ZIPのSKP読み書き（2026-11-23）

## 14-48 窓の左縁を真後ろから押す

配布版 `2eb59bb`。厚さ200 mm、高さ3,000 mm、長さ8,000 mmの壁を南北に4,000 mm離して置いた。北の壁に幅1,000 mm・高さ1,200 mm・腰高900 mmの開口を作り、背面の平行投影で移動ツールを選んだ。

画面で左に見える開口の縁（モデル座標 x=4,500 mm、z=1,500 mm）と、その左右1・3・5・10・20・40 mmを指定した。13回の操作は画面上の6座標に投影された。各回でマウスを横に動かして距離300を入力し、結果を読んでから取り消した。開口は毎回 x 方向に−300 mm動き、両方の壁の外形位置は変わらなかった。取り消しで開口と壁の位置が元に戻ったことも確認した。

今回の条件では、前回に奥の南壁が動いた現象は再現しなかった。人によるピクセル単位の操作確認は未実施。 [以前の事象](254_move_typed_along_an_axis.md)

確認データは配布フォルダの `outputs/window-edge-review/review.json` と `edge-drag-preview.png`。

## 13-3 ZIPが同梱のDLLを使うか

配布版の実行フォルダとWindowsのフォルダだけをプロセスのPATHに入れ、SDKの環境変数を外した。CLIで1,000 × 800 × 700 mmの箱をSKPに書き出して新規モデルに読み戻し、6面の立体1個と同じ外形寸法を確認した。読み書きとも、実際に選ばれた `SketchUpAPI.dll` はZIPの展開先にあるファイルだった。

SDKの入っていない別PCでの書き出し一覧と読み書きは未実施。13-3は一部確認とした。 [同梱DLLの探索順](182_sketchup_dlls_in_the_zip.md)

確認データは配布フォルダの `outputs/window-edge-review/portable-skp-check.json` と `portable-test.skp`。
