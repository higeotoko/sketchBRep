# 平面上での窓・扉の配置（2026-11-05）

基準コミットは `e492b34`。docs/61の優先1を実装した。

## 操作

1. 「建築」ツールバーの「平面で描く」で対象階の高さを選ぶ。
2. 「開口」の右矢印で幅・高さ・腰高を指定する。既存の窓・扉プリセットも使える。
3. 壁の上へカーソルを移し、青い配置範囲と壁端までの距離を確認してクリックする。
4. 置いた直後に「幅,高さ,腰」を入力すると、その開口の寸法を変更する。
   配置と直後の寸法変更は、従来どおり1回のUndoで戻る。

平面の表示モードでも、作られる形状は従来と同じSubtractによるB-repの開口。
保存・再読込・寸法編集・架構からの参照は既存の仕組みを使う。
MCP/CLIの開口配置コマンドと同じModelerへ渡すため、別の平面専用モデルは持たない。

## 対象の決め方

- 壁ツール由来の既知の矩形押出しと、その開口Subtractを対象にする。
  元の壁の基準線を、架構生成と同じ `construction::wallReferenceLine` から取得する。
- 作業面の高さが壁の下端以上・上端未満にある壁を対象にする。
  上端と一致する場合、その壁を下の階へ取り違えないよう対象外とする。
- 画面上の壁の帯から8論理ピクセル以内で候補を探す。候補の距離差が1ピクセル以内で
  判別できない場合は、交点から離すか3D・立面で選ぶよう表示する。
- その壁の外側の縦の面へ位置を投影する。回転・移動・中央/左右の基準線、表裏に対応する。
  外側の面が分割されている場合は、同じ平面の面を集めて端部と腰高の基準を求める。
- 上階の壁や屋根が重なって描かれていても、上から見て最初に当たった物を切らない。
  非表示・ロック中の壁、現在編集中のグループの外にある壁は対象外。
  グループ内の壁を編集する場合は、先にそのグループの編集に入る。

壁中央・端・既存開口との中心揃え・隣接・空き区間中央への吸着を共用する。
既存の開口と重なる位置はプレビューで示し、クリックしても既存の検証で変更を拒否する。

窓の上に残る壁や屋根によって立体の切抜きプレビューが隠れるため、
平面では開口の水平範囲も手前に青色表示する。この表示は作業中の目印であり、
保存対象や図面記号ではない。カーソル移動・取消・配置完了で消す。

## 既存機能との境界

3D・立面で壁面をクリックする操作も継続する。
元の基準線を確定できない任意形状の壁、部品インスタンス、傾斜した壁は、
平面から推測して加工せず、既存の面選択へ戻せる。

作業面と交わらない腰壁などは、作業面の高さを壁の範囲に合わせるか3D・立面で操作する。
平面の階選択だけで上階や屋根を非表示にはしない。表示範囲は既存のタグ・断面で調整する。
配置後の窓を上から見ると上部の壁に隠れる場合があるため、3D・断面でも形状を確認できる。
開口の図面記号や扉の開き方向、建具部品の自動挿入は今回の範囲に含めない。
耐力壁の仕様や壁量計算の入力を、開口の配置から自動で認定・更新することもしていない。
