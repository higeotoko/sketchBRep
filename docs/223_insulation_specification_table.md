# 223. 断熱範囲図の紙に「断熱仕様表」を載せる（2026-11-21）

docs/222 の「まだ」：仕様表（部位・仕様・厚さ・性能値・基準値）を断熱範囲図の紙に並べること。熊本県「省エネ仕様基準適合説明図」の記載例（2025 年）は、平面・断面図と同じ紙に「仕様表（外皮基準 断熱材）」を載せている（部位・仕様又は使用材料等・厚さ・性能値・基準値）。それに合わせた。

## 表（`insulationSpecTable`）

| 列 | 中身 |
|---|---|
| 部位 | 屋根・壁・床（記載例の順：上から） |
| 仕様又は使用材料等 | 断熱材の名前と工法（「グラスウール 16K（充填）」） |
| 厚さ(mm) | 入れた厚さ |
| 性能値 | 熱抵抗 R。入れた R、無ければ厚さ÷熱伝導率。どちらも無い時は「未入力」 |
| 数 | その断熱を入れた壁・床・屋根の数 |

- 同じ部位・断熱材・厚さ・性能値は 1 行にまとめる。
- 記載例の「基準値」の列は**入れていない**。地域ごとに要る熱抵抗との照合をまだしていないので（docs/210 の「まだ」：告示の原文で値と条件を確かめてから）。表の注に「基準値との照合はしていません。申請先と申請時点の告示で確かめます」と書いた。
- 図面一式：断熱範囲図（平面・断面）の紙ぜんぶに、図の横に置く（docs/130 の「図と表を同じ紙に」の仕組み）。断熱の入力が 1 つも無ければ、断熱範囲図の紙そのものが無い。
