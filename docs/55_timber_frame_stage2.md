# 木造レシピ：段階2

docs/52 §5・§11の段階2。段階1のカタログ・役割・プリセットを使い、
矩形の在来軸組・和小屋を生成する。構造の安全や施工可否の判定は行わない。

## できること

- 平屋／2階建て、切妻／片流れ、棟のX・Y方向、寸勾配／角度、軒・けらばの出。
- 新しい通り芯をマス数とモジュールから作るか、既存の水平な通り芯を使う。
- 2階の範囲を通り芯の番号で指定する。残る1階の区域には片流れの下屋の概略形を置く。
- 柱は外周の交点と追加指定位置に置く。全交点へは置かない。
  2階の外周を受ける柱は通し柱、それ以外は階ごとの管柱にする。
- 土台、床組、柱・間柱、横架材、火打、小屋束、母屋・棟木、垂木。
- 根太床／根太レスを階・矩形区域ごとに指定。区域の境界には受け材を置き、床組厚の差を記録する。
- 既存の壁の開口から、まぐさ・窓台と開口をよけた間柱を置く。
  まぐさ・窓台の断面もカタログの役割として追加した。初期値は形を作る仮の値。
- 指定した筋かいと両端の金物。耐力壁の指定・壁量からの配置は段階5。
- 定尺を超える材には「継手候補・仕様未選定」の目印を置く。

基礎コンクリートの寸法・形は今回生成しない。「基礎・土台」グループには土台と金物を置き、
基礎天端は基準レベルとして持つ。下屋の壁際・屋根どうしの取り合いと、継手・仕口は概略で、
納まりや断面照査を済ませた形とは扱わない。

## 画面から使う

1. ツールメニュー →「木造架構を作成・作り直し...」。
2. マス数・モジュール・階数・屋根・床方式を指定して「プレビュー」。
3. 青色の形を確認し、「適用」で確定、「却下」で取り消す。

通り芯を選んで開くと、その通り芯を使える。生成した架構やその中の部材を選んで開くと作り直せる。
手で編集した部材がある場合は、保持するか確認してからプレビューする。
外部AIへの接続をONにしなくても、この画面は使える。

## AIから使う

まず `get_construction_guide {"system":"timber"}` を読む。

```json
{"command":"generate_frame","args":{
  "system":"timber","recipe":"post_beam_2storey","preview":true,
  "inputs":{"x_bays":10,"y_bays":8,"module":910,"storeys":2,"roof":"gable","ridge_axis":"x","roof_pitch":4}
}}
```

返された `revision` を `expected_revision` に入れ、同じ入力で `preview:false` を送る。
確定は既存のUndoに1回で記録し、通り芯・レベル・共有部品もまとめて戻る。
プレビューの `frame` IDは一時コピーのID。確定後のIDは確定結果から取得する。
既存の `preview`／`batch`／画面の `propose` に入れる場合は、内側の `generate_frame` は
`preview:false` とし、外側の適用時に `expected_revision` を確認する。

主な入力（寸法はmm、通り芯の番号は先頭が0）：

| 入力 | 例・意味 |
|---|---|
| `origin` | `[1000,2000,0]`。新規通り芯の原点 |
| `grid` | 既存通り芯のグループID。回転した水平な通り芯も使える。傾斜・拡大縮小した通り芯は対象外 |
| `second_floor` | `{"x":[0,6],"y":[0,8]}`。2階の範囲 |
| `columns` | `[[2,2],[4,4]]`。追加する柱の交点 |
| `first_floor_system` / `second_floor_system` | `joist` / `joistless` |
| `floor_zones` | `[{"storey":1,"x":[0,2],"y":[0,8],"system":"joistless"}]`。同じ階で区域を重ねない |
| `opening_hosts` | 開口がある壁のIDの配列 |
| `floor_openings` | `[{"storey":2,"x":[2,4],"y":[1,3]}]`。階段・吹抜け用の床開口。通り芯番号の矩形範囲。詳しくは [木造の一連操作検証](59_timber_workflow_refinement.md) |
| `braces` | `[{"storey":1,"from":[0,0],"to":[1,0]}]`。同じ通り芯上の区間 |
| `roof_angle` | 角度で指定するとき。`roof_pitch`（寸勾配）に優先 |
| `spacing` | `{"rafter":{"mode":"fixed_pitch","pitch":455}}` または `{"joist":{"mode":"equal_division","divisions":3}}`。端の調整を結果に記録 |
| `sections` | `{"column":"TIMBER-120x120","floor_beam":"TIMBER-120x300"}`。役割ごとの断面指定 |
| `levels` | `{"first_fl":650}` または `{"first_fl":"既存のレベルID"}`。高さまたは既存レベルを使う |
| `finish_thickness` | 既定0。未決時は計画FLと表示する |

`levels` のキーは `gl`、`foundation_top`、`sill_top`、`first_fl`、`second_fl`、`eave_top`。
初期の高さは段階1のプリセットと実際に選んだ断面から求め、架構名つきのレベルとして作る。
梁の幅は柱に合わせる。利用者が役割・断面を明示した場合は、その指定を優先する。

## レベルと共有部品

同じ断面・長さの木材、同じ種類の金物は共有コンポーネントにする。
各配置には通常の `kind`・`material_class` 属性を付ける。役割専用の別モデルは作らない。
グループ・タグは「基礎・土台」「1階床組」「1階軸組」「2階床組」「2階軸組」「小屋組」。
金物と未選定の目印は「金物」、継手候補は「継手」でまとめて表示を切り替える。

既存の通り芯・レベルへの追従を、単一部材のコンポーネントにも拡張した。
柱の片端のレベルを動かすと、その配置だけの長さを変える。共有する別の配置や元の定義は変えない。
梁・床組・小屋組は、付いているレベルに追従する。

`member_info` で共有部材の寸法も読める。`change_member` で1本の寸法を変えると、
その配置だけを普通の独立した部材にして、ID・役割・基準線を保つ。梁せい変更は上端を保つ。
ほかの部材と同じように、コンポーネント編集・独立化・分解・直接編集も使える。

## 金物の範囲

アンカーボルトと梁端・筋かい端の板金物は、共有した簡略形で置く。
`hardware.json` の寸法は表示用の仮寸法で、実製品の仕様ではない。製品は未選定と記録する。
柱頭・柱脚はN値未評価の目印、鋼製束は製品未選定の目印とし、架空の製品を選ばない。
同梱寸法と位置づけは、AIに返す手引きのデータにも含める。

部材を手で動かしても金物は勝手に付いてこない。追従させる場合は既存の「追従」を明示的に使う。
生成時のレベルへの追従と、他の部材への追従は区別する。

## 作り直しと手編集の保護

`replace` に生成済みの架構グループIDを渡す。未編集なら置き換えをUndo 1回で行う。
保存した生成時の状態と比べ、編集・追加・削除した物があれば `requires_decision` を返し、何も変えない。

- 保持する場合：利用者の選択を確認後、`on_modified:"preserve"`。編集した物は同じID・世界座標で保持し、対応する生成物を重ねない。
- 消した部材も保持の対象。削除の記録を残し、次の作り直しでも勝手に復活させない。
- 架構全体のコンテナーを手で動かした・編集した場合は、元の架構を残し、`replace` を省略して別に作る。
- 高さは現在のレベルを使う。作り直す前にレベル編集／`set_levels` で高さを変更する。
  レベルの通常編集による自動追従は、手編集と区別して記録する。

生成の入力・状態記録は既存のグループに保存する。`.sbr` を開き直した後も作り直せる。
共有部品は他の架構やコピーで使っていれば残し、使わなくなった生成用の定義だけを片付ける。

## 検証

`Frames.*`：標準10×8、プレビュー無変更、Undo/Redo、共有、レベル追従、保存・再生成、
手編集・削除の保持、親グループ移動の保護、通り芯の再利用、梁上端、下屋、床区域、開口、筋かい、不正入力、batchの原子性。
`timberFramePreviewApplyLevelsAndUndo`：画面のプレビュー・適用・却下、入力ダイアログ、表示、金物タグ、
架構全体の移動、Undo、レベル変更。生成・移動・表示の時間を記録する。

インストーラーのビルド・アップロードは利用者の指定で `if: false` のまま。
`packaging/installer/SketchBRep.iss` は残す。今回の配布はWindows zip。
